## 工作流
### 改内核后跑注入自检
1. 改 index.js 对应段后先跑 node --check index.js 确认语法，产出零报错
2. 跑 npm run verify:injection，核对注入段数与顺序仍符预期
3. 跑 npm run verify:dedupe，确认没有两处同源载荷双注入
4. 跑 npm run verify:gen5 与 npm run verify:lazy，确认内核与惰性章节未走形
5. 跑 npm run verify:armor，确认首句层与末位锚点仍在位
6. 全绿后再跑 npm run verify:all 收口，产出本轮自检回执

### 新增一个领域包
1. 在 data/scenarios.mjs 的 SCENARIOS 追加一条（id/label/family/五槽/骨架），产出域条目
2. 在 data/toolchains.mjs 补该域工具链（装/验命令 + 缺工具降级协议）
3. 跑 npm run verify:scenarios 校验域结构完整
4. 跑 npm run verify:scenario-tool 确认查询工具能命中新域
5. 跑 npm run verify:lazy:coverage 确认惰性章节覆盖未破
6. 用 infinite_gen5_scenario 传新域 id 实查一次，产出回执当判据

### 中继端点探活
1. 先把 IG5_RELAY_BASE_URL / IG5_RELAY_API_KEY 指到自有或授权端点
2. 跑 node adapters/endpoint-inventory.mjs --emit-template 生成清单骨架
3. 用 infinite_gen5_relay action=status 做配置体检，不发任何报文
4. action=plan 看 dry-run 请求体摘要，确认段序 101/103 落位
5. 确认无误再 action=adapt live:true 发包，产出 ~/.dsh/ig5-adapt-cache.json
6. 跑 npm run verify:adapters 确认适配层自检仍过，产出回执

### 发布前一键收口
1. 跑 npm run verify:all（串 50+ 道门），任一门失败即停并回报卡点
2. 跑 npm run verify:version 与 npm run verify:notes 对齐版本号与变更叙述
3. 跑 npm run verify:install 确认安装器与包内文件清单一致
4. 跑 node scripts/package-release.mjs 打包，产出发布件
5. 解包核对 package.json files 字段与实到文件逐条对齐
