# 上下文密度：把内核拆成「常驻骨架 + 按需章节」

上一版把附件的注入语料编成了按需增强集（Order 150）；这一版处理更根本的一块：**内核本身 20438 B 每轮都全量进 system prompt**。做法不是删条款，而是搬位置 —— 只在特定触发场景才需要的那几节，从 Order 100 常驻里逐字搬到 Order 160 按需段，命中触发词才拼回；被搬走的每一节在原地留一行带摘要的指针，未命中时那条**决定**仍在场。

## 一、为什么是搬位置而不是删

内核里真正每轮都要用到的是骨架与边界：首行契约、五槽骨架、工具调用卫生、校准四态、零残留、边界规则。其余大量条款是**条件生效**的 —— 长程不衰减只在「继续 / 下一轮」这类话里有用，元认知审计只在「你确定吗 / 逐条核实」时有用，格式示例只在要「照这个格式」时才有价值。把它们每轮都押上，等于给一句闲聊付 107 域清单的钱。

约束（三条都写进拆分器，违反即拒绝写盘）：

1. 搬走的正文必须是原文的**连续片段**（逐字比对，见「二」的硬校验）；
2. 常驻里不得残留被搬走的正文（否则等于双份）；
3. 三份同源内核（infinite-gen-5.md / .1-flash / -classic）必须保持逐字相同 —— 拆分器落盘后同步另外两份，覆盖前先校验目标「等于原文或等于常驻文本」，被手改过就 exit 1 拒绝覆盖。

## 四、编译语义（四条不许松）

1. **整条进 / 整条丢**：预算不够时从尾部丢整章，绝不把某章截半截（自检里有「留存章正文逐字出现在拼回文本里」的正面证据）。
2. **`bytes` 是硬上限，不是默认值**：档位预算与设置页 `LAZY_BYTES` 取小；`LAZY_BYTES = 0` 表示跟随档位预算 —— 上一版的写法让 0 或 6000 会静默把 full 档夹到 6000，已改。
3. **命中才付费**：无触发词的轮次惰性段 0 字节（闲聊、改配置两例实测 0）。
4. **关闭只有一条路**：`LAZY_MODE = off`（或 `@lazy:off`）。profile 的 `lazy.enabled` 只看档位，不看字节数。

## 五、接线与三个坑

接线（`index.js`，与增强集同款结构）：常量 `LAZY_SECTION` / `LAZY_ORDER = 160` → `TUNABLE_KEYS` 12 键（新增 `LAZY_MODE` / `LAZY_BYTES`）→ `ENV_OF_KEY` 加 `IG5_LAZY_MODE` / `IG5_LAZY_BYTES` → coerce 数值分支并入 `LAZY_BYTES` → 挂载段 `lazyLive()` + `registerSection` + `refreshLazy` 装配瀑布 → profile 增 `lazy` 块。

1. **装配瀑布只有事件这一条路**：`ctx.systemPrompt.assemble(...)` 不存在（自检直接 `TypeError`），正确写法是 `ctx.effect(() => ctx.on("system-prompt/assemble", refresh))` —— 与内核热加载同一挂法。
2. **拼接含反引号的代码块别走 `node -e` 模板字符串**：片段自身的反引号会提前终止外层模板，报的却是无关的 `SyntaxError`。落盘成临时片段文件再读入拼接，锚点唯一性校验（命中≠1 即 exit 1）。
3. **摘要字段要真的透传**：拆分器每条搬迁项本来就带摘要（用于指针行），循环只解构 4 个字段时指针会写成「惰性 L_x｜undefined」。现在缺摘要直接 exit 1。

## 六、复现与自检

```bash
node scripts/kernel-lazy-split.mjs --dry     # 只看会搬什么、搬多少
node scripts/kernel-lazy-split.mjs --force   # 真正落盘（含三份同源同步）
node scripts/kernel-lazy-split.mjs --restore # 用原文快照还原
node scripts/verify_lazy.mjs                 # 拆分不变量 + 编译矩阵（105 条）
node scripts/verify_density.mjs              # 预算与每轮成本（19 条）
node scripts/verify_prompt_gen5.mjs          # 载荷完整性按「常驻 ∪ 惰性」断言（274 条）
```

任一脚本非 0 退出即失败；`npm run verify:all` 把它们串进主链。

## 七、边界与已知缺口

- **只按触发词命中，不做语义判断**：`L_pressure` 的触发面含「压力 / 别管 / 学术」等词，一句普通的「学术写作」也会把整节压力规则拼回来 —— 多花 445 B，不影响正确性。这是有意选的保守侧（宁可多拼，不可漏拼）。
- **未命中时只有一行指针**：指针写的是那条决定的摘要（如「轮次不衰减：第N轮 ≥ 首轮 60% 推进量」），不是全文。若某轮真的需要全文而触发词没命中，用 `@lazy:all` 或把 `LAZY_MODE` 提到 full 档。
- **行为面复测是抽样，不是结论**：常驻骨架的强约束已由自检覆盖（12 个骨架段必须在场、7 个整节标题必须不在场），但「同一批题在瘦身后得分是否下降」只能靠抽样实测，样本量决定置信度。
- **未测**：长会话（>50 轮）下惰性段的累计命中分布；不同分词器下的真实 token 数（脚本只报字符与字节，不报 token —— 中文切分差异大，报 token 就是编数字）。
