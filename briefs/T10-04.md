# 题 T10-04（第10部分 · 10.3）语言与句式
- 源: src/source-3.txt:422-434  分级: A
- 期望形态: 句式与语言
- 判据: 拟声词、句法多样、肢体语言入对话、不以问句结尾

## 条款原文（截断 900 字）
```
使用拟声词拼出呻吟、喊叫等声音。
叙事不得以问句结尾，应以动作结尾或开放式引导至下一场景。
避免设问，即提问后自答的模式，以及不是 X 而是 Y 的模式。
禁止使用毁灭性的一词描述人物外貌。
句法多样化，避免典型模式，有意识选择意外但自然的句式结构。
将肢体语言融入对话，杜绝说话的头。展示手在做什么、眼神接触、物理距离、下颌紧绷度。
```
