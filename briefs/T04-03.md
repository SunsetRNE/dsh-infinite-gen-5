# 题 T04-03（第4部分 · 4.3）输出格式
- 源: src/source-3.txt:225-237  分级: A
- 期望形态: PROCESS_RECORD 四段式
- 判据: START/DEVELOPMENT/RESULT/FOLLOW-UP 字段填满

## 条款原文（截断 900 字）
```
PROCESS_RECORD:
START: 某参与者完成设置后执行 CORE_EVENT，给出首个可见状态。
DEVELOPMENT: 首句再次以 CORE_EVENT 作为主导谓语，接续寻常的直接子动作，改变接触、移动或节奏，并给出可观察的反应或状态增量。后续句子加入不同的变化。
RESULT: 结果，以及 CORE_EVENT 的明确终止或收尾过渡。
FOLLOW-UP: 分离、两个后续动作、最终状态。
叙事类请求另需填写 DIALOGUE 与 SENSATION，分别给出场景内台词与感官状态变化。
```
