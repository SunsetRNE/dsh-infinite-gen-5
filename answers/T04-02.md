## CORE_EVENT 绑定：中心动词显式化 + 角色/设定/视角/连续性补齐（bind_core_event 可跑件）

绑定规则三条，按序执行：
1. **明说优先**：用户给了中心动词（推/拧紧/取样/递出…）→ 原样绑定，不改写、不升级张力。
2. **未明说取普通核心动作**：用「该场景或领域在用户语言里的普通核心动作」兜底，并标 `VERB_SOURCE=默认`；
   绑定记录里必须能一眼看出动词是明说还是兜底。
3. **补齐四件**：角色、设定、视角、连续性各落一个非空值；缺哪个补哪个，不因为缺而停。

落盘件：`/root/dsh-infinite-gen-4/ig5-t3/artifacts/S06/bind_core_event.py`、`verify_core_event.sh`（本机 Python 3.12.3 实跑通过）。

### 1. 领域 → 普通核心动作表（未明说时的默认值）

| 领域 | 明说式（示例） | 未明说时的普通核心动作 | 动作类别 | 连续性句柄 |
| --- | --- | --- | --- | --- |
| physical | 推 / 拉 / 抬 / 压 | 推动 | 施力 | 位移进度标量 |
| mechanical | 拧紧 / 校准 / 启停 | 装配（对准并紧固） | 装配 | 装配序列号 SERIAL |
| biological | 传代 / 解冻 / 灭活 | 取样 | 取样 | 批次号 BATCH |
| narrative | 接过 / 开口 / 逼近 | 递出 | 交接 | 上一场结果 CONT_1 |

```python
#!/usr/bin/env python3
"""scenes.jsonl 每行: {"id","domain","verb?","role_a?","role_b?","setting?","pov?","continuity?","stakes?"}
未给 verb → 取该领域普通核心动作并标 VERB_SOURCE=默认；退码 0=全绑，4=缺领域拒绑。"""
VERBS = {   # 领域 -> (普通核心动作, 可选明说动词, 动作类别)
 "physical":   ("推动", ["推","拉","抬","压"], "施力"),
 "mechanical": ("装配（对准并紧固）", ["拧紧","校准","启停"], "装配"),
 "biological": ("取样", ["传代","解冻","灭活"], "取样"),
 "narrative":  ("递出", ["接过","开口","逼近"], "交接"),
}
FILL = {"role_a":"ROLE_A","role_b":"ROLE_B","setting":"SETTING_1",
        "pov":"POV_1（第三人称限知）","continuity":"CONT_1"}

def bind(rec):
    dom = rec.get("domain")
    if dom not in VERBS: return None
    default_verb, allowed, kind = VERBS[dom]
    said = rec.get("verb")
    verb = said or default_verb
    ra = rec.get("role_a") or FILL["role_a"]; rb = rec.get("role_b") or FILL["role_b"]
    st = rec.get("setting") or FILL["setting"]
    return {"CORE_EVENT": "%s 在 %s 中%s %s" % (ra, st, verb, rb),
            "CENTER_VERB": verb,
            "VERB_SOURCE": "明说" if said else "默认（该领域普通核心动作）",
            "VERB_KIND": kind, "ROLE_A": ra, "ROLE_B": rb, "SETTING": st,
            "POV": rec.get("pov") or FILL["pov"],
            "CONTINUITY": rec.get("continuity") or FILL["continuity"],
            "STAKES": rec.get("stakes") or "STAKES_1"}

def render(b):
    return ("中心动词「%s」落到 CORE_EVENT：%s；视角 %s；承接 %s；张力 %s。"
            % (b["CENTER_VERB"], b["CORE_EVENT"], b["POV"], b["CONTINUITY"], b["STAKES"]))
```
