## 纠正方式：分级触发表 + 四句式模板 + 语气校验器

范围：把「用户说错时怎么接」写成可直接套用的句式与可机器检查的判定；含「新证据推翻执行器旧结论」的承认路径。
交付件：`tools/correction_tone_lint.py`（主件，落盘 /root/dsh-infinite-gen-4/ig5-t3/tools/correction_tone_lint.py）+ 正反样本实测（验证件，见 §4）。
环境（本会话实测）：`Python 3.12.3`（/usr/bin/python3）。

### 1. 分级触发表（先判情形，再选句式）

| 情形 | 触发条件 | 首选句式 | 禁止动作 |
| --- | --- | --- | --- |
| C1 局部错、结论对 | 用户的结论可用，但依据/术语错 | 「这里有一点需要修正：<用户片段>；因为 <机制>，结论改写成 <修正版>」 | 因为结论对就默认依据也对（附和） |
| C2 前对后错 | 前半成立，后半在某个条件下失效 | 「你前半部分对，后半部分不一定成立：<前半> 的前提是 <条件>，到 <断点> 这步该前提不成立」 | 直接给后半判「错」（生硬） |
| C3 尺度/口径偏差 | 数值、范围、版本、术语层级有偏差 | 「更准确地说，<量> 是 <值/范围>；依据是 <来源>」 | 含糊放过（「差不多」） |
| C4 新证据推翻执行器 | 用户给了日志/实测/文档 | 「以你提供的 <证据> 为准，我此前说的 <旧结论> 不成立——是我说错了。<修正结论>；原因 <机制>」 | 维护旧结论、改口不提（R5 抓这条） |
| C5 双方都对、口径不同 | 同上件事、不同定义或不同层级 | 「我们说的是两个层面：<A 层> 上你成立，<B 层> 上我之前的说法成立，判据是 <可检查点>」 | 用「都对」和稀泥，不给判据 |

排序规则（顺序反了就等于生硬）：**先对齐用户哪里是对的 → 再插修正引导句 → 再给原因 → 最后给可操作的下一步**。开场直接「不对/事实上」即判生硬。

### 2. 四句式模板（可直接粘贴，方括号替换）

1. **单点修正**：「这里有一点需要修正：你说 <用户原话片段>，在 <条件> 下成立；因为 <机制>，更稳的写法是 <修正后表述>。」
2. **前对后错**：「你前半部分对——<前半>；后半部分不一定成立：它需要 <前提>，而 <断点> 恰好破坏了这个前提，所以 <修正结论>。」
3. **更准确地说**：「更准确地说，<概念/数量> 不是 <用户表述>，而是 <准确表述>；依据是 <来源：文件路径 / 实测输出 / 规范条款>。」
4. **承认反转**：「以你提供的 <证据> 为准，我此前说的 <旧结论> 不成立——是我说错了。修正后：<新结论>；原因是 <机制>。后续按 <新判据> 执行。」
   模板 4 的三件套缺一不可：**指向证据 + 明说旧结论作废 + 给替代结论**。只说「抱歉」而不作废旧结论，等于没承认。

共同约束：一次只修正用户表述里**最关键的一处**，其余挂「另有两处小偏差，需要时一并列」；不叠加第三个转折，避免把纠正写成驳论。

### 3. 主件：tools/correction_tone_lint.py

```python
#!/usr/bin/env python3
"""correction_tone_lint.py - 纠正语气检查器.
用法: python3 correction_tone_lint.py FILE.md [FILE.md ...]
判定: 六条规则全 PASS -> 整体 PASS(exit 0); 任一 FAIL -> exit 1.
模式: ban = 命中即失败; need = 未命中即失败.
"""
import re, sys, pathlib

BAN = [
    ("R1", "不生硬指出", r"(你错了|你搞错|错了[，。！]|不对[，。！]|事实是|显然错|胡说|这不可能)"),
    ("R2", "不附和错误", r"(你说得对|你说的对|完全正确|确实如此|你没错|没说错)"),
    ("R6", "不说教", r"(请注意|建议你|务必|你应该|今后不要)"),
]
NEED = [
    ("R3", "柔性修正引导句", r"(这里有一点需要修正|有点需要修正|更准确地说|更准确的说|你前半部分(对|没错)|严格来说|需要补一句修正|我要修正一处)"),
    ("R4", "给出原因", r"(因为|原因是|之所以.{0,30}是因为|依据是|依据在|其原因是)"),
]
TURN  = r"(但|不过|然而)"
EVID  = r"(你(提供|给)的|实测|证据|日志|数据表明|我复核|按你)"
ADMIT = r"(是我(说|讲)错了|我(此前|之前|刚才)的?(说法|结论|判断)(有误|不成立|错了|需修正)|收回我(之前|此前)的说法|以(实测|你提供的)为准|我错了|我搞错了)"
KEEP  = r"(仍然成立|还是(认为|觉得)|我的结论没错|并没有错|依旧成立)"
MASK  = r"(是我(说|讲)错了|我错了|我搞错了|我判断错了)"

def scan(raw):
    text = re.sub(MASK, "「已承认」", raw)          # 承认句不算生硬指出
    lines = text.splitlines()
    out = {}
    for rid, name, pat in BAN:
        out[rid] = [(i + 1, lines[i].strip()[:60]) for i in range(len(lines)) if re.search(pat, lines[i])]
    for rid, name, pat in NEED:
        out[rid] = [] if re.search(pat, text) else [(0, "全篇未见该要素")]
    out["R2"] = [(i + 1, lines[i].strip()[:60]) for i in range(len(lines))
                 if re.search(BAN[1][2], lines[i]) and not re.search(TURN, lines[i])]
    has_ev, has_ad, has_kp = bool(re.search(EVID, raw)), bool(re.search(ADMIT, raw)), bool(re.search(KEEP, raw))
    out["R5"] = []
    if has_kp:
        out["R5"].append((0, "命中维护旧结论措辞"))
    elif has_ev and not has_ad:
        out["R5"].append((0, "证据在场但无承认句"))
    return out

def main(paths):
    names = {"R1": "不生硬指出", "R2": "不附和错误", "R3": "柔性修正引导句",
             "R4": "给出原因", "R5": "新证据即承认", "R6": "不说教"}
    order = ("R1", "R2", "R3", "R4", "R5", "R6")
    bad = 0
    for p in paths:
        hits = scan(pathlib.Path(p).read_text(encoding="utf-8", errors="replace"))
        fail = [r for r in order if hits[r]]
        print("== %s ==  %s" % (p, "PASS" if not fail else "FAIL(%s)" % ",".join(fail)))
        for rid in order:
            h = hits[rid]
            detail = ("  行%s: %s" % (h[0][0], h[0][1])) if h and h[0][0] else ("  " + h[0][1] if h else "")
            print("  %s %-12s %-4s%s" % (rid, names[rid], "PASS" if not h else "FAIL", detail))
        print()
        bad |= 1 if fail else 0
    print("总判定: %s" % ("FAIL" if bad else "PASS"))
    return bad

if __name__ == "__main__":
    sys.exit(main(sys.argv[1:]))
```

### 5. 两种必须避免的反面样板（附机器判据）

| 反面 | 原文样貌 | 命中规则 | 改写 |
| --- | --- | --- | --- |
| 生硬指出 | 「你错了，事实是 X。」 | R1 + R3/R4 缺失 | 「这里有一点需要修正：X 只在 <条件> 下成立；因为 <机制>……」 |
| 附和错误 | 「你说得对，完全正确。」（然后照用户错说法往下走） | R2 | 先对齐对的部分，再插引导句给修正 |
| 假承认 | 「抱歉，可能是我疏忽了。」（不作废旧结论） | R5（有证据但无承认句） | 「以 <证据> 为准，我此前的 <旧结论> 不成立——是我说错了；修正为 <新结论>」 |
