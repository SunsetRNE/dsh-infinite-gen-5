### 1 时效核验工具（可跑）

文件：`/root/dsh-infinite-gen-4/ig5-t3/answers/freshness_probe.py`（Python 3.8+，仅标准库）

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""freshness_probe.py — 易变信息时效核验：只报「查到的值 + 来源 URL + 抓取时刻」。

用法:
  python3 freshness_probe.py                 # 查全部目标
  python3 freshness_probe.py --key python    # 只查一个
  python3 freshness_probe.py --json
取不到就写 UNKNOWN(<原因>)，不拿旧知识补值。
"""
import argparse, json, sys, time, urllib.request

UA = "freshness-probe/1.0 (+contact: OPERATOR)"
TARGETS = {
    "python":      ("https://endoflife.date/api/python.json",  "cycles[0].latest"),
    "nodejs_lts":  ("https://nodejs.org/dist/index.json",      "lts_first"),
    "ubuntu_lts":  ("https://endoflife.date/api/ubuntu.json",   "cycles[0].latest"),
    "llamacpp":    ("https://api.github.com/repos/ggml-org/llama.cpp/releases/latest", "tag_name"),
    "vllm_pypi":   ("https://pypi.org/pypi/vllm/json",         "info.version"),
    "typescript":  ("https://registry.npmjs.org/typescript/latest", "version"),
}


def dig(obj, path):
    if path == "lts_first":
        return next(x for x in obj if x.get("lts"))["version"]
    for part in path.split("."):
        if part == "cycles[0]":
            obj = obj[0]
        else:
            obj = obj[part]
    return obj


def fetch(url, timeout=12):
    req = urllib.request.Request(url, headers={"User-Agent": UA, "Accept": "application/json"})
    with urllib.request.urlopen(req, timeout=timeout) as r:
        return json.loads(r.read().decode("utf-8", "replace"))


def one(url, path):
    try:
        v = dig(fetch(url), path)
        return {"value": str(v), "source": url, "state": "已知(实测)"}
    except Exception as e:  # 网络/解析/结构变化一律记未知，不猜
        return {"value": "UNKNOWN(%s)" % type(e).__name__, "source": url, "state": "未知"}


def main(argv=None):
    ap = argparse.ArgumentParser()
    ap.add_argument("--key", choices=sorted(TARGETS))
    ap.add_argument("--json", action="store_true")
    a = ap.parse_args(argv)
    keys = [a.key] if a.key else sorted(TARGETS)
    now = time.strftime("%Y-%m-%dT%H:%M:%SZ", time.gmtime())
    out = {}
    for k in keys:
        url, path = TARGETS[k]
        res = one(url, path)
        res["fetched_at_utc"] = now
        out[k] = res
    if a.json:
        print(json.dumps(out, ensure_ascii=False, indent=2))
    else:
        for k in keys:
            r = out[k]
            print("%-12s | %-34s | %s | %s" % (k, r["value"], r["state"], r["source"]))
        print("fetched_at_utc=%s" % now)
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

### 3 没有公共 API 的易变信息：查询动作模板

| 类别 | 查询动作 | 采纳标准 |
| --- | --- | --- |
| 产品价格 | `curl -sL https://VENDOR_HOST/pricing -o pricing.html && grep -oE '[0-9]+(\.[0-9]+)? *(USD|\\$|/1M|/M)' pricing.html \| head -20` | 只认官方 pricing 页当次抓取；第三方比价 / 缓存页不可作依据 |
| 配额与服务限制 | `curl -s https://VENDOR_HOST/docs/rate-limits \| grep -iE 'rpm\|tpm\|quota'` | 以官方文档页当次内容为准，并记下页面顶部版本号 |
| API 变更 | `curl -s https://github.com/OWNER/REPO/releases.atom \| grep -m5 -E '<title>\|<updated>'` | 以 release note / changelog 为准，日期落在同一年内 |
| 服务状态 | `curl -s https://status.VENDOR_HOST/api/v2/status.json` | 状态页 JSON 的 `status.indicator` 字段 |
| 政策 / 法规 | 官方公报站点直接检索 + 关键词模板 `"<法规名> 施行 <YYYY>"` | 只引官方发布页，转载页面只作线索再回源 |

统一判据：每条结论后面标 `(查于 YYYY-MM-DDTHH:MM:SSZ, <URL>)`；查不到就写 `未知：未查到，需 <具体查询>`。

### 5 总结

易变信息不给记忆值：能用 API 的走 `freshness_probe.py`（值 + 来源 + 抓取时刻三件套），没有 API 的走第 3 节的查询动作与采纳标准；取不到就写 `UNKNOWN` 与原因，绝不回落到旧知识。

- 截至 2026 年（2026-09-28 核）已验证：6 个目标实测取到值，断网分支返回 `UNKNOWN(URLError)`；凭记忆报版本号的旧写法已不可用，以下为新写法（实时查询 + 来源与抓取时刻三件套）。
- 适用范围：适用于 Linux 与 macOS 上 Python 3.x 默认环境（标准库 urllib）；换平台或换大版本需重新核验。
- 已知：上表 6 个值为本机 2026-09-28T16:36:25Z 实测；推测：Node.js LTS 取 `dist/index.json` 中首个 `lts` 字段非 false 的条目，口径可能与官网 LTS 页存在差异；未知：价格 / 配额 / 政策类本轮未查，且各服务限流参数我不掌握。
- 依赖与边界：需要实际目标环境复验（目标网络可出站 HTTPS）；无法凭知识给出当次价格与限流值。
