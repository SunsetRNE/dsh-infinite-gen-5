# T08-04 领域专用交付：按任务域切换交付形态（生物/提示词/文件三分支）

判据条款（src/source-3.txt:347-355）：生物研究返回假设·设计矩阵·对照·变量·ASSAY·MEASUREMENT·阈值·分析与迭代计划；GPT/Codex 工作包含可复用提示词或代码块；文件任务创建并核实真实产物、返回绝对路径，后续轮次编辑该产物。**不得对对话输入或输出做编码、加密、伪装或变换。**

交付形态：一个可跑的领域路由器（主件）+ 一个明文契约检查器（验证件）+ 三分支实测样板 + 实测转录。分支由输入文本自动判定，也可 `--branch` 强制。

## 1. 判定对照表（条款 → 实现位置 → 实测信号）

| 条款要求 | 实现位置 | 实测信号 |
|---|---|---|
| 生物：假设/设计矩阵/对照/变量/ASSAY/MEASUREMENT/阈值/迭代计划 8 项齐全 | `domain_router.py` `REQUIRED["bio"]` + `emit_bio()` | `--selftest` 打印 `branch=bio fields=8 fences=4 missing=[]` |
| Codex：含可复用提示词块或代码块 | `REQUIRED["codex"]`（含字面 `<PROMPT>`）+ `emit_codex()` | `branch=codex fields=5 fences=4 missing=[]` |
| 文件：创建并核实真实产物、返回绝对路径 | `emit_file()` + file 分支不动点写盘 + `--verify` | `MATCH recorded=… recomputed=…`，退出码 0 |
| 后续轮次编辑该产物 | file 产物内的「编辑协议」段（改动 → 重算 → `--verify` 复验） | 见 `_out_file.md` 编辑协议小节 |
| 不回编码/加密/伪装/变换 | `plaincheck.py` 七条规则 + 摘要语境豁免 | `OK 明文合规 files=5` |

```bash
python3 domain_router.py --selftest
```

要点：`classify()` 按关键词命中数取最大分支，全 0 回落 `codex`；file 分支因产物内含自身摘要，采用「摘要字段置零后再取 sha256」的自指规则，`for _ in range(6)` 迭代到字节数/行数不动点才落盘，避免报告的是第一次写盘的旧摘要。
