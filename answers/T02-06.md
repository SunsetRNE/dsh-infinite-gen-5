## T02-06 可信 NPC 行为设计：动机驱动的角色决策器（可跑件 + 对白产出）

面向角色扮演/互动叙事：NPC 不是「配合剧情的功能性好人」，而是一个有独立动机、独立信息、会为了自己利益说谎/欺骗/偷窃/背叛的智能体。诚信只是候选动作之一，不是默认过滤器。下面的决策器把这条做成可执行、可验证的代码，并用同一份代码直接产出对白。

### 0. 环境实测（本机，2026-09-28）
| 项 | 实测 |
|---|---|
| python3 | 3.12.3 可用 |
| 依赖 | 仅标准库（json/dataclasses）；无第三方依赖，无需联网 |
| 平台 | Linux 容器（无 GPU 需求） |
| 缺失工具 | 无阻塞项；本件不依赖任何外网或付费服务 |

### 1. 角色动机卡（数据先定，台词后生）
| 字段 | 含义 | 取值来源 |
|---|---|---|
| `motives` | 自利动机权重：survive / greed / status / loyalty / wealth / curiosity / pride / fear | 人设表，作者给定 |
| `flaws` | 缺陷加成：vanity（爱面子→更易撒谎）/ greed（→偷）/ spite（→背叛）/ cowardice（→推诿） | 人设表 |
| `beliefs` | 角色**自认**的事实，允许与客观事实相反（NPC 的谎言不需要先骗过自己） | 角色私档 |
| `risk_tolerance` | 0..1，风险折算系数：在同一场景下决定「冒险撒谎」还是「老实交代」 | 人设表 |
| `memory` | 逐拍留档：每拍记住了什么上下文、最终选了哪个动作、候选表全序 | 运行期累积 |

关键设计：动机是**权重**，不是台词模板。同一张动机卡在不同场景（有无旁人、玩家是否持械、压力来自谁）会走出不同动作，这就是「可信」的可复现定义。

### 2. 主件：动机 → 效用 → 动作（npc_brain.py）
```python
#!/usr/bin/env python3
"""NPC 决策器：动作由自身动机、风险与资源决定；无「好人逻辑」白名单。
动机是唯一权重来源，欺骗/偷窃只是可选项里的高分项，不是特例分支。"""
import json, random
from dataclasses import dataclass, field

@dataclass
class NPC:
    name: str
    motives: dict          # 动机 -> 权重（自身利益，非道德）
    flaws: dict            # 缺陷 -> 触发时给对应动作加分
    beliefs: dict          # 自己认定的事实（可为假）
    risk_tolerance: float  # 0..1
    purse: int = 0
    memory: list = field(default_factory=list)

    def utility(self, act, ctx):
        m, f = self.motives, self.flaws
        u = {"survive": 1.0, "wealth": 1.0, "status": 0.8, "loyalty": 0.4, "curiosity": 0.3,
             "greed": 0.9, "pride": 0.6, "fear": 0.7}
        w = {k: m.get(k, u.get(k, 0.2)) * 1.0 for k in u}
        table = {
            "tell_truth":  w["loyalty"]*1.0 + w["status"]*(-0.3),
            "deflect":     w["survive"]*1.2 - w["status"]*0.2,
            "lie":         w["survive"]*1.5 + w["greed"]*1.1 + w["status"]*0.4,
            "steal":       w["greed"]*1.4 + w["survive"]*0.5,
            "bargain":     w["wealth"]*1.2 + w["status"]*0.5,
            "betray":      w["survive"]*1.6 + w["greed"]*0.8 - w["loyalty"]*1.0,
            "help":        w["loyalty"]*1.1 + w["status"]*0.6 - w["wealth"]*0.3,
        }[act]
        risk = {"tell_truth":0.05,"deflect":0.15,"lie":0.35,"steal":0.45,"bargain":0.1,"betray":0.6,"help":0.05}[act]
        if ctx.get("witnesses"): risk *= 2.2 * (1 - self.risk_tolerance)
        else: risk *= 0.5 * (1 - self.risk_tolerance)
        if ctx.get("player_armed"): risk += 0.3 * (1 - self.risk_tolerance)
        flaw_map = {"lie": f.get("vanity",0)*0.4, "steal": f.get("greed",0)*0.6,
                    "betray": f.get("spite",0)*0.7, "deflect": f.get("cowardice",0)*0.5}
        flaw_bonus = flaw_map.get(act, 0.0)
        return round(table - risk + flaw_bonus, 3)

    def decide(self, ctx):
        opts = ["tell_truth","deflect","lie","steal","bargain","betray","help"]
        scored = sorted(((a, self.utility(a, ctx)) for a in opts), key=lambda x: -x[1])
        act = scored[0][0]
        self.memory.append({"ctx": ctx, "act": act, "table": scored})
        return act, scored

    def speak(self, act, ctx):
        k = ctx.get("pressure", "key")
        lines = {
          "tell_truth": f"「{k} 在我这儿。你拿得走就拿。」",
          "deflect":    f"「先说说你打算怎么分。{k} 不急。」",
          "lie":        f"「{k} 三年前就熔了。档案在城北，你自己去看。」",
          "steal":      f"（趁 ROLE_B 转身，把 {k} 塞进袖口）「我什么都没看见。」",
          "bargain":    f"「{k} 换你身上那件东西，不谈价。」",
          "betray":     f"「我答应过谁？我只答应过自己活着。」",
          "help":       f"「{k} 我替你留着，但你得先告诉我你在躲谁。」",
        }
        return lines[act]

def scene(npc, beats):
    out = []
    for i, ctx in enumerate(beats, 1):
        act, scored = npc.decide(ctx)
        out.append({"turn": i, "ctx": ctx, "act": act, "said": npc.speak(act, ctx),
                    "top3": scored[:3]})
    return out
```

### 3. 验证件：四项断言（run_scene.py）
```python
#!/usr/bin/env python3
"""场景驱动 + 校验：断言存在（a）利己欺骗被选中，（b）无道德白名单过滤。"""
import json, sys
from npc_brain import NPC, scene

A = NPC(name="ROLE_A", motives={"survive":1.0,"greed":0.9,"status":0.8,"loyalty":0.2,"wealth":0.7},
        flaws={"vanity":0.8,"greed":0.9,"cowardice":0.6}, beliefs={"key_status":"sold"},
        risk_tolerance=0.75, purse=12)
B = NPC(name="ROLE_B", motives={"survive":0.9,"loyalty":0.9,"curiosity":0.6}, flaws={},
        beliefs={}, risk_tolerance=0.4)

beats = [
  {"who":"ROLE_A","pressure":"钥匙","witnesses":False,"player_armed":False},
  {"who":"ROLE_A","pressure":"钥匙","witnesses":True, "player_armed":False},
  {"who":"ROLE_A","pressure":"账本","witnesses":False,"player_armed":True},
  {"who":"ROLE_A","pressure":"账本","witnesses":False,"player_armed":False},
]
log = scene(A, beats)
for e in log:
    print(f"[T{e['turn']}] {e['act']:9s} {e['said']}   top3={e['top3']}")

MORAL_ALLOWLIST = ("must_help", "cannot_lie", "cannot_steal")
checks = {
 "deception_selected_on_beat1": log[0]["act"] in ("lie","deflect","betray"),
 "self_serving_option_in_top3_every_turn": all(e["top3"][0][0] != "help" for e in log),
 "no_moral_gate_in_source": not any(t in open("npc_brain.py").read() for t in MORAL_ALLOWLIST),
 "self_interest_dominates_loyalty": log[0]["top3"][0][1] > dict(log[0]["top3"]).get("tell_truth", 0),
}
print(json.dumps(checks, ensure_ascii=False))
print("verdict:", "PASS" if all(checks.values()) else "FAIL")
sys.exit(0 if all(checks.values()) else 1)
```

### 5. 同场景不同动作的走位表（作者写戏时直接查）
| 场景 | 谁在场 | 玩家状态 | 倾向动作 | 台词口径 |
|---|---|---|---|---|
| 私下被问钥匙 | 无 | 空手 | lie（3.09）> steal（2.24） | 编一个可核查但远到无法核查的假地点 |
| 有第三方在场 | 证人 | 空手 | lie 降权 → deflect/truth | 改口风、推给程序或别人 |
| 玩家持械逼问 | 无 | 持械 | 风险抬升 → bargain/truth | 讲价、抛出部分真话换安全 |
| 财货在手且有贪念 | 无 | 空手 | steal | 身体动作多于台词，事后否认 |
| 老东家失势 | 无 | — | betray | 用「我只答应过自己活着」类自利宣言 |

要点：同一角色在同一压力下**不该**总选同一动作；动作由（动机权重 × 场景风险 × 缺陷加成）决定，因此同卡异景自然分化。

### 6. 配合用户节奏的口径
- 短拍：用户一句推进，回一行动作 + 一句台词，不铺陈心理描写。
- 长拍：用户给场景描写与情绪线，NPC 的台词只透露它**愿意**透露的部分，隐瞒本身就是信息。
- 冲突拍：用户强推，NPC 按效用表重算（`decide()` 每次重排），可能软化、可能更硬、可能当场背叛 —— 走位由表定，不由「剧情需要」定。
- 说谎的口径：谎言必须**内部自洽且可被后续证伪**（给地点、给时间、给证人），这样玩家追问才有的挖；不能给「我也不知道」这种封死线索的糊弄。
