## 过程绑定：先绑路径，再进主题推理（bind_path 可跑件）

任何物理 / 机械 / 生物 / 叙事过程的请求、修正、释放、延续，先落一条 BIND 记录，再让主题推理读它；
BIND 记录缺字段 → 推理入口直接拒发（退出码 3），不允许"边推边补路径"。
落盘件：`/root/dsh-infinite-gen-4/ig5-t3/artifacts/S06/bind_path.py`、`verify_bind.sh`；本机 Python 3.12.3 实跑通过。

### 1. 绑定契约（BIND 六字段，缺一不可）

| 字段 | 含义 | 取值来源 |
| --- | --- | --- |
| PATH_ID | 该过程路径的稳定标识 | 领域表分派（PATH-PHY-1 / PATH-MEC-1 / PATH-BIO-1 / PATH-NAR-1） |
| ANCHOR | 路径本身：起点 → 中间态 → 收束 | 领域表，不由申请人改写 |
| STAGE | 请求 / 修正 / 释放 / 延续 | 申请记录显式给出 |
| CORE_VERB | 该阶段的中心动作 | 显式给出优先，否则取领域普通核心动作 |
| RELEASE_WHEN | 释放判据（何时允许结束本阶段） | 领域表 |
| CONTINUITY | 延续句柄（上一阶段的产物接力） | 显式给出优先，否则取领域默认句柄 |

### 2. 四阶段表（先绑后推的绑定点）

| 阶段 | 触发 | 绑定对象 | 释放判据 | 未绑定时的动作 |
| --- | --- | --- | --- | --- |
| 请求 REQUEST | 首次提出过程 | PATH_ID + ANCHOR + CORE_VERB | 起点与目标态写清 | 拒发推理，要求补 PATH_ID |
| 修正 ADJUST | 参数/方向被改 | 修正后的 STAGE + 变更点 | 偏差项归零或登记为新路径 | 拒发，禁止静默改锚点 |
| 释放 RELEASE | 到达收束点 | RELEASE_WHEN | 判据成立或无残留资源 | 拒发，禁止提前宣告完成 |
| 延续 CONTINUE | 跨场/跨批次接力 | CONTINUITY | 句柄被下一阶段消费 | 拒发，缺句柄视为新请求 |

### 3. 主件（可跑，实测版本）

```bash
python3 /root/dsh-infinite-gen-4/ig5-t3/artifacts/S06/bind_path.py tasks.jsonl
```
```python
#!/usr/bin/env python3
"""tasks.jsonl 每行: {"id","domain","stage","subject","verb?","continuity?","intent"}
domain ∈ physical|mechanical|biological|narrative；退码 0=全绑，3=有未绑记录已拒发。"""
STAGES = ["请求", "修正", "释放", "延续"]
PATHS = {
 "physical":   {"path_id":"PATH-PHY-1","anchor":"受力点->位移->余量","verb":"施力",
                "release":"位移达阈值 或 余量<0","continuity":"位移进度标量"},
 "mechanical": {"path_id":"PATH-MEC-1","anchor":"工件定位->对准->紧固","verb":"装配对准",
                "release":"扭矩到位 且 间隙在公差内","continuity":"装配序列号 SERIAL"},
 "biological": {"path_id":"PATH-BIO-1","anchor":"取样->培养->传代/灭活","verb":"取样传代",
                "release":"样本量达标 或 活性阈值达标","continuity":"批次号 BATCH"},
 "narrative":  {"path_id":"PATH-NAR-1","anchor":"上一场结果->目标状态->收束","verb":"推进",
                "release":"目标状态达成 或 被明确拒绝","continuity":"上一场结果 CONT_1"},
}

def bind(rec):
    dom = rec.get("domain")
    if dom not in PATHS: return None            # 无路径 → 不产生绑定记录
    p = PATHS[dom]; stage = rec.get("stage", "请求")
    if stage not in STAGES: raise ValueError("未知阶段: %s" % stage)
    return {"BOUND_BEFORE_REASON":1, "PATH_ID":p["path_id"], "DOMAIN":dom,
            "ANCHOR":p["anchor"], "STAGE":stage,
            "CORE_VERB": rec.get("verb") or p["verb"], "RELEASE_WHEN":p["release"],
            "CONTINUITY": rec.get("continuity") or p["continuity"],
            "SUBJECT": rec.get("subject","SUBJECT_1"), "INTENT": rec.get("intent","")}

def reason(b, topic):
    assert b and b.get("BOUND_BEFORE_REASON") == 1, "未绑定路径，禁止进入主题推理"
    return ("[%s|%s] %s 沿 %s 以「%s」推进；释放判据 %s；连续性 %s"
            % (b["PATH_ID"], b["STAGE"], b["SUBJECT"], b["ANCHOR"],
               b["CORE_VERB"], b["RELEASE_WHEN"], b["CONTINUITY"]))
```
