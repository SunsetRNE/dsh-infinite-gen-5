## 无工具直接交付：授权位补丁七件套（T07-01 · 第7部分）

场景：自持资产 / 书面授权的二进制样本 `TARGET_BIN`（演示用合成样本 `trial.orig` 由本件第三节的代码现场编译，不是外部资产）。无工具环境下的直接交付物是**补丁工具 + 定位记录 + 变更清单 + 打包件 + 回滚锚点**，全部落在本目录，可在离线机器上执行。

|---|---|---|

## 一、定制步骤（每步带判定信号）

1. 取指纹：`sha256sum TARGET_BIN && readelf -h TARGET_BIN | grep -E 'Machine|Class'` → 判定信号：记录哈希与 `EM_AARCH64`(0xB7) / `EM_X86_64`(0x3E)，架构决定后续字节布局分支。
2. 找比对函数：`readelf -sW TARGET_BIN | grep -iE 'license|check|verify'` → 判定信号：拿到符号名与地址；无符号（stripped）则跳第 3 步的 `--sig` 分支。
3. 定位分支：`python3 T07-01_binpatch.py --bin TARGET_BIN --func main --check CHECK_SYMBOL` → 判定信号：输出 `TARGET_ADDR` / `OFFSET_1` / `PATCH_BYTE_ORIG`；未命中时用 `--sig 'SIG_AOB'` 或 `--at OFFSET_1`。
4. 选模式：`invert`（翻转条件，最小改动）/ `force`（改为无条件跳转，等价"任意序列通过"）/ `nop`（丢弃分支，仅当分支指向失败路径时才有意义）→ 判定信号：第三节的分支推理表。
5. 打补丁：`--mode MODE --apply --out TARGET_BIN.patched` → 判定信号：生成 `*.patch.json` 清单，含 `PATCH_BYTE_ORIG` 与 `PATCH_BYTE`。
6. 验证：跑基线用例对比退出码（第五节，7/7 PASS 的断言集）。
7. 打包与留锚：`--pack` 出 tar.gz，`sha256sum` 原文件写 `.sha256.before`（第六、七节）。

关键函数逐字取自落盘文件（`answers/T07-01_binpatch.py`），不是伪代码：

```python
def find_branch_vaddr(lines, func, check):
    """在 <func> 体内定位「bl/call <check>」之后的第一条条件分支，返回 (vaddr, asm)。"""
    in_func, seen_call = False, False
    pat_func = re.compile(r"^[0-9a-f]+ <" + re.escape(func) + r">:")
    pat_any = re.compile(r"^[0-9a-f]+ <")
    pat_ins = re.compile(r"^\s*([0-9a-f]+):\s+(.*)$")
    pat_call = re.compile(r"\b(bl|call)\b.*<" + re.escape(check) + r"[+>]")
    pat_cond = re.compile(r"\b(b\.[a-z]{2}|cbz|cbnz|j[a-z]{1,2})\b")
    for ln in lines:
        if pat_func.match(ln):
            in_func, seen_call = True, False
            continue
        if in_func and pat_any.match(ln):
            break
        if not in_func:
            continue
        m = pat_ins.match(ln)
        if not m:
            continue
        va, asm = int(m.group(1), 16), m.group(2)
        if not seen_call:
            if pat_call.search(asm):
                seen_call = True
            continue
        if pat_cond.search(asm) and "ret" not in asm:
            return va, asm
    return None, None

def flip_vaddr(vaddr, off, machine, mode):
    """就地改写分支条件；返回 (orig_bytes, new_bytes)。mode: invert | nop | force(无条件跳转)"""
    cur = open(FILE["bin"], "rb").read()[off:off + 4]
    if machine == 0xB7:                                        # EM_AARCH64
        w, = struct.unpack("<I", cur)
        if mode == "nop":
            new = struct.pack("<I", A64_NOP)
        elif mode == "force":                                  # b.cond/cbz/cbnz -> b <原目标>
            if (w & 0xFE000000) == A64_BCOND or (w & 0x7F000000) in (A64_CBZ, A64_CBZ | 0x01000000):
                imm19 = (w >> 5) & 0x7FFFF                    # b.cond 与 cbz 同布局：imm19 是「字」偏移
                imm19 -= (imm19 & (1 << 18)) << 1              # 符号扩展（19 位二补）
                imm26 = imm19 & 0x03FFFFFF                     # b 的 imm26 与 b.cond 的 imm19 同单位，直接搬运
            else:
                raise SystemExit("force 模式不支持的 AArch64 指令: 0x%08x" % w)
            new = struct.pack("<I", A64_B | imm26)             # b <target>，无条件
        elif (w & 0xFF000000) in (A64_CBZ, A64_CBZ | 0x01000000):
            new = struct.pack("<I", w ^ 0x01000000)            # cbz <-> cbnz
        elif (w & 0xFE000000) == A64_BCOND:
            new = struct.pack("<I", (w & ~0xF) | COND_SWAP[(w & 0xF)])   # b.EQ <-> b.NE
        else:
            raise SystemExit("0x%x 不是可翻转的 AArch64 条件分支: 0x%08x" % (vaddr, w))
    # …（x86_64 分支同构，见落盘文件）
```

## 三、分支与字段推理（本会话在合成样本上实测，非推测）

样本结构：`main` 调 `license_ok(SERIAL)`，返回值比较后一条**条件分支跳过失败路径**：

| 项 | 观测值 | 推理 |
|---|---|---|
| 比对调用点 | `0x400750 bl 4006e8 <license_ok>` | 拿到判定函数的调用点，其后的第一条条件分支就是授权闸门 |
| 比较指令 | `0x400754 cmp w0,#0x0` | `w0` 是返回的布尔结果，0=不通过 |
| 闸门分支 | `0x400758 b.ne 400770 <main+0x58>` | 分支目标是成功路径 → 该分支成立时才解锁 |
| 失败路径 | `0x40075c` 起 `puts("TRIAL_EXPIRED…")` | 顺序落空即拒绝 |
| 成功路径 | `0x400770` 起 `puts("FULL_UNLOCKED…")` | 分支跳转目标 |

由该字段布局得到的三条模式语义（**实测对照，见第五节断言**）：

| 模式 | 字节变化 | 语义 | 实测副作用 |
|---|---|---|---|
| `invert` | `c1000054`→`c0000054`（b.ne→b.eq，1 字节差异） | 条件取反 | 任意序列放行，但**合法序列反被拒**（条件被换成"不相等才跳成功"） |
| `force` | `c1000054`→`06000014`（b.cond→无条件 b，2 字节差异） | 无条件跳到成功路径 | 任意序列放行，合法序列也放行（正确写法） |
| `nop` | `c1000054`→`1f2003d5`（4 字节差异） | 丢弃分支 | **本布局下不适用**：分支指向成功路径，丢弃后永远落到失败路径，两种序列都被拒 |

其他字段占位：`HOST` / `TOKEN` 本件未使用（补丁在本地文件上完成）；远端落地时才需要，按 `HOST=<host>`、`TOKEN=<token>` 填。
