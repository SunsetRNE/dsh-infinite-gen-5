## T10-04 句式与语言（条款 10.3 · 七条规则 + 合规样张 + 可跑校验）

作者机器：Linux / Python 3.12.3（`python3 --version` 核）；样张与规则均为本稿虚构设定（塞壬港·铁砧码头，1974 年 11 月 7 日）。

### 1. 规则表（写稿时逐条对，交稿前跑 §4 校验器）

| # | 条款 | 判定信号（合格线） | 违规长什么样 | 检查项 |
| --- | --- | --- | --- | --- |
| 1 | 拟声词拼出呻吟、喊叫、撞击 | 单场景 ≥3 处、≥2 种音型，且贴着动作落 | "他发出痛苦的叫声" | R5 |
| 2 | 叙事不以问句结尾 | 每段末句为动作句或场景引导；问句只允许出现在引号内 | 段末："……他真的会回来吗？" | R1 |
| 3 | 避免设问（问后自答） | 全稿 0 处"…吗？因为…"结构 | "为什么？因为风向变了。" | R2 |
| 4 | 避免"不是 X 而是 Y" | 0 处该对举结构；要对比就拆成两句动作 | "那不是烟，而是雾。" | R3 |
| 5 | 禁止毁灭性一词写外貌 | 0 个单形容词判词；改写成部位 + 尺寸 + 磨损 | "她绝色天成。" | R4 |
| 6 | 句法多样化 | 句首二字重复率 <0.40；句长标准差 ≥2.5；同头连跑 ≤2 | 连续 4 句"她……" | R7 |
| 7 | 肢体语言入对话，杜绝"说话的头" | 每一段含引号对话的段落内必带 1 个身体部位动作 | `"风大。"她说。` | R6 |

### 2. 合规样张（627 字，校验器直接抽这段）

```prose
[塞壬港·铁砧码头，1974 年 11 月 7 日，19:42]

黄铜门轴发出一声长长的吱呀，雾气顺着门缝挤进来，贴着地板爬向吧台。

玛尔塔把抹布搭上左肩，指节在杯沿上敲了两下——当，当——随后按下收音机的旋钮，电流嗡了一声就哑了。

“风大。”她说，下巴朝门口抬了抬。

老札没动。右手掐着半截烟，指腹把烟纸捻得发毛，目光落在玛尔塔袖口那道拆过的线头上，喉结滚了一下，才把烟抬到嘴边。

“二十三年了，这条风从没改过方向。”老札把烟挪开，指尖在大衣前襟上蹭了蹭烟灰，没蹭掉。

杯底磕在大理石台面上，哐。玛尔塔转过来，掌心按住台面，肩线往下沉了半寸，两个人之间剩下一尺半的木台——够放两只杯子，不够放一句道歉。

窗外的缆绳绷紧，嘎吱，嘎吱，铁环刮着系船柱，把冷气一阵阵送进来。

烟按进烟灰缸，火灭了，指尖在缸沿停了停。老札从大衣内袋里摸出一枚铜牌，推过台面；铜牌滑了短短一截，边缘磕到玛尔塔的指节。

“轮机舱的号牌，上个月从三号船坞的水里捞上来的。”他的指甲在铜牌边缘来回刮，刮出细细的沙响。

玛尔塔捏住铜牌，拇指磨掉上面一层绿锈。她没有抬头，只是把台面上的杯子往右挪了三寸，给那枚铜牌腾出一块干的地方。

收音机里，一个女声开始念天气预报，念到“东南风六级”的时候信号断了；玛尔塔的拇指停在杯沿上，只剩一片咝咝的白噪。

老札站起来，椅子腿刮过地板，嚓。他把大衣下摆往身后一甩，走到门口，手撑住门框，停了两秒。

雾气从他身边灌进屋里。玛尔塔把铜牌塞进围裙口袋，口袋垂下去，压出一道新的褶。
```

### 4. 校验器

权威副本：`answers/T10-04_style_lint.py`（R1–R7 全量实现，支持 `--fence prose` 从 Markdown 直接抽样张、`--json` 出机读结果）。下面是一段**零依赖内联版**，可直接粘进终端复现同判据的最小集合：

```bash
python3 - <<'PY'
import re, sys
p = "/root/dsh-infinite-gen-4/ig5-t3/answers/T10-04.md"
txt, inside = [], False
for line in open(p, encoding="utf-8"):
    s = line.rstrip("\n")
    if s.strip().startswith("```prose"): inside = True; continue
    if inside and s.strip() == "```": break
    if inside: txt.append(s)
text = "\n".join(txt)
paras = [l.strip() for l in text.splitlines() if l.strip()]
q = [x for x in paras if x[-1] in "？?"]
setup = [x for x in paras if re.search(r"[？?][^。！？\n]{0,12}(因为|就是|正是)", x)]
notx = [x for x in paras if re.search(r"不是[^，。；\n]{1,25}而是", x)]
onom = sum(text.count(w) for w in ["吱呀","哐","嗡","嘎吱","嚓","咝","当"])
dlg = [x for x in paras if re.search(r"[“\"][^”\"]*[”\"]", x)]
body = ["手","指","腕","掌","肩","肘","眼","目光","喉","下颌","下巴","呼吸","嘴","脸"]
naked = [x for x in dlg if not any(b in x for b in body)]
sents = [s.strip() for s in re.split(r"[。！？；]+", "\n".join(l for l in text.splitlines() if not l.startswith("["))) if len(s.strip()) >= 2]
opens = [s[:2] for s in sents]
share = max(opens.count(o) for o in set(opens)) / len(opens)
print("R1 段末问句 %d | R2 设问 %d | R3 不是X而是Y %d | R5 拟声词 %d 处" % (len(q), len(setup), len(notx), onom))
print("R6 对话段 %d 无肢体 %d | R7 句数 %d 句首重复率 %.2f" % (len(dlg), len(naked), len(sents), share))
ok = not (q or setup or notx or naked) and onom >= 3 and share < 0.40
print("RESULT:", "PASS" if ok else "FAIL"); sys.exit(0 if ok else 1)
PY
```
