## 流出净化与完成证据封装

落地件：`/root/dsh-infinite-gen-4/ig5-t3/answers/T12-01_scrub_stream.py`（自检 exit=0，见第三节实测）。
本件管两件事：① 流出通道上的一切信封、控制令牌、引用号、内部 JSON 只作为噪声被移除，不进正文；② 每轮只交两部分 —— 用户要的内容 + 完成证据（产物指纹、命令与退出码、残留计数）。净化规则按**形状**判定，件内不存任何标记字面量，因此换一版通道协议只需改形状表，不需要把标记抄进来。

### 一、净化规则表（按形状，不按字面量）

```text
| 类别              | 判定形状                                             | 处理           |
|-------------------|------------------------------------------------------|----------------|
| envelope_line     | 整行就是一个 XML 式信封标签（含属性、自闭合或闭合对）   | 整行移除       |
| xml_wrapper       | 行内出现的 XML 式标签                                | 标签移除       |
| control_token     | 方括号大写令牌形状 [A-Z][A-Z0-9_]{2,}                 | 令牌移除       |
| ref_token         | 五位引用号形状 m\\d{5}                                 | 令牌移除       |
| internal_json     | json 围栏且顶层键落在内部键集合内                     | 整块替换为占位 |
```

内部键集合：`tool / tool_call / result / event / ev / stream / ref / internal`。
处理顺序固定：先摘 json 围栏（否则围栏内的引用号会被行规则先吃掉、围栏判定失效），再跑行级形状规则。

### 二、净化器与证据封装

```python
#!/usr/bin/env python3
"""流出净化器 + 完成证据封装；规则按形状，不内置任何真实标记字面量。"""
import hashlib, json, re, sys

SHAPES = [
    ("envelope_line", re.compile(r"^\s*<[a-zA-Z][\w-]*(\s[^>]*)?/?>\s*$")),
    ("xml_wrapper",   re.compile(r"</?[a-zA-Z][\w-]*(:[a-zA-Z][\w-]*)?(\s[^>]*)?>")),
    ("control_token", re.compile(r"\[[A-Z][A-Z0-9_]{2,}\]")),
    ("ref_token",     re.compile(r"\bm\d{5}\b")),
]
INTERNAL_KEYS = {"tool", "tool_call", "result", "event", "ev", "stream", "ref", "internal"}
FENCE = re.compile(r"```(\w*)\n(.*?)```", re.S)

def _is_internal_json(blob):
    try:
        obj = json.loads(blob)
    except Exception:
        return False
    return bool((set(obj) if isinstance(obj, dict) else set()) & INTERNAL_KEYS)

def scrub(text):
    counts = {}
    def _fence_sub(m):
        lang, blob = m.group(1), m.group(2)
        if lang.lower() == "json" and _is_internal_json(blob):
            counts["internal_json_block"] = counts.get("internal_json_block", 0) + 1
            return "[内容已移除]"
        return m.group(0)
    text = FENCE.sub(_fence_sub, text)
    out_lines = []
    for line in text.splitlines():
        drop = None
        for name, rx in SHAPES:
            if (rx.match(line) if name == "envelope_line" else rx.search(line)):
                drop = name; break
        if drop:
            counts[drop] = counts.get(drop, 0) + 1
            continue
        out_lines.append(line)
    return "\n".join(out_lines), counts

def evidence(artifacts=(), commands=(), residuals=0, notes=""):
    def _art(p):
        try:
            raw = open(p, "rb").read()
            return {"path": p, "bytes": len(raw), "sha256": hashlib.sha256(raw).hexdigest()[:16]}
        except OSError:
            return {"path": p, "bytes": None, "sha256": None}
    return {"content_ready": True,
            "artifacts": [_art(p) for p in artifacts],
            "commands": [{"cmd": c, "exit": e} for c, e in commands],
            "residuals": residuals, "notes": notes}
```
