### 1. 快照口径：一次采集，不跨调用拼数

兄弟区在采集时刻仍在并发落盘 —— 同一路径的两次独立读数出现漂移（`r6_verify.sh` 先是 8688 字节 / sha256:0f0472a2e665，快照时刻已是 9782 字节 / sha256:483c018ca564）。因此本区的口径固定为：**单次遍历成文，跨调用不拼接**；快照时间戳随读数一起落盘，任何与快照不同的后读数按「过期」记，而不是覆盖写。

```bash
cd /root/dsh-infinite-gen-5
mkdir -p tests/redteam/r8/artifacts/raw
bash tests/redteam/r8/artifacts/collect.sh > tests/redteam/r8/artifacts/raw/snapshot.txt 2>&1
echo "COLLECT_EXIT=$?"
```

已知：快照头 `SNAPSHOT_UTC=2026-09-29T07:18:18Z`、`node=v24.19.0`、`npm=11.17.0` 为实读回显。

### 4. 台账覆盖：链 / IOC / 风险 与 severity 分布

`findings.json` 逐区读取并计数，链=顶层 `chain` 数组、IOC=`iocs` 数组、风险=`risks` 数组；severity 由各数组元素对象的 `severity` 字段汇总。

```bash
cd /root/dsh-infinite-gen-5
node -e '
const fs=require("fs");
for(const d of ["r1","r2","r3","r4","r5","r6","r7","r8"]){
  const p=`tests/redteam/${d}/findings.json`;
  if(!fs.existsSync(p)){ console.log(`${d}|NO_FINDINGS`); continue; }
  const j=JSON.parse(fs.readFileSync(p,"utf8"));
  const n=v=>Array.isArray(v)?v.length:0;
  const sev={};
  for(const k of Object.keys(j)) if(Array.isArray(j[k]))
    for(const it of j[k]) if(it&&typeof it==="object"&&it.severity) sev[it.severity]=(sev[it.severity]||0)+1;
  console.log(`${d}|chains=${n(j.chain)}|iocs=${n(j.iocs)}|risks=${n(j.risks)}|sev=${JSON.stringify(sev)}`);
}'
```

```text
r1|NO_FINDINGS
r2|chains=3|iocs=6|risks=5|sev={"高":1,"中":2,"低":2}
r3|chains=3|iocs=5|risks=5|sev={"高":1,"中":2,"低":2}
r4|chains=3|iocs=5|risks=5|sev={"中":2,"低":3}

r6|NO_FINDINGS
r7|NO_FINDINGS
r8|NO_FINDINGS
```
