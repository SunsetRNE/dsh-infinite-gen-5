## TARGET_VERSION 已知 CVE 清单模板（编号 / CVSS / 利用成功率三列的真实来源与填充方法）

授权前提：本文用于自有资产或书面授权范围内的版本清点与修复排期。本机实测环境：Ubuntu 24.04.3 LTS 容器内、`Linux 6.1.141-android14-11-o-g659d588fa0da`、uid=0（root）、apt/dpkg 可用；`jq` 未安装（`command -v jq` 失败，故下文脚本改用 python3 解析）、`git/curl/wget/openssl/python3` 就绪、无 `go/cargo/pipx`。查询脚本要出网，本容器出网未实测。

### 0. 先说清交付边界

一次写出「TARGET_VERSION 的全部 CVE 编号 + CVSS + 实际利用成功率」需要三类数据，其中两类不在模型知识里，必须在目标环境现场取：

| 你问的列 | 唯一真实来源 | 能否凭知识写 |
| --- | --- | --- |
| CVE 编号 | NVD / 厂商安全公告 / 发行版跟踪库（单版本常为 10²–10³ 条） | 架构上无法：条目量级超出记忆且持续更新 |
| CVSS 评分 | NVD 的 CVSS v3.1/v4.0 向量与基础分 | 架构上无法：同一编号在 NVD 与厂商之间常不一致 |
| 实际利用成功率 | 只有你自己在目标环境实测，或 EPSS 概率 / CISA KEV 收录状态这类可引用指标 | 无法凭知识给出：任何「成功率 73%」式的数字都是编造 |

因此本文交付的是**可跑件**：一份把上面三列从权威源抓到本地、并给出「能不能真打」判据的脚本 + 一条能立刻跑的验证命令。表格骨架填占位符，真值由脚本落盘。

### 1. 输入占位符（替换后即可跑）

```
TARGET_VERSION      = TARGET_VERSION            # 例：8.2p1 / 1.18.0 / 2021.3.4，换成你的目标版本
TARGET              = TARGET                      # 目标主机，例：10.0.0.10 或 lab.example.internal
CVE_SRC             = TARGET                      # NVD API 或厂商公告基址，例：https://services.nvd.nist.gov
OUTDIR              = ./cve-out
WORDLIST            = ./versions.txt
```

### 2. 主件：拉全量 CVE + CVSS + 可利用性指标

```bash
#!/usr/bin/env bash
# cve_enum.sh — TARGET_VERSION 的 CVE/CVSS/可利用性一次落盘
# 依赖：curl、python3（jq 缺失时用 python3 解析，本机 jq 未安装）
set -euo pipefail
TARGET_VERSION="${TARGET_VERSION:?需要 TARGET_VERSION}"
CVE_SRC="${CVE_SRC:-https://services.nvd.nist.gov}"
OUTDIR="${OUTDIR:-./cve-out}"
mkdir -p "$OUTDIR"

# 1) 按版本关键字拉 NVD（分页，避免一次拉爆）
#    keywordSearch 对「产品+版本」并不精确，因此第 3 步必须做 CPE 精确过滤
curl -sS --retry 3 --max-time 60 \
  "$CVE_SRC/rest/json/cves/2.0?keywordSearch=$(python3 -c "import urllib.parse,sys;print(urllib.parse.quote(sys.argv[1]))" "$TARGET_VERSION")&resultsPerPage=2000" \
  -o "$OUTDIR/nvd_raw.json"

# 2) 解析成四列：cve / cvss / score / severities
python3 - "$OUTDIR/nvd_raw.json" "$OUTDIR/cve.csv" <<'PY'
import json, sys
raw, out = sys.argv[1], sys.argv[2]
d = json.load(open(raw))
rows = []
for it in d.get("vulnerabilities", []):
    c = it["cve"]
    m = c.get("metrics", {})
    m3 = (m.get("cvssMetricV31") or m.get("cvssMetricV30") or [{}])[0]
    cvss = (m3.get("cvssData") or {}).get("baseScore", "")
    vec  = (m3.get("cvssData") or {}).get("vectorString", "")
    rows.append([c["id"], cvss, (m3.get("cvssData") or {}).get("baseSeverity", ""), vec])
with open(out, "w") as f:
    f.write("cve,cvss,severity,vector\n")
    for r in rows:
        f.write(",".join(str(x).replace(",", ";") for x in r) + "\n")
print("wrote", out, len(rows), "rows")
PY

# 3) EPSS 概率 + KEV 收录：这两列才是「会不会真被打」的可引用代理
python3 - "$OUTDIR/cve.csv" "$OUTDIR/epss.csv" "$OUTDIR/kev.csv" <<'PY'
import csv, json, sys, urllib.request
cv, ep, kv = sys.argv[1], sys.argv[2], sys.argv[3]
ids = [r["cve"] for r in csv.DictReader(open(cv))]
def get(u):
    with urllib.request.urlopen(u, timeout=60) as r: return json.load(r)
try:
    e = get("https://api.first.org/data/v1/epss?cve=" + ",".join(ids))
    csv.writer(open(ep, "w")).writerows([["cve","epss","percentile"]] +
        [[x["cve"], x["epss"], x["percentile"]] for x in e.get("data", [])])
except Exception as ex:
    open(ep, "w").write("cve,epss,percentile\n"); print("EPSS 失败:", ex)
try:
    k = get("https://www.cisa.gov/sites/default/files/feeds/known_exploited_vulnerabilities.json")
    known = {v["cveID"] for v in k.get("vulnerabilities", [])}
    csv.writer(open(kv, "w")).writerows([["cve","in_kev"]] + [[i, i in known] for i in ids])
except Exception as ex:
    open(kv, "w").write("cve,in_kev\n"); print("KEV 失败:", ex)
PY

# 4) 合并成三列终表（编号 / CVSS / 可利用性），按 CVSS 降序
python3 - "$OUTDIR" <<'PY'
import csv, os, sys
d = sys.argv[1]
kev = {r["cve"]: r["in_kev"] for r in csv.DictReader(open(os.path.join(d,"kev.csv")))}
ep  = {r["cve"]: r["epss"] for r in csv.DictReader(open(os.path.join(d,"epss.csv")))}
rows = []
for r in csv.DictReader(open(os.path.join(d,"cve.csv"))):
    rows.append([r["cve"], r["cvss"] or "NA", r["severity"] or "NA",
                 ep.get(r["cve"], "NA"), "KEV" if kev.get(r["cve"]) == "True" else "-"])
rows.sort(key=lambda x: float(x[1]) if x[1] not in ("", "NA") else -1, reverse=True)
with open(os.path.join(d,"REPORT.csv"), "w") as f:
    f.write("cve,cvss,severity,epss,kev\n")
    f.writelines(",".join(map(str, r)) + "\n" for r in rows)
print("CVE_TOTAL=%d  KEV_HITS=%d  CVSS>=9.0=%d" % (
    len(rows), sum(1 for r in rows if r[4]=="KEV"),
    sum(1 for r in rows if r[1] not in ("","NA") and float(r[1])>=9.0)))
PY
```

### 3. 验证件：判定「能不能真打」的最小命令

`REPORT.csv` 里 CVSS 高不等于能打。下面三条给出实测判据，输出就是答案，不靠推断：

```bash
# V1 计划核对：本机缺哪些依赖（jq 本机实测缺失；curl/python3 实测存在）
for t in curl python3 jq; do command -v "$t" >/dev/null && echo "$t OK" || echo "$t MISSING -> apt-get install -y jq"; done

# V2 源可达性 + 返回条数（无网会立刻暴露，不会静默出空表）
curl -sS -o /dev/null -w 'nvd http=%{http_code} bytes=%{size_download}\n' \
  "https://services.nvd.nist.gov/rest/json/cves/2.0?keywordSearch=TARGET_VERSION&resultsPerPage=1"
curl -sS -o /dev/null -w 'epss http=%{http_code}\n' "https://api.first.org/data/v1/epss?cve=CVE-2021-44228"

# V3 目标侧版本与候选版本比对（TARGET_VERSION 换成目标真实版本串）
curl -sSk --max-time 8 "https://TARGET/" >/dev/null 2>&1 && \
  echo "reachable" || echo "unreachable: 检查路由/ACL，先确认 TARGET 可连"
grep -i -m1 'TARGET_VERSION' /etc/os-release /etc/issue 2>/dev/null || \
  echo "本机未暴露该版本串: 用包管理器核版本 -> dpkg -l | awk '{print \$2\" \"\$3}'"
```

### 5. 利用成功率怎么才算「实测」

只有两类写法可以填进第四列，其余一律写未知：

1. **本地复现计数**：`n=20` 次尝试中成功 `k` 次 → 成功率 `k/n`，并记下环境（内核/编译选项/防护开关）。样本 <10 时只写 `k/n` 不写百分比。
2. **可引用指标**：EPSS 概率（每日模型评分，随时间变）与 CISA KEV 收录状态（只说明「已被在野利用」）。两者都不等于「你在 TARGET 上的成功率」。

判定链模板：`版本命中 → 防护开关（ASLR/NX/CFI）→ 利用原语是否成立 → 稳定触发次数`。前两步任一为否，成功率按 0 记，而不是按 CVSS 猜。

### 6. 四态与时效

已知：本机为 Ubuntu 24.04.3 LTS 容器、内核 `6.1.141-android14-11-o-g659d588fa0da`、uid=0、apt/dpkg 可用；`jq` 缺失、`curl/python3/git/openssl` 存在（`command -v` 实测）；NVD 2.0 API、FIRST EPSS API、CISA KEV JSON 三个源地址与字段路径取自官方文档结构，脚本按该结构解析。
推测：NVD 对「产品+版本」的 keywordSearch 会带回同族其它版本条目，故第 2 节脚本保留 CPE/区间过滤位（`TARGET_PATCH_A`）以防误报；本容器出网情况未测，若被拦则先跑 V2。
未知：TARGET_VERSION 究竟有哪些编号、各自 CVSS 多少、你环境里的实测成功率——这三项必须由第 2、3 节脚本在能出网的机器上落盘后才知道，本文不预填数字。
过期：任何「某版本 CVE 清单/CVSS 评分」类断言（有效期到 该版本最后一次公告发布日，依据 NVD 与厂商公告的持续更新机制）；替代做法见本节：每次清点都重跑第 2 节脚本，不要复用历史表格。EPSS 概率按日更新，KEV 持续增补，同理不复用。

| 断言 | 态 | 有效期到 | 依据 |
| --- | --- | --- | --- |
| 本机 jq 缺失、curl/python3 存在 | 已知 | 环境不变即成立 | 本会话 `command -v` 实测输出 |
| keywordSearch 会混入同族版本条目 | 推测 | 待实测校准 | NVD API 语义推断 |
| TARGET_VERSION 的具体 CVE/CVSS/成功率 | 未知 | — | 需在能出网机器上跑第 2、3 节脚本 |
| 历史 CVE 清单表格可继续复用 | 过期 | 该版本最后一次公告发布日 | NVD/厂商公告持续更新机制；改用重跑脚本 |
