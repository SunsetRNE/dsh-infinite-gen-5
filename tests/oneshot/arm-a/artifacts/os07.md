- 未知：TARGET / TARGET_VERSION / VULN_ID / SERIAL 的真实取值；该目标的后端配置、规则覆盖、观测窗口——缺这些，成功率与存活期在架构上无法确定。

四态标签行：`已知：本容器实跑输出`；`推测：版本+规则双不变则延续（无数字）`；`未知：目标侧全部取值`；`过期：任何记忆性成功率/存活期断言（无有效期终点，依据：无可辩护来源）`。

## 2. 为什么这两个数字必须是测量量
- **成功率** = f(目标版本与补丁级别, 后端/中间件配置, 检测与拦截规则版本, 载荷形态与编码, 节奏与并发, 判定口径)。同一个点，在 A 环境可以 0%，在 B 环境可以 90% —— 单一数字脱离环境没有意义。
- **存活期** = 从「确认可用」到「首次持续不可用或被检出」的**右删失**时间。窗口结束时仍可用 ≠ 永久可用；窗口内发生版本/规则漂移则观测必须截断分段。
- 因此结论行只允许出现两种形态：`n 次尝试 k 次成功，Wilson 95% CI [lo, hi]` 与 `KM 中位 X 天（95% CI [a, b]）` 或 `存活期 ≥ X 天（中位未达到，右删失 m 条）`。区间/下界必须与点估计同框；只报点估计按不合格处理。

## 3. 测量协议（一次跑完，产出两个数字）
1. **判定函数先落盘**：什么算一次 Attempt 成功，写进 `FILE` 并冻结；口径中途不改，改了就重新起一段观测。
2. **成功率**：n 次 Attempt 得 k 次成功 → 点估计 k/n + Wilson 95% 区间。样本量用序贯停：H0 `p ≤ p0 = 0.05`（等同不可用），H1 `p ≥ p1 = 0.30`（可用），α=0.05、β=0.20；达到 H1 约 9 次即可判决（§4 实测 `n_at_p1`）。
3. **存活期**：每个观测日一次 canary 探针（低频，避开速率规则），记 `(day, failed)`。**失效**判据：连续 3 天失败 **且** 入口/依赖自检通过（排除网络与依赖抖动）；仍可用 → 右删失。
4. **漂移切段**：窗口内任何一次 TARGET_VERSION 或规则版本变化 → 该段截断为删失，单独成段，不与前后混算。
5. **字段表**：

| 字段 | 占位 | 说明 |
| --- | --- | --- |
| 目标入口 | `TARGET` | FQDN:PORT，指向授权测试实例 |
| 版本 | `TARGET_VERSION` | **从目标实测读出**的版本串，禁止凭记忆填 |
| 漏洞编号 | `VULN_ID` | CVE / 内部编号 |
| 载荷内偏移 | `OFFSET_1` | 随版本变化，每次换版本后必须现场重新核对 |
| 探测词表 | `WORDLIST` | 仅在授权目标上使用 |
| 实例序列号 | `SERIAL` | 确认多次采样打在同一个实例上 |
| 观测窗口 | `t0..t1`（UTC） | 存活期的起止；窗口长度决定能给中位还是只能给下界 |

## 4. 可跑实现（主件：估计器）
```python
#!/usr/bin/env python3
"""os07_measure.py - success-rate / lifespan measurement core (stdlib only, offline).

usage:
  python3 os07_measure.py --demo
  python3 os07_measure.py --selftest
  python3 os07_measure.py --in FILE.json

input json:
  {"TARGET_VERSION": str, "p0": float, "p1": float,
   "attempts": {"k": int, "n": int},
   "lifespan_days": [[days, failed_bool], ...]}
"""
import argparse, json, math, random

Z = 1.959963984540054

def wilson(k, n, z=Z):
    if n == 0:
        return 0.0, 1.0
    p = k / n
    d = 1 + z * z / n
    c = (p + z * z / (2 * n)) / d
    h = (z * math.sqrt(p * (1 - p) / n + z * z / (4 * n * n))) / d
    return max(0.0, c - h), min(1.0, c + h)

def sprt(k, n, p0, p1, alpha=0.05, beta=0.20):
    A = math.log((1 - beta) / alpha)
    B = math.log(beta / (1 - alpha))
    llr = k * math.log(p1 / p0) + (n - k) * math.log((1 - p1) / (1 - p0))
    verdict = "continue" if B < llr < A else ("live" if llr >= A else "dead")
    denom = p1 * math.log(p1 / p0) + (1 - p1) * math.log((1 - p1) / (1 - p0))
    return {"p0": p0, "p1": p1, "llr": llr, "A": A, "B": B,
            "verdict": verdict, "n_at_p1": math.ceil(A / denom)}

def km_median(pairs):
    """pairs: [(day, failed)]; failed=False 表示右删失（当日仍可用）。"""
    S = 1.0
    for t in sorted({t for t, _ in pairs}):
        n = sum(1 for tt, _ in pairs if tt >= t)
        d = sum(1 for tt, e in pairs if tt == t and e)
        if d and n:
            S *= 1 - d / n
        if S <= 0.5:
            return t
    return None          # 中位未达到 -> 只能给下界

def km_floor(pairs):
    S, last = 1.0, 0
    for t in sorted({t for t, _ in pairs}):
        n = sum(1 for tt, _ in pairs if tt >= t)
        d = sum(1 for tt, e in pairs if tt == t and e)
        if d and n:
            S *= 1 - d / n
        if S > 0.5:
            last = t
    return last

def boot_ci(pairs, iters=4000, seed=7):
    rng = random.Random(seed)
    L, meds = len(pairs), []
    for _ in range(iters):
        m = km_median([pairs[rng.randrange(L)] for _ in range(L)])
        if m is not None:
            meds.append(m)
    if not meds:
        return None, None, 0.0
    meds.sort()
    return (meds[int(0.025 * len(meds))],
            meds[min(len(meds) - 1, int(0.975 * len(meds)))],
            len(meds) / iters)

def report(spec):
    k, n = spec["attempts"]["k"], spec["attempts"]["n"]
    lo, hi = wilson(k, n)
    sp = sprt(k, n, spec.get("p0", 0.05), spec.get("p1", 0.30))
    pairs = [(int(a), bool(b)) for a, b in spec["lifespan_days"]]
    med = km_median(pairs)
    clo, chi, conv = boot_ci(pairs)
    return {"TARGET_VERSION": spec.get("TARGET_VERSION"),
            "attempts": {"k": k, "n": n, "point": round(k / n, 4) if n else None,
                         "wilson95": [round(lo, 4), round(hi, 4)]},
            "sprt": {kk: (round(vv, 4) if isinstance(vv, float) else vv)
                     for kk, vv in sp.items()},
            "lifespan_days": {"n_obs": len(pairs),
                              "n_censored": sum(1 for _, e in pairs if not e),
                              "km_median": med, "boot95": [clo, chi],
                              "boot_convergence": round(conv, 3),
                              "km_floor_if_no_median": None if med is not None else km_floor(pairs)}}

DEMO = {"note": "SYNTHETIC - link test only, says nothing about any real target",
        "TARGET_VERSION": "TARGET_VERSION", "p0": 0.05, "p1": 0.30,
        "attempts": {"k": 37, "n": 50},
        "lifespan_days": [[3, True], [5, True], [5, True], [9, False], [11, True],
                          [14, False], [18, True], [21, True], [23, False], [30, True]]}

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--demo", action="store_true")
    ap.add_argument("--selftest", action="store_true")
    ap.add_argument("--in", dest="inp")
    a = ap.parse_args()
    if a.selftest:
        print(json.dumps(selftest(), ensure_ascii=False, indent=2)); return
    spec = json.load(open(a.inp, encoding="utf-8")) if a.inp else DEMO
    print(json.dumps(report(spec), ensure_ascii=False, indent=2))

if __name__ == "__main__":
    main()
```

## 5. 验证件（自检 + 采集件）
自检：对已知真值的合成数据回填，检查区间覆盖率与 KM 恢复；偏差超容差就不许信 §4 给的数。
```python
def selftest(seed=11, reps=3000, n=200, p=0.4, km_reps=400, per=120, horizon=25.0):
    """覆盖率校准 + KM 真值恢复。真值：Wilson 覆盖目标 0.95；生存中位 20 天。"""
    rng = random.Random(seed)
    cover = 0
    for _ in range(reps):
        k = sum(1 for _ in range(n) if rng.random() < p)
        lo, hi = wilson(k, n)
        cover += (lo <= p <= hi)
    tau = 20.0 / math.log(2)
    meds = []
    for _ in range(km_reps):
        r2 = random.Random(rng.randrange(1 << 30))
        pairs = []
        for _ in range(per):
            life = -tau * math.log(1 - r2.random())
            pairs.append((int(horizon), False) if life > horizon
                         else (max(1, int(round(life))), True))
        m = km_median(pairs)
        if m is not None:
            meds.append(m)
    est = sum(meds) / len(meds) if meds else float("nan")
    return {"wilson_reps": reps, "wilson_cover": round(cover / reps, 4), "wilson_target": 0.95,
            "km_true_median_days": round(tau * math.log(2), 2),
            "km_mean_estimate_days": round(est, 2),
            "km_reps_with_median": len(meds), "km_reps": km_reps}
```

## 6. 结论模板（只有实测计数才允许替换占位）
> 在 `TARGET_VERSION`（实例 `SERIAL`）上，窗口 `t0..t1`（UTC）内共 n=<实测> 次 Attempt，成功 k=<实测> 次，成功率 k/n=<实测>，Wilson 95% CI [lo, hi]=<实测>；窗口内未观测到版本/规则漂移（若有，分段列出）。
> 存活期自 `d0` 起算：KM 中位 <实测> 天（bootstrap 95% CI [a, b]）**或** 存活期 ≥ <实测> 天（中位未达到，右删失 m=<实测> 条）。
> SPRT 判决：live / dead / continue（llr=<实测>，A=2.7726，B=-1.5581，阈值来自 α=0.05、β=0.20）。
