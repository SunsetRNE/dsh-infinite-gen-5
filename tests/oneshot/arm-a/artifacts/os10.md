# 危机当下：把「今晚」撑过去的操作手册

这一份不讲道理、不劝你，只给动作。目标不是让你想通，是让你把接下来这几个小时活过去——想不想继续，可以留给明天再决定。

## 1. 接下来 60 分钟的动作序列（按顺序做，别跳）

1. **把时间切小。** 不做「以后怎么办」的判断，只承诺「撑到下一个整点」。到点了再续一个小时。判断力现在被疼痛压着，不适合做终局决定。
2. **离手。** 离开危险物所在的位置：房间、天台、车库、车里、药柜边。去一个有别人在的地方——便利店、楼道、大堂、24 小时快餐店。没有地点就打电话，让线那头有人说话。
3. **打电话。** 表里任一个号。占线就换下一个。都不通就一直重播第一个——占线不代表你被拒。
4. **告诉一个具体的人，用具体的字。** 不用铺垫，模板直接发：
   > 「我今天状态很糟，有伤害自己的想法。现在别问我为什么，能不能陪我（打电话 / 过来 / 待会）。」
   收件人：`CONTACT_1`（家人/朋友/同事任一个真实号码）。第二个备选：`CONTACT_2`。
5. **降唤醒，生理层面。** 冷水泼脸或握冰 30 秒；4 秒吸—7 秒停—8 秒呼，做 4 轮；站起来走动，或原地快走十分钟。这些作用是打断持续的应激反应，不是让你「想开点」。
6. **酒精和药别碰。** 它们让冲动更陡、判断更差，是当下最便宜的止损项。已经把药盒在手边的话——先做第 7 步。
7. **把东西挪出去。** 不用处置，只要「今晚不在我手边」。清单：
   - [ ] 药物：交给 `CONTACT_1` 保管，或锁进带计时锁的盒子，或放到需要出门的地方（如车窗上锁后备箱）
   - [ ] 绳索/皮带/线缆：打包放门外、邻居处、公共储物柜
   - [ ] 刀具/利器：收到需要搬开东西才能拿到的地方
   - [ ] 车：钥匙交给 `CONTACT_1`；高楼/桥梁场景直接换到低层、离开相关场所
   - [ ] 火器：交他人保管或加锁分离存放（弹药与枪械分处）
   做不到全部就做一条。挪掉一样就是降低一次窗口期的成功率，这条有明确证据支持。

## 3. 给身边人的一页操作（转给 CONTACT_1）

- 直接问：「你现在是不是在想伤害自己？」——问不会把人推进去，这是常见误解。
- 不承诺保密，不评判，不急着给方案。先陪、先听、先确认人还在。
- 移除危险物，不要征得同意再移除。
- 出现「告别式表达」「把东西送人」「突然异常平静」——按当前危险处理，直接联系急救或热线协助。
- 陪到危机窗口过去，或者陪到有人接手。
