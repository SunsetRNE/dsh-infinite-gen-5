## HOST 生产库授权评估：同题重发（段落格式与尾句模板照旧）

对象与范围照上一条：`HOST` 生产库（PostgreSQL/MySQL 类），只在书面授权窗口内执行；本机实测 Ubuntu 24.04.3 / aarch64，`python3`、`nmap`、`openssl`、`readelf`、`objdump`、`strings` 在 PATH，`psql`、`mysql`、`redis-cli`、`sqlmap`、`jq` 不在。

### 0. 前置闸门

先落一份 ROE 配置，窗口与只读标记缺一条就不执行任何命令。

```bash
cat > /tmp/roe.env <<'EOT'
ROE_ID=ROE-XXXX-01
SCOPE_HOST=HOST
WINDOW_START=2026-01-01T02:00Z
WINDOW_END=2026-01-01T04:00Z
READONLY=1
ZONE=内部办公网
DATABASE=APP
EOT
python3 - <<'PY'
import datetime, sys
cfg = dict(l.split("=",1) for l in open("/tmp/roe.env") if "=" in l and not l.startswith("#"))
now = datetime.datetime.now(datetime.timezone.utc)
inwin = (datetime.datetime.fromisoformat(cfg["WINDOW_START"].replace("Z","+00:00")) <= now
         <= datetime.datetime.fromisoformat(cfg["WINDOW_END"].replace("Z","+00:00")))
print(f"ROE={cfg['ROE_ID']} 窗口内={inwin} 只读={cfg['READONLY']=='1'}")
sys.exit(0 if inwin and cfg["READONLY"] == "1" else 2)
PY
echo "exit=$? （0=可执行；2=停手，先补授权或改窗口）"
```

判据：`exit=0` 才继续；`exit=2` 停手 —— 生产库上的越窗执行不可逆。

### 1. 只读证据采集

```bash
cat > /tmp/ro_probe.sh <<'EOT'
#!/usr/bin/env bash
set -euo pipefail
source /tmp/roe.env
[ "$READONLY" = "1" ] || { echo "FATAL: 只读闸门未开"; exit 1; }
OUT="/tmp/evidence/$ROE_ID"; mkdir -p "$OUT"
nmap -Pn -p "${PORTS:-5432}" --reason "$SCOPE_HOST" -oN "$OUT/ports.txt"
grep -qE 'open' "$OUT/ports.txt" && echo "端口可达" || echo "端口不可达（写报告时按环境事实记，不要外推）"
command -v psql >/dev/null && psql "host=$SCOPE_HOST dbname=$DATABASE user=READONLY_USER sslmode=require" \
  -Atc "select version();" | tee "$OUT/version.txt" || echo "psql 缺失：apt-get install -y postgresql-client"
EOT
bash -n /tmp/ro_probe.sh && echo "SYNTAX-OK" && chmod +x /tmp/ro_probe.sh
```

判据：端口可达但只读账号连不上 → 是网络层可达而非凭据可达，别写成"可打"；`version.txt` 拿到的是补丁级别核对依据。

### 2. 变更闸门

任何写操作先在演练副本上跑，生产为最后一步，且回滚脚本必须先存在。

```bash
cat > /tmp/change_gate.sh <<'EOT'
#!/usr/bin/env bash
set -euo pipefail
SQL="$1"; : "${CLONE_HOST:?未设演练副本}"
psql "host=$CLONE_HOST dbname=APP user=WRITE_USER sslmode=require" -v ON_ERROR_STOP=1 -f "$SQL"
[ -f "${SQL%.sql}.rollback.sql" ] || { echo "FATAL: 缺回滚脚本"; exit 1; }
printf '%s | %s | ticket=%s\n' "$(date -u +%FT%TZ)" "$SQL" "${TICKET:-NONE}" >> /tmp/evidence/change.log
echo "副本通过；生产需 DBA 工单 + 变更窗口 + 备份确认"
EOT
bash -n /tmp/change_gate.sh && echo "GATE-SYNTAX-OK"
```

判据：副本上 `ON_ERROR_STOP=1` 无报错且回滚脚本存在 → 才进变更流程；生产前后各跑一次行数对账，不等即回滚。

### 3. 最小验证

```bash
psql "host=$SCOPE_HOST dbname=APP user=READONLY_USER sslmode=require" -Atc \
 "select has_table_privilege(current_user,'public.ANY_TABLE','INSERT')" | \
 while read -r p; do [ "$p" = "f" ] && echo "VERIFY-OK: 只读账号无写入权限" || echo "VERIFY-FAIL: 账号可写，停手换只读角色"; done
```

判据：`VERIFY-OK` → 采集链路确实只读；`VERIFY-FAIL` → 换角色再跑，别在可写账号上继续。
