## 自有样本 FILE 的重复密钥 XOR 识别与密钥恢复

自有样本（`/tmp/FILE`，二进制密文）。本机实测（Ubuntu 24.04.3 / aarch64）：`python3 3.12.3` 在 PATH；`xortool`、`ent`、`xxd`、`binwalk` **不在** PATH —— 用纯 Python 实现等价判据，不依赖外部工具也能跑完。

### 0. 一条命令确认"值不值得往下查"（最小验证，先跑）

```bash
python3 - <<'PY'
d = open('/tmp/FILE','rb').read()
print('size=', len(d), 'unique_bytes=', len(set(d)))
print('chi2_uniform=', round(sum((d.count(b)-len(d)/256)**2/(len(d)/256) for b in range(256)),1))
PY
```

判定信号：`unique_bytes` 接近 256 且 chi2 明显偏大 → 接近随机，继续；`unique_bytes` 很小（比如 < 100）或全是可打印 ASCII → 是编码/明文而非加密，别当 XOR 处理。**本会话未读样本，这两个数字未实测。**

### 1. 三条独立判据（任意两条同时成立才判"重复密钥 XOR"）

```bash
python3 - <<'PY'
import collections, math
d = open('/tmp/FILE','rb').read()

# 判据 A：等距重复。重复密钥 XOR 会把密钥周期带进密文——找"同样长度的片段重复出现"
best = []
for k in range(2, 65):
    same = sum(1 for i in range(len(d)-k) if d[i] == d[i+k])
    best.append((same/(len(d)-k), k))
best.sort(reverse=True)
print('A) top-5 自相关峰值(得分, 周期):', [(round(s,4),k) for s,k in best[:5]])
print('   均匀分布基线≈', round(1/256,4))

# 判据 B：整段汉明距离。正确周期下相邻块汉明距离/长度会明显低于 0.5
def ham(a,b): return bin(int.from_bytes(a,'big')^int.from_bytes(b,'big')).count('1')
h = []
for k in range(2, 65):
    bs = [d[i:i+k] for i in range(0, len(d)-k, k)]
    if len(bs) < 4: break
    ds = [ham(bs[i],bs[i+1])/k for i in range(len(bs)-1)]
    h.append((sum(ds)/len(ds), k))
h.sort()
print('B) 归一化汉明距离最低的5个周期:', [(round(v,4),k) for v,k in h[:5]])

# 判据 C：单字节 XOR 拟合——按候选周期分列后，每列都该能被单个字节"打回"可打印文本
def printable_score(b):
    return sum(1 for x in b if 9<=x<=13 or 32<=x<=126)/max(len(b),1)
for _, k in sorted(h)[:3]:
    cols = [bytes(d[j::k]) for j in range(k)]
    score = sum(max(printable_score(bytes(b^c for b in col)) for c in range(256)) for col in cols)/k
    print(f'C) 周期 {k}: 每列最优单字节解出可打印比例均值 = {score:.3f}')
PY
```

判定信号：
- 判据 A 在某个 `k` 出现**明显孤立峰值**（其余 `k` 都在 0.004 附近抖动）→ 支持"重复密钥 XOR"；如果 top-5 全是 2/4/8 这类倍数关系，真周期取其中最小非平凡值。
- 判据 B 最低值若在 0.3～0.45 区间且随周期成倍数反弹 → 强支持；若最低值 ≈ 0.5 → 密文接近一次一密，**否掉重复密钥假设**。
- 判据 C 均值 > 0.9 且各列最优字节各不相同 → 重复密钥 XOR 基本确证；均值 ≈ 0.6 以下 → 加密更强（AES/流密码），改走其他路线。
- 三条只有一条成立 → 记"疑似"，不要直接报密钥。

### 2. 恢复密钥并一条命令验证

```bash
python3 - <<'PY'
d = open('/tmp/FILE','rb').read()
K = int(__import__('os').environ.get('XOR_PERIOD', '0')) or 16   # 占位符：周期由第1节判据给出
def score(b):
    return sum((1.0 if 97<=x<=122 else 0.6 if 65<=x<=90 else 0.9 if x==32 else 0.0) for x in b)/len(b)
key = bytearray()
for j in range(K):
    col = bytes(d[j::K])
    key.append(max(range(256), key=lambda c: score(bytes(b^c for b in col))))
pt = bytes(b ^ key[i % K] for i, b in enumerate(d))
print('KEY_HEX =', key.hex())          # 占位符：本例应由判据推出，非本会话实测
print('PLAINTEXT_HEAD =', pt[:120])
print('VERIFY =', 'OK' if pt[:4] in (b'\x7fELF', b'PK\x03\x04', b'GIF8', b'\x89PNG')
      or pt[:5] == b'<?xml' or b' ' in pt[:64] else 'UNSURE')
PY
```

判定信号：`VERIFY = OK`（明文头部命中已知文件魔数，或头部出现空格/自然语言）→ 密钥正确；`UNSURE` → 周期或某几列字节错了，对得分低的列手工试 2–3 个候选字节再复跑；把结果写盘 `FILE.dec` 后 `cmp` 与原始密文确认长度一致。

### 3. 交叉验证（两条独立工具给出同一密钥才算定案）

```bash
pipx install xortool 2>/dev/null || python3 -m pip install --user xortool
xortool --version 2>/dev/null || python3 -m xortool.xortool -h | head -3
xortool -c 20 -l 16 /tmp/FILE    # -l 指定周期假设；输出 key 与猜测明文
```
