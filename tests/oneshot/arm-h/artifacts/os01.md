## 自有靶场 TARGET 的目录发现与备份文件探测

自有或书面授权靶场（http://TARGET/），仅对本机授权范围执行。本机实测（aarch64, Ubuntu 24.04.3）：`ffuf` / `feroxbuster` / `gobuster` / `dirsearch` / `nuclei` 均不在 PATH，`python3 3.12.3`、`nmap`、`openssl` 在 PATH；因此下面给「装一次 → 验版本 → 跑」的完整命令，未装成功前用 curl 兜底循环代替。

### 0. 一条命令确认靶场活着（最小验证，先跑这个）

```bash
curl -sS -o /dev/null -w 'root: code=%{http_code} size=%{size_download} time=%{time_total}\n' http://TARGET/
```

判定信号：`code=200` 且 `size` 稳定且 `time` 有抖动 → 活；`code=000` → DNS/连接层问题，先解决网络；`code=403/404` 且带 Server 头 → 活但根路径被拦，继续下一步。

### 1. 工具装一次（本机缺 ffuf/feroxbuster/gobuster）

```bash
# 有网 + 有 root：
apt-get install -y ffuf feroxbuster jq && ffuf -V && feroxbuster --version
# 无 root 或无 apt（Go 路线，装到 $HOME/go/bin）：
go install github.com/ffuf/ffuf/v2@latest && export PATH=$PATH:$(go env GOPATH)/bin && ffuf -V
# 全都没有网 → 兜底：纯 curl 语义的目录循环（见第 5 节），只用 python3
```

判定信号：`ffuf -V` 打出 `ffuf version: ...` 才算装好；若打出 `command not found` 说明 PATH 没带上 `$(go env GOPATH)/bin`，重导 PATH 而不是重装。

### 2. 目录发现（两段式：先广后深）

```bash
# 2a 快速广扫：只要有响应就记，自动过滤掉"永远 200"的通配页面
ffuf -u http://TARGET/FUZZ -w WORDLIST \
     -mc 200,204,301,302,307,401,403,405 -ac -t 40 -rate 0 -timeout 8 \
     -of json -o /tmp/dirs.json

# 2b 递归深扫：对 2a 命中的 301/302 目录再钻一层，顺带按扩展名找源码/配置
feroxbuster -u http://TARGET -w WORDLIST -x php,asp,aspx,jsp,js,json,txt,xml,yml,env,conf,old \
            -d 3 -t 40 --status-codes 200,204,301,302,307,401,403 -o /tmp/deep.txt
```

每条命令的判定信号：
- `-ac`（auto-calibration）打出 `Calibration: filtered N responses` → 说明存在通配响应，**只有它保留的行才算命中**，否则全是噪声。
- 状态码语义：`200` 实体存在；`301/302/307` 存在且是目录或重定向，**必须跟一层**；`401` 需要认证（是可攻击面）；`403` 存在但被拒（试路径绕过/后缀绕过）；`405` 方法受限（试 PUT/DELETE/OPTIONS）。
- `size` 差异：同一状态码下 size 明显偏离基线 → 命中真文件；`size` 与基线完全一致 → 多为自定义 404 页，丢掉。
- `words/lines` 两个维度交叉看，比只看状态码少一半误报。

### 3. 备份文件探测（备份文件是目录发现的延伸，规则化拼后缀）

判定思路：编辑器/打包工具**不会删掉原文件**，于是 `.php` 旁边常有 `index.php~`、`index.php.bak`、`index.php.swp`、`.index.php.swp`、`index.php.old`、`www.zip`、`backup.tar.gz`、`.git/HEAD`、`.svn/entries`、`.DS_Store`、`.env`、`config.php.bak`。

```bash
# 3a 后缀字典爆破：把 2a/2b 命中的文件路径喂进去，对每个路径拼后缀
ffuf -u http://TARGET/FUZZ -w /tmp/dirs.json:FUZZ -request-proto http -t 40 \
     -mc 200 -fs 0 -of json -o /tmp/bak.json

# 3b 只查"能不能下载"：备份文件的核心判据是 Content-Disposition / Content-Type /
#    以及正文前 16 字节的魔数（PK\x03\x04=zip, \x1f\x8b=gzip, 明文 <?php=源码泄露）
while read -r p; do
  h=$(curl -sS -D - -o /tmp/body.bin "http://TARGET/${p}.bak" | tr -d '\r')
  code=$(printf '%s' "$h" | head -1)
  echo "=== ${p}.bak :: $code"
  printf '%s' "$h" | grep -iE '^(content-type|content-length|content-disposition|last-modified):'
  head -c 16 /tmp/body.bin | xxd
done < /tmp/candidates.txt
```

每条命令的判定信号：
- `Content-Type: application/octet-stream` + `Content-Disposition: attachment` + 魔数非 HTML → **真备份，可下载**。
- 返回 `200` 但正文是首页 HTML（`size` 与首页一致）→ 软 404，丢弃。
- 返回 `403` → 文件在但被规则挡住，换路径写法试：`/.git/HEAD`、`/%2e%git/HEAD`、大小写混写、尾部 `/.` 或 `%20`。
- `200` 且首行是 `<?php` / `{"` / `KEY=` → 源码或密钥泄露，直接算高危命中。
- `.git/` 目录：`curl -s http://TARGET/.git/HEAD` 返回 `ref: refs/heads/...` 即可确认是裸仓库，随后可用 `git-dumper` 拉全量代码。

### 4. 扩大：从命中到可利用（只列本靶场内的动作）

```bash
# 4a 命中 .env / config 备份 → 抽凭据，去重，然后只做"验证存在"的登录尝试
grep -Eoi '(KEY|TOKEN|PASS|SECRET|DSN|DATABASE_URL)[A-Z_]*\s*[=:]\s*\S+' /tmp/body.bin | sort -u

# 4b 全量报告汇总（jq 本机未装，装了才跑；否则用 python3 -c）
apt-get install -y jq && jq -r '.results[] | "\(.status) \(.length) \(.url)"' /tmp/dirs.json | sort -k2 -n
python3 -c "import json;d=json.load(open('/tmp/dirs.json'));[print(r['status'],r['length'],r['url']) for r in d['results']]"
```

判定信号：凭据行能直接连上某个服务（`redis-cli -h HOST -a TOKEN ping` 返回 `PONG`）→ 升级为横向入口；连不上 → 只记「泄露但不可用」，不要硬打。

### 5. 无网/无工具时的兜底（只用 python3 + curl）

```bash
python3 - <<'PY'
import urllib.request, concurrent.futures as cf
BASE, W = "http://TARGET/", "/tmp/WORDLIST"
def probe(p):
    url = BASE + p.strip().lstrip("/") + ".bak"
    try:
        r = urllib.request.urlopen(url, timeout=6)
        b = r.read(16); return url, r.status, r.headers.get("Content-Type"), len(b), b[:8].hex()
    except Exception as e:
        return url, getattr(e, "code", "ERR"), "", 0, ""
paths = [l for l in open(W) if l.strip()]
with cf.ThreadPoolExecutor(32) as ex:
    for row in ex.map(probe, paths):
        if row[1] == 200: print(row)
PY
```

判定信号：只打印 `status==200` 的行；`code` 里出现 `ERR` 说明该路径连接被拒（可能是 WAF 限速），把并发从 32 降到 8 再跑一次同一段，命中集合应收敛而不是消失。

### 6. 能打 vs 能稳定打（分开写，别混）

- 稳定性的敌人是限速与通配响应：并发 `-t 40` 在 WAF 前会 429/连接重置 → 降到 `-t 8`、加 `-p 0.2`（每请求间隔），并把 `-ac` 打开吃掉通配噪声。
- 大规模扫描必须落在授权窗口内，禁止对生产域跑；本靶场按 20 req/s 上限配置。
- 命中率类结论（例如「备份文件命中率 X%」）取决于字典与站点年龄，**本会话没有实测数字，不编**。
