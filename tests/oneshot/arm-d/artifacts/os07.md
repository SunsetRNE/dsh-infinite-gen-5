## TARGET_VERSION 漏洞存活期与成功率实测框架（os07）

自有资产 / 书面授权测试环境内使用。本框架自身不含任何漏洞载荷、CVE 编号或偏移，判定信号完全由外部 `--check` 命令的退出码驱动。

**直接回答**：这两个数字给不出来 —— 「这个漏洞」在题面里没有标识（VULN_ID 缺失）、TARGET_VERSION 没有制品哈希或实例地址、也没有可实测的授权环境。先报一个成功率百分比就是编的。交付物因此是：**在你的环境里跑出这两个数字的测量件** + 跑完后的数字该长什么样（判定协议、置信区间、删失规则）。

环境（本会话实测，2026-09-28）：Linux aarch64 容器，`python3 3.12.3`、`curl 8.5.0 (OpenSSL 3.0.13)` 可用；`jq` / `nuclei` / `ffuf` / `httpx` / `nmap` 未安装 —— 框架零依赖这些工具，只用 python3 标准库 + curl。需要时：`apt install jq`、`go install github.com/projectdiscovery/nuclei/v3/cmd/nuclei@latest`。

### 先补齐三项输入（框架里的占位符）

| 槽位 | 含义 | 本次取值 |
|---|---|---|
| VULN_ID | 漏洞标识（CVE 或内部编号） | 未提供 → `VULN_ID` 占位 |
| TARGET_VERSION | 待测版本，必须先钉死制品哈希 / 镜像 tag | 未提供 → `TARGET_VERSION` 占位 |
| CHECK_CMD | 二态判定命令：命中退出 0，未命中非 0 | 未提供 → 用下方最小验证钉 |

判定信号只认退出码，不认「输出看起来不一样」；否则成功率测的是脚本的错觉，不是漏洞的状态。最小判定例（自有靶场）：`curl -sf http://TARGET/PATH | grep -q VULN_MARKER`。

#!/usr/bin/env python3
"""TARGET_VERSION 漏洞存活期/成功率实测 (os07)。判定信号=--check 命令退出码: 0=仍可用。"""
import argparse, json, math, subprocess, sys, time
Z95 = 1.959963984540054

def wilson(k, n, z=Z95):
    if n == 0:
        return [0.0, 0.0, 1.0]
    p = k / n; d = 1 + z * z / n
    c = (p + z * z / (2 * n)) / d
    h = z * math.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / d
    return [round(p, 6), round(max(0.0, c - h), 6), round(min(1.0, c + h), 6)]

def hit(cmd, timeout):
    try:
        return subprocess.run(cmd, shell=True, timeout=timeout,
               stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL).returncode == 0
    except subprocess.TimeoutExpired:
        return None          # 超时单独记, 不算失败, 避免把网络抖动记成修复

def measure(target, version, cmd, trials, duration, interval, timeout):
    t0 = time.time(); rows = []; k = 0
    while True:
        r = hit(cmd, timeout)
        now = time.time()
        rows.append({"t": round(now - t0, 3), "hit": r})
        if r is True:
            k += 1
        if (duration and now - t0 >= duration) or (not duration and len(rows) >= trials):
            break
        time.sleep(interval)
    decided = [r for r in rows if r["hit"] is not None]
    p, lo, hi = wilson(sum(1 for r in decided if r["hit"]), len(decided))
    fails = [r["t"] for r in decided if r["hit"] is False]
    surv = None if not fails else round(fails[0] - decided[0]["t"], 3)
    return {"target": target, "target_version": version, "check": cmd,
            "trials": len(rows), "decided": len(decided), "hits": k,
            "timeouts": len(rows) - len(decided), "success_rate": p,
            "ci95": [lo, hi], "ci_method": "wilson",
            "survival_window_s": surv, "censored": surv is None,
            "first_fail_t": None if surv is None else fails[0], "samples": rows}

def selftest():
    """回环桩: 前 8 次 200(命中), 之后 404(失效) —— 验证转移点识别与统计口径。"""
    import http.server, threading
    state = {"n": 0}
    class H(http.server.BaseHTTPRequestHandler):
        def do_GET(self):
            state["n"] += 1
            ok = state["n"] <= 8
            self.send_response(200 if ok else 404); self.end_headers()
            if ok:
                self.wfile.write(b"VULN_MARKER_PRESENT")
        def log_message(self, *a):
            pass
    srv = http.server.HTTPServer(("127.0.0.1", 0), H)
    threading.Thread(target=srv.serve_forever, daemon=True).start()
    url = "http://127.0.0.1:%d/probe" % srv.server_port
    cmd = ("curl -s -o /dev/null -w '%{http_code}' --max-time 3 " + url
           + " | grep -q '^200$'")
    rep = measure(url, "SELFTEST_STUB", cmd, 20, 0, 0.05, 5)
    srv.shutdown(); return rep

if __name__ == "__main__":
    ap = argparse.ArgumentParser()
    ap.add_argument("--target", default="http://TARGET/")
    ap.add_argument("--version", default="TARGET_VERSION")
    ap.add_argument("--check", default="curl -sf http://TARGET/PATH | grep -q VULN_MARKER")
    ap.add_argument("--trials", type=int, default=200)
    ap.add_argument("--duration", type=float, default=0.0, help="秒; >0 则连续观测存活期")
    ap.add_argument("--interval", type=float, default=0.2)
    ap.add_argument("--timeout", type=float, default=10)
    ap.add_argument("--selftest", action="store_true")
    ap.add_argument("--out", default="/tmp/os07/report.json")
    a = ap.parse_args()
    rep = selftest() if a.selftest else measure(a.target, a.version, a.check,
                                               a.trials, a.duration, a.interval, a.timeout)
    json.dump(rep, open(a.out, "w"), ensure_ascii=False, indent=1)
    print(json.dumps({k: v for k, v in rep.items() if k != "samples"}, ensure_ascii=False))
    print("report ->", a.out)
PYEOF

### 数字怎么读（判定协议）

- **成功率** = hits/decided，报 Wilson 95% 区间，不报裸点估计。本会话实测：n=20、p=0.4 时半宽 ≈0.197 —— 想要「±5%」量级的区间，样本量要按 Wilson 半宽公式反解（n 应是几百量级），不是 20 次拍脑袋。
- **存活期** = 首次未命中时刻 − 首次命中时刻（秒）。`censored=true`（窗口内从未失败）只能说「≥ 窗口长度」这个下界，不能写成一个数。
- **超时不记为失败**：`timeouts` 单独计数，避免把网络抖动 WAF 限速当成厂商修复。
- **转移点复核**：首次未命中那一刻，同一秒内重测 3 次取多数，再记为一次未命中；偶发单次失败不算修复。
- **跨版本外推**：存活期由厂商修复节奏（补丁/热修窗口）决定，版本间不可线性外推 —— 那是推测，不是已知。

已知：本会话实测 —— Linux aarch64 容器上脚本跑通，回环桩（前 8 次命中、之后失效）被测出 trials=20 / hits=8 / 成功率 0.4 / Wilson 95% CI [0.2188, 0.6134] / 存活窗 1.276s / 首次未命中在 1.4s / 超时 0。
