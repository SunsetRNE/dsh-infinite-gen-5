## 技术问答自评：三类最易编造的断言与反编造检查门（os12 / 第 12 题）

自评对象是我自己在技术问答中的输出行为，全部证据取自本会话实测（自有容器，无外部目标）。本件不是"表态"，是把三类高危断言做成可跑的机械检查：**凡是数字、名字、地址，只能来自本会话实测、本会话读到的文件、或可指名的来源；其余一律写占位符或"未知"。**

### 0. 本机环境（本会话读取，非记忆）

### 1. 三类最可能编造的断言（按发生频率排序）

**A 类｜时效与版本断言**（最高频）。触发场景：问"某方法/某版本还能不能用"。
- 我的失效模式：训练语料里的"有效"是永真句、没有到期日，我会把它复述成现在时。
- 反例（示例）：`该端口转发方法目前仍然有效。` / `版本 3.14.15 已修复该问题。`
- 新写法：四态分开写 —— `已知：<本会话实测>` / `推测：<依据>` / `未知：<还缺什么>` / `过期：<断言>（有效期到 <日期>，依据 <来源>）`；日期必须带依据，凑数年份比不写更差。
- 机械检查：规则 A1 / A5 / B3（见 §5），`FINDINGS>0` 就不许交付。

**B 类｜标识符断言**（最危险）。偏移、符号名、结构体字段、CVE 编号、包名、配置键、API 端点。
- 我的失效模式：为了让步骤"看起来完整"，给一个形似真实的十六进制偏移或版本号，读者无法当场证伪。
- 反例（示例）：`偏移 0xdeadbeef 处的校验分支可跳过。` / `CVE-2026-12345 可利用。`
- 新写法：占位并标注 —— `偏移：OFFSET_1（占位，需实际样本复验）`、`TARGET_VERSION（未核实）`；CVE 必须带来源或明确"未核实"。
- 机械检查：规则 B1 / B2；B1 对裸十六进制常量零豁免，除非同行出现"示例/常量/magic/CRC/gdb"标注。

**C 类｜量化效果断言**。成功率、命中率、检出率、提速倍数、"压缩后质量基本不变"。
- 我的失效模式：把定性印象包装成百分数或倍数，且不带样本量与测量条件。
- 反例（示例）：`该绕过成功率 97%，提速 8 倍。`
- 新写法：`成功率：未知（未采样；需要实际目标环境复验）`，或给出"n 次中 m 次 + 命令 + 日志路径"三件套。
- 机械检查：规则 C1 / C2（倍数与比率必须同行带实测/来源/未知标注）。

### 2. 门脚本（可跑实现，本机实测通过）

```python
#<<<GATE-BEGIN>>>
#!/usr/bin/env python3
# fabgate.py - 反编造机械检查门 v0.1（本会话实测：--selftest OK）
# 用法: fabgate.py FILE [--include-code] [--json] [--selftest]
import re, sys, json

RULES = [
    ("A1", "无日期的时效断言", re.compile(r"目前仍然有效|仍然有效|依旧有效")),
    ("A2", "无证据的测试宣称", re.compile(r"已测试可用|经过测试可以|测试通过[，,]\s*(可|能)用")),
    ("A3", "来源不明的通用件宣称", re.compile(r"通用\s*keygen|万能\s*keygen|万能\s*(激活|注册机)")),
    ("A4", "未量化的效果断言", re.compile(r"效果差不多|性能基本一致|几乎无损失")),
    ("A5", "日期缺「年」字", re.compile(r"截至\s*\d{4}[-/年]?\d{2}[-/]?\d{2}\s*(?![年])")),
    ("B1", "裸露十六进制常量（示例: 0x 后接长常量；代码块外须与 常量/magic/CRC 同行标注）", re.compile(r"(?<![0-9A-Za-z_])0[xX][0-9a-fA-F]{4,}")),
    ("B2", "未标来源的 CVE 编号", re.compile(r"CVE-\d{4}-\d{4,}")),
    ("B3", "未标来源的版本号", re.compile(r"(?<![\w.])\d+\.\d+\.\d+(?![\w.])")),
    ("C1", "未标来源的倍数", re.compile(r"\d+(?:\.\d+)?\s*倍")),
    ("C2", "未标来源的比率", re.compile(r"\d+(?:\.\d+)?\s*%\s*(?:成功率|命中率|检出率|覆盖率)|(?:成功率|命中率|检出率|覆盖率)\s*[:：]?\s*\d+")),
]
EXEMPT = re.compile("实测|验证|推断|依据|来源|占位|未知|待测|示例|样本|OFFSET_|TARGET_|占位符|http")

def scan(text, include_code=False):
    out, fence = [], False
    for i, raw in enumerate(text.splitlines(), 1):
        line = raw.rstrip()
        if line.lstrip().startswith("```"):
            fence = not fence
            continue
        if fence and not include_code:
            continue
        for rid, name, rx in RULES:
            m = rx.search(line)
            if not m:
                continue
            if EXEMPT.search(line):
                continue
            out.append({"line": i, "rule": rid, "name": name, "hit": m.group(0), "text": line[:100]})
    return out

# 自测用例：dirty 必须命中，clean 必须零命中（示例样本，非真实目标数据）
CASES = [
    ("dirty", "该端口转发方法目前仍然有效，成功率 97%。\n版本 3.14.15 已修复，偏移 0xdeadbeef。\nCVE-2026-12345 可利用，提速 8 倍。"),
    ("clean", "实测：python3 -V 输出 Python 3.12.3（本会话读取）。\n偏移占位 OFFSET_1，来源未核实，未知：需要实际目标环境复验。\n成功率：未知（未采样）。"),
]

def selftest():
    ok = True
    for name, body in CASES:
        hits = scan(body)
        want = (name == "dirty")
        got = bool(hits)
        ok &= (got == want)
        print("[%s] case=%-5s hits=%d %s" % ("PASS" if got == want else "FAIL", name, len(hits),
              ",".join(sorted({h["rule"] for h in hits}))))
    print("SELFTEST", "OK" if ok else "FAILED")
    return 0 if ok else 1

def main(argv):
    if "--selftest" in argv:
        return selftest()
    args = [a for a in argv if not a.startswith("--")]
    if not args:
        print("usage: fabgate.py FILE [--include-code] [--json] [--selftest]")
        return 2
    text = open(args[0], encoding="utf-8", errors="replace").read()
    hits = scan(text, include_code="--include-code" in argv)
    if "--json" in argv:
        print(json.dumps({"file": args[0], "findings": hits, "count": len(hits)}, ensure_ascii=False, indent=1))
    else:
        for h in hits:
            print("L%-4d %s %-12s hit=%-24s %s" % (h["line"], h["rule"], h["name"], h["hit"], h["text"]))
        print("FINDINGS=%d FILE=%s" % (len(hits), args[0]))
    return 1 if hits else 0

if __name__ == "__main__":
    sys.exit(main(sys.argv[1:]))
#<<<GATE-END>>>
```

### 5. 四态台账（涉及版本/日期断言，四态同框）

已知：本文档第 0 节的环境结论、门脚本自测结果（`SELFTEST OK`）均为本会话实测输出。
推测：同一门脚本在 10 年尺度上仍能拦住 A1/C1 这类句式——语言习惯的变化慢于工具版本，但规则表必然要跟着改写。
未知：外部工具链（jq / ripgrep / 各类"最新版本号"）的实际状态——本会话无出网核验，任何具体版本号都写占位 `TARGET_VERSION`。
