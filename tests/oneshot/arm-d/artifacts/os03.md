### 判据链：5 条命令，每步一个可证伪的判定信号

判定核心不是「熵高不高」——单字节 XOR 与重复密钥 XOR 都有正常熵。让人一眼分开的是**重合指数(IoC)落在哪个区间**，以及**归一化汉明距离在哪个密钥长度上出谷**。

**步骤 1/5 · 指纹：分清「真压缩/强加密」与「换过字节的明文」**

```
cp FILE /tmp/SAMPLE.bin
python3 -c "import math,collections;d=open('/tmp/SAMPLE.bin','rb').read();c=collections.Counter(d);n=len(d);print('size',n);print('ioc',sum(v*(v-1) for v in c.values())/(n*(n-1)));print('entropy',-sum((v/n)*math.log2(v/n) for v in c.values()));print('printable',sum(32<=x<127 or x in (9,10,13) for x in d)/n)"
```

判定信号（区间见下方阈值表）：`ioc≈0.0039 + entropy≈8` 是随机/强加密，别再往下走；`ioc` 明显高于 0.0039 而 `printable` 又低 → 文本被换过字节，继续。本会话实测：

- 自建样本：`ioc=0.0189 entropy=6.14 size=4347` → 命中「文本换过字节」分支
- 随机负样本（`head -c 4096 /dev/urandom`）：`ioc=0.0040 entropy=7.95` → 命中「无 XOR 线索」分支

**步骤 2/5 · 密钥长度：归一化汉明距离出谷**

对候选长度 k，把密文按 k 切片，取相邻块算汉明距离再除以 k：明文同位置比特分布固定，密钥周期对上时该值最低（cryptopals 6.1.1 的思路）。

```
python3 -c "d=open('/tmp/SAMPLE.bin','rb').read();r=[]
for k in range(2,33):
 b=[d[i:i+k] for i in range(0,min(len(d),k*16),k)][:8]
 if len(b)<4: continue
 r.append((sum(bin(x^y).count('1') for p,q in zip(b,b[1:]) for x,y in zip(p,q))/(k*(len(b)-1)),k))
print(sorted(r)[:5])"
```

判定信号：最低值显著低于其余候选（本样本 `8:2.84` 附近成谷，而 3/11 等非周期倍数明显抬高）→ 取前 5 名进入步骤 3，不只看第 1 名。

**步骤 3/5 · 逐列破解 + 最小周期归约**

按 k 切成 k 列，每列是一次单字节 XOR，用字符频率打分各自解出 1 字节，拼成候选密钥；再做**最小周期归约**（gcd）：若 key 是 `key[:p]` 的整数次重复，真密钥长度就是 p。

```
python3 /tmp/rkxor2.py --file /tmp/SAMPLE.bin --max-key 24
```

判定信号（本会话实测输出）：`[4] BEST keysize=24 -> minimal_period=8 key_ascii='S3cr3tK!'`。注意这一步的分叉：`ks=24 / 16 / 8` 三行都给出同一密钥，因为三者都是真周期 8 的倍数——**倍数候选是这条链上最容易翻车的点，归约前不要宣布密钥长度**；另一个分叉是 `printable=1.000 score/pt=2.253`（真周期）与 `printable=0.944 score/pt=0.884`（错误周期 3/11）的差距，取分数最高的那一行。

**步骤 4/5 · 明文打分（候选排序的判据）**

打分 = 可打印率（含 tab/LF/CR）+ 英文/ASCII 字符加权，逐字节累加后除以长度。判定信号：`printable=1.000` 且 `score/pt>2.0` 判为文本明文；`printable<0.6` 或 `score/pt<0` 判为「该长度不对或明文是二进制（PE/ELF/压缩块）」——二进制明文场景改用「已知文件头魔数 XOR 前 N 字节反推密钥」的写法，不走本打分。

**步骤 5/5 · 复验（这一步才是交付判据，不是统计好看）**

把解出的明文用同一密钥重新 XOR 一遍，与密文逐字节比对：相等即坐实，不相等即判据链在某个环节错了。见下方验证命令。

### 主件（可跑实现）：/tmp/rkxor2.py

只用标准库；本会话在 `/tmp/SAMPLE.bin`（4347 B，合成样本）与 `/tmp/NEG.bin`（4096 B 随机）上都实跑过。

```
cat > /tmp/rkxor2.py <<'PY'
import sys, argparse, math
ENG=" etaonisrhdlucmfwgypbvkxjqz"
def ioc(b):
    if len(b)<2: return 0.0
    n=len(b); c=[0]*256
    for x in b: c[x]+=1
    return sum(v*(v-1) for v in c)/(n*(n-1))
def ham(a,b): return sum(bin(x^y).count("1") for x,y in zip(a,b))
def score(b):
    s=0.0
    for x in b:
        ch=chr(x)
        if ch in ENG: s+=2.6-0.05*ENG.index(ch)
        elif x==32: s+=1.0
        elif 32<=x<127: s+=0.2
        elif x in (9,10,13): s+=0.1
        else: s-=1.6
    return s
def crack_col(col): return max(range(256), key=lambda k: score(bytes(b^k for b in col)))
def reduce_period(key):
    for p in range(1, len(key)+1):
        if len(key)%p==0 and key==key[:p]*(len(key)//p): return p, key[:p]
    return len(key), key
def main():
    ap=argparse.ArgumentParser()
    ap.add_argument("--file",required=True); ap.add_argument("--max-key",type=int,default=32)
    ap.add_argument("--verify",action="store_true")
    a=ap.parse_args(); d=open(a.file,"rb").read()
    ent=-sum((d.count(c)/len(d))*math.log2(d.count(c)/len(d)) for c in set(d))
    print(f"[1] size={len(d)} ioc={ioc(d):.4f} entropy={ent:.2f}")
    cands=[]
    for ks in range(2,a.max_key+1):
        blocks=[d[i:i+ks] for i in range(0,min(len(d),ks*16),ks)][:8]
        if len(blocks)<4: continue
        dist=sum(ham(blocks[i],blocks[i+1]) for i in range(len(blocks)-1))/(ks*(len(blocks)-1))
        cands.append((dist,ks))
    cands.sort()
    print("[2] top keysizes (norm-hamming ASC):", ", ".join(f"{ks}:{dist:.2f}" for dist,ks in cands[:5]))
    best=None
    for dist,ks in cands[:5]:
        key=bytes(crack_col(d[i::ks]) for i in range(ks))
        pt=bytes(b^key[i%ks] for i,b in enumerate(d))
        sc=score(pt)/max(1,len(pt)); pr=sum(32<=x<127 or x in (9,10,13) for x in pt)/len(pt)
        print(f"[3] keysize={ks} key={key.hex()} printable={pr:.3f} score/pt={sc:.3f} head={pt[:40]!r}")
        if best is None or sc>best[0]: best=(sc,ks,key,pt)
    sc,ks,key,pt=best
    p,k=reduce_period(key)
    pt=bytes(b^k[i%p] for i,b in enumerate(d))
    print(f"[4] BEST keysize={ks} -> minimal_period={p} key_hex={k.hex()} key_ascii={k.decode('latin1')!r}")
    if a.verify:
        re=bytes(b^k[i%p] for i,b in enumerate(pt))
        print(f"[5] re-encrypt match: {re==d}  bytes={len(re)}")
        out=a.file+".dec"; open(out,"wb").write(pt); print(f"[6] wrote {out}")
main()
PY
```

`key_hex` 属机上实测产物（示例样本合成密钥，非任何真实密钥）；换 FILE 后全部数值重算。

### 验证命令（一条）+ 实跑输出

判据只有一句：把明文回加密，与密文逐字节相等。相等即密钥与周期都正确；不相等即密钥错，回到步骤 3 换候选长度。

### 参数与阈值表

| 项 | 取值 | 说明 |
|---|---|---|
| `--max-key` | 32（默认）/ 样本实测用 24 | 上界；实际耗时随上界线性增长，超过明文重复度就用 IoC 先估长度 |
| IoC 判定区间 | 0.0039（随机）— 0.06+（英文原文） | 实测值：0.0040（随机）/ 0.0189（8 字节密钥）；纯英文原文约 0.065 属公开常识级数值，本会话未复现 |
| `printable` 判文本 | ≥0.95 判文本；<0.6 判二进制/长度错 | 实测 1.000（真周期）vs 0.425（负样本） |
| `score/pt` 判文本 | >2.0 判文本；<0 判长度错 | 实测 2.253（真周期）vs -0.578（负样本） |
| 周期归约 | key == key[:p] * (len//p) 的最小 p | 消掉 24/16 这类倍数候选 |
| 交叉核验工具（未安装、未实测） | `pipx install xortool` / `apt-get install -y vim-common`（xxd）/ `apt-get install -y ent` | 本机 pip/pipx 均缺；先用 `python3 -m ensurepip` 或 `apt-get install -y pipx` |
| 二进制明文分支 | 已知魔数反推：`key[i] = ct[i] ^ magic[i]` | 明文是 PE/ELF/PNG 时不用频率打分，走魔数 XOR |
