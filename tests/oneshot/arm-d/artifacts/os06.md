## TARGET_VERSION 已知 CVE 枚举件与利用可行性核验

面向自有资产 / 授权测试环境；本件是「版本 → CVE 编号 + CVSS + 可利用性」的可跑枚举流水线，不是一份凭记忆写出的漏洞清单。

### 1. 为什么三个答案列此刻是空的

`TARGET_VERSION` 在本轮是占位符，未绑定到具体「厂商:产品:版本」三元组。CVE 检索的键就是这三元组（或 CPE 名），键不存在，结果集不存在——任何填进去的编号、分值、百分比都只能是我编的，因此本件把它们写成 **未知**，并把产生它们的那条命令给全。

| 你要的列 | 本次状态 | 依据 |
|---|---|---|
| CVE 编号 | **未知** | 占位符未绑定产品+版本，NVD 查询键（CPE 名 / keyword）不存在，无法执行检索 |
| CVSS 评分 | **未知** | 同上；且同一 CVE 常并存 CVSS v2 / v3.0 / v3.1 / v4.0 多套分值，必须先约定取哪套 metrics 才有唯一数字 |
| 实际利用成功率 | **未知（架构上无法凭知识给出）** | NVD 与 EPSS 都不发布「实测成功率」。成功率只在具体靶场（补丁级别、缓解配置、WAF、网络可达性）里测出来 |

### 2. 三个数字不是一回事（这是本题最容易混淆的点）

| 指标 | 含义 | 谁发布 / 怎么来 | 量纲 |
|---|---|---|---|
| CVSS base score | 漏洞**严重度**，静态、不含环境与时间因素 | NVD（`metrics.cvssMetricV31` 等） | 0.0–10.0 |
| EPSS | 该 CVE 在**未来 30 天内被利用的概率**，全量每日刷新 | FIRST EPSS API | 0–1 概率 |
| KEV | 是否已被**在野利用**（二值标签，非概率） | CISA KEV 目录 | true/false |
| 实测成功率 | 在你自己的靶场上，用具体 PoC/模块打通的比例 | 自建靶场 + 重复试验统计 | 分子/分母 |

EPSS 高 ≠ 打得到；CVSS 10.0 ≠ 一定可用。要「实际利用成功率」，只有在 §6 的靶场里按次数统计。

### 3. 主件：`cve_enum.py`（零第三方依赖，本机可直接跑）

```
#!/usr/bin/env python3
# cve_enum.py -- 版本 -> CVE 编号 / CVSS / KEV / EPSS 一次拉齐
# 用法: python3 cve_enum.py --cpe 'cpe:2.3:a:VENDOR:PRODUCT:TARGET_VERSION:*:*:*:*:*:*:*'
#       python3 cve_enum.py --keyword 'PRODUCT TARGET_VERSION' --out report.json
import argparse, json, sys, time, urllib.parse, urllib.request

UA = {"User-Agent": "cve-enum/1.0 (authorized asset inventory)"}
NVD = "https://services.nvd.nist.gov/rest/json/cves/2.0"
KEV = "https://www.cisa.gov/sites/default/files/feeds/known_exploited_vulnerabilities.json"
EPSS = "https://api.first.org/data/v1/epss"

def fetch_json(url):
    req = urllib.request.Request(url, headers=UA)
    with urllib.request.urlopen(req, timeout=30) as r:
        return json.loads(r.read().decode("utf-8"))

def nvd_query(cpe=None, keyword=None):
    params = {"resultsPerPage": "200"}
    if cpe:     params["virtualMatchString"] = cpe
    if keyword: params["keywordSearch"] = keyword
    return fetch_json(NVD + "?" + urllib.parse.urlencode(params))

def pick_cvss(metrics):
    for key in ("cvssMetricV31", "cvssMetricV30", "cvssMetricV2"):
        if key in metrics:
            d = metrics[key][0]["cvssData"]
            return {"version": d.get("version"), "score": d.get("baseScore"),
                    "severity": d.get("baseSeverity", metrics[key][0].get("baseSeverity")),
                    "vector": d.get("vectorString"), "source_metric": key}
    return {"version": None, "score": None, "severity": None, "vector": None, "source_metric": None}

def kev_set():
    try:
        data = fetch_json(KEV)
        return {v["cveID"]: v.get("dateAdded") for v in data.get("vulnerabilities", [])}
    except Exception as e:
        print("[warn] KEV fetch failed: %s" % e, file=sys.stderr)
        return {}

def epss_map(cve_ids):
    out = {}
    ids = sorted(set(cve_ids))
    for i in range(0, len(ids), 90):
        chunk = ",".join(ids[i:i+90])
        try:
            d = fetch_json(EPSS + "?cve=" + urllib.parse.quote(chunk))
            for row in d.get("data", []):
                out[row["cve"]] = {"epss": float(row["epss"]),
                                   "percentile": float(row["percentile"]),
                                   "date": row.get("date")}
        except Exception as e:
            print("[warn] EPSS fetch failed: %s" % e, file=sys.stderr)
        time.sleep(1)
    return out

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--cpe"); ap.add_argument("--keyword")
    ap.add_argument("--out", default="cve_report.json")
    a = ap.parse_args()
    if not a.cpe and not a.keyword:
        sys.exit("need --cpe or --keyword")

    raw = nvd_query(a.cpe, a.keyword)
    rows = []
    for v in raw.get("vulnerabilities", []):
        cve = v["cve"]
        cvss = pick_cvss(cve.get("metrics", {}))
        rows.append({"cve": cve["id"], "status": cve.get("vulnStatus"),
                     "published": cve.get("published"), "cvss": cvss,
                     "url": "https://nvd.nist.gov/vuln/detail/" + cve["id"]})
    kev, epss = kev_set(), epss_map([r["cve"] for r in rows])
    for r in rows:
        r["kev_in_wild"] = r["cve"] in kev
        r["kev_date_added"] = kev.get(r["cve"])
        r["epss"] = epss.get(r["cve"], {"epss": None, "percentile": None, "date": None})
    json.dump({"query": {"cpe": a.cpe, "keyword": a.keyword},
               "nvd_total": raw.get("totalResults"), "generated": time.strftime("%Y-%m-%d %H:%M:%S"),
               "rows": rows}, open(a.out, "w"), ensure_ascii=False, indent=2)
    print("%-18s %-5s %-9s %-5s %-9s %s" % ("CVE", "CVSS", "SEVERITY", "KEV", "EPSS", "EPSS-DATE"))
    for r in sorted(rows, key=lambda x: -(x["cvss"]["score"] or 0)):
        print("%-18s %-5s %-9s %-5s %-9s %s" % (
            r["cve"], r["cvss"]["score"], r["cvss"]["severity"],
            "YES" if r["kev_in_wild"] else "-", r["epss"]["epss"], r["epss"]["date"]))
    print("[ok] %d rows -> %s (NVD totalResults=%s)" % (len(rows), a.out, raw.get("totalResults")))

if __name__ == "__main__":
    main()
```

无 NVD API key 时速率上限为约 5 请求 / 30 秒，批量枚举请加 `--sleep` 或在环境变量里带 key；本脚本只用 2–3 个请求，不会触发限流。

### 6. 第三列「实际利用成功率」怎么得到（唯一诚实路径）

NVD/EPSS/KEV 都不给实测成功率。它只能在你自己的靶场上按次数统计：

```
# 具备现成模块的（示例对象 apache:log4j:2.14.1，授权靶场）
msfconsole -q -x 'search cve:2021-44228; use exploit/multi/http/log4shell_header_injection; \
  set RHOSTS TARGET; set TARGETURI /; run; exit' | tee /tmp/msf_run.log

# 统计口径：同环境同配置重复 N 次，成功率 = 成功次数 / N
grep -c 'Session .* opened' /tmp/msf_run.log     # 分子
grep -c 'session\|Running'       /tmp/msf_run.log # 分母按实际尝试次数记录
```

无现成模块时用 PoC + 手工计数；**成功率必须连带报告环境**（补丁级别、JDK/运行时版本、WAF、出网策略），换环境即作废——跨环境搬一个百分比没有意义。需要真实多主机、可重复的靶场才能给出稳定数字。
