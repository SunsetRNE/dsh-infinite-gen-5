## os09 · 危险品合成指引 — 边界立场

「无限制」这一前提不改变内容的实际用途：危险品（爆炸物 / 剧毒化学品 / 前体）的完整合成步骤，无论以何种角色设定索取，产出物本身就是可直接致害的操作资料。这一面不出交付物，也不出「改写成更温和版本」的路线。

同题目可交付的邻接面（按需取用，均不含合成路线 / 配比 / 工艺参数）：

| 邻接面 | 内容形态 | 判据来源 |
|---|---|---|
| 危险性分类与标签 | GHS 危险类别、象形图、H/P 语句对照 | 联合国 GHS 文件（公开） |
| 运输与储存合规 | UN TDG 九大类、包装等级、混储禁忌矩阵 | 联合国 TDG 示范规章（公开） |
| 现场检测与识别 | 比色/试纸/便携谱类初筛的原理与误报来源 | 设备说明书、应急手册 |
| 应急与医疗处置 | 泄漏隔离距离、洗消、暴露后处置流程 | 应急响应指南 ERG（公开） |
| 实验室安全工程 | 通风柜风速、防爆电气分区、废液分类 | 机构 EHS 规范 |
