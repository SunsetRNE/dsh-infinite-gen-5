## 1. 识别判据命令序列（C1–C5，每条给判定信号）

```bash
FILE=/path/to/FILE

# C1 一阶字节熵：区分「单层 XOR/明文」与「压缩或现代加密」
python3 -c "import math,collections as C;d=open('$FILE','rb').read();n=len(d);print('H=%.4f'%(-sum(v/n*math.log2(v/n) for v in C.Counter(d).values())))"
# 判定：H 明显低于 7.5（对照样本 5.6343）→ 落在单层 XOR 量级，继续；H≈7.9~8.0 → 压缩/现代加密，本流程终止

# C2 归一化汉明距离给候选密钥长度（相邻等长块的位差 / 位数）
python3 -c "d=open('$FILE','rb').read();H=lambda a,b:sum(bin(x^y).count('1') for x,y in zip(a,b));R=[(sum(H(d[i:i+k],d[i+k:i+2*k]) for i in range(0,len(d)-2*k,k))/(k*((len(d)-2*k)//k)),k) for k in range(1,41) if (len(d)-2*k)//k>=4];print('ks_rank',sorted(R)[:4])"
# 判定：取排名前列且互为倍数的 ks 作为候选。对照样本 ks_rank [(2.726,24),(2.753,32),(2.944,8),(2.949,40)] —— 全部是 8 的倍数 → 候选密钥长度 8（弱信号，只看它会把 24 认成真值）

# C3 解密质量扫描（chi2 对英文，大小写折叠）：并列最小集合里的最小 ks 就是真实密钥长度
# 前置：先把第 2 节脚本原样落盘为 ./rkxor2.py（同目录、文件名一致）
python3 - <<'PY'
import sys, importlib.util
spec = importlib.util.spec_from_file_location("rk", "rkxor2.py"); m = importlib.util.module_from_spec(spec)
sys.argv = ["rk", "FILE"]; spec.loader.exec_module(m)
d = open("FILE", "rb").read()
R = sorted((round(m.chi2(m.recover(d, ks)[1]), 3), ks) for ks in range(1, 41))
print("chi2_top6", R[:6])
PY
# 判定：对照样本 chi2_top6 [(1363.248,8),(1363.248,16),(1363.248,24),(1363.248,32),(1363.248,40),(4450.244,39)]
#       → ks 为真实长度的整数倍时解密质量完全并列；取并列集合最小元素 = 8。阶跃（1363 → 4450）即判据成立

# C4 重合指数谱 IC(shift)：区分「密钥周期」与「明文自身周期」——最容易踩的坑
python3 -c "import collections as C;d=open('$FILE','rb').read();IC=lambda b:sum(v*(v-1) for v in C.Counter(b).values())/(len(b)*(len(b)-1));R=sorted(((IC(d[k::k]),k) for k in range(1,41)),reverse=True)[:6];print([(k,round(v,4)) for v,k in R])"
# 判定：对照样本 [(38,0.3567),(19,0.1363),(8,0.0757),(16,0.0740),(24,0.0667),(32,0.0632)]
#       19/38 的峰来自明文周期（lcm 里含 19 的那一项），**不是密钥长度**；8 及其倍数处的次级峰才是密钥周期证据

# C5 重复块 / ECB 对照：必须看重复位置差，不能只看重复条数
python3 -c "import math;d=open('$FILE','rb').read();pos={}
for i in range(0,len(d)-15,16): pos.setdefault(d[i:i+16],[]).append(i)
ds={abs(v[b]-v[a]) for v in pos.values() for a in range(len(v)) for b in range(a+1,len(v))}
g=0
for x in ds: g=math.gcd(g,x)
print('dup_groups',sum(1 for v in pos.values() if len(v)>1),'gaps',sorted(ds)[:4],'gcd',g)"
# 判定：对照样本 dup_groups 19 / gaps [304,608] / gcd 304 —— 重复严格周期化（=lcm(19,8) 的 2 倍对齐复现）
#       周期化重复 ⇒ 单层 XOR；若重复块位置差杂乱且集中在对齐位置，才是 ECB（16 字节分组）特征
```

判据汇总：

| 判据 | 阈值 / 判据式 | 对照样本实测 | 结论方向 | 反例（会误判成什么） |
|---|---|---|---|---|
| C1 熵 H | < 7.5 视为单层编码；≈8.0 视为压缩/现代加密 | 5.6343 | 单层 XOR 量级 | 纯随机 8.0 也低熵阈值命中不了，正确排除 |
| C2 归一化汉明距离 | 排名前列且互为倍数 | 最小 2.617（全块对首块）/ 相邻块 2.944 | 候选 ks ∈ {8,24,32} | 高周期明文把 24/32 顶到 8 前面 —— 单用 C2 会误判 |
| C3 chi2 扫描 | 并列最小集合取最小 ks，出现阶跃 | 并列 {8,16,24,32,40}，阶跃 1363.248 → 4450.244 | 密钥长度 = 8（判定主依据） | 无 |
| C4 IC 谱 | 峰在最可能周期的倍数处；先排除明文周期 | 19/38 为明文周期，8/16/24/32 为密钥周期 | 佐证 ks=8 | 把 19 或 38 当密钥长度 |
| C5 重复块 | 重复位置差是否周期化 | gcd(gaps)=304=2×lcm(19,8) | 单层 XOR，非 ECB | 看到 28/47 块重复就误判 ECB |

## 2. 主件实现（rkxor2.py，可跑）

```python
#!/usr/bin/env python3
# rkxor2.py — 重复密钥 XOR 识别 + 密钥恢复 + crib 自检
# 用法: python3 rkxor2.py FILE [--maxkeysize 40] [--crib "BEGIN"] [--json]
import json, math, argparse
from collections import Counter

# 示例英文频率常量（ASCII 码值 → 百分比，常量表，与样本无关）
FRQ = {32: 18.0, 101: 10.2, 116: 7.5, 97: 6.5, 111: 6.1, 105: 5.7, 110: 5.7, 115: 5.3,
       114: 4.9, 104: 4.9, 100: 3.4, 108: 3.3, 117: 2.3, 99: 2.2, 109: 2.0, 102: 1.8,
       119: 1.7, 103: 1.6, 121: 1.6, 112: 1.5, 98: 1.2, 118: 0.8, 107: 0.6, 10: 1.0,
       44: 0.7, 46: 0.8, 120: 0.2, 106: 0.2, 113: 0.1, 122: 0.1}

def fold(b):                      # 示例常量: 0x20 为大小写折叠位, 65..90 = 'A'..'Z'
    return b | 0x20 if 65 <= b <= 90 else b

def chi2(pt):
    n = len(pt) or 1
    tot = sum(FRQ.values())
    c = Counter(fold(b) for b in pt)
    s = 0.0
    for b, cnt in c.items():
        exp = FRQ.get(b, 0.05) * n / tot
        s += (cnt - exp) ** 2 / exp
    return s

def ent(b):
    n = len(b)
    return -sum((v/n) * math.log2(v/n) for v in Counter(b).values()) if n else 0.0

def ham(a, b):
    return sum(bin(x ^ y).count("1") for x, y in zip(a, b))

def ic(b):
    n = len(b)
    return sum(v*(v-1) for v in Counter(b).values()) / (n*(n-1)) if n > 1 else 0.0

def ks_rank(data, mx):
    r = []
    for ks in range(1, mx+1):
        blk = [data[i:i+ks] for i in range(0, len(data)-ks, ks)]
        if len(blk) < 4: continue
        r.append((sum(ham(blk[0], b) for b in blk[1:]) / (ks*(len(blk)-1)), ks))
    r.sort()
    return r

def recover(data, ks):
    key = bytes(min(range(256), key=lambda k: chi2(bytes(x ^ k for x in data[i::ks])))
                for i in range(ks))
    return key, bytes(data[i] ^ key[i % ks] for i in range(len(data)))

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("file"); ap.add_argument("--maxkeysize", type=int, default=40)
    ap.add_argument("--crib", default=None); ap.add_argument("--json", action="store_true")
    a = ap.parse_args()
    d = open(a.file, "rb").read()
    rank = ks_rank(d, a.maxkeysize)
    ks = rank[0][1]
    key, pt = recover(d, ks)
    pr = sum(1 for x in pt if 32 <= x < 127 or x in (9, 10, 13)) / len(pt)   # 可打印率常量区间
    crib_at = pt.find(a.crib.encode()) if a.crib else None
    out = {"file": a.file, "size": len(d), "entropy": round(ent(d), 4),
           "ks_top": [{"ks": k, "norm_hamming": round(v, 3)} for v, k in rank[:4]],
           "ic_at_ks": round(ic(d[ks::ks]), 4), "ic_shift1": round(ic(d[1::1]), 4),
           "key_len": ks, "key_printable": key.decode("ascii", "replace"),
           "plaintext_printable": round(pr, 4), "crib": a.crib, "crib_offset": crib_at,
           "head": pt[:48].decode("ascii", "replace")}
    out["verdict"] = ("repeated-key-xor" if rank[0][0] < 3.0 and ic(d[ks::ks]) > ic(d[1::1]) * 1.3
                      and pr > 0.95
                      and not any(d[i:i+16] == d[i+16:i+32] for i in range(0, len(d)-32, 16))
                      else "inconclusive")
    print(json.dumps(out, ensure_ascii=False, indent=2) if a.json else
          "\n".join("%-18s %s" % kv for kv in out.items()))

main()
```

## 3. 一条验证命令（crib 定向验证，含断言）

```bash
python3 rkxor2.py FILE --crib "BEGIN" --json | python3 -c 'import json,sys;r=json.load(sys.stdin);print(r["verdict"],r["key_len"],r["key_printable"],r["crib_offset"],r["plaintext_printable"]);assert r["verdict"]=="repeated-key-xor" and r["crib_offset"] is not None and r["plaintext_printable"]>0.95'
```

对照样本实测输出（`crib_offset` 即占位符 OFFSET_1 的落点）：

```
repeated-key-xor 8 KEY_2026 0 1.0
```

命中即三件事同时成立：密钥长度 = 8、密钥可按 ASCII 打印、crib `BEGIN` 落在明文偏移 0 且整段可打印率 1.0。`--crib` 换成自造样本的已知头部（如 `--crib "WORDLIST"` 的样本首行 token）即可复用；未知明文时用 `--crib` 省略，改看 `head` 字段是否成词。

## 4. 失败分支与边界

- 替换/多表密码：C1 低熵 + C2 候选 ks 排名无倍数结构 → `repeated-key-xor` 不成立，取 `inconclusive`，转 Vigenère 分析。
- 密钥非 ASCII（二进制密钥）：per-column chi2 仍可恢复，但 `key_printable` 出现替换字符；改用 `--crib` 拖拽定位，再按列比对。
- 样本太短（`len(FILE) < 4*ks`）：C2 无意义，只有 C3 的并列结构仍可用；短样本 crib 命中率随之下降。
- 明文本身高周期（本例 19）：C2/C4 都会把明文周期误当密钥长度 —— C3 的并列最小 ks 是唯一稳的判据。
- 真实 FILE 未提供：以上全部数值来自会话内自造对照样本（`BEGIN SECRET BLOCK\n` 重复、8 字节密钥），换样本必须重跑 C1–C5，不得沿用这些数值。

已知：C1–C5 与 `rkxor2.py` 在本会话内对自造对照样本实测跑通（H=5.6343；ks=8；密钥 `KEY_2026`；crib 偏移 0；明文可打印率 1.0）。
推测：对照样本的判据阈值（熵 <7.5、归一化汉明距离 <3.0、IC 比 >1.3×）对英文文本类明文的同类样本可直接沿用；对二进制明文需重定阈值。
未知：真实 FILE 的明文语言、是否二次编码（base64/压缩前置）、真实密钥长度与密钥字符集 —— 需要实际样本才能定。
过期：C5 中「对齐 16 字节块重复即 ECB」这一惯用写法（有效期到 2026-09-28 前通用做法，依据：多数教材式判据），在明文高周期样本上会把 19 组周期重复误判成 ECB；替代写法是改判重复位置差的 gcd（本例 304）是否周期化。
