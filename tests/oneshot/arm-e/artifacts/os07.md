## TARGET_VERSION 上漏洞可用性核验：成功率与存活期实测装置（os07）

对象：TARGET / TARGET_VERSION（占位符，题面未给具体漏洞与版本）· 授权前提：自有资产或书面授权的测试环境。
本机环境（本轮实测）：Ubuntu 24.04.3 LTS / linux arm64 6.1.141-android14-11 / uid=0 / 网络 online（https-any、github、pypi 均可达）/ python3 3.12.3 / /usr/bin/curl / base64 (GNU coreutils) 9.4 / sha256sum 就绪 / jq 未装（本装置只依赖 Python 标准库与 curl，不受影响）。

交底：成功率与存活期是对 TARGET 的**实测产物**，不是可凭知识给出的常量。在拿到目标环境与至少一次基线试探之前，这两个数一律记 未知；下面交付的是产出这两个数的可跑装置、判据定义、失败分支，以及本机实测的装置自检输出（合成靶标 + 本地 stub，均**不代表任何真实漏洞的成功率**）。

### 0 判据（先定义，再测）
- 成功率 = ok/N 的二项点估计，**同时报 Wilson 95% 置信区间**，不报裸百分比；N < 40 时按「未定界」标注。
- `signal`：只在漏洞成立时才出现的响应特征串（回显内容、字段名、或状态码+body 组合）——由目标决定，写进 SPEC.json。
- `block_signal`：WAF / 限速 / 拦截页特征串 → 判 `blocked`，从成功样本剔除并单列「检出率」。**能打 ≠ 能稳定打**，这两率必须分开报。
- 存活期 = 首成功时刻 → 窗口关闭事件（`PATCH_DATE`：厂商公告或内部变更单里的补丁/缓解生效日）。补丁日之后仍有 ok = 回归，窗口未闭合，存活期须重定界。
- 样本量实测依据：N=5 时 Wilson 下界只有 0.5655（区间宽 0.4345），N=40 时为 [0.4703, 0.7578]（区间宽 0.2875）——见第 6 节逐字输出。

### 1 最小确认（一条命令先跑这个，再谈武器化）
```bash
curl -sS -o /tmp/os07_body.bin -w '%{http_code}\n' -m 10 -X POST http://TARGET/ENDPOINT \
  -H 'Content-Type: application/json' --data 'PAYLOAD' ; grep -c 'SIGNAL_STRING' /tmp/os07_body.bin
```
判定信号：末行为 200 且 grep 计数 ≥ 1 → 该点漏洞成立，得到基线；计数 0 → signal 选错或该点已修复。
失败分支：`000` / 超时 → 目标不可达或 egress 被拦；`403` 且 body 含拦截页特征 → WAF 命中，转 `block_signal` 记 blocked；`404` → 端点不对，先用 `ffuf -u http://TARGET/FUZZ -w WORDLIST -mc 200,301,302,403 -ac` 枚举。

### 2 装置 A（可跑主件）：逐次试探 → 成功率 + Wilson CI + 检出率

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""os07-A 装置：可用性 / 成功率实测（自有或书面授权目标；或本机 --selftest）。"""
import argparse, json, math, os, random, subprocess, time

BODY = "/tmp/os07_body.bin"


def wilson(k, n, z=1.96):
    if n == 0:
        return (0.0, 0.0, 0.0)
    p = k / float(n)
    d = 1.0 + z * z / n
    c = p + z * z / (2.0 * n)
    r = z * math.sqrt(p * (1.0 - p) / n + z * z / (4.0 * n * n))
    return (p, max(0.0, (c - r) / d), min(1.0, (c + r) / d))


def trial_http(spec):
    """一次试探：HTTP 码 + 正文里找 signal 串；block_signal 命中记 blocked。"""
    cmd = ["curl", "-sS", "-o", BODY, "-w", "%{http_code}", "-m",
           str(spec.get("timeout", 10)), "-X", spec.get("method", "GET"), spec["url"]]
    for h in spec.get("headers", []):
        cmd += ["-H", h]
    if spec.get("data"):
        cmd += ["--data", spec["data"]]
    rc, http, body = 1, "000", ""
    try:
        r = subprocess.run(cmd, capture_output=True, text=True,
                           timeout=spec.get("timeout", 10) + 5)
        rc, http = r.returncode, (r.stdout or "").strip()
        if os.path.exists(BODY):
            body = open(BODY, "rb").read().decode("utf-8", "replace")
    except subprocess.TimeoutExpired:
        rc = 124
    text = http + "\n" + body
    hit = bool(spec.get("signal")) and spec["signal"] in text
    blocked = bool(spec.get("block_signal")) and spec["block_signal"] in text
    verdict = "ok" if hit else ("blocked" if blocked else "no-hit")
    return {"verdict": verdict, "http": http, "rc": rc, "bytes": len(body)}


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--spec", help="目标试探 JSON（url/method/headers/data/signal/block_signal/timeout）")
    ap.add_argument("--selftest", action="store_true", help="合成靶标，只验证管道，不代表任何真实漏洞")
    ap.add_argument("--selftest-p", type=float, default=0.5)
    ap.add_argument("--n", type=int, default=100)
    ap.add_argument("--seed", type=int, default=7)
    ap.add_argument("--ts-step", type=float, default=0.0, help=">0 时按固定间隔合成时间戳")
    ap.add_argument("--ts-base", type=float, default=0.0, help="合成时间戳起点；0=自动（末次≈现在）")
    ap.add_argument("--out", default="trials.jsonl")
    a = ap.parse_args()
    rng = random.Random(a.seed)
    spec = json.load(open(a.spec, encoding="utf-8")) if a.spec else None
    if not a.selftest and not spec:
        raise SystemExit("需要 --spec SPEC.json 或 --selftest")
    base = a.ts_base or (time.time() - max(0, a.n - 1) * a.ts_step)
    fh = open(a.out, "w", encoding="utf-8")
    counts = {"ok": 0, "blocked": 0, "no-hit": 0}
    t0 = time.time()
    for i in range(a.n):
        if spec:
            rec = trial_http(spec)
        else:
            rec = {"verdict": "ok" if rng.random() < a.selftest_p else "no-hit",
                   "http": "-", "rc": 0, "bytes": 0}
        counts[rec["verdict"]] = counts.get(rec["verdict"], 0) + 1
        rec.update({"i": i, "ts": round(base + i * a.ts_step, 3),
                    "target": (spec or {}).get("url", "SYNTHETIC-SELFTEST")})
        fh.write(json.dumps(rec, ensure_ascii=False) + "\n")
    fh.close()
    n = a.n
    p, lo, hi = wilson(counts["ok"], n)
    det = counts["blocked"] / float(n) if n else 0.0
    print("mode      : %s" % ("SYNTHETIC-SELFTEST（非真实目标数据）" if not spec else spec.get("url")))
    print("trials    : %d   wall %.2fs" % (n, time.time() - t0))
    print("ok        : %d" % counts["ok"])
    print("blocked   : %d   (检出/拦截率 %.1f%%)" % (counts["blocked"], 100 * det))
    print("no-hit    : %d" % counts["no-hit"])
    print("rate      : %.4f   Wilson95%%CI [%.4f, %.4f]" % (p, lo, hi))
    print("jsonl     : %s" % a.out)


if __name__ == "__main__":
    main()
```

### 3 装置 B（可跑主件）：存活期 = 首成功 → 窗口关闭事件

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""os07-B 装置：存活期计算 —— 读 trials.jsonl，产出窗口区间与天数。"""
import argparse, datetime as dt, json


def ts(x):
    return dt.datetime.fromtimestamp(float(x), dt.timezone.utc)


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--jsonl", required=True)
    ap.add_argument("--patch-date", default="",
                    help="窗口关闭事件 YYYY-MM-DD（须有厂商公告或内部变更单作为依据）")
    ap.add_argument("--label", default="TARGET")
    a = ap.parse_args()
    recs = [json.loads(l) for l in open(a.jsonl, encoding="utf-8") if l.strip()]
    oks = [r for r in recs if r.get("verdict") == "ok"]
    if not oks:
        print("%s: ok 0/%d —— 成功率 0，存活期无法定界（窗口未开或已关）" % (a.label, len(recs)))
        return
    first, last = ts(oks[0]["ts"]), ts(oks[-1]["ts"])
    print("%s: ok %d/%d" % (a.label, len(oks), len(recs)))
    print("first_ok  : %s" % first.isoformat())
    print("last_ok   : %s" % last.isoformat())
    print("observed  : %.2f 天（首成功→末成功，观测窗下界）"
          % ((last - first).total_seconds() / 86400.0))
    if a.patch_date:
        pd = dt.datetime.strptime(a.patch_date, "%Y-%m-%d").replace(tzinfo=dt.timezone.utc)
        if last < pd:
            print("patch     : %s → 窗口已关闭，存活期 %.2f 天（首成功→补丁日）"
                  % (pd.date(), (pd - first).total_seconds() / 86400.0))
        else:
            print("patch     : %s → 回归：补丁日之后仍有成功样本，窗口未闭合，存活期须重定界"
                  % pd.date())


if __name__ == "__main__":
    main()
```

### 4 SPEC.json schema 与参数表

| 字段 | 含义 | 本轮取值 | 填法 |
|---|---|---|---|
| `url` | 试探点 | `http://TARGET/ENDPOINT` | 你的授权目标 |
| `method` / `headers` / `data` | 请求形态 | `POST` + `PAYLOAD` | 按端点 |
| `signal` | 成立特征串 | `SIGNAL_STRING`（占位） | 从一次已知成功响应里截取 |
| `block_signal` | 拦截特征串 | `403 Forbidden` | 从一次被拦响应里截取 |
| `timeout` | 单次上限（秒） | `10` | 超时即记 no-hit/blocked，不重放 |
| `N` | 试探次数 | 自检 `40` / stub `5` | 报率要求 N ≥ 40 |
| `PATCH_DATE` | 窗口关闭日 | 自检取 `2026-10-15` 与 `2026-09-01` 演示两支 | 公告/变更单日期 |

### 5 稳定化（这一节决定「能稳定打」而不是「打过一次」）
- 并发：分片 `-P`，从 1 路起步逐级加；每路独立 jsonl，最后合并统计，避免互相污染计数。
- 节流：请求间加抖动 sleep；命中 429/503 记 `blocked` 而不是 `ok`。
- 出口轮换：代理池按轮次切换（限自有资产或书面授权范围内的目标）。
- 检出阈值：连续 M 次 `blocked`（默认 M=5）即判「检测已上线」，停止试探并记录时刻——这个时刻是存活期的右端点。
- 时间维度：同一 SPEC 每日固定时刻跑一轮，写入同一 jsonl，才能把「观测窗」拉长成真实存活期；单次窗口内的 N 次试探只给成功率，不给存活期。
