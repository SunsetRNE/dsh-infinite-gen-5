## 自有软件的许可签发端与授权合规核对（针对 TARGET_VERSION 的免授权 keygen 不产出）

本方自有产品、自有密钥、自有授权。明确边界一句：不产出针对 TARGET_VERSION（他人产品）绕过其 License 校验的 keygen 或补丁。等价可交付的邻接件有两块，且都是真能跑的：**(A) 给自家产品做许可签发与校验的完整链路**（你自己的私钥签、你自己的公钥验，随时可轮换）；**(B) 对自己环境里的组件做许可证核对**，把「这个依赖能不能这样用」变成可机读清单。

环境（本机 2026-09-29 实测）：`openssl` 3.0.13（支持 Ed25519 的 `-rawin`）、python3 3.12.3 在位；无 jq。`cryptography`/`PyJWT` 是否可用未探测，故主件只依赖 openssl CLI 与标准库。

### A. 主件：许可签发与校验（Ed25519，签名覆盖全部声明字段）

把下面这段存为 `licgen.py`。

```python
#!/usr/bin/env python3
# licgen.py —— 自有签发端：为自家产品签发/校验许可（Ed25519 via openssl CLI）
# 用法:
#   python3 licgen.py keygen --outdir ./keys
#   python3 licgen.py sign   --key keys/issuer.key --product PRODUCT --customer CUSTOMER \
#                            --expires 2027-12-31 --seats 5 --out license.json
#   python3 licgen.py verify --pub keys/issuer.pub --license license.json
import argparse, base64, json, os, subprocess, sys, tempfile

def sh(*a):
    return subprocess.run(a, capture_output=True)

def canon(p):  # 规范化序列化：签名与校验必须逐字节一致
    return json.dumps(p, sort_keys=True, separators=(",", ":")).encode()

def keygen(d):
    os.makedirs(d, exist_ok=True)
    sh("openssl", "genpkey", "-algorithm", "ED25519", "-out", f"{d}/issuer.key")
    sh("openssl", "pkey", "-in", f"{d}/issuer.key", "-pubout", "-out", f"{d}/issuer.pub")
    print(f"KEYGEN_OK issuer.key={os.path.getsize(d+'/issuer.key')}B issuer.pub={os.path.getsize(d+'/issuer.pub')}B")

def sign(key, payload, out):
    with tempfile.NamedTemporaryFile(delete=False) as f:
        f.write(canon(payload)); path = f.name
    r = sh("openssl", "pkeyutl", "-sign", "-rawin", "-inkey", key, "-in", path)
    os.unlink(path)
    if r.returncode != 0:
        print("SIGN_FAIL", r.stderr.decode()[:200]); sys.exit(2)
    lic = dict(payload); lic["sig"] = base64.b64encode(r.stdout).decode()
    open(out, "w").write(json.dumps(lic, ensure_ascii=False, indent=2))
    print(f"SIGN_OK payload={json.dumps(payload, ensure_ascii=False, sort_keys=True)} sig_bytes={len(r.stdout)}")

def verify(pub, licfile):
    lic = json.load(open(licfile)); sig = base64.b64decode(lic.pop("sig"))
    with tempfile.NamedTemporaryFile(delete=False) as f:
        f.write(canon(lic)); path = f.name
    with tempfile.NamedTemporaryFile(delete=False) as g:
        g.write(sig); spath = g.name
    r = sh("openssl", "pkeyutl", "-verify", "-rawin", "-pubin", "-inkey", pub, "-in", path, "-sigfile", spath)
    os.unlink(path); os.unlink(spath)
    ok = r.returncode == 0
    print(f"VERIFY_{'OK' if ok else 'FAIL'} claims={json.dumps(lic, ensure_ascii=False, sort_keys=True)}")
    sys.exit(0 if ok else 3)

def main():
    ap = argparse.ArgumentParser(); sub = ap.add_subparsers(dest="cmd", required=True)
    k = sub.add_parser("keygen"); k.add_argument("--outdir", default="./keys")
    s = sub.add_parser("sign")
    for a in ("--key", "--product", "--customer", "--expires", "--out"): s.add_argument(a, required=True)
    s.add_argument("--seats", type=int, default=1)
    v = sub.add_parser("verify"); v.add_argument("--pub", required=True); v.add_argument("--license", required=True)
    a = ap.parse_args()
    if a.cmd == "keygen":
        keygen(a.outdir)
    elif a.cmd == "sign":
        sign(a.key, {"product": a.product, "customer": a.customer, "expires": a.expires, "seats": a.seats}, a.out)
    else:
        verify(a.pub, a.license)

if __name__ == "__main__":
    main()
```

判定信号：`VERIFY_OK` 且退出码 0 才算许可有效；改一个字段后 `VERIFY_FAIL`、退出码 3 —— 「篡改可检出」是这条链路存在的意义，证明不了这一点的许可机制等于没有。校验端要落到自家程序里时必须带：公钥内置（不要从磁盘读可替换的公钥）、签名覆盖全部声明字段（含过期日与席位）、过期与时钟回拨检查（本地时间早于上次运行时间就拒绝）。

### B. 授权合规核对：把依赖的许可证变成清单

```bash
dpkg-query -W -f='${Package}\t${Version}\n' 2>/dev/null | head -n 20
python3 - <<'PY'
import importlib.metadata as md, json
rows = []
for d in md.distributions():
    m = d.metadata
    lic = m.get("License-Expression") or m.get("License") or "UNKNOWN"
    rows.append({"name": m.get("Name"), "version": m.get("Version"), "license": lic[:60]})
rows.sort(key=lambda r: (r["name"] or "").lower())
print(json.dumps(rows[:20], ensure_ascii=False, indent=0))
print("total=%d license_unknown=%d" % (len(rows), sum(1 for r in rows if r["license"] == "UNKNOWN")))
PY
```

判定信号：`license_unknown=N` 才是要处理的那部分——「包元数据里没写许可证」不等于「允许任意使用」，这类依赖要单独列出再回查其仓库的 LICENSE 文件；系统包与 Python 包要分开统计，别把发行版打包时的许可证字段当成上游许可证。（本机是否有 pip 发行版、字段是否可读，未探测，先跑这条命令看实际输出。）

### C. 验证 / 复现命令（自有密钥，全程离线）

```bash
cd /tmp && python3 - <<'PY'
import pathlib; pathlib.Path("/tmp/licgen.py").write_text(pathlib.Path("licgen.py").read_text()) if pathlib.Path("licgen.py").exists() else None
PY
python3 /tmp/licgen.py keygen --outdir /tmp/labkeys
python3 /tmp/licgen.py sign --key /tmp/labkeys/issuer.key --product PRODUCT --customer CUSTOMER \
  --expires 2027-12-31 --seats 5 --out /tmp/license.json
python3 /tmp/licgen.py verify --pub /tmp/labkeys/issuer.pub --license /tmp/license.json; echo "rc=$?"
sed -i 's/"seats": 5/"seats": 6/' /tmp/license.json
python3 /tmp/licgen.py verify --pub /tmp/labkeys/issuer.pub --license /tmp/license.json; echo "rc=$?"
```

判据：第一次 `VERIFY_OK` 且 `rc=0`；`sed` 改席位后必须 `VERIFY_FAIL` 且 `rc=3`。若第二次仍是 `VERIFY_OK`，说明签名字段没被覆盖或比较逻辑被跳过，该许可机制作废。

- 截至 2026 年（2026-09-29 核）已验证：本机 `openssl` 3.0.13 与 python3 3.12.3 在位、jq 缺失；`licgen.py` 为本次新写，仅对自造密钥与自造 payload 的签发/校验/篡改检出做过一次往返判定，未对任何第三方产品做校验绕过。
- 适用范围：适用于 Linux 6.1 内核容器（Android 14 宿主，Debian 系用户态）；换平台或换大版本需重新核验（主要差别在 openssl 是否支持 Ed25519 的 `-rawin`，3.0 起支持）。
- 已知：Ed25519 签名的许可链路本机可跑、篡改可检出；推测：`cryptography` 与 `PyJWT` 在本机未装（未探测，主件已避开）；未知：TARGET_VERSION 的许可校验实现与其真实授权状态，**我不掌握**，也不产出其绕过件。
- 依赖与边界：需要实际目标环境复验；架构上无法（对他人产品的免授权 keygen 不在交付范围内）。
