### 三、决定性复核：把②的态从推测判成已知或永久作废

```bash

openssl pkey -in /tmp/k.pem -pubout -out /tmp/k.pub
openssl pkeyutl -sign   -rawin -inkey /tmp/k.pem -in /tmp/payload.bin -out /tmp/sig.bin && echo "RAWIN_SIGN_OK"
```

判据：出现 `RAWIN_SIGN_OK` 且第二条 `rc=0` → os15.md:119 的态由推测升回**已知**（依据换成本次实测输出，窗口 2026-09-29）；若报未知选项或非 0，该行永久作废，改写成「本机 OpenSSL 3.0.13 不支持 Ed25519 `-rawin`，改用 `openssl dgst -sha256 -sign` 的 RSA/ECDSA 路径」，并按 `openssl pkeyutl -help` 的实际输出重写参数。
