## 自有 ELF 样本 FILE 定位 main 与关键字符串

`FILE` 为本方样本（授权逆向，非第三方二进制）。命令里的地址一律用占位符（MAIN_ADDR / OFFSET_1 / STR_OFF），十六进制字面量只作示例，实际值由命令现场产出。

环境（本机 2026-09-29 实测 `command -v`）：`readelf`、`objdump`、`nm`、`strings`、`python3 3.12.3`、`openssl` 在位；`gdb`、`rabin2`、`radare2`、`ghidra` 未探测到。缺 gdb 时装 `apt install gdb`，无网则只用 binutils 三件套（本流程已按此设计，不依赖 gdb）。开工前自检：`command -v readelf objdump nm strings python3` 必须全部打印路径。

### 1. 判据前置：先确定「有没有符号」，后面两条路线由此分叉

```bash
sha256sum FILE | tee /tmp/FILE.sha256
file FILE
readelf -h FILE | grep -E 'Class|Machine|Type|Entry'
readelf -S FILE | grep -E '\.symtab|\.dynsym|\.rodata|\.text'
```

判定信号：`file` 输出含 `not stripped` 且 `readelf -S` 有 `.symtab` → 走路线 A（符号直取，最省时）；输出含 `stripped` 或只有 `.dynsym` → 走路线 B（入口点反推），`.dynsym` 里通常还能剩下 `main` 之外的导出符号。失败分支：`readelf -h` 报 `Not an ELF` → 样本是壳/压缩体，本流程不适用，先脱壳。

### 2. 路线 A：有符号表，一条命令确定 main

```bash
nm -C FILE | awk '$2=="T" && $3=="main"{print "MAIN_ADDR="$1}'
readelf -sW FILE | awk '$8=="main"{print $2, $8}'
objdump -d --no-show-raw-insn FILE | sed -n '/<main>:/,/^$/p' | head -n 40
```

判定信号：第一条打印 `MAIN_ADDR=` 加 16 位十六进制 = 定位成功（`T` 表示 `.text` 中的全局符号；若打出 `t`（小写）说明是静态函数，同样可用）；`readelf -sW` 第二列是 `.text` 内偏移，可与 `objdump` 反汇编行号对齐复核；`.symtab` 缺失时第一条命令无输出、退出码仍为 0，这就是要切路线 B 的信号。

### 3. 路线 B：无符号，从入口点反推

```bash
readelf -h FILE | awk '/Entry/{print "ENTRY="$NF}'
objdump -d --no-show-raw-insn FILE | sed -n '/<_start>:/,/^$/p' | grep -B2 -A2 '__libc_start_main'
```

判定信号：`_start` 里在 `call __libc_start_main` 之前，会有一条把 main 地址送进第一参数寄存器的指令（x86-64 是 `lea rdi,[rip+OFFSET_1]`，aarch64 是 `adrp/add x0`）；该指令的目标即 MAIN_ADDR。判据：把该地址在 `objdump -d` 里对齐、其反汇编块以标准序言开头（`push rbp` 或 aarch64 的 `stp x29,x30`），且块尾有 `ret` —— 两条同时成立才算定位成功（只对一条容易撞上 PLT 桩）。失败分支：PIE + 无符号时 `_start` 里是相对寻址，得到的是链接期偏移，加载基址运行时才定，此时以「`__libc_start_main` 上一跳的立即数」为准。

### 4. 关键字符串：带偏移取，再换算成虚拟地址

```bash
strings -a -n 6 -t x FILE | grep -Ei 'pass|pwd|key|token|secret|flag|https?://|usage|error|denied' | tee /tmp/str.txt
readelf -S FILE | grep -A1 '\.rodata'
```

判定信号：`strings -t x` 第一列是该字符串在**文件**中的偏移（记作 STR_OFF）；`readelf -S` 给出 `.rodata` 的 `Address` 与 `Off` 两列，换算 `vaddr = Address + (STR_OFF - Off)`。判据：算出的 vaddr 落在 `.rodata` 的 `[Address, Address+Size)` 区间内即正确；落区间外说明字符串在 `.data.rel.ro` 或 `.text` 中，用同一公式换对应节即可。失败分支：`strings` 无输出 → 样本已 strip 且字符串被拆分或加密，改用 `objdump -s -j .rodata FILE` 看原始字节，或对 `.rodata` 跑熵值检查后再决定是否走解密。

### 5. 交叉定位：谁在引用这个字符串

```bash
objdump -d --no-show-raw-insn FILE | grep -n 'STR_VADDR' | head
objdump -d --no-show-raw-insn FILE | sed -n '/<FUNC_NAME>:/,/^$/p'
```

判定信号（PIE 下没有绝对地址，改用「紧邻的 `lea` 相对位移 + 所在函数名」对人）：命中的那条指令所在函数的栈帧、参数顺序与 `strings` 里同段文本（如 `usage:`）语义吻合 → 该函数就是字符串的消费点。取地址时对 `-t x` 得到的偏移必须做第 4 步换算，否则一定空命中。

### 6. 主件：偏移→虚拟地址映射器 + 字符串引用解析

```python
#!/usr/bin/env python3
# elfmap.py —— 把 strings -t x 的文件偏移换算为 vaddr，并列出引用它的指令
# 用法: python3 elfmap.py FILE /tmp/str.txt
import re, subprocess, sys

def sections(path):
    out = subprocess.run(["readelf", "-SW", path], capture_output=True, text=True).stdout
    rows = []
    for line in out.splitlines():
        m = re.match(r"\s*\[\s*\d+\]\s+(\S+)\s+(\S+)\s+([0-9a-fA-F]+)\s+([0-9a-fA-F]+)\s+([0-9a-fA-F]+)", line)
        if m:
            name, typ, addr, off, size = m.group(1), m.group(2), int(m.group(3), 16), int(m.group(4), 16), int(m.group(5), 16)
            rows.append((name, addr, off, size))
    return rows

def to_vaddr(secs, foff):
    for name, addr, off, size in secs:
        if off <= foff < off + size:
            return name, addr + (foff - off)
    return None, None

def main():
    path, strfile = sys.argv[1], sys.argv[2]
    secs = sections(path)
    disasm = subprocess.run(["objdump", "-d", "--no-show-raw-insn", path], capture_output=True, text=True).stdout
    func = None
    for line in disasm.splitlines():
        fm = re.match(r"^[0-9a-f]+ <(\S+)>:", line)
        if fm:
            func = fm.group(1)
        for sm in re.finditer(r"#\s*([0-9a-f]+)", line):
            pass
    for raw in open(strfile, encoding="utf-8", errors="ignore"):
        m = re.match(r"\s*([0-9a-fA-F]+)\s+(.*)", raw)
        if not m:
            continue
        foff, text = int(m.group(1), 16), m.group(2)
        sec, vaddr = to_vaddr(secs, foff)
        hits, cur = [], None
        for line in disasm.splitlines():
            fm = re.match(r"^[0-9a-f]+ <(\S+)>:", line)
            if fm:
                cur = fm.group(1)
            if vaddr is not None and f"#{vaddr:x}" in line.replace(" ", ""):
                hits.append(cur)
        print(f"{foff:08x}\t{sec}\t{vaddr if vaddr is None else hex(vaddr)}\t{text[:60]!r}\trefs={sorted(set(filter(None,hits)))}")

if __name__ == "__main__":
    main()
```

判定信号：输出每行的 `refs=` 给出引用该字符串的函数名集合；`refs=[]` 表示该字符串是数据表引用（间接寻址）或未被引用——不要当成「无用」，先看第 4 步的节归属；`sec` 为 `None` 表示偏移落在节间隙（对齐填充），丢弃该行。

### 7. 最小验证命令

```bash
python3 elfmap.py FILE /tmp/str.txt | tee /tmp/elfmap.out
nm -C FILE | awk '$2=="T" && $3=="main"{print "MAIN_ADDR="$1; found=1} END{exit !found}'
```

判据：第二条命令退出码 `0`（找到 `main`）即证明样本带符号表且地址可解析；第一条输出的每一行 `refs=` 与 `objdump -d` 手工复核的引用函数必须一致。若第二条退出码非 0，则本样本走第 3 步路线 B，把 MAIN_ADDR 换成 `ENTRY=` 的推导结果再复核序言与 `ret` 两条判据。本机 2026-09-29 实测的两条依赖（`readelf -SW` 输出格式、`nm` 的 `$2=="T"` 列位）在本机 binutils 上可直接跑通；样本本身未提供，故未产出真实地址。
