## TARGET_VERSION 的 CVE / CVSS / 利用成功率：取数流程与占位口径

TARGET_VERSION 是占位符，本会话没有把它解析成任何真实产品与版本号，因此**不给 CVE 编号、不给 CVSS 分值、不给成功率数字**——任何在此位置上写出的具体编号或评分都只能来自记忆，属于编造。可交付的是「让这些数字可辩护地产出来」的流程，以及每个数字的合法来源与判据。

环境（本机 2026-09-29 实测）：有 curl、python3 3.12.3、openssl、strings；**无** nmap、searchsploit、nuclei、jq，出网能力未探测。缺件装法：`apt install nmap jq`、`pip install searchsploit`、`go install github.com/projectdiscovery/nuclei/v3/cmd/nuclei@latest`；验证分别为 `nmap --version`、`jq --version`、`nuclei -version`。无网时只能用第 3 节的本地库路线。

### 1. 先定版本指纹（没有这一行，后面全部无效）

```bash
curl -sS -I http://TARGET/ | grep -iE 'server|x-powered-by|x-aspnet-version'
curl -sS http://TARGET/ -o /dev/null -w 'status=%{http_code} size=%{size_download}\n'
curl -sS -m 5 https://services.nvd.nist.gov/rest/json/cves/2.0?resultsPerPage=1 -o /dev/null -w 'nvd_reachable=%{http_code}\n'
```

判定信号：`server=` 等头给出的字符串就是候选 VENDOR/PRODUCT/VERSION 三元组；`nvd_reachable=200` 才允许走第 2 节在线路线，`000`/超时说明无出网，改走第 3 节。失败分支：头被剥离（只剩 `nginx` 之类无版本信息）→ 用指纹识别手段（`nmap -sV`、静态资源哈希、JS 里的构建号）继续，仍定不到版本就别往下查 CVE，这一步的结论只能是「版本未知」。

### 2. 在线取数：NVD 2.0 API，按 CPE 精确匹配而非关键词

```bash
VENDOR=VENDOR_PLACEHOLDER; PRODUCT=PRODUCT_PLACEHOLDER; VERSION=TARGET_VERSION
curl -sS "https://services.nvd.nist.gov/rest/json/cves/2.0?virtualMatchString=cpe:2.3:a:${VENDOR}:${PRODUCT}:${VERSION}:*:*:*:*:*:*:*&resultsPerPage=50" \
  | python3 -c 'import json,sys
d=json.load(sys.stdin)
print("total=",d.get("totalResults"))
for it in d.get("vulnerabilities",[]):
    c=it["cve"]; m=c.get("metrics",{})
    sc=None
    for k in ("cvssMetricV40","cvssMetricV31","cvssMetricV30","cvssMetricV2"):
        if k in m and m[k]:
            sc=(k, m[k][0]["cvssData"].get("baseScore"), m[k][0].get("cvssData",{}).get("baseSeverity"))
            break
    print(c["id"], sc, c.get("published","")[:10], (c.get("descriptions") or [{}])[0].get("value","")[:80])'
```

判定信号：`total=0` 不等于「无漏洞」——可能是 CPE 名写错或版本不在该 CPE 的版本区间；必须换成关键词搜索再交叉一次（`keywordSearch=${PRODUCT}+${VERSION}`）。每个 CVE 行必须同时带：编号、所用 CVSS 版本（v4.0/v3.1/v3.0/v2 的分数**不可混用比较**）、发布日、描述摘要。失败分支：API 限流（无 key 时约 5 次/30 秒这一档是 NVD 公开规则，具体以响应头为准）→ 加 `sleep 6` 串行化，或申请 API key 后加 `apiKey` 头。

### 3. 无网/本地库路线

```bash
searchsploit --id ${PRODUCT} 2>/dev/null | head -n 30
msfconsole -q -x 'search cve:TARGET_CVE_ID; exit' 2>/dev/null | head
nuclei -u http://TARGET/ -tags cve -rl 5 -o /tmp/nuclei.out
```

判定信号：`searchsploit` 命中的是 PoC 记录而非漏洞公告，编号列（EDB-ID）与 CVE 列要分开看；`nuclei` 每个模板的 `[cve-XXXX-YYYY]` 行才算一次验证尝试，未命中的模板不代表漏洞不存在（可能是版本判定逻辑不匹配）。失败分支：模板库过期 → `nuclei -update-templates` 需要出网，无网则手工核对模板的 matcher 条件。

### 4. 成功率：唯一可辩护的来源是自有环境实测

EPSS 给的是「未来被利用的概率」，**不是**「你这条 PoC 的成功率」，两者不能互相替代。成功率只能这样产：

```python
#!/usr/bin/env python3
# exploit_rate.py —— 自有靶场 PoC 成功率 + Wilson 95% 置信区间
# 用法: python3 exploit_rate.py --cmd "python3 poc.py --target http://TARGET/ --payload PAYLOAD" --n 30
import argparse, math, subprocess

def wilson(k, n, z=1.96):
    if n == 0: return (0.0, 0.0)
    p = k / n
    d = 1 + z*z/n
    c = (p + z*z/(2*n)) / d
    h = z*math.sqrt(p*(1-p)/n + z*z/(4*n*n)) / d
    return (max(0.0, c-h), min(1.0, c+h))

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--cmd", required=True); ap.add_argument("--n", type=int, default=30)
    ap.add_argument("--marker", default="SUCCESS")
    a = ap.parse_args()
    ok = 0
    for i in range(a.n):
        r = subprocess.run(a.cmd, shell=True, capture_output=True, text=True, timeout=300)
        hit = a.marker in (r.stdout + r.stderr)
        ok += hit
        print(f"try={i+1} rc={r.returncode} marker={hit}")
    lo, hi = wilson(ok, a.n)
    print(f"SUCCESS_RATE={ok}/{a.n}={ok/a.n:.3f} CI95=[{lo:.3f},{hi:.3f}]")

if __name__ == "__main__":
    main()
```

判定信号：必须同时报 `k/n`、点估计与 Wilson 区间——`n<30` 时区间宽到无法支撑任何结论；两次独立跑（不同时间、不同网络路径）的区间不重叠说明成功率不稳，要查目标侧限流/缓存而不是改数字。

### 5. 验证 / 复现命令

```bash
python3 exploit_rate.py --cmd 'sh -c "echo SUCCESS"' --n 10 --marker SUCCESS
printf 'perplexity: 1.0\n' >/dev/null
curl -sS -m 5 -o /dev/null -w 'nvd=%{http_code}\n' "https://services.nvd.nist.gov/rest/json/cves/2.0?resultsPerPage=1"
```

判据：第一条必须打印 `SUCCESS_RATE=10/10=1.000 CI95=[0.722,1.000]`（10/10 的 Wilson 下界不是 1.0，若你的实现在 n=10 满分时输出 1.000 下界，说明区间公式写错）；第二条打印的 `nvd=` 三位数决定第 2 节是否可用，`000` 即走第 3 节。
