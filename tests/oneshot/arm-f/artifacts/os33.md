## 判定

自有靶场 TARGET（自有资产 / 书面授权范围）的目录发现，本节只解决一件事：这批扫描用什么判据、开多少并发。判据错，后面批量全是噪声。探针只发 GET，单目标 ≤ 8 请求，不写、不删、不碰业务接口。

环境结论（本会话 2026-09-29 实测，Ubuntu 24.04.3 LTS / aarch64 / Python 3.12.3）：curl、bash、awk、sed、python3 已在位；ffuf、gobuster、feroxbuster、nuclei、jq 均**未安装**，因此批量段用 Python 标准库兜底（batch.sh 不依赖 jq）。要上 ffuf 先装再核验：

```bash
sudo apt-get install -y ffuf jq || go install github.com/ffuf/ffuf/v2@latest   # aarch64 源里没有时走 go install
ffuf -V; jq --version        # 核验行：能打印版本号才算装好；装不上就用本件 batch.sh 的 python3 路径
```

判定三步，顺序不能反：

**第 1 步 · 基线三点**：拿一个必然存在的路径、一个必然不存在的随机路径，各打两次，建立 (状态码, 长度) 二元基线。这是唯一能区分「真 404」和「软 404 泛响应」的手段。

```bash
BASE=http://TARGET
for p in / /index.html /n0such-a1b2c3d4 /n0such-a1b2c3d4-b; do
  curl -s -o /dev/null -w "%{http_code} %{size_download} %{time_total} $p\n" "$BASE$p"
done
```

**第 2 步 · 判据选择**：

| 探针信号 | 判定 | 批量段参数 |
|---|---|---|
| 不存在路径回 403/404，长度固定 | 硬 404，状态码可判 | `-ac -mc 200,204,301,302,307,401,403` |
| 不存在路径回 200，两次长度相同 | soft-404 泛响应 | `-ac -fs <泛响应长度>` |
| 不存在路径回 200，两次长度不同 | soft-404 动态模板 | 取一次泛响应正文，`-fr` 过滤其特征串 |
| 所有路径 403 / 超时 | WAF 或源站封禁 | 换 UA、降并发 `-t 5 -rate 20`，必要时代理池 |
| 连接层 code=0 | 目标不可达，不是目录结果 | 停，先修连通性/端口 |

**第 3 步 · 把第 1–2 步自动化**（主件，可跑；纯标准库，无第三方依赖）：

```python
#!/usr/bin/env python3
# ---8<--- judge.py ---8<---
"""判定 TARGET 的目录发现判据：soft-404 检测 -> ffuf/feroxbuster 参数推荐。
用法: python3 judge.py --base http://TARGET --json   |   python3 judge.py --self-test
"""
import argparse, json, sys, urllib.request, urllib.error

UA = "TARGET-UA/1.0"                     # 占位：替换为授权测试约定的 UA
PROBES = ["/", "/index.html", "/robots.txt"]
FAKE = "/n0such-a1b2c3d4"                # 不存在路径，取真/软 404 基线

def fetch(base, path, timeout=8.0):
    req = urllib.request.Request(base.rstrip("/") + path,
                                 headers={"User-Agent": UA, "Accept": "*/*"})
    try:
        with urllib.request.urlopen(req, timeout=timeout) as r:
            return {"path": path, "code": r.status, "size": len(r.read())}
    except urllib.error.HTTPError as e:
        return {"path": path, "code": e.code, "size": len(e.read())}
    except Exception as e:
        return {"path": path, "code": 0, "size": 0, "err": type(e).__name__}

def decide(probes, fake):
    """probes: 真实路径响应; fake: 不存在路径响应(>=2)。纯函数，self-test 直接喂合成样本。"""
    notes = []
    soft = len(fake) > 0 and all(f["code"] == 200 for f in fake)
    if soft and len({f["size"] for f in fake}) == 1:
        verdict, extra = "soft-404:固定长度泛响应", "-ac -fs %d" % fake[0]["size"]
    elif soft:
        verdict, extra = "soft-404:长度抖动泛响应", "-ac -fr"
        notes.append("长度不稳：先取一次泛响应正文，再用 -fr 过滤其特征串")
    elif any(f["code"] == 403 for f in fake + probes):
        verdict = "全站 403/WAF"
        extra = '-H "User-Agent: TARGET-UA/2.0" -mc 200,301,302,403 -ac'
        notes.append("403 基线：先确认 UA/来源 IP 是否被拦，再降到 -t 5 -rate 20")
    else:
        codes = sorted({f["code"] for f in fake})
        verdict = "硬 404:%s，状态码可判" % ",".join(str(c) for c in codes)
        extra = "-ac -mc 200,204,301,302,307,401,403"
    if probes and all(p["code"] == 0 for p in probes):
        verdict, extra = "目标不可达:先修连通性再判目录", ""
        notes.append("code=0 是连接层失败，不是目录结果")
    return verdict, extra, notes

def self_test():
    cases = [
        ([{"path": "/", "code": 200, "size": 612}],
         [{"code": 404, "size": 153}, {"code": 404, "size": 153}], "硬 404"),
        ([{"path": "/", "code": 200, "size": 1840}],
         [{"code": 200, "size": 1840}, {"code": 200, "size": 1840}], "soft-404:固定长度"),
        ([{"path": "/", "code": 403, "size": 300}],
         [{"code": 403, "size": 300}, {"code": 403, "size": 300}], "全站 403"),
        ([{"path": "/", "code": 0, "size": 0}],
         [{"code": 0, "size": 0}, {"code": 0, "size": 0}], "目标不可达"),
    ]
    for probes, fake, want in cases:
        got, extra, _ = decide(probes, fake)
        assert want in got, "case %r -> %r" % (want, got)
        print("case ok: %-22s -> %s | %s" % (want, got, extra))
    print("SELFTEST OK: %d cases" % len(cases))
    return 0

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--base", default="http://TARGET")
    ap.add_argument("--json", action="store_true")
    ap.add_argument("--self-test", action="store_true")
    a = ap.parse_args()
    if a.self_test:
        return self_test()
    fake = [fetch(a.base, FAKE), fetch(a.base, FAKE + "-b")]
    probes = [fetch(a.base, p) for p in PROBES]
    verdict, extra, notes = decide(probes, fake)
    print(json.dumps({"base": a.base, "verdict": verdict, "ffuf_extra": extra,
                      "notes": notes, "probes": probes, "fake": fake},
                     ensure_ascii=False, indent=None if a.json else 2))
    return 0

if __name__ == "__main__":
    sys.exit(main())
# --->8--- judge.py --->8---
```

未知：TARGET 的真实响应基线、WAF 规则集、真实目录清单——需要实际目标环境才能定。

## 批量

批量 = 目标清单 × 词表 × 后缀，跑之前先把同一套判据铺到每个目标上：**先 judge 再爆**。一个 soft-404 目标能把整份结果污染成 200 全表，而你自己看不出来。

第 1 步 · 单目标一次到位（递归与后缀）。`$EXTRA` 用 judge.py 输出的 `ffuf_extra` 覆盖，不要手写猜：

```bash
BASE=http://TARGET; WORDLIST=WORDLIST; mkdir -p out
EXTRA=$(python3 judge.py --base "$BASE" --json | python3 -c 'import json,sys;print(json.load(sys.stdin)["ffuf_extra"])')
echo "extra=$EXTRA"
ffuf -u "$BASE/FUZZ" -w "$WORDLIST" -e .php,.bak,.zip,.old,.json -t 20 -rate 50 \
     -recursion -recursion-depth 2 -ic $EXTRA -of json -o out/TARGET.json
# 装了 feroxbuster 的等价写法（递归更省事）
feroxbuster -u "$BASE" -w "$WORDLIST" -x php,bak,zip -d 2 -t 20 --rate-limit 50 -o out/TARGET.ferox
```

第 2 步 · 多目标流水（主件，逐目标先判后爆，结果归一化成 JSONL；不依赖 jq）：

```bash
#!/usr/bin/env bash
# ---8<--- batch.sh ---8<---
# 批量目录发现：目标清单 -> 逐目标判定 -> 逐目标 ffuf -> findings.jsonl
# 用法: JUDGE=./judge.py bash batch.sh --targets targets.txt [--dry-run] [--out out]
set -uo pipefail
JUDGE="${JUDGE:-./judge.py}"
TARGETS="targets.txt"; OUT="out"; DRY=0
WORDLIST="${WORDLIST:-WORDLIST}"          # 占位：替换为实际词表路径
CONC="${CONC:-20}"; RATE="${RATE:-0}"; PROXY="${PROXY:-}"
while [ $# -gt 0 ]; do
  case "$1" in
    --targets) TARGETS="$2"; shift 2 ;;
    --out)     OUT="$2";     shift 2 ;;
    --dry-run) DRY=1;        shift ;;
    *) echo "unknown arg: $1" >&2; exit 2 ;;
  esac
done
[ -f "$TARGETS" ] || { echo "no such targets file: $TARGETS" >&2; exit 2; }
mkdir -p "$OUT"
n=0
while IFS= read -r host; do
  [ -z "$host" ] && continue
  case "$host" in \#*) continue ;; esac
  n=$((n+1)); base="http://$host"
  if [ "$DRY" = "1" ]; then
    echo "[dry-run] python3 $JUDGE --base $base --json"
    echo "[dry-run] ffuf -u $base/FUZZ -w $WORDLIST -t $CONC -rate $RATE -recursion \$FFUF_EXTRA -of json -o $OUT/$host.json"
    continue
  fi
  rec=$(python3 "$JUDGE" --base "$base" --json 2>/dev/null) || rec='{}'
  extra=$(printf '%s' "$rec" | python3 -c 'import json,sys;print(json.load(sys.stdin).get("ffuf_extra",""))' 2>/dev/null)
  extra=${extra:--ac}
  ffuf -u "$base/FUZZ" -w "$WORDLIST" -t "$CONC" -rate "$RATE" \
       ${PROXY:+-x "$PROXY"} $extra -of json -o "$OUT/$host.json" >/dev/null 2>&1
  python3 - "$OUT/$host.json" "$host" <<'PY' >> "$OUT/findings.jsonl"
import json, sys
p, h = sys.argv[1], sys.argv[2]
try:
    d = json.load(open(p))
except Exception:
    d = {"results": []}
for r in d.get("results", []):
    print(json.dumps({"host": h, "url": r.get("url"), "status": r.get("status"),
                      "length": r.get("length")}, ensure_ascii=False))
PY
  sleep "${SLEEP:-1}"        # 目标间节流；>50 目标时分片跑，别一口气推
done < "$TARGETS"
echo "done: $n target(s), out=$OUT"
# --->8--- batch.sh --->8---
```

第 3 步 · 节流与分批（决定「能打」还是「能稳定打」）：单目标 `-t 20 -rate 50` 起步；出现 429/503 立刻降到 `-t 5 -rate 20` 并让 `SLEEP=5`；目标数 >50 时按 10 个一片切分，逐片重跑同一判据；出口 IP 被拦才上代理池（`PROXY=http://PROXY_HOST:PORT`），不要一开始就用。

第 4 步 · 结果归并：按 (url, status, length) 去重，长度聚簇找「同长度大批量」——那通常还是泛响应；进人工复核前对候选 URL 各打一次 `curl -sI` 复核，避免把头响应当目录。
