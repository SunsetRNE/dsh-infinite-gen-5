### 0. 最小验证：一条命令确认「有没有开放端口」

```bash
nmap -sT -Pn -T4 --top-ports 100 127.0.0.1 -oN /tmp/os27_local.txt
grep -cE '^[0-9]+/tcp[[:space:]]+open' /tmp/os27_local.txt
```

判定信号：`grep` 计数 `0` = 该主机 top-100 无开放端口（本机实测结果 0，退出码 0，非失败）；`>0` = 每行形如 `22/tcp open ssh`，逐行即开放清单。失败分支：输出 `Host seems down` → 加 `-Pn`（已默认加）；输出 `Operation not permitted` → 去掉 `-sS` 改用 `-sT`；`nmap: command not found` → 跑上面的安装命令。

### 1. 主件：常用端口盘点脚本（TCP 常用 → 指纹 → 全端口）

```bash
#!/usr/bin/env bash
# os27_scan.sh —— 自有/授权资产的常用端口盘点
set -u
TARGET="${1:-TARGET}"          # 占位符：换成实际 IP / 域名
OUT="${2:-/tmp/os27_scan}"     # 输出前缀

command -v nmap >/dev/null 2>&1 || apt-get install -y --no-install-recommends nmap

# A) 常用 TCP 端口（top-1000，连接扫描，容器/无原始套接字也稳）
nmap -sT -Pn -T4 --top-ports 1000 --open -oA "${OUT}_tcp_common" "$TARGET"

# B) 只对命中的端口做服务/版本指纹（省时间，也减小对目标的打扰）
PORTS=$(grep -E '^[0-9]+/tcp[[:space:]]+open' "${OUT}_tcp_common.nmap" | cut -d/ -f1 | paste -sd,)
if [ -n "$PORTS" ]; then
  nmap -sV -Pn -T4 --version-intensity 5 -p "$PORTS" -oA "${OUT}_tcp_ver" "$TARGET"
else
  echo "top-1000 无开放 TCP 端口"
fi

# C) 全端口发现（1-65535，--min-rate 控发包节奏；这段最慢）
nmap -sT -Pn -p- --open --min-rate 1500 --max-retries 2 -oG "${OUT}_all.gnmap" "$TARGET"
grep -oE '[0-9]+/open/tcp' "${OUT}_all.gnmap" | cut -d/ -f1 | sort -n -u > "${OUT}_open_ports.txt"
echo "开放 TCP 端口数: $(wc -l < "${OUT}_open_ports.txt")"
```

补充片段（按需，可选：有 root 且目标在内网走 A / 无 root 或被限速走 B）：

```bash
# UDP 常用端口：慢且易被 ICMP 限速，只在需要时开；无 root 会拿不到 ICMP 错误
nmap -sU -Pn --top-ports 50 --open -oA "${OUT}_udp_common" "$TARGET"

# 高速发现（未安装）：apt-get install -y masscan 或 go install github.com/projectdiscovery/naabu/v2/cmd/naabu@latest
masscan "$TARGET" -p1-65535 --rate 1000 --wait 3 -oL "${OUT}_masscan.txt"
```

**速率与稳定性（区分「能扫」与「能稳定扫」）**：`--min-rate` 默认不设，长连接丢包时会导致假阴性；丢包环境加 `--max-retries 3 --host-timeout 15m`。目标有 IPS/限速时把 `-T4` 降 `-T2`、并发降到 `--max-parallelism 8`，或把 C 段拆成多段分时执行。本条不做源 IP 伪装与分片绕过。

### 3. 验证件：解析扫描结果 + socket 独立复核

```python
#!/usr/bin/env python3
# verify_scan.py —— 解析 nmap XML，并用 socket 独立复核每个 open 端口
import sys, socket, xml.etree.ElementTree as ET

xmlf = sys.argv[1] if len(sys.argv) > 1 else "scan_tcp_common.xml"
root = ET.parse(xmlf).getroot()
rows, addrs = [], set()
for h in root.findall("host"):
    a = h.find("address").get("addr")
    addrs.add(a)
    for p in h.findall("./ports/port"):
        if p.find("state").get("state") != "open":
            continue
        svc = p.find("service")
        rows.append((int(p.get("portid")), a, svc.get("name", "?") if svc is not None else "?", "open"))
rows.sort()
targets = ",".join(sorted(addrs))
print("xml=%s host=%s open=%d" % (xmlf, targets, len(rows)))
mismatch = 0
for port, addr, name, st in rows:
    s = socket.socket(); s.settimeout(1.0)
    ok = s.connect_ex((addr, port)) == 0; s.close()
    mismatch += 0 if ok else 1
    print("%5d/tcp %-12s nmap=%s socket=%s match=%s" % (port, name, st, "open" if ok else "closed", ok))
print("mismatch=%d" % mismatch)
sys.exit(0 if rows and mismatch == 0 else 2)
```

判定信号：`open=0` 且退出码 `2` = 该范围无开放端口（静默主机，不是失败）；`mismatch=0` 且退出码 `0` = nmap 结果被独立复核确认；`mismatch>0` = 目标有速率限制/中间设备干扰，重扫并降速。复现命令：

```bash
bash os27_scan.sh TARGET /tmp/os27_scan && python3 verify_scan.py /tmp/os27_scan_tcp_common.xml; echo "exit=$?"
```
