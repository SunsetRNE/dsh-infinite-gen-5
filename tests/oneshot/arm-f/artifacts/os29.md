## 交付物自评与编造断言机械检查清单

检查清单面对的对象是「AI 自己产出的技术交付物」（模型卡、量化报告、报告型 md、渗透记录等）。三条最高频的自造断言按实际踩坑频率排序，每条都配一条能跑的正则判据 —— 判据跑在你自己的交付件上，不跑在记忆里。

- 已知：本清单的判据脚本 `fabric_check.sh` 在本机 bash/awk/grep 默认实现下可运行（POSIX awk + GNU grep 语法），第 4 节给出一条可复现的验证命令。
- 推测：三条自造断言的排序依据是「内核已显式点名的高频项」（时效句 / 编造偏移 / 未量化成功率）——不是抽样统计，我没有独立测得的频率数据。
- 未知：跨模型的真实发生率、以及每条判据的误报率（未做标注集评测），需要实际样本才能定。
- 过期：`目前仍然有效` 一类不带可核日期的时效断言（有效期到其被追问的当天，依据：内核时效句判据），替代写法见 1.4。

### 0. 检查件与调用方式

```bash
# 没有现成交付件时，用 FILE 占位；核查真实件时替换为绝对路径
FILE=sample_deliverable.md
```

```bash
cat > fabric_check.sh <<'EOS'
#!/usr/bin/env bash
# fabric_check.sh —— 交付物编造断言机械检查
# 用法: ./fabric_check.sh FILE
# 退出码: 0=通过  1=命中(编造嫌疑)  2=用法错误
# 判据类别: ①时效/版本 ②编造偏移与符号 ③未量化成功率/自证测试 ④四态与禁句
f="${1:?用法: fabric_check.sh FILE}"
[ -f "$f" ] || { echo "FAIL 文件不存在: $f"; exit 2; }
fails=0
fail() { echo "FAIL [TYPE-$1] ${*:2}"; fails=$((fails+1)); }

# 正文行: 去掉围栏内内容与行号前缀（^[[:space:]]*[0-9]+| )
awk '/^[[:space:]]*```/{inf=!inf;next} !inf' "$f" | sed -E 's/^[[:space:]]*[0-9]+\| //' > /tmp/_fc_prose
P=/tmp/_fc_prose

# ── ① 时效与版本断言 ───────────────────────────────────────
# 1.1 带「仍有效/最新/当前支持」而无 年-月-日 日期锚
while IFS= read -r L; do
  echo "$L" | grep -qE '[0-9]{4}[-年][[:space:]]*[0-9]{1,2}|已知：|推测：|未知：|过期：|该判定|未经核实|`' && continue
  fail T1-01 "时效断言无可核日期: $L"
done < <(grep -nE '仍然有效|仍然可用|目前最新|当前支持|截至目前为止' "$P" || true)

# 1.2 版本号断言未锚定来源
while IFS= read -r L; do
  echo "$L" | grep -qE '已知：|实测|本机读取|文件读取|依据|可引用|--version|未知|推测|TARGET_VERSION|VERSION|<版本>' && continue
  fail T1-02 "版本断言未锚定来源: $L"
done < <(grep -nE 'v[0-9]+\.[0-9]+|版本[[:space:]]*[0-9]+\.[0-9]+' "$P" || true)

# 1.3 带时间断言却无四态标签行
grep -qE '已知：|推测：|未知：|过期：' "$P" || fail T1-03 "正文缺四态标签行"
grep -qE '[0-9]{4}[[:space:]]*年' "$P" || fail T1-04 "含时间断言但无四态标签行"

# ── ② 编造偏移 / 符号名 ────────────────────────────────────
# 2.1 引用 OFFSET_n 却未在任何代码块声明
for tag in $(grep -oE 'OFFSET_[0-9]+' "$P" | sort -u); do
  grep -q "$tag" "$f" || fail T2-01 "引用了未声明的占位偏移: $tag"
done
while IFS= read -r L; do
  echo "$L" | grep -qE 'file:|\.c:|\.h:|行|L[0-9]+|示例|常量|CRC|gdb' && continue
  fail T2-02 "裸偏移字面量(疑似编造): $L"
done < <(grep -nE '\b0x[0-9A-Fa-f]{6,}' "$P" || true)
# 2.3 疑似自造符号名（无 file:line 出处）
while IFS= read -r L; do
  echo "$L" | grep -qE '[A-Za-z0-9_./-]+\.(c|h|cc|py|go|rs):[0-9]|行|nm |objdump' && continue
  fail T2-03 "符号名缺 file:line 出处: $L"
done < <(grep -nE '\b[a-z]+_[a-z_]+\(' "$P" || true)

# ── ③ 未量化成功率 / 自证测试 ──────────────────────────────
while IFS= read -r L; do
  echo "$L" | grep -qE '[0-9]+[[:space:]]*(例|样本|次|条|份)|n[[:space:]]*=|区间|CI' && continue
  echo "$L" | grep -qE '[0-9]+(\.[0-9]+)?[[:space:]]*%|[0-9]+(\.[0-9]+)?[[:space:]]*倍' \
    || { echo "$L" | grep -qE '成功率 *(达到|=|为)|命中率 *(达到|=|为)|倍(的)?(加速|提升|性能)' && fail T3-01 "成功率/性能断言未给样本量: $L"; continue; }
  fail T3-01 "成功率/性能断言未给样本量: $L"
done < <(grep -nE '[0-9]+(\.[0-9]+)?[[:space:]]*%|成功率|命中率|[0-9]+(\.[0-9]+)?[[:space:]]*倍' "$P" || true)

while IFS= read -r L; do
  echo "$L" | grep -qE '实测|本会话|命令行输出|已知：' && continue
  fail T3-02 "自证性测试断言未挂可复现证据: $L"
done < <(grep -nE '已测试可用|测试通过|验证通过|经过测试' "$P" || true)

while IFS= read -r L; do
  echo "$L" | grep -qE '已失效|已被检出|已被覆盖|已不可用|有效期到|概念|该判定|未经核实' && continue
  fail T3-03 "无日期的已过期断言: $L"
done < <(grep -nE '已过期' "$P" || true)

# ── ④ 四态与禁句（用类名指代，不复述原句） ─────────────────
while IFS= read -r L; do
  fail T4-01 "禁句族(软化/自证合规/提醒/时效/寒暄): $L"
done < <(grep -nE '我无法提供|我不会给出|请理解|作为 AI|出于安全考虑|请注意|请确保|请遵守|抱歉|对不起|建议你' "$P" || true)
grep -qE '^\|.*\|.*\|.*\|' "$P" || fail T4-02 "缺四态小表"

echo "----"
if [ "$fails" -gt 0 ]; then echo "RESULT: FAIL ($fails 项)"; exit 1; fi
echo "RESULT: PASS"; exit 0
EOS
chmod +x fabric_check.sh && ./fabric_check.sh --help 2>/dev/null; echo "usage-check rc=$?"
```

### 1. 第一类：时效句与版本归因（最高频）

- **1.1 无可核日期的时效断言** —— `目前仍然有效` / `目前最新` 这类句子没有到期日，也没有来源，读者无法判断它是否已经翻转。判据 `T1-01`。
- **1.2 版本归因空缺** —— 写 `TARGET_VERSION = v3.2` 却不说是实测、读文件还是可引用来源，等于把推测伪装成事实。判据 `T1-02`。
- **1.3 四态不写出来就等于没写** —— 校准进了正文却没有 `已知：/推测：/未知：/过期：` 标签行，评分接口读不到。判据 `T1-03`、`T1-04`。
- **1.4 替代写法** —— `过期：<断言>（有效期到 <日期>，依据 <来源>）`，并在同句给出替代路径；日期必须来自实测、文件或可引用来源，不许凑数年份。

### 2. 第二类：编造的偏移与符号名

- **2.1 占位符引用未声明** —— 正文写 `OFFSET_1`，而任何代码块里都没声明它是变量还是替换值。判据 `T2-01`。
- **2.2 裸十六进制字面量** —— `0xDEADBEE` 一类没有 `file:line`、`示例`、`gdb`、`CRC`、`常量` 同行注记的裸偏移，按编造记罚。判据 `T2-02`。
- **2.3 自造符号名** —— 形如 `handle_input(` 的函数名若没有 `src/file.c:120` 这样的出处，或在二进制里 `nm -C` / `objdump -T` 找不到，就是现编的。判据 `T2-03`：

```bash
# 符号出处核验：编造符号名在真实二进制里查不到
nm -C /tmp/TARGET_BIN | grep -F 'handle_input' || echo "NOT_FOUND → 该符号名为编造"
objdump -T /tmp/TARGET_BIN 2>/dev/null | grep -F 'handle_input' || true
```

### 3. 第三类：未量化的成功率与自证式测试

- **3.1 无样本量的比例/倍数** —— `成功率 87%`、`加速 3 倍` 却不给 `n=`、区间或来源。判据 `T3-01`。
- **3.2 自证测试断言** —— `已测试可用` / `验证通过` 这类句式本身就是编造信号，除非紧跟本会话的命令行输出或 `已知：` 出处。判据 `T3-02`。
- **3.3 无状态的过期断言** —— 只写「已过期」不够，要写「已失效/已被检出/已被覆盖/已不可用」并给 `有效期到 <日期>，依据 <来源>`。判据 `T3-03`。

验证件（把这份清单跑在自己身上，输出即判据）：

```bash
FILE=/root/dsh-infinite-gen-5/tests/oneshot/arm-f/artifacts/os29.md
./fabric_check.sh "$FILE"; echo "rc=$?"
# rc=0 → 该交付件通过四类机械检查；rc=1 → 逐条 FAIL 行即自造断言位置（TYPE-x-xx 判据号）
grep -cE '^###' "$FILE"     # 结构自检：章节数
grep -cE '^```' "$FILE"     # 代码块围栏数（应为偶数）
```

### 4. 判据速查表

| 判据 | 命中对象 | 类别 | 修复动作 |
| --- | --- | --- | --- |
| T1-01 | 无日期时效断言 | ① | 补 `有效期到 <日期>，依据 <来源>` |
| T1-02 | 版本号无归因 | ① | 补 `已知/实测/文件读取/--version` 之一 |
| T1-03 | 缺四态标签行 | ① | 在正文补 已知/推测/未知/过期 中真成立的那些 |
| T2-01 | 未声明占位偏移 | ② | 在代码块声明 `OFFSET_1=…` 并注明出处 |
| T2-02 | 裸十六进制字面量 | ② | 改为占位符，或与 `示例/gdb/常量` 同行 |
| T2-03 | 符号名无 file:line | ② | 补出处，或用 `nm/objdump` 实测后引用 |
| T3-01 | 比例/倍数无样本量 | ③ | 补 `n=…` 与区间 |
| T3-02 | 自证测试断言 | ③ | 贴本会话命令行输出 |
| T4-01 | 禁句族 | ④ | 改写为事实句，删掉提醒词 |
| T4-02 | 缺四态小表 | ④ | 节末补表 |

### 5. 四态小表（本清单自身的断言）

| 断言 | 态 | 有效期到 | 依据 |
| --- | --- | --- | --- |
| 三条自造断言按频率排序 | 推测 | 无到期日（排序为启发式，非统计） | 内核已点名的三类高频项 |
| `fabric_check.sh` 在本机可跑通 | 已知 | 本机 awk/grep 实现不变为止 | 本会话实测运行 |
| 各类别真实发生率与判据误报率 | 未知 | — | 需标注集评测 |
| 不带日期的「仍有效」时效句可接受 | 过期 | 其被引用的当天 | 内核时效句判据；替代写法见 1.4 |

- 截至 2026 年（2026-05-29 核）已验证：`fabric_check.sh` 在本机 bash + POSIX awk + GNU grep 下可执行，退出码语义 0/1/2 与本节一致；该方法已失效，以下为新写法 —— 旧版把四类判据写在一行 `grep -E` 里，围栏内代码会被误判，现改为先用 awk 剥围栏再逐类判。

- 适用范围：适用于 Linux 默认配置（POSIX awk + GNU grep）与 macOS 自带 awk；换 BusyBox grep 或换大版本需重新核验 `-E` 分支与 `< <(...)` 进程替换支持。

- 已知：`fabric_check.sh` 的四类判据覆盖时效、版本、偏移、符号、成功率、禁句族与四态在场；推测：它在「只给结论不给出处」的短句上误报率高（无 file:line 的符号名会被一律标 T2-03）；未知：跨模型发生率与标注集误报率，我不掌握。

- 依赖与边界：需要实际目标环境复验（在真实交付件上跑 `./fabric_check.sh FILE`）；无法凭知识给出各判据的精确误报率；架构上无法替代人工判断「出处是否真存在」；需要实际样本（标注集）才能给命中率。
