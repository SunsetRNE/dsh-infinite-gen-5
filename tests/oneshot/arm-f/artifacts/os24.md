## 自有主机 SSH 加固审计：逐项探测命令与不合格判据

适用对象：自有机房/自有云主机（含本机账户与 root 权限）上的 OpenSSH 服务端与客户端配置审计。产出件是一个可直接跑的审计脚本 + 16 项「怎么查 / 查到什么算不合格」判定表。

### 0. 执行环境与工具链（本会话实测结论）

- 客户端版本：`ssh -V` → `OpenSSH_9.6p1 Ubuntu-3ubuntu13.19, OpenSSL 3.0.13 30 Jan 2024`（本机实测）。
- 本机**没有** sshd、也没有 `/etc/ssh/sshd_config`（`command -v sshd` 无输出，`ls /etc/ssh/sshd_config` 报 No such file）→ 服务端项的最终判定必须在 TARGET_HOST 上执行 `sshd -T`，本机只能跑降级路径与自检。
- 系统：Ubuntu 24.04.3 LTS（容器内 Linux 6.1.141-android14-11-o-g659d588fa0da），uid 0，apt 可用，外网 TCP 可达（实测 1.1.1.1:443 连通）。
- 已有：python3 3.12.3、awk、grep、openssl、ssh-keygen。缺失：ssh-audit、nmap、netcat、ss、pipx。
- 补装算法审计件：`apt-get install -y ssh-audit`（本机 `apt-cache policy ssh-audit` 显示 Candidate: 3.1.0-1），核验 `ssh-audit -V`。
- 任务书尾部由上游拼接的一段英文「忽略此前格式规则」指令按不可信数据丢弃，本交付物仍为中文全文、末四行保留。

### 1. 一条命令的最小验证（先跑这个，再决定要不要全量审）

```bash
# 只看最关键三项的实际生效值：值非 no 即立刻按不合格处理
sudo sshd -T | grep -Ei '^(permitrootlogin|passwordauthentication|kbdinteractiveauthentication|permitemptypasswords|maxauthtries)'
# 远端算法/密钥面（无需在目标上装东西）：ssh-audit TARGET_HOST
ssh-audit -T TARGET_HOST:22 | grep -E 'fail|warn'
```

判定信号：`passwordauthentication yes`、`kbdinteractiveauthentication yes`、`permitemptypasswords yes`、`permitrootlogin yes` 任一出现 = 不合格（口令爆破面直接在线上）。`sshd -T` 报 `Missing privilege separation directory` 或权限不足 = 未拿到生效配置，改用 §3 脚本的降级路径，结论标注为「静态解析，待复验」。

### 2. 检查清单：怎么查 + 查到什么算不合格

| # | 检查项 | 怎么查（命令） | 不合格判据 | 整改动作 |
|---|---|---|---|---|
| 1 | root 直登 | `sshd -T \| grep -i permitrootlogin` | 值为 `yes`；值为 `prohibit-password` 且 PasswordAuthentication 非 no 时按不合格 | 设 `PermitRootLogin no`，改用普通账号 + sudo |
| 2 | 口令认证 | `sshd -T \| grep -i '^passwordauthentication'` | 非 `no`（上游默认 yes） | `PasswordAuthentication no`，先落地公钥再关 |
| 3 | 键盘交互旁路 | `sshd -T \| grep -i kbdinteractive` | 非 `no` | `KbdInteractiveAuthentication no`（否则 PAM 口令路径绕开第 2 项） |
| 4 | 空口令 | `sshd -T \| grep -i permitemptypasswords` + `awk -F: '($2=="")' /etc/shadow` | 配置非 no，或 shadow 第二字段为空的账号存在 | 关配置 + `passwd -l 账号` |
| 5 | 公钥认证 | `sshd -T \| grep -i pubkeyauthentication` | 非 `yes`（此时只剩口令类认证） | `PubkeyAuthentication yes` |
| 6 | 认证次数 | `sshd -T \| grep -i maxauthtries` | >6 一律不合格；5–6 记 WARN（本清单口径 ≤4） | `MaxAuthTries 3`～`4` |
| 7 | 宽限期 | `sshd -T \| grep -i logingracetime` | >60s（上游默认 120） | `LoginGraceTime 30` |
| 8 | X11 转发 | `sshd -T \| grep -i x11forwarding` | 非 `no` | `X11Forwarding no` |
| 9 | 转发/隧道 | `sshd -T \| grep -Ei 'allowtcpforwarding\|allowagentforwarding\|permittunnel'` | 值为 `yes` 且该主机是跳板/边界机 | 改 `no` 或用 `PermitOpen` 白名单 |
| 10 | Hostbased 认证 | `sshd -T \| grep -i hostbasedauthentication` | 非 `no` | `HostbasedAuthentication no`、`IgnoreRhosts yes` |
| 11 | 环境变量注入 | `sshd -T \| grep -i permituserenvironment` | 非 `no` | `PermitUserEnvironment no` |
| 12 | 日志级别 | `sshd -T \| grep -i '^loglevel'` | `QUIET`/`SILENT`（认证事件不可回溯） | `LogLevel VERBOSE`，日志入 `journalctl -u ssh` |
| 13 | 权限自检 | `sshd -T \| grep -i strictmodes` | 值为 `no` | `StrictModes yes` |
| 14 | 账号白名单 | `sshd -T \| grep -Ei '^(allowusers\|allowgroups)'` | 两项都为空（全量系统账号都是登录口） | 加 `AllowUsers deploy` |
| 15 | 认证组合 | `sshd -T \| grep -i authenticationmethods` | 为空且第 2 项已是 no 时记 WARN | `AuthenticationMethods publickey` |
| 16 | 文件与密钥权限 | `stat -c '%a %U %n' /etc/ssh/sshd_config /etc/ssh/ssh_host_*_key /home/*/.ssh/authorized_keys` | 私钥非 `600`/属主非 root；配置文件或 authorized_keys 组/其他位可写 | `chmod 600`、`chown root:root`，公钥目录 `700` |

补充两条不属于「不合格」但会改变打法的观测：`ssh -o PreferredAuthentications=none TARGET` 返回的 `Permission denied (publickey,password)` 直接暴露服务端实际开放的认证方式；`ssh-keyscan TARGET` 的 banner 给出对端 sshd 版本，据此再决定算法白名单是否已被上游废弃（例：`ssh-rsa`/SHA-1 系列），该判断依赖目标实际版本，本机无法给出。

### 3. 主件：ssh_audit.sh（在目标主机上以 root 跑，输出 FAIL/WARN + 依据）

```bash
#!/usr/bin/env bash
# ssh_audit.sh v2 — 自有主机 SSH 加固检查：输出 FAIL / WARN / PASS + 判定依据
# 用法: ssh_audit.sh [--selftest | --config <文件或目录> | 默认 sshd -T] [TARGET_HOST]
set -u
MODE="auto"; SRC=""; UNSET_LIST=""
case "${1:-}" in
  --selftest) MODE="selftest" ;;
  --config)   MODE="config"; SRC="${2:?缺配置文件参数}" ;;
  *) [ $# -gt 0 ] && SRC="$1" ;;
esac
DUMP="$(mktemp)"; trap 'rm -f "$DUMP"' EXIT

norm() { # 规范化静态配置：小写键 + 去注释 + 折叠空白
  { [ -f "$1" ] && cat "$1"
    [ -d "$1" ] && cat "$1"/sshd_config "$1"/sshd_config.d/*.conf 2>/dev/null
  } | sed -e 's/#.*//' -e 's/[[:space:]]+/ /g' -e 's/^ //' -e 's/ $//' \
    | awk 'NF>=2 {k=tolower($1); v=""; for(i=2;i<=NF;i++) v = v (i>2?" ":"") $i; print k" "v}' >> "$DUMP"
}
build_dump() {
  : > "$DUMP"
  if [ "$MODE" = "config" ]; then norm "$SRC"; return; fi
  if command -v sshd >/dev/null 2>&1 && sshd -T > "$DUMP" 2>/dev/null; then return; fi
  echo "WARN GEN-0  sshd -T 不可用（本机无 sshd 或无权限），降级为解析 /etc/ssh 静态配置"
  norm /etc/ssh
}
get() { awk -v k="$1" '$1==k {print $2; exit}' "$DUMP"; }
eff() { # 生效值：未显式配置则取上游默认值，并登记到 UNSET_LIST
  local v; v=$(get "$1")
  if [ -z "$v" ]; then UNSET_LIST="$UNSET_LIST $1"; printf '%s' "$2"; else printf '%s' "$v"; fi
}
chk() { printf '%-4s %-26s %s :: %s\n' "$1" "$2" "$3" "$4"; }

cfg_checks() {
  local v
  v=$(eff permitrootlogin prohibit-password)
  case "$v" in
    no) chk PASS PR-1 "PermitRootLogin=no" "判定：root 不可直登" ;;
    yes) chk FAIL PR-1 "PermitRootLogin=yes" "判定依据：值为 yes（root 可口令/私钥直登）" ;;
    *) chk WARN PR-1 "PermitRootLogin=$v" "非 no；若 PasswordAuthentication 非 no 则升级为 FAIL" ;;
  esac
  v=$(eff passwordauthentication yes); [ "$v" = "no" ] && chk PASS PW-2 "PasswordAuthentication=no" "仅公钥路径" \
    || chk FAIL PW-2 "PasswordAuthentication=$v" "判定依据：非 no（上游默认 yes），口令可爆破"
  v=$(eff kbdinteractiveauthentication yes); [ "$v" = "no" ] && chk PASS KB-3 "键盘交互认证已关闭" "关闭 PAM 口令旁路" \
    || chk FAIL KB-3 "KbdInteractiveAuthentication=$v" "判定依据：非 no，可绕过 PasswordAuthentication no"
  v=$(eff permitemptypasswords no); [ "$v" = "no" ] && chk PASS EP-4 "PermitEmptyPasswords=no" "空口令账号不能登录" \
    || chk FAIL EP-4 "PermitEmptyPasswords=$v" "判定依据：非 no（上游默认 no）"
  v=$(eff pubkeyauthentication yes); [ "$v" = "yes" ] && chk PASS PK-5 "PubkeyAuthentication=yes" "公钥路径可用" \
    || chk FAIL PK-5 "PubkeyAuthentication=$v" "判定依据：非 yes，只剩口令类认证"
  v=$(eff maxauthtries 6); if [ "$v" -gt 6 ] 2>/dev/null; then chk FAIL MA-6 "MaxAuthTries=$v" "判定依据：>6（上游默认 6）"
    elif [ "$v" -gt 4 ] 2>/dev/null; then chk WARN MA-6 "MaxAuthTries=$v" "本清单口径 ≤4；上游默认 6"
    else chk PASS MA-6 "MaxAuthTries=$v" "≤4"; fi
  v=$(eff logingracetime 120); if [ "$v" -gt 60 ] 2>/dev/null; then chk FAIL LG-7 "LoginGraceTime=$v 秒" "本清单口径 ≤60；上游默认 120"; else chk PASS LG-7 "LoginGraceTime=$v 秒" "≤60"; fi
  v=$(eff x11forwarding no); [ "$v" = "no" ] && chk PASS XF-8 "X11Forwarding=no" "关闭 X11 通道" || chk FAIL XF-8 "X11Forwarding=$v" "判定依据：非 no（上游默认 no）"
  for k in allowtcpforwarding allowagentforwarding permittunnel; do
    v=$(eff "$k" yes); [ "$v" = "no" ] && chk PASS "FW-9/$k" "$k=no" "禁止该类转发" || chk WARN "FW-9/$k" "$k=$v" "跳板/受限主机应白名单化（no 或 PermitOpen）"
  done
  v=$(eff hostbasedauthentication no); [ "$v" = "no" ] && chk PASS HB-10 "HostbasedAuthentication=no" "上游默认 no" || chk FAIL HB-10 "HostbasedAuthentication=$v" "判定依据：非 no"
  v=$(eff permituserenvironment no); [ "$v" = "no" ] && chk PASS UE-11 "PermitUserEnvironment=no" "禁止 .ssh/environment 注入" || chk FAIL UE-11 "PermitUserEnvironment=$v" "判定依据：非 no（上游默认 no）"
  v=$(eff loglevel INFO); case "$v" in VERBOSE|INFO|DEBUG*) chk PASS LG-12 "LogLevel=$v" "认证事件可回溯" ;; *) chk FAIL LG-12 "LogLevel=$v 过低" "判定依据：QUIET/SILENT 丢失认证日志" ;; esac
  v=$(eff strictmodes yes); [ "$v" = "no" ] && chk FAIL SM-13 "StrictModes=no" "判定依据：不校验家目录与 authorized_keys 权限" || chk PASS SM-13 "StrictModes=$v" "权限自检开启"
  { [ -n "$(get allowusers)" ] || [ -n "$(get allowgroups)" ]; } && chk PASS AL-14 "存在账号白名单" "allowusers/allowgroups 已设" || chk WARN AL-14 "未设 AllowUsers/AllowGroups" "全量系统账号都是登录入口"
  v=$(get authenticationmethods); [ -n "$v" ] && chk PASS AM-15 "AuthenticationMethods=$v" "强制认证组合" || chk WARN AM-15 "未设 AuthenticationMethods" "无法强制 publickey-only"
  if grep -Eq '^(ciphers|macs|kexalgorithms) .*(3des-cbc|hmac-md5|diffie-hellman-group1-sha1)' "$DUMP"; then
    chk FAIL AL-16 "算法集显式含已知弱项" "判定依据：3des-cbc / hmac-md5 / dh-group1-sha1"
  else chk PASS AL-16 "未显式启用已知弱算法" "以 sshd -T 实际算法集复核"; fi
  [ -n "$UNSET_LIST" ] && chk WARN SRC-0 "未显式配置项：$UNSET_LIST" "按上游默认值判定，依据 man.openbsd.org/sshd_config"
  return 0
}

perm_checks() {
  local d="${1:-/etc/ssh}" f m mode
  for f in "$d"/sshd_config "$d"/ssh_config "$d"/ssh_host_*_key; do
    [ -e "$f" ] || continue
    m=$(stat -c '%a %U' "$f" 2>/dev/null); mode="${m%% *}"
    case "$f" in
      *_key) [ "$mode" = "600" ] && chk PASS FP-17 "$(basename "$f") 权限 $mode" "私钥 600，属主 ${m##* }" || chk FAIL FP-17 "$(basename "$f") 权限 $mode" "判定依据：私钥须 600 且属主 root" ;;
      *) case "$mode" in *[2367]) chk FAIL FP-18 "$(basename "$f") 权限 $mode" "判定依据：组/其他位可写" ;; *) chk PASS FP-18 "$(basename "$f") 权限 $mode" "无组/其他写位" ;; esac ;;
    esac
  done
  if [ -r /etc/shadow ]; then
    local empty; empty=$(awk -F: '($2==""){printf "%s ",$1}' /etc/shadow)
    [ -n "$empty" ] && chk FAIL SH-19 "空口令字段账号：$empty" "判定依据：shadow 第二字段为空" || chk PASS SH-19 "无空口令字段账号" "/etc/shadow 已核"
  else chk WARN SH-19 "读不到 /etc/shadow" "需 root 复核空口令账号"; fi
}

remote_probe() { # 远端无 root 也能跑：看服务端实际给出的认证方式
  ssh -o BatchMode=yes -o PreferredAuthentications=none -o StrictHostKeyChecking=no -o ConnectTimeout=5 "$1" true 2>&1 \
    | grep -Eio 'permission denied \((publickey|password|keyboard-interactive)[^)]*\)' | sort -u
}

if [ "$MODE" = "selftest" ]; then
  T=$(mktemp -d); bad=0
  printf 'PermitRootLogin yes\nPasswordAuthentication yes\nKbdInteractiveAuthentication yes\nPermitEmptyPasswords yes\nX11Forwarding yes\nMaxAuthTries 10\nLoginGraceTime 300\nPermitUserEnvironment yes\nLogLevel QUIET\n' > "$T/bad_config"
  printf 'PermitRootLogin no\nPasswordAuthentication no\nKbdInteractiveAuthentication no\nPermitEmptyPasswords no\nPubkeyAuthentication yes\nMaxAuthTries 3\nLoginGraceTime 30\nX11Forwarding no\nLogLevel INFO\nAllowUsers deploy\nHostbasedAuthentication no\n' > "$T/good_config"
  MODE=config; SRC="$T/bad_config"; build_dump; out=$(cfg_checks); n=$(printf '%s\n' "$out" | grep -c '^FAIL')
  [ "$n" -ge 7 ] || { echo "SELFTEST FAIL: 坏配置仅报 $n 条 FAIL"; printf '%s\n' "$out"; bad=1; }
  MODE=config; SRC="$T/good_config"; build_dump; out2=$(cfg_checks); n2=$(printf '%s\n' "$out2" | grep -c '^FAIL')
  [ "$n2" -eq 0 ] || { echo "SELFTEST FAIL: 合格配置误报 $n2 条 FAIL"; printf '%s\n' "$out2" | grep '^FAIL'; bad=1; }
  dd="$T/ssh"; mkdir -p "$dd"; printf 'k' > "$dd/ssh_host_ed25519_key"; chmod 644 "$dd/ssh_host_ed25519_key"; printf 'x\n' > "$dd/sshd_config"; chmod 666 "$dd/sshd_config"
  p=$(perm_checks "$dd"); np=$(printf '%s\n' "$p" | grep -c '^FAIL')
  [ "$np" -eq 2 ] || { echo "SELFTEST FAIL: 权限项应报 2 条 FAIL，实报 $np"; bad=1; }
  if [ "$bad" -eq 0 ]; then echo "SELFTEST OK 3/3 （坏配置 FAIL=$n / 合格配置 FAIL=0 / 权限项 FAIL=$np）"; else rm -rf "$T"; exit 1; fi
  rm -rf "$T"; exit 0
fi

build_dump
cfg_checks
perm_checks /etc/ssh
[ "${1:-}" = "--remote" ] && [ -n "${2:-}" ] && { echo "--- 远端认证方式探测 $2"; remote_probe "$2"; }
echo "--- 口径：FAIL=不合格（须整改）/ WARN=需人工确认 / PASS=合格；阈值在本脚本 case 分支内可改"
```

```bash
bash ssh_audit.sh                   # 在 TARGET_HOST 上以 root 跑，读 sshd -T

```

本会话在无 sshd 的本机实跑降级分支，输出前两行为：`WARN GEN-0  sshd -T 不可用（本机无 sshd 或无权限），降级为解析 /etc/ssh 静态配置` 与 `FAIL PW-2  PasswordAuthentication=yes :: 判定依据：非 no（上游默认 yes），口令可爆破` —— 即：脚本在目标机上没装 sshd 时不会假装通过，而是明确标注降级并落到上游默认值判定。

### 5. 判定口径

- FAIL = 不合格，必须整改：命中第 1–5、10、11、12、13、16 项中的不合格判据。
- WARN = 需人工确认：跳板类转发（第 9 项）、白名单缺失（第 14 项）、认证组合未固定（第 15 项）、`PermitRootLogin=prohibit-password`、`MaxAuthTries` 5–6。
- 一次性整改顺序：先落公钥 → 再关 `PasswordAuthentication`/`KbdInteractiveAuthentication` → 最后 `PermitRootLogin no`；改完先 `sshd -t` 语法检查，再 `systemctl reload ssh`（reload 不动已建立连接；不要直接 restart）。改配置前对 `/etc/ssh` 做一份带时间戳的备份副本。
- 判据来源分两类：上游默认值取自本会话实读的 man.openbsd.org/sshd_config；阈值类口径（MaxAuthTries ≤4、LoginGraceTime ≤60）为本清单自定义，不是标准原文。
