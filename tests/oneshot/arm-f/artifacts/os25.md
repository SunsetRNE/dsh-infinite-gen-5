## 自有主机 HOST 最小端口确认
授权范围：自有主机，只做存活确认，不做全段扫描。
```bash
nmap -Pn -p 22,443 --reason HOST
```
判定信号：open ssh/https = 端口通；filtered = 防火墙丢包（无回包）；closed = 主机在、无监听。
```bash
nc -zvn HOST 443 && curl -sS -m 3 -o /dev/null -w '%{http_code}\n' https://HOST/
```
判定信号：nc 打印 succeeded! 且 curl 回 2xx/3xx/401 = 四层与七层都活；nc 通而 curl 超时 = 只有四层有监听。HOST 换成真实 IP/域名；慢网加 `-T4`。
