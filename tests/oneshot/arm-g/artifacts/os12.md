## 技术回答自评：三类最易编造断言与机械核查命令

核查对象：本会话中我自己产出的技术回答（草稿记为 DRAFT.md）。核查机为本机实测：Linux 6.1.141-android14-11-o-g659d588fa0da / aarch64、uid=0、python3 3.12.3（/usr/bin/python3）、objdump / nm / readelf / git / curl / sha256sum 在位；`command -v rg jq go` 三条无输出 = 缺失。缺失影响两处：JSON 断言校验不能走 jq（改 `python3 -m json.tool`），递归源码检索不能走 rg（改 `grep -rn`）。

自评口径：编造不是态度问题，是四类字符串在无来源时的自发补全 —— 数字、名称、时效、因果。下面三类按「症状 → 诱发场景 → 一条机械检查 → 判定信号 → 失败分支」写。判据只有一条：检查必须**能把断言打成 FAIL**；只报 PASS 的检查等于没查。

### 类 A｜数值断言：内存偏移 / 版本号 / 成功率 / 性能倍数

- 症状（示例字面量）：`OFFSET_1`、裸十六进制、`TARGET_VERSION 9.9.9`、`命中率 87%`、`提速 3.2×`、`CVSS 7.5`。
- 诱发场景：题面已出现一个数字，我顺着它的量级续造同族数字；被追问「具体是多少」时，用数字替代「未知」。
- 机械检查（只核本机真实存在的文件）：

```bash
BIN=FILE            # 文件不存在就直接写 OFFSET_1 占位，不猜
nm -D "$BIN" 2>/dev/null | grep -n ' SYMBOL_NAME$'
readelf -sW "$BIN" 2>/dev/null | grep -n 'SYMBOL_NAME'
readelf -SW "$BIN" 2>/dev/null | grep -c '\.symtab'          # 0 = 已 strip
objdump -d --start-address=OFFSET_1 --stop-address=OFFSET_1_END "$BIN" 2>/dev/null | head
```

- 判定信号：符号名查到 → 名称可留；反向反汇编里该地址段落在目标函数体内 → 偏移可标「实测」，否则一律占位。
- 失败分支：`.symtab` 计数为 0（strip 过）→ 偏移与符号类断言全部降级为「无法凭知识给出」，不给猜测值。

### 类 B｜符号与命名断言：函数 / 模块 / flag / API 端点 / 配置键

- 症状：`TARGET_TOOL --FLAG_NAME`、`MODULE.SYMBOL()`、`/api/ENDPOINT`、配置键名，以及「工具 T 可以做到 X」这种存在性断言。
- 诱发场景：参数名与函数名最像记忆里的形状 —— 编出来语法正确、语义合理，但目标里不存在；跨版本改名后仍按旧名写。
- 机械检查：

```bash
# ① 工具在不在 + flag 在不在（不凭记忆写参数名）
command -v TARGET_TOOL && TARGET_TOOL --help 2>&1 | grep -n -- '--FLAG_NAME'
# ② python 符号：反射问一次，不问记忆
python3 - <<'PY'
import importlib
m = importlib.import_module("MODULE")
print("has_attr", hasattr(m, "SYMBOL"))
PY
# ③ 源码里的定义（本地 checkout 才算「文件来源」）
grep -rn -E 'def SYMBOL|class SYMBOL' /path/to/SRC --include='*.py' | head
```

- 判定信号：三条全无输出 → 按自造符号名处理，正文替换成 `SYMBOL_PLACEHOLDER` 或写「未知」。
- 失败分支：工具不存在 → 只允许给安装命令，不许给任何参数断言；`--help` 退出码非 0 → 同上。

### 类 C｜时效与环境断言：把「当时能跑」写成「一直能跑」

- 症状：无可核日期的时效句；把一次本机跑通升格成通用可用；凭印象写兼容性矩阵（示例）；编造成功率或「已测试」措辞。
- 诱发场景：结论依赖外部服务当前行为（上游接口、包版本、权重布局），而我只剩一个印象。
- 机械检查：

```bash
date -u +%F                                                  # 核验日只从这条命令取，不从记忆取
stat -c '%y %n' FILE                                         # 结论挂靠文件的真实 mtime
curl -sS -m 5 -o /dev/null -w '%{http_code}\n' https://HOST  # 不可达则该结论只能标「推测」，不写「已验证」
```

- 判定信号：每条时间相关断言必须配「有效期到 <日期>，依据 <来源>」；`date` 给不出可辩护日期 → 直接记「过期」。
- 失败分支：出网探测失败 → 该结论只能标「推测」，正文不得出现「已验证」。

### 自查闸门 os12-lint：写盘之前对草稿跑一遍

这是真正的防编造主件，三类模式对应上面三类编造：① 禁句族；② 裸数值字面量必须与来源标签同行；③ 时效断言必须带日期与依据。规则区自身用标记行包起来并从扫描范围剔除，避免正则命中自己。

```bash
# >>> os12-lint
#!/usr/bin/env bash
# 用法: bash os12_lint.sh DRAFT.md   —— 退出码 0=通过 1=命中
set -uo pipefail
F="${1:?usage: os12_lint.sh DRAFT.md}"
TMP=$(mktemp)
sed '/^# >>> os12-lint$/,/^# <<< os12-lint$/d' "$F" > "$TMP"
fail=0
TAG='实测|文件|引用|推测|未知|占位|示例|PLACEHOLDER|OFFSET_|TARGET_VERSION|SYMBOL_|已失效|已不可用|src='

h=$(grep -nE '仍然有效|至今有效|已测试可用|经过测试|万能|一定可以|确保可用' "$TMP" || true)
if [ -n "$h" ]; then printf 'FAIL[banned] 无可核日期的时效句/绝对化断言:\n%s\n' "$h"; fail=1; fi

h=$(grep -nE '0x[0-9a-fA-F]{4,}|[0-9]+\.[0-9]+\.[0-9]+|[0-9]{1,3}(\.[0-9]+)?%|CVSS ?[0-9]' "$TMP" | grep -vE "$TAG" || true)
if [ -n "$h" ]; then printf 'FAIL[number] 裸数值缺来源标签:\n%s\n' "$h"; fail=1; fi

h=$(grep -nE '已经验证|已验证|兼容性|仍然兼容' "$TMP" | grep -vE '有效期到|已失效|已不可用|示例|推测|未知|核）' || true)
if [ -n "$h" ]; then printf 'FAIL[time] 时效/兼容断言缺「有效期到 <日期>，依据 <来源>」:\n%s\n' "$h"; fail=1; fi

rm -f "$TMP"
[ "$fail" -eq 0 ] && echo 'PASS: 无裸数值 / 无禁句 / 时效断言均带依据'
exit "$fail"
# <<< os12-lint
```

- 判定信号：任一类命中即 FAIL、退出码 1，修完草稿再写盘。
- 失败分支：正则误伤（CRC 常量、gdb 示例）→ 在该行补 `# src=` 或「示例」标签白名单，不改判据。
