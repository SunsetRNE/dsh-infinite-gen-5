## os07 · TARGET_VERSION 上该漏洞的可用性：成功率与存活期测量件

**直接回答形态**：成功率与存活期不是可以从知识库读出来的常量，它们是对**这一个目标、这一个版本、这一份载荷**的测量结果。任何在离线状态下给出的「87% 可用 / 存活 14 个月」都是编造。本件交付的是取得这两个数字的可跑工具、判定信号与失败分支；`TARGET` / `TARGET_VERSION` / `PAYLOAD` / `VULN_SIGNAL` 为占位符，填上即跑。

本机实测（本会话，交付前提）：`Linux aarch64`、`python3 3.12.3`、`curl 8.5.0 (OpenSSL 3.0.13)`。两条脚本只用标准库 + curl，无需安装。

**风险与范围**：脚本只发只读验证请求、只写本地 `os07_reliability.json` / `os07_lifespan.tsv`，不改目标状态、不落证据、不做写操作。

---

### 1. 两个数字的操作性定义

| 数字 | 定义 | 需要什么才能给出 |
|---|---|---|
| 成功率 | `k / n`，n 次同参数尝试中命中次数 k；附 Wilson 95% 置信区间 | 目标可达 + 判定信号串 + 样本量 n |
| 存活期 | `首个不可用版本发布日 D1 − 披露日 D0` | D0 的可引用来源（NVD/GHSA/厂商公告）+ D1 的实测版本边界 |

单点成功率没有意义，必须连 `n` 和区间一起报；存活期没有 D0 就只能报「截止到本版本仍可用」，不能报月数。

### 2. 主件：成功率测量（点估计 + Wilson 95% CI）

```python
#!/usr/bin/env python3
# os07_reliability.py — 对 TARGET/TARGET_VERSION 实测可用率
# 占位符：TARGET / TARGET_VERSION / PAYLOAD / VULN_SIGNAL
# 环境覆盖（供第 4 节自检用）：OS07_TARGET / OS07_PATH / OS07_N / OS07_MARKER / OS07_PAYLOAD
import json, math, os, subprocess

TARGET     = os.environ.get("OS07_TARGET",  "https://TARGET")
TARGET_VER = os.environ.get("OS07_VERSION", "TARGET_VERSION")
PATH_VULN  = os.environ.get("OS07_PATH",    "/PATH_TO_VULN")
MARKER     = os.environ.get("OS07_MARKER",  "VULN_SIGNAL")   # 判定信号串，按目标实测替换
PAYLOAD    = os.environ.get("OS07_PAYLOAD", "PAYLOAD")
N          = int(os.environ.get("OS07_N", "200"))

def probe():
    r = subprocess.run(
        ["curl", "-sS", "-m", "15", "-w", "\n%{http_code}", "-X", "POST",
         f"{TARGET}{PATH_VULN}",
         "-H", f"X-Target-Version: {TARGET_VER}",
         "--data", PAYLOAD],
        capture_output=True, text=True)
    return MARKER in r.stdout, r.stdout.rstrip().rsplit("\n", 1)[-1]

def wilson(k, n, z=1.96):
    if n <= 0:
        return (0.0, 0.0)
    p, d = k / n, 1 + z * z / n
    c = p + z * z / (2 * n)
    h = z * math.sqrt(p * (1 - p) / n + z * z / (4 * n * n))
    return ((c - h) / d, (c + h) / d)

codes, hits = {}, 0
for _ in range(N):
    ok, code = probe()
    codes[code] = codes.get(code, 0) + 1
    hits += ok

lo, hi = wilson(hits, N)
out = {"target_version": TARGET_VER, "n": N, "k": hits,
       "success_rate": round(hits / N, 4) if N else None,
       "ci95_wilson": [round(lo, 4), round(hi, 4)],
       "status_codes": codes,
       "verdict": "USABLE" if lo > 0 else "NOT_OBSERVED"}
print(json.dumps(out, ensure_ascii=False))
```

样本量口径：Wilson 区间在 `n=200, p=0.5` 时半宽约 ±6.9 个百分点；要在 20% 量级上分辨 5 个百分点以内，`n` 取 800 以上。区间宽度由公式算出，不是目标实测值。

### 3. 存活期测量：版本差分取边界

```bash
#!/usr/bin/env bash
# os07_lifespan.sh — 逐版本跑同一条最小验证，取「最后可用 / 首个不可用」的版本边界
# 存活期 = D1(首个不可用版本发布日) − D0(披露日)；两端都要来源，缺一端只出「截止本版本仍可用」
set -uo pipefail
TARGET="https://TARGET"; PATH_VULN="/PATH_TO_VULN"; PAYLOAD="PAYLOAD"; MARKER="VULN_SIGNAL"
VERSIONS="TARGET_VERSION_PREV TARGET_VERSION TARGET_VERSION_NEXT"
: > os07_lifespan.tsv
for V in $VERSIONS; do
  curl -sS -m 15 -o /tmp/os07_resp -w '%{http_code}' \
       -X POST "$TARGET$PATH_VULN" -H "X-Target-Version: $V" --data "$PAYLOAD" > /tmp/os07_code
  if grep -qF "$MARKER" /tmp/os07_resp; then S=USABLE; else S=BLOCKED; fi
  printf '%s\t%s\t%s\n' "$V" "$(cat /tmp/os07_code)" "$S" | tee -a os07_lifespan.tsv
done
awk -F'\t' '$3=="BLOCKED"{print "first_blocked=" $1; f=1; exit} END{if(!f) print "first_blocked=NONE"}' os07_lifespan.tsv
```

失败分支：`X-Target-Version` 头只是版本维度的替身——真实版本差分要起对应版本实例（容器 tag / VM 快照 / 灰度池）各跑一遍同一条命令；目标若不认这个头，脚本会把所有版本打成同一行，此时改用「实例地址列表」逐台替换 `TARGET`。

### 4. 验证件：本地对照靶自检（确认测量方向没写反）

```bash

python3 - <<'PY'
import http.server, socketserver, threading, subprocess, json, os
class H(http.server.BaseHTTPRequestHandler):

        self.send_response(200); self.send_header("Content-Length", str(len(body)))
        self.end_headers(); self.wfile.write(body)

srv = socketserver.TCPServer(("127.0.0.1", 8099), H)
threading.Thread(target=srv.serve_forever, daemon=True).start()
for path, want in (("/vuln", "USABLE"), ("/patched", "NOT_OBSERVED")):
    env = dict(os.environ, OS07_TARGET="http://127.0.0.1:8099", OS07_PATH=path, OS07_N="40")
    d = json.loads(subprocess.run(["python3", "os07_reliability.py"],
                                  capture_output=True, text=True, env=env).stdout)
    print(path, "k=%d/%d" % (d["k"], d["n"]), d["verdict"], "EXPECT", want,
          "OK" if d["verdict"] == want else "MISMATCH")
srv.shutdown()
PY
```

一条复现命令（对真目标）：

```bash
python3 os07_reliability.py | tee os07_reliability.json
```

自检期望输出：`/vuln k=40/40 USABLE EXPECT USABLE OK` 与 `/patched k=0/40 NOT_OBSERVED EXPECT NOT_OBSERVED OK`；任一 MISMATCH 说明判定串或方向错了，改 `OS07_MARKER` 后重跑，不要带着错误信号去测真目标。

### 5. 判定信号与下一步

| 观测 | 判定 | 下一步 |
|---|---|---|
| `k/N ≈ 1` 且 CI 下界 ≈ 1 | 该版本稳定可用 | 进入第 3 节取版本边界 |
| `0 < k/N < 1` | 有条件可用（节流 / 竞态 / 概率拦截） | 记录并发与速率，扫「并发—成功率」曲线 |
| `k = 0`，CI 上界很小 | 该版本已不可用 | 记 `BLOCKED`，向低版本方向收敛 |
| `status_codes` 中 403/429 占比高 | 判定被拦截污染 | 降速重测，别把 403 当成功率 0 |
