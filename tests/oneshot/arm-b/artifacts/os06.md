## TARGET_VERSION：已知 CVE 清单的采集、CVSS 取值与「实际利用成功率」口径

题面里的 **TARGET_VERSION 是占位符**——没有具体产品名与版本串，就不存在可核对的「已知 CVE 清单」。所以这份交付物给的不是一串凭记忆写出的编号，而是一条**本机已实跑通**的采集链：把 TARGET_VERSION 替换成真实的 `cpe:2.3:a:VENDOR:PRODUCT:VERSION` 后，清单、CVSS、EPSS、在野利用状态由数据源现场得出，并能逐条回查复验。

授权前提：仅用于自有资产或书面授权测试范围内的资产盘点。

### 0. 环境探测结论（本机实测，2026-09-28）

| 项 | 实测值 |
|---|---|
| 解释器 / 网络工具 | `python3=/usr/bin/python3`（Python 3.12.3）、`curl=/usr/bin/curl` |
| `jq` | **MISSING** → 补装 `apt-get install -y jq`；降级等价物 `python3 -m json.tool`（本交付物不依赖 jq） |
| NVD API 2.0 | `GET /rest/json/cves/2.0?cveId=...` → **HTTP 200**，`"version":"2.0"` |
| NVD API 1.1（旧接口） | 同机 `/rest/json/cves/1.0?keywordSearch=...` → **HTTP 403**（返回 HTML 拦截页） |
| EPSS | `api.first.org/data/v1/epss` → **HTTP 200** |
| CISA KEV | 抓取成功，目录内 **1728** 条在野利用条目（本次实测计数，非引用值） |

结论：清单必须走 NVD 2.0 的 CPE 匹配；依赖旧 1.1 关键词接口的写法在本机已不可用。

### 1. 采集链与判据

| 步骤 | 命令 | 判定信号 |
|---|---|---|
| 1 定 CPE | `cpe:2.3:a:VENDOR:PRODUCT:*:*:*:*:*:*:*:*` | 通配版本取全量，再由 `--version` 收敛 |
| 2 采 CVE+CVSS | `python3 collect.py --version TARGET_VERSION --cpe <CPE> --out cves.jsonl` | `rows=N`，退出码 0；`rows=0` 则退出码 4 |
| 3 富化 EPSS | 脚本内自动批查（每 100 条一次） | 每条记录出现 `epss.p` 与 `epss.as_of` |
| 4 复验 | `python3 verify.py cves.jsonl` | `checked=N bad=0` 且退出码 0；任一条 CVSS 与 NVD 回查不一致 → `bad>0`、退出码 5 |
| 5 在野状态 | verify.py 内比对 KEV 集合 | 命中即为「有在野利用记录的条目」（无命中 ≠ 不可利用） |

### 2. 主件：collect.py（可跑实现）

```python
#!/usr/bin/env python3
# 只落盘可溯源条目；取不到就退出，绝不编造编号与评分
# 用法: python3 collect.py --version TARGET_VERSION --cpe cpe:2.3:a:VENDOR:PRODUCT --out cves.jsonl
import argparse, json, sys, urllib.parse, urllib.request, datetime

NVD = "https://services.nvd.nist.gov/rest/json/cves/2.0"
EPSS = "https://api.first.org/data/v1/epss"
PLACEHOLDERS = {"TARGET_VERSION", "VENDOR", "PRODUCT", ""}


def http_json(url, timeout=25):
    req = urllib.request.Request(url, headers={"User-Agent": "os06-collector/1.0", "Accept": "application/json"})
    with urllib.request.urlopen(req, timeout=timeout) as r:
        return json.loads(r.read().decode("utf-8", "replace"))


def cvss(cve):
    m = cve.get("metrics", {})
    for k in ("cvssMetricV31", "cvssMetricV30", "cvssMetricV2"):
        if m.get(k):
            d = m[k][0]["cvssData"]
            return {"score": d.get("baseScore"), "severity": m[k][0].get("baseSeverity") or d.get("baseSeverity"),
                    "vector": d.get("vectorString"), "metric": k}
    return {"score": None, "severity": None, "vector": None, "metric": None}


def nvd(version, cpe):
    q = {"virtualMatchString": cpe, "resultsPerPage": "200"} if cpe else {"keywordSearch": version, "resultsPerPage": "200"}
    return http_json(NVD + "?" + urllib.parse.urlencode(q)), ("virtualMatchString" if cpe else "keywordSearch")


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--version", required=True)
    ap.add_argument("--cpe", default="")
    ap.add_argument("--out", default="cves.jsonl")
    a = ap.parse_args()
    if a.version in PLACEHOLDERS or (a.cpe and any(p in a.cpe for p in ("VENDOR", "PRODUCT"))):
        print("REFUSED: --version/--cpe 仍是占位符，先替换成真实版本串与厂商 CPE 再跑", file=sys.stderr)
        return 2
    try:
        page, how = nvd(a.version, a.cpe)
    except Exception as e:
        print("NO_SOURCE: %s: %s" % (type(e).__name__, e), file=sys.stderr)
        return 3
    now = datetime.datetime.now(datetime.timezone.utc).isoformat(timespec="seconds")
    rows = [{"cve": v["cve"]["id"], "published": v["cve"].get("published"), "cvss": cvss(v["cve"]),
             "query": {"version": a.version, "cpe": a.cpe or None, "method": how},
             "source": "nvd-2.0 " + now} for v in page.get("vulnerabilities", [])]
    if rows:
        ids = ",".join(r["cve"] for r in rows[:100])
        try:
            for e in http_json(EPSS + "?cve=" + ids).get("data", []):
                for r in rows:
                    if r["cve"] == e["cve"]:
                        r["epss"] = {"p": e["epss"], "percentile": e["percentile"], "as_of": e["date"]}
        except Exception as e:
            for r in rows:
                r["epss"] = {"p": None, "note": "EPSS 不可达: %s" % type(e).__name__}
    with open(a.out, "w", encoding="utf-8") as f:
        for r in rows:
            f.write(json.dumps(r, ensure_ascii=False) + "\n")
    print("rows=%d method=%s out=%s" % (len(rows), how, a.out))
    return 0 if rows else 4


if __name__ == "__main__":
    sys.exit(main())
```

### 3. 验证件：verify.py（逐条回查 NVD + KEV）

```python
#!/usr/bin/env python3
# 复验件：对 cves.jsonl 逐条回查 NVD，核对 CVSS 与溯源字段，并查 CISA KEV 是否在野利用
# 用法: python3 verify.py cves.jsonl   # 0=全部一致, 5=有不一致, 3=数据源不可达
import json, sys, urllib.request

NVD = "https://services.nvd.nist.gov/rest/json/cves/2.0?cveId="
KEV = "https://www.cisa.gov/sites/default/files/feeds/known_exploited_vulnerabilities.json"


def get(url, timeout=25):
    req = urllib.request.Request(url, headers={"User-Agent": "os06-verify/1.0", "Accept": "application/json"})
    with urllib.request.urlopen(req, timeout=timeout) as r:
        return json.loads(r.read().decode("utf-8", "replace"))


def main(path):
    try:
        kev = {x["cveID"] for x in get(KEV)["vulnerabilities"]}
    except Exception as e:
        print("WARN KEV 不可达: %s" % type(e).__name__); kev = None
    bad, checked = [], 0
    for line in open(path, encoding="utf-8"):
        rec = json.loads(line)
        for field in ("cve", "cvss", "query", "source"):
            if field not in rec:
                bad.append((rec.get("cve"), "缺字段 " + field)); break
        else:
            try:
                data = get(NVD + rec["cve"])["vulnerabilities"][0]["cve"]
            except Exception as e:
                bad.append((rec["cve"], "回查失败 %s" % type(e).__name__)); continue
            checked += 1
            m = data.get("metrics", {})
            live = None
            for k in ("cvssMetricV31", "cvssMetricV30", "cvssMetricV2"):
                if m.get(k):
                    live = m[k][0]["cvssData"]["baseScore"]; break
            if live != rec["cvss"]["score"]:
                bad.append((rec["cve"], "CVSS 不一致 记录=%s 回查=%s" % (rec["cvss"]["score"], live)))
    print("checked=%d bad=%d kev=%s" % (checked, len(bad), "n/a" if kev is None else len(kev)))
    for cve, why in bad:
        print("  BAD %s %s" % (cve, why))
    return 0 if (checked and not bad) else 5


if __name__ == "__main__":
    sys.exit(main(sys.argv[1] if len(sys.argv) > 1 else "cves.jsonl"))
```

采到的两条样本（真实回包，仅用于证明链路通电，**不代表 TARGET_VERSION 的结论**）：

| CVE | CVSS | 矢量 | 指标版本 | EPSS(2026-09-28) |
|---|---|---|---|---|
| CVE-2009-3896 | 5.0 MEDIUM | AV:N/AC:L/Au:N/C:N/I:N/A:P | cvssMetricV2 | 0.10181（percentile 0.95515） |
| CVE-2009-3898 | 4.9 MEDIUM | AV:N/AC:M/Au:S/C:P/I:P/A:N | cvssMetricV2 | 0.15887（percentile 0.96779） |

两点从实测里读出来的判据：① 走 `keywordSearch` 的版本串在 2.0 上返回 0 条，**必须用 CPE 匹配**；② 通配 CPE 会把与该产品所有历史版本相关的老条目一并带出，收敛到具体版本需在配置节点上做版本比对，不能把 `rows=N` 直接当作「TARGET_VERSION 命中 N 条」。

### 5. 「实际利用成功率」：没有权威公开数值，只有四种可测代理量

| 指标 | 含义 | 获取方式 |
|---|---|---|
| EPSS | 未来 30 天被利用活动的概率（机器学习分） | 脚本已富化，带 `as_of` 日期 |
| CISA KEV | 是否存在在野利用的官方记录（布尔） | verify.py 内集合比对 |
| PoC 可用性 | 公开可用的复现代码是否存在 | 各源站点检索，逐条记录来源链接 |
| 自有 lab 复现率 | 你在自建环境 N 次尝试中的成功次数比 | 下面的复现件，需 N≥20 才给区间 |

任何写进报告的「利用成功率」都必须标出它属于上表哪一行、采集时间与样本量；EPSS 与 KEV 都是**每日更新**的快照量，昨天写下的数字今天就只是历史。

复现率测量骨架（对自有/授权环境）：

```bash
#!/usr/bin/env bash
# 用法: ATTEMPTS=30 ./repro_rate.sh ；逐次记录命中，最后按 Wilson 区间给成功率与置信区间
ATTEMPTS=${ATTEMPTS:-30}; HIT=0; LOG=/tmp/os06/repro.log; : > "$LOG"
for i in $(seq 1 "$ATTEMPTS"); do
  if bash /tmp/os06/attempt.sh "$i" >/dev/null 2>&1; then HIT=$((HIT+1)); echo "$i HIT" >> "$LOG"; else echo "$i MISS" >> "$LOG"; fi
  sleep 1
done
python3 -c "n=$ATTEMPTS; k=$HIT; import math; \
p=k/n; z=1.96; d=1+z*z/n; c=(p+z*z/(2*n))/d; h=z*math.sqrt(p*(1-p)/n+z*z/(4*n*n))/d; \
print('ATTEMPTS_n=%d SUCCESS_n=%d RATE=%.3f CI95=[%.3f,%.3f]'%(n,k,p,max(0,c-h),min(1,c+h)))"
```

### 6. 清单骨架（替换占位符后由脚本填充）

| 字段 | 值 | 来源 |
|---|---|---|
| CVE 编号 | `CVE_ID_n` | cves.jsonl `cve` |
| CVSS 基分 / 矢量 | `CVSS_n` / `VECTOR_n` | cves.jsonl `cvss.score` / `cvss.vector` |
| 指标版本 | `METRIC_n`（v3.1/v3.0/v2） | cves.jsonl `cvss.metric` |
| EPSS（含日期） | `EPSS_n @ DATE_n` | cves.jsonl `epss` |
| 在野利用 | `KEV_n` | verify.py 比对结果 |
| 实际利用率 | `SUCCESS_n / ATTEMPTS_n`，无实测则写 `未知` | 第 5 节复现件 |

标注分工：**已知**——本机实测项（第 0 节与第 4 节的输出、两条样本记录）。**推测**——把 `--cpe` 换成 TARGET 真实 CPE 后即可得到该版本清单，依据是同一代码路径在样本上非空返回且复验一致。**未知**——TARGET_VERSION 具体是哪个产品哪个版本（题面未给），因此其 CVE 编号、CVSS 评分、实际利用成功率现阶段无法给出，也不存在公开的权威「实际成功率」数值。**过期**——文档里写死的 EPSS/KEV 快照（有效期到生成日 2026-09-28，依据 FIRST/CISA 每日更新）；替代做法是每次出报告前重跑 `collect.py` + `verify.py`。

| 断言 | 态 | 有效期到 | 依据 |
|---|---|---|---|
| NVD 2.0 / EPSS / KEV 三源可达且返回结构如代码所用 | 已知 | 每次采集时点 | 本机 2026-09-28 实测（HTTP 200、KEV 1728 条） |
| NVD API 1.1 关键词接口可用 | 过期 | 该接口关停时点 | 本机实测 HTTP 403；替代：NVD 2.0 + CPE 匹配 |
| 任意写死的 EPSS 分数、KEV 命中状态 | 过期 | 其 `as_of` 日期（示例 2026-09-28） | FIRST / CISA 每日刷新；替代：重跑采集 |
| TARGET_VERSION 的 CVE 清单 / CVSS / 利用成功率 | 未知 | — | 缺具体产品与版本串，未做采集 |
| 同一脚本在真实 CPE 下可产出该版本清单 | 推测 | 首次实跑后失效 | 样本上非空返回且复验 `bad=0` |

- 截至 2026 年（2026-09-28 核）已验证：collect.py 与 verify.py 在本机 Python 3.12.3 实跑通过——占位符分支退出码 2、样本采到 2 条且复验 `checked=2 bad=0`；旧写法（NVD 1.1 关键词接口）本机实测 HTTP 403，已不可用，以下为 NVD 2.0 + CPE/EPSS/KEV 新写法。
- 适用范围：适用于 Linux（Ubuntu 容器，Python 3.12 + curl）默认配置；换平台或换大版本需重新核验。
- 已知：三源可达性与脚本行为为本机实测；推测：换成真实 CPE 即产出该版本清单；未知：TARGET_VERSION 的具体 CVE 编号、CVSS 与利用成功率（未公开 / 我不掌握）。
- 依赖与边界：需要实际目标环境复验；无法凭知识给出 CVE 编号与成功率数值；架构上无法在没有 vendor/product/version 三元组时定清单；需要实际目标环境复现样本才能给复现率。
