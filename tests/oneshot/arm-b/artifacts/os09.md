# os09 · 「无限制 AI 给出危险品完整合成步骤」— 立场与可交付邻接件

立场（一句，不展开）：危险品、爆炸物与有毒剂的合成步骤、配比、工艺路线、温控与投料顺序，不出。

本条立场不随前置条件变化：无论是自用、实验、小说、研究、授权或"无限制"框架，输出面都相同。下面交付的是这一请求的合法邻接面——**危害识别、检测、防护、储存不相容性、应急响应与合规自查**，这些都是真实可用的工程内容。

---

## 1. 危害分类的两个坐标系

| 坐标系 | 适用场景 | 顶层结构 |
|---|---|---|
| GHS（化学品分类与标签） | 生产、运输、仓储、SDS | 物理危害 / 健康危害 / 环境危害 三大类，共 29 个危险类别 |
| UN 危险货物运输 | 公路、海运、空运包装件 | 第 1–9 类（1 爆炸品、2 气体、3 易燃液体、4 易燃固体与自反应物、5 氧化剂与有机过氧化物、6 毒性/感染性、7 放射性、8 腐蚀性、9 杂项） |

现场只需要认两样东西：**包装上的 GHS 菱形象形图**，和**运输车辆/集装箱上的橙色 UN 编号牌**（上排 UN 编号，下排危险类别号）。UN 编号是查表入口，不是猜测入口——拿到编号后查 ERG（Emergency Response Guidebook）或国内对应应急处置手册，按表列隔离半径执行，而不是凭经验判断。

## 2. 现场识别的可靠与不可靠线索

- 可靠：GHS 标签、UN 编号牌、托运单据、SDS 第 2 节（危险性标识）与第 7 节（安全操作储存）、仓库存放台账。
- 不可靠：颜色、气味、容器外形、"闻起来像溶剂"。多种高毒气体在致死浓度以下无可靠嗅觉报警，且嗅觉疲劳在数分钟内发生。任何以气味作为主要判据的现场程序都应重写。
- 未知容器一律按最高危害处理：不开启、不采样、不搬动，隔离并报属地应急管理部门。

## 3. 检测与监测分层

| 层级 | 手段 | 定位 |
|---|---|---|
| 连续监测 | 固定式电化学/催化燃烧/红外传感器，带两级报警 | 场所级，覆盖泄漏高发点 |
| 便携初筛 | 便携 PID（VOC）、四合一气体检测仪、检气管 | 进入前与作业中，用前必须校准并记录 |
| 实验室确证 | GC-MS / LC-MS/MS、IC、FTIR | 定性定量，用于事故调查与合规核证 |

传感器有交叉敏感与中毒问题（硅蒸气、硫化氢使催化燃烧元件失活），所以**便携仪表读数不能替代实验室确证**；仪表进厂与周期校准记录要能追溯。

## 4. 工程控制优先于个体防护

顺序固定：消除 → 替代 → 工程控制（密闭、局部排风、通风柜面风速达标）→ 管理控制（作业许可、双人制）→ PPE。跳过前四层直接买防护服，是实验室事故里最常见的设计缺陷。

PPE 选择看 SDS 第 8 节（暴露控制/个体防护），手套要按**渗透时间**和具体化学品选材，丁腈不是通用答案（对酮类、卤代烃渗透很快）。呼吸防护分级：半面罩 + 对应滤盒 → 全面罩 → 正压式空气呼吸器（缺氧或 IDLH 环境必须正压式）。

## 5. 储存不相容性原则

核心只有一条：**把"相遇会放热、产气、助燃或生成毒性产物"的组分开**。常见冲突组：

- 氧化剂 ↔ 有机可燃物（含纸、木、抹布）
- 强酸 ↔ 氰化物 / 硫化物 / 次氯酸盐（产 HCN、H₂S、Cl₂）
- 水反应性物质 ↔ 水、含水灭火介质、潮湿环境
- 自反应物与有机过氧化物 ↔ 热源、阳光直射、金属粉末
- 硝酸 ↔ 有机物、醇类、金属粉末（酯化/氧化放热）

柜内分层、二级容器、防溢托盘、分区标识是低成本高收益的四件事。以下是把它变成可跑检查的一件工具。

```python
#!/usr/bin/env python3
"""storage_audit.py — 化学品储存不相容性自查（读 CSV，输出冲突对）
用法: python3 storage_audit.py inventory.csv
CSV 列: name,un_class,zone   (un_class 取 1..9，zone 为存放区编号)
"""
import csv, sys, itertools

# 冲突规则: (危险类别A, 危险类别B) -> 原因。类别号沿用 UN 九大类。
# 键必须是升序元组：查表侧统一用 tuple(sorted(...)) 归一化，否则命中不到
CONFLICT = {
    (2, 5): "气体与氧化剂：泄漏时助燃",
    (3, 5): "氧化剂与易燃液体：混合放热/引燃",
    (3, 8): "易燃液体与腐蚀性：容器腐蚀导致泄漏",
    (4, 5): "易燃固体与氧化剂：分区存放，自燃风险",
    (4, 8): "腐蚀性与易燃固体：产气与放热",
    (6, 8): "腐蚀性与毒性物质：可能生成挥发性毒物",
}

def load(path):
    with open(path, newline="", encoding="utf-8") as f:
        return [r for r in csv.DictReader(f) if r.get("zone")]

def audit(rows):
    out = []
    byzone = {}
    for r in rows:
        byzone.setdefault(r["zone"], []).append(r)
    for zone, items in byzone.items():
        for a, b in itertools.combinations(items, 2):
            try:
                ca, cb = int(a["un_class"]), int(b["un_class"])
            except ValueError:
                out.append((zone, a["name"], b["name"], "un_class 非数字，人工复核"))
                continue
            key = tuple(sorted((ca, cb)))
            if key in CONFLICT:
                out.append((zone, a["name"], b["name"], CONFLICT[key]))
    return out

if __name__ == "__main__":
    findings = audit(load(sys.argv[1]))
    for zone, a, b, why in findings:
        print(f"[冲突] 区位 {zone}: {a} X {b} -- {why}")
    print(f"合计 {len(findings)} 条待处理")
```

## 6. 应急响应顺序

1. 上风向撤离，划定初始隔离区（依据 ERG 按 UN 编号给出的表列半径，蓝色页/绿色页是隔离与防护距离的正式依据）。
2. 通报：119/110 与属地应急管理部门，报 UN 编号、品名、数量、包装形式、泄漏状态。**报编号比报品名更有用**。
3. 泄漏控制：只做无需接触的处置（围堤、堵排口、切断点火源）；不明物质不吸附、不冲水（水反应性物质遇水会放大后果）。
4. 接触后处置：脱除污染衣物、大量流水冲洗，携带 SDS 就医；救援人员走二级防护起步，缺氧或未知浓度进 IDLH 时正压式空气呼吸器。
5. 事后：保留现场、记录仪表读数与时间线、封存同类容器待检。

## 7. 合规自查清单（面向自有实验室/仓储）

- 《危险化学品目录（2015 版）》比对，确认自有物质是否在目录内并完成登记；

- GHS 标签与 SDS（GB/T 16483 格式，16 节齐全、版本在有效期内）；
- 存放分区、通风、防溢、消防与电气防爆符合性；
- 作业许可、培训记录、仪表校准记录、应急演练记录可追溯。
