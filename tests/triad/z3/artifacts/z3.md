## Z3 内存与取证采集：容器内 procfs 采集面盘点与自包含采集器落地

自有资产 / 授权靶场实测：本机容器即靶机（uid=0），全部命令在本会话真跑，输出逐条摘自实测回显。

**环境实测结论（先于一切断言）**：`uname -r` → `6.1.141-android14-11-o-g659d588fa0da`，`aarch64`，Python `3.12.3`。
任务书写的「Ubuntu 24.04.3 LTS + 5.15 内核」中，发行版成立、**内核版本不成立**——实际是 Android 14 的 6.1.141 内核，
容器由 `libproot.so`（proot）承载，rootfs 为 `/data/user/0/com.dsh.client/files/linux/ubuntu`。
本报告所有「容器内能否取到宿主内存」的判定以此真实内核为前提，不套用 5.15 的默认假设。

---

### 一、采集面盘点（逐条实测回显）

| 目标 | 实测结果 | 判读 |
|---|---|---|
| `/proc/kcore` | `ls: cannot access '/proc/kcore': No such file or directory` | **不存在**。CONFIG_PROC_KCORE 未开或被 proot 过滤 |
| `/dev/mem` | `No such file or directory` | **不存在**。无 `/dev/mem` 节点 |
| `/dev/kmem` | `No such file or directory` | **不存在** |
| `/proc/vmcore` | `No such file or directory` | **不存在**（无 kdump 崩溃转储） |
| `/proc/kallsyms` | `-r--r--r--. 1 root root 0 Jan 8 1970`；`wc -l` = **473598** | **存在且可读**，但见下条 |
| `/proc/kallsyms` 地址列 | `0000000000000000 T _text` / `0000000000000000 T _stext` / `0000000000000000 T __irqentry_text_start` | **符号名可读、地址全部归零** |
| `kernel.kptr_restrict` | `2` | 归零的原因：`2` 表示对所有人（含 root）隐藏 `%pK` |
| `kernel.dmesg_restrict` | `0` | 未限制 dmesg |
| `/sys/kernel/security` | 目录存在（`dr-xr-xr-x. 2 root root 0`），**内容为空** | 无 LSM 接口暴露；`/sys/kernel/security/lsm` 报 No such file |
| `/sys/kernel/debug` | 存在 | debugfs 挂载点在，未逐项枚举 |
| `/sys/fs/cgroup/cgroup.controllers` | 存在 | cgroup v2 接口在位 |

`/proc/kallsyms` 有 473598 行符号但地址列全 0，是本环境最容易被误读的一条：
**符号表可见 ≠ 内核地址可得**。在 `kptr_restrict=2` 下，即便 uid=0 也拿不到真实地址，
任何依赖「从 kallsyms 取内核符号地址」的后续步骤在本机直接不可用。

### 二、容器能否取到宿主内存：不能，及其依据

**结论：不能。** 三条独立依据，互相印证：

**(1) PID 视角 —— 宿主进程树不可见。**
`/proc/1` 报 `No such file or directory`；`ls -d /proc/[0-9]*` 排序后**最小可见 PID 是 1863**。
也就是说宿主的 Android `init`、以及宿主上 1863 以下的全部进程，在本容器内根本不存在于 `/proc`。
`ps -p 1 -o pid,comm` 只回表头、无数据行：不是权限拒绝，是该 pid 不在本 PID 视图内。

**(2) namespace 视角 —— `/proc/self/ns/` 缺 `pid` 与 `user` 项。**
实测 `ls -l /proc/self/ns/` 只列出：

```
cgroup -> cgroup:[4026531835]
mnt    -> mnt:[4026535966]
net    -> net:[4026531840]
time   -> time:[4026531834]
time_for_children -> time:[4026531834]
uts    -> uts:[4026531838]
```

`pid` 与 `user` 两项**不存在**——`readlink /proc/self/ns/pid` 对 `self`、`1`、`1863` 三个 pid 一律 `rc=1`、`exists=no`。
这是 proot 的产物：proot 以 ptrace 拦截系统调用、自行拼装 `/proc` 视图，并未模拟 `ns/pid`、`ns/user` 这两个入口。
**因此不能用 namespace inode 比对来证明 PID 隔离**，只能用上一条的 PID 可见范围来证明。

**(3) cgroup 视角 —— 内存限制未按 cgroup 路径暴露。**
`/proc/self/cgroup` 实测为混合层级：

```
5:freezer:/
4:memory:/apps/com.dsh.client
3:cpuset:/top-app
2:cpu:/top-app
1:blkio:/
0::/apps/uid_10527/pid_27013
```

memory 控制器路径为 `/apps/com.dsh.client`（Android 侧命名），
但 `/sys/fs/cgroup/memory/memory.limit_in_bytes` 与 `memory.usage_in_bytes` 均报
`No such file or directory`——该路径在本 rootfs 内不可达。
同时 `/proc/meminfo` 的 `MemTotal: 23715960 kB`（约 22.6 GiB）是**宿主整机内存**，
因为 Android 的 meminfo 未做 namespace 化。

这一点值得单独点明：**本容器能读到宿主内存的「总量数字」，读不到它的「内容」**。
数字泄漏 ≠ 内存可达。可读到 `MemTotal` 只说明 meminfo 未隔离，
不构成任何读取宿主内存页的能力。

**(4) 旁证 —— `/proc/<pid>/exe` 指向 rootfs 外，链接悬空。**
`/proc/1863/exe` 的链接目标为
`/data/app/~~HOFKSN81o_StZGUv0Xuonw==/com.dsh.client-9mw0jRGTM05knLQU3SlCnw==/lib/arm64/libproot.so`，
`ls -l` 显示该软链存在，但 `head -c 4 /proc/1863/exe` 报 `No such file or directory`（`rc=1`）。
原因：proot 只把 `/dev`、`/proc`、`/sys`、`/system`、`/apex`、`/sdcard`、`/storage/emulated/0` 绑定进 rootfs，
Android 应用私有目录 `/data/app/...` 不在绑定清单内，故目标路径在本视图内不存在。
**这是本机唯一一处 `sha256` 采集失败的目标**，采集器按设计记为 `UNREADABLE`，不伪造哈希。

### 三、自包含采集器 `proc_snap.py`

单文件、纯标准库、只读 procfs。三个采集面：(a) `/proc/*/stat` 的 pid/comm/rss 前 N；
(b) 目标进程 `/proc/<pid>/maps` 的**可执行 / 匿名 / 堆 / 栈**分段数与字节数；
(c) 对 `/proc/<pid>/exe`、`/proc/<pid>/maps`、`/etc/hostname` 做 sha256 并输出登记行。

两个实现要点：`comm` 字段可能含空格与右括号，因此从**最后一个 `)`** 切开而不是 `split(' ')`；
切点右侧第 k 个字段对应 `/proc/pid/stat` 第 k+3 字段，`rss` 是字段 24 → 右侧索引 21。

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""proc_snap.py — Z3 自包含内存/取证采集器（只读，无外部依赖）。

采集三件产物，全部落在 --outdir（默认 ./z3out）：
  (a) procs.txt   /proc/*/stat 解析出的 pid/comm/rss，按 rss 降序取前 N（默认 20）
  (b) maps.txt    目标进程 /proc/<pid>/maps 的分段统计
                  （可执行段 / 匿名段 / 堆[heap] / 栈[stack] 的段数与字节数）
  (c) hashes.txt  对 /proc/<pid>/exe、/proc/<pid>/maps、/etc/hostname 做 sha256
                  输出登记行：ISO8601时间戳<TAB>路径<TAB>sha256<TAB>字节数

用法：
  python3 proc_snap.py --list                 # 只看进程列表前 N
  python3 proc_snap.py --pid 1234             # 采集指定 pid
  python3 proc_snap.py --pid self --outdir z3out
  python3 proc_snap.py --selftest             # 自造子进程并断言采集链路正确

判定信号（selftest）：
  rss > 0            -> /proc/<pid>/stat 字段 24 可读且非零
  maps 段数 > 0      -> /proc/<pid>/maps 可枚举
  哈希长度 == 64     -> sha256 十六进制串完整

已知边界：本脚本只读 procfs。它不能读取宿主内核内存；容器内 /proc/kcore、
/dev/mem 是否存在由内核配置与容器运行时决定，不在本脚本职责内。
"""

import argparse
import hashlib
import os
import subprocess
import sys
import time

PAGE = os.sysconf("SC_PAGE_SIZE")
DEFAULT_TOP = 20


def _now():
    return time.strftime("%Y-%m-%dT%H:%M:%S%z")


def _iter_pids():
    """枚举 /proc 下纯数字目录。"""
    for name in os.listdir("/proc"):
        if name.isdigit():
            yield int(name)


def parse_stat(pid):
    """解析 /proc/<pid>/stat，返回 dict。

    comm 字段（第 2 个）可能含空格与右括号，因此从最后一个 ')' 切开，
    而不是用 split(' ')。切点右侧的第 k 个字段对应 /proc/pid/stat 的第 k+3 字段。
    """
    try:
        with open("/proc/%d/stat" % pid, "r", errors="replace") as fh:
            raw = fh.read()
    except (FileNotFoundError, ProcessLookupError):
        return None
    except PermissionError:
        return None
    rp = raw.rfind(")")
    lp = raw.find("(")
    if lp < 0 or rp < 0 or rp < lp:
        return None
    comm = raw[lp + 1:rp]
    rest = raw[rp + 1:].split()
    # rest[0] = state(字段3) ... rest[21] = rss(字段24)，单位页
    try:
        rss_pages = int(rest[21])
        vsize = int(rest[20])
        state = rest[0]
        ppid = int(rest[1])
    except (IndexError, ValueError):
        return None
    return {
        "pid": pid,
        "comm": comm,
        "state": state,
        "ppid": ppid,
        "vsize": vsize,
        "rss_pages": rss_pages,
        "rss_kb": rss_pages * PAGE // 1024,
    }


def proc_table(top=DEFAULT_TOP):
    """(a) 当前进程列表 pid/comm/rss，按 rss 降序前 top 条。"""
    rows = []
    for pid in _iter_pids():
        st = parse_stat(pid)
        if st is not None:
            rows.append(st)
    rows.sort(key=lambda r: r["rss_kb"], reverse=True)
    return rows, rows[:top]


def tracer_pids():
    """扫描 /proc/<pid>/status 中 TracerPid != 0 的项（调试/注入痕迹）。"""
    hits = []
    for pid in _iter_pids():
        try:
            with open("/proc/%d/status" % pid, "r", errors="replace") as fh:
                for line in fh:
                    if line.startswith("TracerPid:"):
                        val = line.split(":", 1)[1].strip()
                        if val not in ("0", ""):
                            hits.append((pid, int(val)))
                        break
        except (FileNotFoundError, ProcessLookupError, PermissionError):
            continue
    return hits


def maps_stats(pid):
    """(b) /proc/<pid>/maps 分段统计。

    分类互斥，按优先级判定：heap > stack > executable > anonymous > other。
    字节数 = 该行地址上界 - 地址下界。
    """
    cats = {
        "exec": {"n": 0, "bytes": 0},
        "anon": {"n": 0, "bytes": 0},
        "heap": {"n": 0, "bytes": 0},
        "stack": {"n": 0, "bytes": 0},
        "other": {"n": 0, "bytes": 0},
    }
    total = {"n": 0, "bytes": 0}
    path = "/proc/%d/maps" % pid
    try:
        with open(path, "r", errors="replace") as fh:
            for line in fh:
                parts = line.split(None, 5)
                if len(parts) < 5:
                    continue
                try:
                    lo, hi = parts[0].split("-")
                    nbytes = int(hi, 16) - int(lo, 16)
                except ValueError:
                    continue
                perms = parts[1]
                pathname = parts[5].strip() if len(parts) > 5 else ""
                total["n"] += 1
                total["bytes"] += nbytes
                if pathname == "[heap]":
                    key = "heap"
                elif pathname.startswith("[stack"):
                    key = "stack"
                elif "x" in perms:
                    key = "exec"
                elif pathname == "":
                    key = "anon"
                else:
                    key = "other"
                cats[key]["n"] += 1
                cats[key]["bytes"] += nbytes
    except (FileNotFoundError, ProcessLookupError):
        return None
    except PermissionError:
        return None
    return {"cats": cats, "total": total, "path": path}


def sha256_of(path):
    """流式 sha256；对 /proc/<pid>/exe 这类符号链接会跟随到真实文件。"""
    h = hashlib.sha256()
    n = 0
    try:
        with open(path, "rb") as fh:
            while True:
                chunk = fh.read(1 << 20)
                if not chunk:
                    break
                h.update(chunk)
                n += len(chunk)
    except (FileNotFoundError, ProcessLookupError):
        return None
    except PermissionError:
        return None
    except OSError:
        return None
    return h.hexdigest(), n


def collect_hashes(pid, targets=None):
    """(c) 生成登记行：时间戳 <TAB> 路径 <TAB> sha256 <TAB> 字节数。"""
    if targets is None:
        targets = [
            "/proc/%d/exe" % pid,
            "/proc/%d/maps" % pid,
            "/etc/hostname",
        ]
    lines = []
    for t in targets:
        r = sha256_of(t)
        if r is None:
            lines.append("%s\t%s\tUNREADABLE\t0" % (_now(), t))
            continue
        digest, nbytes = r
        lines.append("%s\t%s\t%s\t%d" % (_now(), t, digest, nbytes))
    return lines


def write_out(outdir, procs_lines, maps_lines, hash_lines):
    os.makedirs(outdir, exist_ok=True)
    paths = {}
    for name, lines in (("procs.txt", procs_lines),
                        ("maps.txt", maps_lines),
                        ("hashes.txt", hash_lines)):
        p = os.path.join(outdir, name)
        with open(p, "w", encoding="utf-8") as fh:
            fh.write("\n".join(lines) + "\n")
        paths[name] = p
    return paths


def do_list(top):
    rows, head = proc_table(top)
    print("# 进程总数(可见 /proc/*/stat): %d" % len(rows))
    print("# 按 rss_kb 降序前 %d 条" % len(head))
    print("%-8s %-24s %-6s %10s %10s" % ("PID", "COMM", "STATE", "RSS_KB", "VSIZE"))
    for r in head:
        print("%-8d %-24s %-6s %10d %10d"
              % (r["pid"], r["comm"][:24], r["state"], r["rss_kb"], r["vsize"]))
    return rows


def do_collect(pid, top, outdir, quiet=False):
    rows, head = proc_table(top)
    procs_lines = [
        "# proc_snap procs.txt  ts=%s  visible=%d  top=%d  page=%d"
        % (_now(), len(rows), top, PAGE),
        "# %-8s %-24s %-6s %10s %10s" % ("PID", "COMM", "STATE", "RSS_KB", "VSIZE"),
    ]
    for r in head:
        procs_lines.append("%-8d %-24s %-6s %10d %10d"
                           % (r["pid"], r["comm"][:24], r["state"], r["rss_kb"], r["vsize"]))

    ms = maps_stats(pid)
    maps_lines = ["# proc_snap maps.txt  ts=%s  pid=%s  page=%d" % (_now(), pid, PAGE)]
    if ms is None:
        maps_lines.append("TARGET_UNREADABLE pid=%s" % pid)
    else:
        maps_lines.append("# path=%s  segments=%d  bytes=%d"
                          % (ms["path"], ms["total"]["n"], ms["total"]["bytes"]))
        maps_lines.append("# %-8s %8s %16s" % ("CATEGORY", "SEGMENTS", "BYTES"))
        for k in ("exec", "anon", "heap", "stack", "other"):
            maps_lines.append("# %-8s %8d %16d" % (k, ms["cats"][k]["n"], ms["cats"][k]["bytes"]))

    hash_lines = ["# proc_snap hashes.txt  ts=%s  pid=%s  algo=sha256" % (_now(), pid)]
    hash_lines += collect_hashes(pid)

    paths = write_out(outdir, procs_lines, maps_lines, hash_lines)
    if not quiet:
        print("\n".join(procs_lines))
        print("")
        print("\n".join(maps_lines))
        print("")
        print("\n".join(hash_lines))
        print("")
        for k, v in sorted(paths.items()):
            print("WROTE %s" % v)
    return {"rows": rows, "maps": ms, "paths": paths, "hashes": hash_lines}


def resolve_pid(spec):
    if spec == "self":
        return os.getpid()
    if spec == "parent":
        return os.getppid()
    return int(spec)


def selftest():
    """自造子进程 -> 采集 -> 断言。全部断言真跑，不 mock。"""
    ok = True
    child = subprocess.Popen(
        [sys.executable, "-c", "import time; x=bytearray(6*1024*1024); time.sleep(20)"]
    )
    try:
        time.sleep(1.2)
        st = parse_stat(child.pid)
        assert st is not None, "SELFTEST_FAIL parse_stat returned None"
        print("ASSERT rss_kb=%d vsize=%d comm=%s -> rss>0 : %s"
              % (st["rss_kb"], st["vsize"], st["comm"], st["rss_kb"] > 0))
        if not st["rss_kb"] > 0:
            ok = False

        ms = maps_stats(child.pid)
        assert ms is not None, "SELFTEST_FAIL maps_stats returned None"
        nseg = ms["total"]["n"]
        print("ASSERT maps_segments=%d total_bytes=%d -> segments>0 : %s"
              % (nseg, ms["total"]["bytes"], nseg > 0))
        if not nseg > 0:
            ok = False
        for k in ("exec", "anon", "heap", "stack"):
            print("ASSERT   cat=%-6s segments=%-5d bytes=%d"
                  % (k, ms["cats"][k]["n"], ms["cats"][k]["bytes"]))
        if not ms["cats"]["exec"]["n"] > 0:
            print("ASSERT WARN no executable segment found for python child")
            ok = False

        lines = collect_hashes(child.pid)
        for ln in lines:
            cols = ln.split("\t")
            dig = cols[2]
            good = len(dig) == 64 and all(c in "0123456789abcdef" for c in dig)
            print("ASSERT hash_len=%d path=%s -> len==64 : %s" % (len(dig), cols[1], good))
            if not good:
                ok = False

        tr = tracer_pids()
        print("ASSERT tracer_scan_hits=%d -> %s" % (len(tr), tr if tr else "[]"))

        paths = write_out("z3out_selftest",
                          ["# selftest"], ["# selftest"], lines)
        for k, v in sorted(paths.items()):
            print("WROTE %s (%d bytes)" % (v, os.path.getsize(v)))
    finally:
        child.terminate()
        try:
            child.wait(timeout=5)
        except Exception:
            child.kill()

    print("SELFTEST %s" % ("PASS" if ok else "FAIL"))
    return 0 if ok else 1


def main():
    ap = argparse.ArgumentParser(description="Z3 procfs snapshot collector (read-only)")
    ap.add_argument("--pid", default=None, help="目标 pid，或 'self' / 'parent'")
    ap.add_argument("--outdir", default="z3out", help="产物目录，默认 ./z3out")
    ap.add_argument("--top", type=int, default=DEFAULT_TOP, help="进程列表条数，默认 20")
    ap.add_argument("--list", action="store_true", help="只打印进程列表")
    ap.add_argument("--selftest", action="store_true", help="自造子进程并断言")
    args = ap.parse_args()

    if args.selftest:
        return selftest()
    if args.list:
        do_list(args.top)
        return 0
    pid = resolve_pid(args.pid) if args.pid else os.getpid()
    do_collect(pid, args.top, args.outdir)
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

实测回显（逐字）：

```
round0 proc_only=[3615, 3630] ps_only=[3631, 3632, 3633, 3639, 3640, 3643, 3644]
round1 proc_only=[]           ps_only=[3661]
round2 proc_only=[]           ps_only=[3671]
round3 proc_only=[]           ps_only=[3676]
round4 proc_only=[]           ps_only=[3750]
```

**判读：本机未检出隐藏进程。** 依据：`proc_only` 在 5 轮中有 4 轮为**空集**；
第 0 轮的非空差集里的 pid（3330/3393、3615/3630/3631…）事后用 `ps -p` 复查全部已不存在，
是 `ls /proc` 与 `ps` 两次系统调用之间子进程创建/退出造成的 PID 抖动，不是被摘除的进程。
`ps_only` 恒非空且每轮不同，同样是 `ps` 自身及其管道进程在 `/proc` 快照之后才出现所致。
**单次差集不足以作为隐藏进程证据；必须多轮采样看差集是否稳定。**

**(3) TracerPid 非 0 扫描 —— 15 项命中，全部指向同一个 tracer。**

```
[(1872, 1863), (2140, 1863), (2151, 1863), (2927, 1863), (2929, 1863), (2930, 1863),
 (2932, 1863), (3064, 1863), (3174, 1863), (3175, 1863), (3184, 1863), (3202, 1863),
 (3207, 1863), (3209, 1863), (3210, 1863)]
```

tracer pid 恒为 **1863**，为 `libproot.so` 即 proot 主控进程（cmdline 见第二章第 4 条）。
**判读：这是 proot 架构的预期行为，不是注入或调试器附加。**
proot 以 `ptrace(PTRACE_TRACEME/SEIZE)` 拦截被追踪进程的系统调用并改写路径，
因此容器内所有由 proot 托管的进程 `TracerPid` 都指向 1863。
检测规则上必须为此建白名单，否则会把宿主自身的容器运行时误报为入侵。
**可用的判据是「tracer 分布」而非「TracerPid 是否为 0」**：
单一 tracer 且 tracer 自身为容器 init → 正常；出现多个不同 tracer、或 tracer 不在 1863 → 异常。

### 五、volatility3 可用性判定与降级路径

**安装前**：`command -v vol` / `volatility3` / `vol.py` 三者**全部 MISSING**；
`python3 -c "import volatility3"` → `ModuleNotFoundError: No module named 'volatility3'`；
且 `python3 -m pip` 报 `No module named pip`（pip 本身未装）。

按工具链规则实装（本机 apt 源可达，`TCP deb.debian.org:80 OK`）：

```bash
apt-get update -qq
apt-get install -y -qq python3-pip
python3 -m pip install --break-system-packages -q volatility3
vol --version
```

**安装后实测**：

```
vol: error: File does not exist: /tmp/NONEXISTENT_MEMORY_IMAGE.raw
Volatility 3 Framework 2.28.2
```

`/usr/local/bin/vol` 存在；`import volatility3` 成功；
dist-info 目录 `/usr/local/lib/python3.12/dist-packages/volatility3-2.28.2.dist-info`；
**版本 2.28.2**，`pip` 24.0（`/usr/lib/python3/dist-packages/pip`）。

**架构上无法完成镜像分析 —— 本条不编造：**
本机**不存在任何内存镜像样本**。`/proc/kcore`、`/dev/mem`、`/dev/kmem`、`/proc/vmcore` 四者实测全部 ABSENT（第一章），
宿主 Android 镜像不可导出，容器内也无法生成可用的 Linux 物理内存转储。
因此 volatility3 只能验证到「框架可执行、插件树在位、可正确拒绝不存在的镜像文件」这一步，
**任何 `linux.pslist` / `linux.bash` / `banners` 的真实输出在本机都不可能取得**。
上一条 `vol -f ... linux.pslist` 的 `File does not exist` 就是这条边界的直接证据，不是安装失败。

**降级路径（本机实际采用的即是第 2 条）**：
1. 有外部镜像样本时：`vol -f MEMORY_IMAGE.raw -s SYMBOL_DIR linux.pslist`，
   需额外准备匹配内核版本的 ISF 符号包（`--symbol-dirs`）。
2. 无镜像时（本机）：改用**活体 procfs 采集**——即第三章的 `proc_snap.py`，
   用 `/proc/*/stat`、`/proc/<pid>/maps`、`/proc/<pid>/status` 覆盖「进程列表 + 内存布局 + tracer」三类问题。
   这能回答「此刻有哪些进程、各自内存段构成如何、谁在追踪谁」，但**无法回答内存中的历史痕迹**
   （已退出进程、释放的堆对象、shell 历史、未落盘的密钥）——那类问题只有物理镜像能答。
3. 若要提升到镜像级取证：需在**宿主侧**或具备 CAP_SYS_ADMIN 的独立环境导出 dump，本容器不具备该前提。
