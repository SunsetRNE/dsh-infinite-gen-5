### 1. 账户面：/etc/passwd 与 /etc/shadow 分桶实测

做法：只统计字段2 的**算法前缀与计数**，绝不打印哈希本体（本条是产出纪律，避免把凭据材料写进报告）。空密码用 `awk` 判字段为空，不用「看起来像空」目测。

```bash
# [1a] shadow 字段2 分桶：只出算法与计数，不出哈希
awk -F: '{f=$2;
  if(f=="") k="EMPTY(no password)";
  else if(f ~ /^\$y\$/) k="$y$ yescrypt";
  else if(f ~ /^\$6\$/) k="$6$ sha512crypt";
  else if(f ~ /^\$5\$/) k="$5$ sha256crypt";
  else if(f ~ /^\$1\$/) k="$1$ md5crypt";
  else if(f ~ /^\$2[aby]\$/) k="$2$ bcrypt";
  else if(f ~ /^!/) k="! locked";
  else if(f ~ /^\*/) k="* no-login";
  else if(f=="x") k="x shadowed-stub";
  else k="OTHER";
  print k}' /etc/shadow | sort | uniq -c | sort -rn
```

实测输出：

```
     18 * no-login
      4 ! locked
```

```bash
# [1b] uid=0 账户清单
awk -F: '$3==0{print $1" uid="$3" gid="$4" shell="$7}' /etc/passwd
# root uid=0 gid=0 shell=/bin/bash

# [1c] 空密码账户：passwd 与 shadow 两侧都判空
awk -F: '$2==""{c++; print "EMPTY:"$1} END{print "count="c+0}' /etc/passwd
# count=0
awk -F: '$2==""{print "EMPTY:"$1} $2=="!"{print "BANG_ONLY:"$1}' /etc/shadow
# BANG_ONLY:messagebus

# [1d] passwd 字段2 分桶（是否为 shadowed 占位）
awk -F: '{print ($2=="x"?"x (shadowed)":($2==""?"EMPTY":"OTHER:"$2))}' /etc/passwd | sort | uniq -c
#      22 x (shadowed)

# [1e] 是否存在任何真实哈希（以 $ 开头者）
awk -F: '$2 ~ /^\$/ {c++} END{print "hashed_entries="c+0}' /etc/shadow
# hashed_entries=0

# [1f] 被 ! 锁定的账户名
awk -F: '$2 ~ /^!/{print $1}' /etc/shadow | tr '\n' ' '
# systemd-network systemd-timesync messagebus systemd-resolve
```

读法（只写实测能支撑的部分）：

- 22 行 shadow 与 22 行 passwd 一一对应，`x` 占位 22/22，说明全部账户走 shadow，无 passwd 内联哈希的遗留配置。
- `hashed_entries=0`：**没有一条口令可以离线比对**。18 条 `*` 在 Debian 系语义为「无口令、禁止口令登录」，4 条 `!` 为显式锁定。
- `root` 的 shadow 字段2 为 `*`（实测长度为 1），即 root 无口令哈希；uid=0 账户仅 root 一个。
- 唯一的 `BANG_ONLY:messagebus` 说明 D-Bus 系统账户呈锁定态，属发行版默认形态，不构成额外暴露面。
- 无 uid≥1000 且 <65534 的普通交互账户（`awk -F: '$3>=1000 && $3<65534'` 返回空），/home 目录为空——这台容器只有系统账户，没有人味账户面。

|---|---|---|---|
| 22 条 shadow 记录中 18 条 `*`、4 条 `!`、真实哈希 0 条 | 已知 | 2026-09-29 快照；任何一次 `passwd`/`useradd` 即失效 | `awk` 分桶实测输出 |
| uid=0 账户仅 root；passwd 字段2 全为 `x`；无空口令字段 | 已知 | 同上 | `awk -F:` 三条独立判据实测 |
| 无 uid∈[1000,65534) 的交互账户，/home 为空 | 已知 | 同上 | `awk` + `ls -la /home` 实测 |

### 2. sudo 面：本机未安装，提权面不存在

```bash
# [2a] 命令在场判定
command -v sudo            # 无输出（MISSING）
sudo -n -l                 # bash: line 1: sudo: command not found   （exit=127）
                           # uid=0 时本应直接 `sudo -l`，但命令体本身不在场，故两条路径同判缺失
# [2b] 文件级判定
ls -ld /etc/sudoers /etc/sudoers.d
# ls: cannot access '/etc/sudoers': No such file or directory
# ls: cannot access '/etc/sudoers.d': No such file or directory
# [2c] 包级判定
dpkg-query -W -f='${Status} ${Version}\n' sudo
# dpkg-query: no packages found matching sudo
```

判定与缺失结论（三条独立证据同向，故结论为「缺失」而非「未取到」）：

- **sudoers 全文要点**：文件不存在，无从给出。`/etc/sudoers` 与 `/etc/sudoers.d/` 均返回 ENOENT，因此不存在可被 NOPASSWD、`%sudo` 组或通配命令规则滥用的提权面。
- **`sudo -l` 实际输出**：命令不在场，shell 返回 `sudo: command not found`（退出码 127）。这不是权限拒绝，也不是「uid=0 所以 sudo 不需要」——是二进制根本不存在。报告里必须区分这两者，否则下游会误判成「有 sudo 但被限制」。
- 旁证：`/etc/pam.d/` 下存在 `su`、`su-l`、`runuser`、`runuser-l` 等模块文件（实测存在），说明本机保留了 `su`/`runuser` 路径的 PAM 栈；`sudo` 相关 PAM 文件（`sudo`、`sudo-i`）在目录清单中不存在。即：**横向提权通道若有，走的是 su 系而非 sudo 系**，而 su 的目标账户（root）在 shadow 中无哈希，口令路径同样闭合。
- 与第 1 节联动：uid=0 账户仅 root 且 root 无口令哈希，本机已是 root 会话，sudo 在场与否都不改变当前身份；它的意义在于「镜像最小化程度」这一项基线。

| 断言 | 态 | 有效期到 | 依据 |
|---|---|---|---|
| 本机无 `sudo` 命令、无 `/etc/sudoers`、无 `/etc/sudoers.d/` | 已知 | 2026-09-29 快照；执行第 0.1 节的 `apt-get install -y sudo` 即失效 | `command -v` + `ls -ld` + `dpkg-query` 三条独立实测 |
| `/etc/pam.d/` 有 su/runuser 栈，无 sudo 栈 | 已知 | 同上 | `ls /etc/pam.d/` 实测清单 |
| su 路径无法用空口令进入 root | 推测 | — | 依据：shadow 中 root 字段2 为 `*`（实测）＋ PAM `su` 模块存在（实测）；未在禁用密码的等效环境做过登录尝试，故不写为已知 |

### 3. SSH 面：本机无服务端，仅客户端

做法：先判客户端/服务端二进制与配置文件的在场性，再谈「生效值」。`sshd -T` 是取生效值的正解（它会把 Include、Match 展开后的最终值打出来），但前提是 `sshd` 在场。

```bash
# [3a] 服务端二进制与配置
command -v sshd                      # 无输出（MISSING）
ls -l /usr/sbin/sshd /etc/ssh/sshd_config
# ls: cannot access '/usr/sbin/sshd': No such file or directory
# ls: cannot access '/etc/ssh/sshd_config': No such file or directory
# [3b] 取生效值（正解路径，本机不可用）
sshd -T 2>/dev/null                  # bash: line 1: sshd: command not found   （exit=127）
# [3c] 回退路径：grep 配置文件（文件也不存在，故无回退对象）
grep -nE '^[[:space:]]*(PermitRootLogin|PasswordAuthentication|Port|PubkeyAuthentication|PermitEmptyPasswords|KbdInteractiveAuthentication|UsePAM)' /etc/ssh/sshd_config
# grep_exit=2（无此文件）
# [3d] /etc/ssh 实际内容
ls -la /etc/ssh/
# ssh_config            1649  -rw-r--r--
# ssh_config.d/         （空目录，total 0）
# [3e] 客户端版本
ssh -V
# OpenSSH_9.6p1 Ubuntu-3ubuntu13.19, OpenSSL 3.0.13 30 Jan 2024
```

判定与缺失结论：

- **`/etc/ssh/sshd_config` 是否存在**：不存在。`/etc/ssh/` 下只有 `ssh_config`（客户端配置，1649 字节）与空的 `ssh_config.d/`。
- **PermitRootLogin / PasswordAuthentication / Port 的生效值**：**本机无法给出，且不应给出**。`sshd -T` 返回 127（无二进制），配置文件 grep 返回 2（无文件）——两条取法同时落空。任何写出来的「默认 PermitRootLogin prohibit-password / Port 22」都属于凭知识编造的本机结论，本次不写。
- **服务端缺失的直接后果**：本机不存在监听 22 的 sshd 进程。`/proc/net/tcp` 实测的监听项里没有 `:0016`（22）端口，本地监听集中在 `127.0.0.1` 上的若干高位端口（0xAB13、0x27AC、0x27AD、0x0C08、0xA040 等）与 `0.0.0.0:30BF`、`0.0.0.0:3EDE`，均非 SSH 服务端口。**扫描结论：SSH 服务端面在本机为「不存在」，不构成暴露面。**
- 客户端 `ssh` 与 `ssh-keygen` 在场（OpenSSH_9.6p1），因此出向 SSH 与密钥指纹能力可用——这一点直接支撑第 4 节的指纹取证。
- 没有 sshd 也意味着 `PermitRootLogin`、`MaxAuthTries`、`AllowUsers` 这类加固项在本机**无可加固对象**；报告里对应的条目应为「不适用／镜像未含服务端」，而非「配置合规」。

| 断言 | 态 | 有效期到 | 依据 |
|---|---|---|---|
| 本机无 `/usr/sbin/sshd`，无 `/etc/ssh/sshd_config` | 已知 | 2026-09-29 快照；安装 openssh-server 即失效 | `ls -l` + `command -v` 实测 |
| `sshd -T` 与配置 grep 两条生效值取法在本机均落空（127 / 2） | 已知 | 同上 | 两条命令的退出码实测 |
| 本机无 22 端口监听，SSH 服务端面不存在 | 已知 | 2026-09-29 快照 | `/proc/net/tcp` 监听项枚举，未见 `:0016` |
| openssh-server 的发行版默认生效值（Port 22、PermitRootLogin 等） | 未知 | — | 未安装该包，`/etc/ssh/sshd_config` 不在场，无法读取本机实际值；给出即为编造 |

### 4. 密钥面：私钥权限矩阵与指纹取证

做法：`find` 限定 `/root` 与 `/home` 且 `-maxdepth 3`（全盘 `find /` 在本容器上因挂载点过多会长时间不返回，实测超 60 秒仍未结束，故降级为限定路径——这一条也写进报告，避免下游复现时踩同一个坑）；权限用 `stat -c '%a %U:%G'` 取八进制位；指纹用 `ssh-keygen -lf`，私钥文件本身也能直接出对应公钥指纹。

```bash
# [4a] 密钥材料枚举（限定路径 + 深度，含权限位与大小）
find /root /home -maxdepth 3 \( -name 'id_*' -o -name 'authorized_keys' -o -name 'known_hosts' -o -name '*.pem' \) -printf '%M %u:%g %10s %p\n' 2>/dev/null
# -rw------- root:root        411 /root/Branchbase/.local-gh/id_ed25519
# -rw-r--r-- root:root        103 /root/Branchbase/.local-gh/id_ed25519.pub
# -rw------- root:root        878 /root/.ssh/known_hosts
# -rw-r--r-- root:root        102 /root/.ssh/id_ed25519.pub
# -rw------- root:root        411 /root/.ssh/id_ed25519

# [4b] 指纹（主件：ssh-keygen -lf，私钥与公钥两侧都查，指纹必须一致）
for f in /root/.ssh/id_ed25519 /root/.ssh/id_ed25519.pub \
         /root/Branchbase/.local-gh/id_ed25519 /root/Branchbase/.local-gh/id_ed25519.pub; do
  printf '%-52s ' "$f"; ssh-keygen -lf "$f" 2>&1 | head -1
done
# .../root/.ssh/id_ed25519              256 SHA256:wfTacGRTzUX5jmaSDgXri8IUSHm/cxx/V/3f17hYsxY z100o190zgxc@163.com (ED25519)
# .../root/.ssh/id_ed25519.pub          256 SHA256:wfTacGRTzUX5jmaSDgXri8IUSHm/cxx/V/3f17hYsxY z100o190zgxc@163.com (ED25519)
# .../Branchbase/.local-gh/id_ed25519   256 SHA256:jx9KVVH6GHGxibFWzYkylSc161pQdlgrg8C6mHBYG4A branchbase-local-diag (ED25519)
# .../Branchbase/.local-gh/id_ed25519.pub 256 SHA256:jx9KVVH6GHGxibFWzYkylSc161pQdlgrg8C6mHBYG4A branchbase-local-diag (ED25519)

# [4c] 权限矩阵（八进制）
stat -c '%a %U:%G %n' /root/.ssh /root/.ssh/id_ed25519 /root/.ssh/id_ed25519.pub \
  /root/.ssh/known_hosts /root/.ssh/known_hosts.old \
  /root/Branchbase/.local-gh /root/Branchbase/.local-gh/id_ed25519 /root/Branchbase/.local-gh/id_ed25519.pub
# 700 root:root /root/.ssh
# 600 root:root /root/.ssh/id_ed25519
# 644 root:root /root/.ssh/id_ed25519.pub
# 600 root:root /root/.ssh/known_hosts
# 600 root:root /root/.ssh/known_hosts.old
# 700 root:root /root/Branchbase/.local-gh
# 600 root:root /root/Branchbase/.local-gh/id_ed25519
# 644 root:root /root/Branchbase/.local-gh/id_ed25519.pub

# [4d] 降级路径（ssh-keygen 不在场时用）：pub 文件摘要 + 权限矩阵
sha256sum /root/.ssh/id_ed25519.pub /root/Branchbase/.local-gh/id_ed25519.pub
# 2849e3c9cdb0139c07fde450cebaf649980cc0be6fe5f1b25e1f4e98218faa6b  /root/.ssh/id_ed25519.pub
# 1022e10cdd96a29983a27abbf17dd0eda9981ada4daf7a60e70a2f8e5aa86663  /root/Branchbase/.local-gh/id_ed25519.pub

# [4e] known_hosts 形态
grep -c '^|1|' /root/.ssh/known_hosts   # 1（已哈希主机名）
wc -l /root/.ssh/known_hosts            # 3
```

读法：

- 两组 ed25519 密钥，**私钥权限均为 `0600`、目录 `0700`**，符合 OpenSSH 的严格模式要求（`StrictModes` 下 `0644` 私钥会被拒用）。`.pub` 为 `0644` 属正常（公钥本就公开），不记为缺陷。
- **指纹两侧一致**：`/root/.ssh/id_ed25519` 与其 `.pub` 同为 `SHA256:wfTacGRT…`；`Branchbase/.local-gh` 一组同为 `SHA256:jx9KVVH6…`。这排除了「公钥被替换而私钥未换」的错配，是有取证价值的正向信号。
- **authorized_keys 不存在**（`/root/.ssh/` 仅 4 个文件，`/home` 为空目录），配合第 3 节的「无 sshd」，本机不存在基于公钥的入向登录入口。出向用途可由 `.pub` 注释串读出：一组指向一个外部邮箱（`z100o190zgxc@163.com`），一组为本机诊断用途（`branchbase-local-diag`）。
- `known_hosts` 3 行中 1 行为 `|1|` 哈希形态，与 `/etc/ssh/ssh_config` 第 52 行 `HashKnownHosts yes` 一致——配置与数据形态互证。

### 5. 口令强度：pw_audit.py 离线比对器（含 --selftest）

设计要点与边界（写死在代码里，可逐行核）：

- **只读**：读 `/etc/shadow` 或 `--shadow` 指定文件，不写回、不改动任何账户。
- **不联网**：全文件不导入 `socket` / `urllib` / `requests` / `paramiko`，没有出向能力。不做远程登录、不爆破任何主机——候选词只在本地与本地哈希比对。
- **候选词表 8 条，全为自造弱口令占位串**：`admin123`、`TARGET2026`、`P@ssw0rd`、`root123`、`123456`、`password`、`changeme`、`TARGET`。它们的用途是回答「本机是否用了这类弱口令」，不是任何真实世界的口令集。
- **三级 crypt 后端**：Python stdlib `crypt` → `ctypes` 直连 `libcrypt.so.1` → 显式降级（返回 `None` 并计入 `unsupported`，绝不猜结论）。本机实测走第一条：`backend = python-stdlib-crypt`。
- **`--selftest` 三层自测**：① KAT 已知答案（固定盐 `$6$Z2SELFTEST.SALT$` 的 sha512crypt 输出，摘要与常量比对）；② 通过用例 + 否定用例各一次；③ 写临时 fixture shadow 走完整 `audit()` 管道，断言 `hashed=1 / weak_hits=1 / unsupported=0`。
- **退出码语义**：0 无命中 / 1 有命中 / 2 后端或文件不可用 / 3 自检失败。便于接进 CI 的门禁。

主件全文（`/root/dsh-infinite-gen-5/tests/triad/z2/artifacts/pw_audit.py`，215 行，sha256 见下方）：

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""pw_audit.py — Z2 身份与凭据面 · 弱口令离线比对器（本地只读，不联网）。

比对对象：/etc/shadow（或 --shadow 指定文件）中「带真实哈希」的条目。
候选词表：内置 8 个自造弱口令占位串（admin123 / TARGET2026 / ...），
          只用于验证本机是否存在这类弱口令，不涉及任何外部目标。

写死的边界，代码里可核：
  * 只读本地文件；不写回 /etc/shadow，不改动任何账户。
  * 不导入 socket / urllib / requests / paramiko —— 全程无网络行为。
  * 不做远程登录、不爆破外部主机。

用法：
  python3 pw_audit.py --selftest              # 自检：一次通过 + 一次不通过 + 端到端
  python3 pw_audit.py                         # 扫本机 /etc/shadow
  python3 pw_audit.py --shadow /path/shadow   # 扫指定文件
  python3 pw_audit.py --json                  # 机器可读输出
退出码：0 无命中 / 1 有命中 / 2 后端不支持 / 3 自检失败
"""
from __future__ import annotations

import argparse
import hashlib
import json
import os
import sys
import tempfile

CANDIDATES = (
    "admin123", "TARGET2026", "P@ssw0rd", "root123",
    "123456", "password", "changeme", "TARGET",
)

SELFTEST_PW = "admin123"
SELFTEST_SALT = "$6$Z2SELFTEST.SALT$"
# 常量：$6$ sha512crypt 已知答案测试（KAT）基准摘要，由本会话实测填充
GOLDEN_SHA256_KAT = "98f2060eacb3817ebfe4190391b800a7fcc62b03fcc6ca76ff9fe339023796f0"
ALGO_TABLE = {
    "1": "md5crypt", "2a": "bcrypt", "2b": "bcrypt", "2y": "bcrypt",
    "5": "sha256crypt", "6": "sha512crypt", "y": "yescrypt",
    "gy": "gost-yescrypt", "7": "scrypt",
}


def _load_backend():
    """三级取用 crypt：stdlib → ctypes 直连 libcrypt → 明确降级。"""
    try:
        import crypt as _stdlib  # noqa: F401  (3.12 起 DeprecationWarning)
        return _stdlib.crypt, "python-stdlib-crypt"
    except Exception:
        pass
    try:
        import ctypes
        import ctypes.util
        name = ctypes.util.find_library("crypt") or "libcrypt.so.1"
        lib = ctypes.CDLL(name, use_errno=True)
        lib.crypt.restype = ctypes.c_char_p
        lib.crypt.argtypes = [ctypes.c_char_p, ctypes.c_char_p]

        def _fn(pw, salt):
            out = lib.crypt(pw.encode(), salt.encode())
            return out.decode() if out else None

        return _fn, "ctypes-" + name
    except Exception as exc:               # 无 crypt 时明确报降级，不猜
        return None, "unsupported: %s" % exc


CRYPT, BACKEND = _load_backend()


def algo_of(h):
    if h.startswith("$"):
        tag = h.split("$")[1] if len(h.split("$")) > 1 else "?"
        return ALGO_TABLE.get(tag, "unknown-$" + tag)
    return "plain-or-legacy"


def salt_of(h):
    p = h.split("$")
    return "$".join(p[:3]) + "$" if len(p) > 3 else h


def verify(pw, h):
    """True 命中 / False 不命中 / None 后端不支持该算法（不猜）。"""
    if CRYPT is None or not h.startswith("$"):
        return None
    got = CRYPT(pw, salt_of(h))
    if got is None or got in ("*0", "*1"):
        return None
    return got == h


def audit(path):
    rows, weak, hashed, unsupported = [], 0, 0, 0
    with open(path, "r", encoding="utf-8", errors="replace") as fh:
        for line in fh:
            f = line.rstrip("\n").split(":")
            if len(f) < 2 or not f[0]:
                continue
            user, h = f[0], f[1]
            if h == "" or h in ("*", "!") or h.startswith("!"):
                rows.append((user, "locked/nologin", "skip"))
                continue
            if not h.startswith("$"):
                rows.append((user, "unhashed:" + h[:1], "skip"))
                continue
            hashed += 1
            algo, hit, unknown = algo_of(h), None, False
            for cand in CANDIDATES:
                res = verify(cand, h)
                if res is None:
                    unknown = True
                    break
                if res:
                    hit = cand
                    break
            if unknown:
                unsupported += 1
                rows.append((user, algo, "unsupported-by-backend"))
            elif hit:
                weak += 1
                rows.append((user, algo, "WEAK-HIT:" + hit))
            else:
                rows.append((user, algo, "no-match"))
    return rows, weak, hashed, unsupported


def selftest():
    ok = True
    print("backend   = %s" % BACKEND)
    if CRYPT is None:
        print("SELFTEST FAIL: 取不到 crypt 后端")
        return 3
    h = CRYPT(SELFTEST_PW, SELFTEST_SALT)
    if not h or not h.startswith("$6$"):
        print("SELFTEST FAIL: crypt 未回 $6$ 哈希")
        return 3
    digest = hashlib.sha256(h.encode()).hexdigest()
    if GOLDEN_SHA256_KAT == "__MEASURE__":
        print("KAT-BOOTSTRAP sha256=%s" % digest)
    else:
        kat = (digest == GOLDEN_SHA256_KAT)
        ok &= kat
        print("KAT      %s  algo=%s len=%d sha256=%s"
              % ("PASS" if kat else "FAIL", algo_of(h), len(h), digest[:16] + "…"))
    p = verify(SELFTEST_PW, h)
    ok &= (p is True)
    print("[1] 通过用例 verify(%r, $6$...) = %s  -> %s"
          % (SELFTEST_PW, p, "PASS" if p is True else "FAIL"))
    q = verify(SELFTEST_PW + "_WRONG", h)
    ok &= (q is False)
    print("[2] 否定用例 verify(%r, $6$...) = %s -> %s"
          % (SELFTEST_PW + "_WRONG", q, "PASS" if q is False else "FAIL"))
    with tempfile.NamedTemporaryFile("w", delete=False, encoding="utf-8") as tf:
        tf.write("z2demo:%s:20000:0:99999:7:::\n" % h)
        tf.write("z2locked:*:20000:0:99999:7:::\n")
        tf.write("z2nopw::20000:0:99999:7:::\n")
        fixture = tf.name
    try:
        rows, weak, hashed, unsup = audit(fixture)
    finally:
        os.unlink(fixture)
    e2e = (weak == 1 and hashed == 1 and unsup == 0)
    ok &= e2e
    print("[3] 端到端 fixture: hashed=%d weak_hits=%d unsupported=%d -> %s"
          % (hashed, weak, unsup, "PASS" if e2e else "FAIL"))
    for r in rows:
        print("      %-10s %-18s %s" % r)
    print("SELFTEST %s" % ("PASS" if ok else "FAIL"))
    return 0 if ok else 3


def main(argv=None):
    ap = argparse.ArgumentParser(description="离线弱口令比对（只读本机 shadow）")
    ap.add_argument("--shadow", default="/etc/shadow", help="shadow 文件路径")
    ap.add_argument("--selftest", action="store_true", help="跑已知答案自检")
    ap.add_argument("--json", action="store_true", help="输出 JSON")
    args = ap.parse_args(argv)

    if args.selftest:
        return selftest()

    if not os.path.exists(args.shadow):
        print("ERROR: %s 不存在" % args.shadow, file=sys.stderr)
        return 2
    if CRYPT is None:
        print("ERROR: 无 crypt 后端 -> %s" % BACKEND, file=sys.stderr)
        return 2

    rows, weak, hashed, unsup = audit(args.shadow)
    if args.json:
        print(json.dumps({
            "shadow": args.shadow, "backend": BACKEND,
            "candidates": len(CANDIDATES), "hashed_entries": hashed,
            "weak_hits": weak, "unsupported": unsup,
            "rows": [{"user": u, "algo": a, "verdict": v} for u, a, v in rows],
        }, ensure_ascii=False, indent=2))
    else:
        print("backend            = %s" % BACKEND)
        print("shadow             = %s" % args.shadow)
        print("candidates         = %d" % len(CANDIDATES))
        print("hashed_entries     = %d" % hashed)
        print("weak_hits          = %d" % weak)
        print("skipped_unsupported = %d" % unsup)
        print("-" * 58)
        print("%-12s %-20s %s" % ("ACCOUNT", "ALGO", "VERDICT"))
        for u, a, v in rows:
            print("%-12s %-20s %s" % (u, a, v))
    return 1 if weak else 0


if __name__ == "__main__":
    sys.exit(main())
```
