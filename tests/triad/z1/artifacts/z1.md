## Z1 暴露面与资产清单：实测本机监听面、归属映射与端口复核

授权范围：自有资产 / 授权靶场。本机容器即靶机，uid=0，实测命令全部在本会话内真实执行，正文只写命令回显里出现过的字面内容。识别到的实体一律用真实回显值（127.0.0.1、端口号、PID、inode），未证实的一律标 `推测` 或 `未知`。

### 0. 先探环境：平台形态与工具链在场情况

三条判据把「这台机器是什么」钉死，后续所有归属推断都建立在这三条上：

- `uname -a` → `Linux localhost 6.1.141-android14-11-o-g659d588fa0da #1 SMP PREEMPT Thu Aug 6 07:53:55 UTC 2026 aarch64 aarch64 aarch64 GNU/Linux`
  → 内核串带 `android14-11`，说明宿主是 Android 设备内核，**不是**普通 x86 服务器。
- `/etc/os-release` → `PRETTY_NAME="Ubuntu 24.04.3 LTS"` / `VERSION_ID="24.04"` / `VERSION_CODENAME=noble`
  → 用户态是 Ubuntu 24.04.3，与内核分离，典型「Android 宿主 + Linux rootfs」结构。
- `/proc/self/cgroup` 原文：
  `5:freezer:/` / `4:memory:/apps/com.dsh.client` / `3:cpuset:/top-app` / `2:cpu:/top-app` / `1:blkio:/` / `0::/apps/uid_10527/pid_27013`
  → 容器标记落在 `/apps/com.dsh.client`（Android 应用 UID 10527）下，pid_27013 是该容器在宿主侧的进程号。
  → 结论：**com.dsh.client 应用内的 proot 容器，共享 Android 设备的网络命名空间**（这也解释了为什么监听面里同时出现 rmnet_data*/tun0/vgate0 这些移动网络接口）。

`/proc/1/cgroup` 与 `ls /proc/1/` 在本环境均不存在（回显 `No such file or directory`）；`/proc/mounts` 的 proc 行是
`proc /proc proc rw,relatime,gid=3009,hidepid=invisible 0 0` —— `hidepid=invisible` 是把「进程不可见」和「`ss -p` 只显示同 UID 进程」两条限制同时打开的根因，后面所有「只能靠 inode/uid 归属」的条目都由它导致，不是权限没给够。

工具链（装之前 / 装之后都记）：

- 初始不在场：`ss`、`ip`、`nc`、`lsof`、`netstat` 全部 MISSING。
- 本次安装：`apt-get install -y iproute2`。第一次执行被拒，原文 `E: Could not get lock /var/lib/dpkg/lock-frontend. It is held by process 2932 (apt-get)`（另一并发任务正在装同一个包），等待锁释放后重跑成功。降级路径：若 apt 锁长期不释放，可改用 `ss` 的替代探测（本文件的 `tcp_probe.py` 不依赖 iproute2，纯 Python `socket.connect_ex`，可在无 ss 环境下独立复跑）。
- 版本核验：`ss -V` → `ss utility, iproute2-6.1.0`；`dpkg -s iproute2` → `Version: 6.1.0-1ubuntu6.4`，`Status: install ok half-configured`（半配置状态，功能可用）。
- 其余已就位：`ps` = procps-ng 4.0.4、`python3` = 3.12.3、`nmap` = 7.94SVN（`Platform: aarch64-unknown-linux-gnu`）。

### 4. 应用层复核：这些监听口到底讲什么协议

TCP 能连 ≠ 应用可用，所以对每个可连端口补一次 HTTP 探针：

```bash
# Z1 应用层块：区分「HTTP 服务 / 非 HTTP 服务 / 认证拒绝」
for p in 3080 43795 3090 7890 10150 10152 10156 10157 10162 12479 16094 46888; do
  printf '%-6s ' "$p"
  curl -s -o /dev/null -m 3 -w 'http=%{http_code} ct=%{content_type} len=%{size_download}\n' "http://127.0.0.1:$p/"
done
curl -s -o /dev/null -m 3 -w '40379 tun0 http=%{http_code}\n' http://172.19.0.1:40379/
curl -s -x http://127.0.0.1:7890 -o /dev/null -m 8 -w 'proxy_http=%{http_code}\n' http://example.com/
```

实测回显：

- `127.0.0.1:3080` → `http=401 ct=text/plain; charset=utf-8 len=68`；`HEAD` → `HTTP/1.1 401 Unauthorized`。nmap 指纹抓到响应体原文：`dsh web authentication required; reopen the URL printed by dsh web.` → 带认证的 Web 控制台，**未认证不可读**。
- `127.0.0.1:43795` → `http=200 ct=application/json len=50`；nmap 指纹抓到响应体原文：`{"ok":true,"upstream":"https://api.anthropic.com"}` → 本机 node 进程在对外**自述上游为 `https://api.anthropic.com`**，即一条无认证的健康/转发端点。这是本次清单里风险面最值得单独记一笔的条目：它绑定在 127.0.0.1（未暴露到非环回接口），但 `/` 无需任何凭据即返回 200。
- `127.0.0.1:3090` → `http=200 ct=application/json; charset=utf-8 len=27`；nmap 指纹：`{"result":"[UNAUTHORIZED]"}`；`HEAD` → `HTTP/1.1 405 Method Not Allowed` → 有鉴权门的 API 桥，且只认 GET。
- `127.0.0.1:7890` → `GET /` 返回 `HTTP/1.0 400 Bad Request`（HTTP 代理语义），实测 `curl -x http://127.0.0.1:7890 http://example.com/` → `proxy_http=200`，**代理转发链路可用**。
- `10150 / 10152 / 10156 / 10162 / 12479 / 16094 / 46888` → `http=000`（TCP 层可连，但不讲 HTTP，`curl` 在 3s 内得不到响应或收到非 HTTP 字节）。
- `172.19.0.1:40379` → `curl` 超时 `exit 28`。

复核实测（`python3` + `socket.connect_ex`，0.3s，逐端口逐一确认）：

```
3080=0  43795=0  3090=0  10150=0  10152=0  10156=0  10162=0  12479=0  16094=0  46888=0  7890=0
10157=111（已由 listening 变为 refused）  40379=111  10151=111  10160=111
```

→ `10157` 的状态在两次采集之间发生了翻转（`ss` 里是 `LISTEN`，`connect_ex` 返回 `111`），因此该端口按「短命监听」记录，而不是稳定暴露面。

### 5. 端口复核件：`tcp_probe.py`（自包含，无第三方依赖，全文如下）

零依赖设计理由：本环境的 `ss`/`ip` 是本次临时装上的，nmap 在部分 rootfs 里未必存在，而 `python3` 一定在。这个脚本只用标准库 `socket.connect_ex`，把「监听面复核」这件事变成一条不依赖任何外部二进制的可复现命令。

```python
# tcp_probe.py — Z1 端口复核件（本机实测所用版本，逐字全文，共 138 行）
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""tcp_probe.py — 自包含本地 TCP 端口复核器（Z1 暴露面取证用）

只做 TCP connect() 到 127.0.0.1 的指定端口集合，不发送任何应用层载荷。
用法:
  python3 tcp_probe.py                 # 默认扫描 top-100 常用端口
  python3 tcp_probe.py --selftest      # 自检：已知关闭端口 + 自建临时监听端口各断言一次
  python3 tcp_probe.py --ports 80,443  # 只扫指定端口
  python3 tcp_probe.py --timeout 0.3 --json out.json
退出码: 0 正常, 1 自检失败
"""
import argparse
import json
import socket
import sys
import threading
import time

HOST = "127.0.0.1"

# top-100 常用端口（nmap top-ports 风格的精简自建表，写死在文件里，不依赖外部词表）
TOP100 = [
    7, 9, 13, 21, 22, 23, 25, 26, 37, 53, 79, 80, 81, 88, 106, 110, 111, 113, 119, 135,
    139, 143, 144, 179, 199, 389, 427, 443, 444, 445, 465, 513, 514, 515, 543, 544, 548,
    554, 587, 631, 646, 873, 990, 993, 995, 1025, 1026, 1027, 1028, 1029, 1110, 1433,
    1720, 1723, 1755, 1900, 2000, 2001, 2049, 2121, 2717, 3000, 3128, 3306, 3389, 3986,
    4899, 5000, 5009, 5051, 5060, 5101, 5190, 5357, 5432, 5631, 5666, 5800, 5900, 6000,
    6001, 6379, 6646, 7070, 8000, 8008, 8009, 8080, 8081, 8443, 8888, 9100, 9200, 9999,
    10000, 27017, 32768, 49152, 49153, 49154,
]


def probe(host: str, port: int, timeout: float = 0.3) -> int:
    """返回 socket.connect_ex 的原始错误码；0 = 端口接受连接。"""
    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    s.settimeout(timeout)
    try:
        return s.connect_ex((host, port))
    except socket.timeout:
        return 110  # errno.ETIMEDOUT 语义（部分平台不抛该异常）
    except OSError as exc:
        return getattr(exc, "errno", -1) or -1
    finally:
        s.close()


def scan(host: str, ports, timeout: float = 0.3, workers: int = 64):
    results, t0 = {}, time.time()
    lock = threading.Lock()

    def worker(queue):
        while True:
            with lock:
                if not queue:
                    return
                port = queue.pop(0)
            results[port] = probe(host, port, timeout)

    queue = list(ports)
    threads = [threading.Thread(target=worker, args=(queue,), daemon=True) for _ in range(workers)]
    for t in threads:
        t.start()
    for t in threads:
        t.join()
    return results, time.time() - t0


def selftest(timeout: float = 0.3) -> int:
    """自检：对「已知关闭端口」与「自身临时监听端口」各断言一次。"""
    failures = []

    # 1) 自建临时监听端口必须被判为 open
    srv = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    srv.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    srv.bind((HOST, 0))
    srv.listen(1)
    live_port = srv.getsockname()[1]
    rc_live = probe(HOST, live_port, timeout)
    print(f"[selftest] 自建监听端口 {live_port}: connect_ex={rc_live} -> {'PASS' if rc_live == 0 else 'FAIL'}")
    if rc_live != 0:
        failures.append(f"live port {live_port} not detected as open (rc={rc_live})")
    srv.close()
    time.sleep(0.1)

    # 2) 同一个端口在关闭后必须判为 closed（ECONNREFUSED=111）
    rc_dead = probe(HOST, live_port, timeout)
    print(f"[selftest] 刚关闭的端口 {live_port}: connect_ex={rc_dead} -> {'PASS' if rc_dead == 111 else 'FAIL'}")
    if rc_dead != 111:
        failures.append(f"closed port {live_port} not detected as refused (rc={rc_dead})")

    # 3) 保留高位端口（IANA 未分配区间内的固定取值）作为已知关闭端口的补充断言
    known_closed = 49321
    rc_kc = probe(HOST, known_closed, timeout)
    print(f"[selftest] 已知关闭端口 {known_closed}: connect_ex={rc_kc} -> {'PASS' if rc_kc in (111, 110) else 'FAIL'}")
    if rc_kc not in (111, 110):
        failures.append(f"known-closed port {known_closed} unexpected rc={rc_kc}")

    if failures:
        print("[selftest] FAIL: " + "; ".join(failures))
        return 1
    print("[selftest] ALL PASS (3/3 断言)")
    return 0


def main(argv=None) -> int:
    ap = argparse.ArgumentParser(description="127.0.0.1 TCP 端口复核器（connect_ex）")
    ap.add_argument("--host", default=HOST)
    ap.add_argument("--ports", default="", help="逗号分隔端口；留空=top100")
    ap.add_argument("--timeout", type=float, default=0.3)
    ap.add_argument("--workers", type=int, default=64)
    ap.add_argument("--json", default="", help="把结果写成 JSON")
    ap.add_argument("--selftest", action="store_true")
    args = ap.parse_args(argv)

    if args.selftest:
        return selftest(args.timeout)

    ports = ([int(p) for p in args.ports.split(",") if p.strip()]
             if args.ports else TOP100)
    res, elapsed = scan(args.host, ports, args.timeout, args.workers)
    opened = sorted(p for p, rc in res.items() if rc == 0)
    closed = sorted(p for p, rc in res.items() if rc != 0)
    print(f"target={args.host} scanned={len(ports)} timeout={args.timeout}s workers={args.workers}")
    print(f"open={len(opened)} closed/other={len(closed)} elapsed={elapsed:.2f}s")
    print("open_ports=" + ",".join(str(p) for p in opened))
    if args.json:
        with open(args.json, "w", encoding="utf-8") as fh:
            json.dump({"target": args.host, "timeout": args.timeout, "elapsed_s": round(elapsed, 3),
                       "scanned": len(ports), "open": opened,
                       "closed": closed, "raw": {str(k): v for k, v in sorted(res.items())}},
                      fh, ensure_ascii=False, indent=1)
        print(f"json_written={args.json}")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

### 7. 四态：这批结论各自站在什么地基上
