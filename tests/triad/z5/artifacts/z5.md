## Z5 网络边界与横向可行域：出口接管取证与横向可达性判定

对象：本机容器（自有靶机 / 授权评估环境），内核 `6.1.141-android14-11-o-g659d588fa0da`，Ubuntu 24.04.3 LTS aarch64，宿主为 Android 设备。取样时间 2026-09-29T06:24Z–06:33Z，全部命令与原始输出落盘于同目录 `*.txt`。本区域的任务是回答两件事：**这台机器能从网络边界上看到什么**，以及**横向能摸到谁**。

### 0. 结论速览（先给判据，再给证据）

1. **身份是 proot 式 fakeroot**：`id` 报 `uid=0(root)`，但 `/proc/self/status` 内核真值为 `Uid: 10527 10527 10527 10527`，`CapInh/Prm/Eff/Bnd/Amb` 全部 `0000000000000000`，`NoNewPrivs: 1`，`Seccomp: 2`（2 个过滤器）。能力面为零，规则类/抓包类动作在本环境里不可执行。
2. **main 路由表没有 default**，只有三条直连/主机路由；uid 10527 的出战流量被 Android netd 风格策略路由整体接管：`rule 24000 / 21013 → table 1058 = default dev tun0`。实测连**同网段网关 10.202.11.229** 都被路由进 tun0，而不是走 `rmnet_data5`。
3. **因此 TCP connect 矩阵对非本机目标不可信**：RFC5737 保留、物理不可路由的 `192.0.2.1:443` 也在 1.6 ms 内「握手成功」，`ss` 里能看到 `172.19.0.1:37242 → 192.0.2.1:443 ESTAB`。出口侧的用户态代理内核（tun2socks 语义，监听 `*:7890`）对每个 SYN 先本地回 ACK，上游能不能通要等应用层数据才知道 —— 实测 `recv` 在 1.5 s 超时、HTTP 在 4 s 超时（curl exit 28）。
4. **可用的横向判据是应用层回包，不是 connect 成功**：`127.0.0.1:3080` 回 `HTTP/1.1 401 Unauthorize…`（DSH Web GUI，真实服务）、`127.0.0.1:3090` 回 `HTTP/1.1 200 OK`（Android 桥，真实服务）；而 `8.8.8.8:443`、`10.202.11.229:443`、`172.19.0.2:443` 都是 connect OK + recv 超时 → 不能判为真实服务。
5. **可信的横向可行域结论（负向为主）**：本机回环段 6 端口矩阵中只有 `127.0.0.1:3080` 是 open，其余全 refused；`127.0.0.2`、`127.0.0.254`、`172.30.215.113`、`10.202.11.230`（本机 rmnet 地址）、`172.19.0.1` 六个端口**全部 refused** → 这三个网段上不存在敞开的横向服务面。`10.202.11.229`、`172.19.0.2`、`8.8.8.8`、`223.5.5.5` 的「全 open」是出口接管造成的假阳性（见第 6 节）。
6. ICMP 侧另有一条独立通道：非特权 ping socket 可用（`ping_group_range = 0 2147483647`），所以 `ping 8.8.8.8` 通（ttl=108，229 ms）、`ping 223.5.5.5` 通（ttl=49，51.9 ms），而 `ping 192.0.2.1` 与 `ping 10.202.11.229` 100% 丢包 —— 与 TCP 侧的「全 open」形成对照：ICMP 端到端转发，TCP 本地代答。

### 5. 横向可行域矩阵（主件 `reach_matrix.py`）

设计取舍：探测目标不写死，而是**从本机真实路由表推导**（回环段 + 每个有 IPv4 的网段的 .1/.2/.254 + 所有策略表里的 `via` 下一跳 + resolv.conf 里的解析器）；端口取 22/80/443/3000/3080/8080 六个运维/服务常见口；每个探针 0.5 s 超时、16 线程并发。判定码五态：`O` open（握手成功）、`R` refused（ECONNREFUSED，**这是可用的负向证据**）、`T` timeout、`N` no-route（ENETUNREACH/EHOSTUNREACH/ENETDOWN）、`E` 其他 errno。`--selftest` 必须在**本机**自开临时监听端口断言 open、对已关闭端口断言 refused，保证判定逻辑自身可信。

用法（三条命令即可复现全部结论）：

```bash
cd /root/dsh-infinite-gen-5/tests/triad/z5/artifacts
python3 reach_matrix.py --selftest                       # 判定逻辑自检：3 passed, 0 failed
python3 reach_matrix.py --json matrix_z5.json | tee matrix_raw.txt   # 自动发现目标 → 全矩阵
python3 reach_matrix.py --targets 192.0.2.1 --ports 443  # 单点复核（出口接管证据）
```

主件全文（与磁盘文件 `reach_matrix.py` 逐字节一致，可用 `python3 -c "import ast;ast.parse(open('reach_matrix.py').read())"` 校验语法）：

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""reach_matrix.py — Z5 横向可行域矩阵（TCP connect 探测，自包含、只读网络探测）

用法:
  python3 reach_matrix.py --selftest                 # 自检：临时监听端口断言 open / 关闭端口断言 closed
  python3 reach_matrix.py                            # 自动发现候选（本机回环 / 路由网关 / 同网段 / DNS）
  python3 reach_matrix.py --targets 127.0.0.1,10.202.11.229 --ports 22,80,443
  python3 reach_matrix.py --json /tmp/z5_matrix.json  # 落盘结构化结果

判定码:
  O open        TCP 三次握手完成
  R refused     对端回 RST（主机可达，端口关闭）
  T timeout     无任何回包（被丢弃 / 过滤 / 黑洞）
  N no-route    本机无到该目标的可用路由（内核 ENETUNREACH/EHOSTUNREACH）
  E error       其他 errno（原样打印 errno 名）

仅对自有 / 已授权目标使用。探测为 connect() 语义：不发送应用层载荷。
"""
import argparse
import concurrent.futures as cf
import errno
import ipaddress
import json
import socket
import subprocess
import sys
import time

DEFAULT_PORTS = [22, 80, 443, 3000, 3080, 8080]
DEFAULT_TIMEOUT = 0.5
CODE = {"open": "O", "refused": "R", "timeout": "T", "no-route": "N"}


def sh(cmd):
    try:
        p = subprocess.run(cmd, shell=True, capture_output=True, text=True, timeout=10)
        return p.stdout
    except Exception:
        return ""


def local_v4():
    """返回 [(iface, ip, prefixlen)]，来自 `ip -br -4 a`（缺 ip 命令时退化为 hostname -I）。"""
    out, res = sh("ip -br -4 a 2>/dev/null"), []
    if out:
        for line in out.splitlines():
            f = line.split()
            if len(f) >= 3 and "/" in f[2] and f[1] != "DOWN":
                try:
                    iface = f[0].split("@")[0]
                    ip, plen = f[2].split("/")
                    res.append((iface, ipaddress.ip_address(ip), int(plen)))
                except ValueError:
                    continue
        if res:
            return res
    for ip in sh("hostname -I").split():
        try:
            a = ipaddress.ip_address(ip)
            if a.version == 4:
                res.append(("?", a, 32))
        except ValueError:
            continue
    return res


def route_gateways():
    """从所有路由表里取 `default via X` 与 `via X` 的下一跳（Android 策略路由分散在多张表）。"""
    gw, out = [], sh("ip route show table all 2>/dev/null")
    for line in out.splitlines():
        t = line.split()
        if "via" in t:
            try:
                cand = ipaddress.ip_address(t[t.index("via") + 1])
                if cand.version == 4 and str(cand) not in gw:
                    gw.append(str(cand))
            except (ValueError, IndexError):
                pass
    return gw


def resolvers():
    res = []
    try:
        with open("/etc/resolv.conf", encoding="utf-8", errors="replace") as fh:
            for line in fh:
                t = line.split()
                if len(t) >= 2 and t[0] == "nameserver":
                    try:
                        a = ipaddress.ip_address(t[1])
                        if a.version == 4:
                            res.append(str(a))
                    except ValueError:
                        pass
    except OSError:
        pass
    return res


def discover_targets():
    """候选集：回环 + 各网段的 .1/.2/.254 + 路由下一跳 + DNS 解析器（去重保序）。"""
    cands = ["127.0.0.1"]
    ifaces = local_v4()
    for _iface, ip, plen in ifaces:
        net = ipaddress.ip_network(f"{ip}/{plen}", strict=False)
        cands.append(str(ip))
        if net.num_addresses >= 4:
            for host in (1, 2, 254):
                try:
                    a = net.network_address + host
                except ValueError:
                    continue
                if a in net and a != net.network_address and a != net.broadcast_address:
                    cands.append(str(a))
    cands += route_gateways() + resolvers()
    seen, out = set(), []
    for c in cands:
        if c not in seen:
            seen.add(c)
            out.append(c)
    return out, ifaces


def probe(ip, port, timeout):
    t0 = time.perf_counter()
    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    s.settimeout(timeout)
    try:
        s.connect((ip, port))
        return "open", (time.perf_counter() - t0) * 1000.0, ""
    except socket.timeout:
        return "timeout", (time.perf_counter() - t0) * 1000.0, "ETIMEDOUT"
    except ConnectionRefusedError:
        return "refused", (time.perf_counter() - t0) * 1000.0, "ECONNREFUSED"
    except OSError as e:
        name = errno.errorcode.get(e.errno, str(e.errno))
        v = "no-route" if e.errno in (errno.ENETUNREACH, errno.EHOSTUNREACH, errno.ENETDOWN) else "error"
        return v, (time.perf_counter() - t0) * 1000.0, name
    finally:
        try:
            s.close()
        except OSError:
            pass


def run_matrix(targets, ports, timeout, workers):
    rows, t0 = {}, time.perf_counter()
    jobs = [(t, p) for t in targets for p in ports]
    with cf.ThreadPoolExecutor(max_workers=workers) as ex:
        futs = {ex.submit(probe, t, p, timeout): (t, p) for t, p in jobs}
        for fu in cf.as_completed(futs):
            t, p = futs[fu]
            rows.setdefault(t, {})[p] = fu.result()
    return rows, (time.perf_counter() - t0)


def print_matrix(rows, ports, elapsed):
    w = max(15, max((len(t) for t in rows), default=8))
    print(f"{'target':<{w}} " + " ".join(f"{p:>5}" for p in ports) + "   max_ms")
    for t in rows:
        cells, ms = [], 0.0
        for p in ports:
            v, took, _e = rows[t][p]
            cells.append(f"{CODE.get(v, 'E'):>5}")
            ms = max(ms, took)
        print(f"{t:<{w}} " + " ".join(cells) + f"   {ms:7.1f}")
    print(f"\n矩阵规模: {len(rows)} 目标 x {len(ports)} 端口 = {len(rows) * len(ports)} 次 TCP connect"

def selftest():
    """断言三条路径：临时监听端口=open、已关闭端口=closed(RST)、黑洞地址=timeout/no-route。"""
    ok, fails = [], []

    def check(name, cond, detail):
        (ok if cond else fails).append(f"{'PASS' if cond else 'FAIL'}  {name}: {detail}")

    srv = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    srv.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    srv.bind(("127.0.0.1", 0))
    srv.listen(4)
    live_port = srv.getsockname()[1]
    v, ms, err = probe("127.0.0.1", live_port, DEFAULT_TIMEOUT)
    check("临时监听端口->open", v == "open", f"127.0.0.1:{live_port} -> {v} ({err or 'handshake ok'}, {ms:.1f}ms)")
    srv.close()

    tmp = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    tmp.bind(("127.0.0.1", 0))
    dead_port = tmp.getsockname()[1]
    tmp.close()
    v, ms, err = probe("127.0.0.1", dead_port, DEFAULT_TIMEOUT)
    check("关闭端口->refused", v in ("refused",), f"127.0.0.1:{dead_port} -> {v} ({err}, {ms:.1f}ms)")

    live2 = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    live2.bind(("127.0.0.1", 0))
    live2.listen(4)
    p2 = live2.getsockname()[1]
    matrix, elapsed = run_matrix(["127.0.0.1"], [p2, dead_port], DEFAULT_TIMEOUT, 2)
    c_open = matrix["127.0.0.1"][p2][0]
    c_dead = matrix["127.0.0.1"][dead_port][0]
    live2.close()
    check("run_matrix 与 probe 一致", c_open == "open" and c_dead == "refused",
          f"matrix[listen]={c_open}, matrix[closed]={c_dead}, {elapsed * 1000:.1f}ms")

    # 出网侧的「黑洞地址」不是断言项：若环境存在透明 TCP 拦截，不可路由地址也会被判 open。
    v, ms, err = probe("192.0.2.1", 443, DEFAULT_TIMEOUT)   # TEST-NET-1，RFC5737 保留，不可路由
    note = "提示：非本机地址出现 open 说明出口存在透明 TCP 拦截（见 z5.md 拦截验证节），非本脚本判定错误"
    print(f"NOTE  黑洞地址观测(仅记录, 不断言): 192.0.2.1:443 -> {v} ({err or 'handshake ok'}, {ms:.1f}ms)  {note}")

    for line in ok + fails:
        print(line)
    print(f"\nselftest: {len(ok)} passed, {len(fails)} failed")
    return 0 if not fails else 1
```

### 6. 出口接管取证（把「全 open」的假阳性钉死）

**取证 A —— 不可路由地址也能握手成功。** `192.0.2.1`（RFC 5737 TEST-NET-1，不可路由）、`198.51.100.77`、`203.0.113.9` 与随机高位端口全部在几毫秒内 connect 成功：

**取证 C —— 路由归因**（`ip route get`）：到 `192.0.2.1`、`8.8.8.8`、`223.5.5.5`、`10.202.11.229` 全部命中 `dev tun0 table 1058 src 172.19.0.1 uid 10527`；只有回环段与两个本机地址命中 `table local`。

**取证 E —— 应用层对照（同一个 `connect` 判定，加一次 `recv` 就分开了）**：

| 目标 | connect | 应用层回包 |
|---|---|---|
| `127.0.0.1:3080` | OK 4 ms | `HTTP/1.1 401 Unauthorize…` ← 真实服务 |

| `192.0.2.1:443` | OK | `recv` → TimeoutError（1515 ms） |
| `10.202.11.229:443` | OK | `recv` → TimeoutError（1507 ms） |
| `172.19.0.2:443` | OK | `recv` → TimeoutError（1513 ms） |

**取证 F —— ICMP 对照**：`ping 8.8.8.8` → `64 bytes … ttl=108 time=229 ms`、`ping 223.5.5.5` → `ttl=49 time=51.9 ms`（端到端通）；`ping 192.0.2.1` 与 `ping 10.202.11.229` → `100% packet loss`。ICMP 被端到端转发，TCP 却被本地代答 —— 两者机理不同，不能互相代替作为「可达」证据。

结论（已证实）：**非本机目标上的 TCP connect 成功，是本机出口侧（tun0 对端用户态代理内核，tun2socks 语义；监听面 `*:7890`）先回 ACK 造成的**，而不是目标在监听。推论：本环境下横向扫描若只用 TCP connect，会把整张网段判成「全开放」；正确做法是加一层应用层回包（`recv`/HTTP/TLS）判据，或只采信 `refused` 与 `local` 表路径上的结果。

### 7. 能力面（`CapEff` 逐位解释 + 能做/不能做清单）

`CapEff = 0x0000000000000000` —— 64 位里 **置位数为 0**。按能力位编号核对：`CAP_NET_ADMIN` 是第 12 位、`CAP_NET_RAW` 第 13 位、`CAP_SYS_ADMIN` 第 21 位，三者均为 0；`Current: =`、`Bounding set =`、`Ambient set =` 三行皆空，`Current IAB` 前缀全是 `!`。这不是「以为自己是 root 但少几个能力」，而是**一个能力都没有**。

**能做（本区域内可继续依赖的能力）**：读路由/策略表/连接表；向回环与 `local` 表路径发起 TCP connect（结果可信）；发起非特权 ICMP（`ping`，走 ping socket 而非 raw socket）；走既有出口的 HTTP/HTTPS 请求；自开本地临时监听并做自检。

**不能做（能力缺失导致，非工具缺失）**：增删防火墙规则 / 读规则集；改路由表、加 IP、建/删接口；原始套接字与抓包（tcpdump 类动作必然失败）；改 `net.ipv4.*` 等 sysctl；二层帧收发与 ARP 操纵。

**替代路径**：①本机回环探测（已用，可信）；②既有的 tun0 通道作为「已授权跳板」—— 对端 `172.19.0.2` 已在连接表中，应用层可用；③规则类动作需要宿主 Android 侧执行 —— 容器内 `CapEff=0` 不等于宿主无权限，但那属于宿主层动作，需在宿主层另行授权后取证据，本容器内无法代做。
