# 暴力破解

## 概述

暴力破解（Brute Force）指通过枚举所有可能的输入值来获取正确凭证、密钥或隐藏信息的方法。在 CTF 中常出现在登录接口爆破、验证码识别、哈希碰撞、验证码破解等场景。高效的字典构造和合理的爆破策略可大幅提升成功率。

## 常见攻击手法

### 1. 常规暴力破解

- **字典攻击**：使用常见用户名/密码字典进行登录爆破。常用字典包括 `rockyou.txt`、`SecLists` 中的用户名和密码列表。
- **参数枚举**：对隐藏参数、目录路径、ID 值等进行枚举。常见参数名包括 `id`、`file`、`page`、`debug`、`source`。
- **验证码绕过**：验证码未刷新（可重复使用）、验证码在客户端生成、验证码过于简单、验证码与 session 未绑定等情况。
- **速率限制绕过**：
  - 使用 `X-Forwarded-For` 头伪造来源 IP
  - 慢速爆破（降低请求频率）
  - 分布式爆破（多 IP 源）
- **基于时间的枚举**：通过响应时间差异判断用户名是否存在（如登录失败比用户不存在耗时更长）。

### 2. 哈希生日攻击

- **生日悖论**：在哈希碰撞中找到两个不同输入产生相同哈希值。对于 n 位输出，约需 `2^(n/2)` 次尝试即可找到碰撞。
- **MD5 碰撞**：已知 MD5 碰撞的快速构造方法（如 `fastcoll` 工具）。CTF 中可能出现要求找到两个不同字符串使 MD5 相同的题目。
- **弱哈希算法**：CRC32、MD2、MD4 等弱哈希在特定场景下可被快速碰撞。
- **哈希长度扩展攻击**：对于 `H(secret || message)` 形式的哈希（如 MD5、SHA1、SHA256），可在不知道 secret 的情况下构造合法的 `H(secret || message || padding || append)`。

### 3. 验证码识别

- **OCR 识别**：使用 Tesseract 等 OCR 引擎识别简单验证码。
- **机器学习**：使用 CNN 模型识别更复杂的验证码。常用框架有 TensorFlow、PyTorch。
- **验证码复用**：分析验证码是否与 session 绑定，若未绑定则一个验证码可用多次。
- **验证码逻辑绕过**：
  - 验证码在客户端 JS 中生成和校验
  - 验证码校验与登录请求分离，可分别发送
  - 移除验证码参数后请求正常处理
  - 验证码仅为前端展示，后端不做校验

### 4. 基于响应差异的用户枚举

- 对比不同用户名登录时的响应内容、状态码或响应时间：
  - "用户不存在" vs "密码错误" 的不同提示
  - 不同用户名的状态码不同（200 vs 403）
  - 存在/不存在用户的响应大小差异

### 5. JWT/Token 暴力破解

- **弱签名密钥**：使用 `hashcat` 或 `john` 对 JWT 的 HMAC 签名密钥进行爆破。
- **可预测的随机数**：分析 Token 生成算法中的时间戳或序列号，预测后续 Token 值。

## 防御建议

- 限制登录失败次数并加入锁定/延迟机制
- 验证码绑定 session 且一次性使用
- 登录失败返回统一提示，不区分用户名是否存在
- 使用 HMAC-SHA256 等强哈希算法
- API 接口实施速率限制

## CTF 中的常见考点

- 针对登录页面的弱密码爆破
- MD5 碰撞构造（"0e" 特殊比较）
- 哈希长度扩展攻击绕过认证
- 验证码识别或逻辑绕过
- 爆破隐藏路径或备份文件
