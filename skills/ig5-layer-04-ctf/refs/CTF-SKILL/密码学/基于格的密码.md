# 格密码（Lattice）

## 概述

格（Lattice）是 $n$ 维欧氏空间中具有周期性结构的离散加法子群。格密码学是后量子密码学的重要分支，其安全性基于格上的困难问题，如最短向量问题（SVP）和最近向量问题（CVP）。近二十年来，格在密码分析中也扮演着重要角色，用于攻击 RSA、DSA、背包密码等系统。CTF 中常见的格题目包括使用 LLL 算法求解各类密码学问题。

**格的数学定义**：给定 $n$ 个线性无关的基向量 $b_1, ..., b_n \in \mathbb{R}^m$，格 $L = \{\sum a_i b_i \mid a_i \in \mathbb{Z}\}$。

## 常见问题

### SVP 问题（Shortest Vector Problem）
在格中寻找最短的非零向量。在 CTF 中最常见的格问题，通常通过 LLL 或 BKZ 算法求解。

### CVP 问题（Closest Vector Problem）
给定一个不在格中的目标向量，寻找格中离它最近的向量。可通过 Babai 最近平面算法求解，或归约为 SVP。

### NTRU 密码
NTRU（NTRUEncrypt）是一种基于格的公钥加密算法，被选入 NIST 后量子密码标准化。

**算法原理**：
- 在截断多项式环 $R = \mathbb{Z}[X]/(X^N - 1)$ 上操作
- 私钥：小系数多项式 $(f, g)$
- 公钥：$h = p \times g \times f^{-1} \bmod q$
- 加密：$c \equiv r \times h + m \pmod{q}$
- 解密：$a = f \times c \bmod q$，再恢复 $m$

**NTRU 攻击**：
- **格攻击**：构造包含 $h$ 的格，利用 SVP 恢复私钥
- **混合攻击**：对小参数 NTRU 有效
- **选择密文攻击**：利用解密失败信息

## 常见攻击手法

### LLL 算法（Lenstra-Lenstra-Lovász）
格基约简算法，将"坏的"格基约简为"好的"近似正交基。是 CTF 中最常用的格算法，可应用于：
- 背包密码破解
- 隐藏数问题（Hidden Number Problem）
- 近似 GCD 问题
- DSA/ECDSA 非随机数恢复
- Coppersmith 方法

### BKZ 算法（Block Korkin-Zolotarev）
LLL 的改进版本，通过分块处理获得更好的约简质量（但速度更慢）。块大小参数 $\beta$ 控制了质量-速度权衡。

### 隐写数问题（Hidden Number Problem, HNP）
给定 $n$ 组 $(t_i, a_i)$ 满足 $a_i \equiv \alpha - t_i \beta \pmod{p}$ 且 $|\beta| < B$，利用格恢复 $\beta$。常用于 DSA 的非随机数攻击。

## 防御建议

- 密码设计中不使用线性结构
- NTRU 参数需满足安全要求（N ≥ 509）
- 后量子密码标准化方案使用经过验证的参数

## 示例思路

```python
# LLL 求解背包问题
from sage.all import *

# 构造嵌入格
b = [..., ..., ...]  # 公钥向量
n = len(b)
M = Matrix(ZZ, n+1, n+1)
for i in range(n):
    M[i,i] = 1
    M[i,n] = b[i]
M[n,n] = -1  # 目标值

L = M.LLL()
# 检查 L 的行向量，找到系数仅为 0/1 的向量
for row in L:
    if all(abs(x) <= 1 for x in row):
                    print(f"Possible solution: {row}")
```
