# 数学工具（Math）

## 概述

密码学深深植根于数论和抽象代数。CTF 密码学题目中经常涉及各种数学原理和算法。掌握这些数学工具是解决复杂密码学问题的关键。本专题涵盖 Costas 阵列、欧拉降幂、BSGS 和相关数论概念。

## 常见数学概念

### Costas 阵列
一种 $n \times n$ 的排列矩阵，其中任意两个 1 的位移向量不同。在声纳和通信系统中用于跳频设计。在 CTF 中偶有出现作为编码谜题。

**性质**：每行每列恰好有一个 1，且任意两个 1 的向量差 $(dx, dy)$ 在整个矩阵中唯一。

### 欧拉降幂（Euler's Theorem / Power Reduction）
欧拉定理：若 $\gcd(a, m) = 1$，则 $a^{\phi(m)} \equiv 1 \pmod{m}$。

**降幂公式**：
$$a^b \bmod m = \begin{cases} a^{b \bmod \phi(m)} \bmod m, & \gcd(a, m) = 1 \\ a^{b \bmod \phi(m) + \phi(m)} \bmod m, & b \geq \phi(m) \end{cases}$$

适用于指数 $b$ 极大（如 $b > 10^{1000000}$）时快速取模。

### BSGS（Baby-Step Giant-Step）
Shanks 算法，用于离散对数求解。时间复杂度 $O(\sqrt{n})$。详见 discrete-log 专题。

### 同余（Congruence）
基本数论关系：$a \equiv b \pmod{m}$ 表示 $m \mid (a - b)$。

**核心运算**：
- 线性同余：$ax \equiv b \pmod{m}$
- 同余方程组：中国剩余定理（CRT）
- 乘法逆元：$ax \equiv 1 \pmod{m}$，$x = a^{-1} \bmod m$

### 扩展欧几里得算法（Extended Euclidean Algorithm）
求解 $ax + by = \gcd(a, b)$ 的整数解 $(x, y)$。

### 中国剩余定理（Chinese Remainder Theorem, CRT）
求解同余方程组 $x \equiv a_i \pmod{m_i}$，其中 $m_i$ 两两互素。

## 相关工具

- **`gmpy2`**：`powmod`、`invert`、`gcdext`
- **`sage`**：数论全套函数
- **`sympy`**：`ntheory` 模块
- **`pycryptodome.Util.number`**：`inverse`、`GCD`

## 防御建议

数学工具本身是分析工具，不涉及防御。密码系统的安全性依赖于数学难题的难度，而非数学工具的保密。

## 示例思路

```python
# 欧拉降幂（指数太大时）
from gmpy2 import powmod
phi = 100  # phi(m)

# b 极其巨大时的 b mod phi(m)
b_big = 10**1000000
exp = b_big % phi  # 降幂
result = powmod(a, exp, m)

# 中国剩余定理
from sympy.ntheory.modular import crt
moduli = [3, 5, 7]
remainders = [2, 3, 2]  # x ≡ 2 mod 3, x ≡ 3 mod 5, x ≡ 2 mod 7
x = crt(moduli, remainders)[0]
print(x)  # 23
```
