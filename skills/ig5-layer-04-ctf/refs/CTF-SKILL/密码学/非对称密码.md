# 非对称密码（其他）（Asymmetric Cryptography）

## 概述

公钥密码学中除了 RSA、ElGamal、ECC 等主流算法外，还有一些其他重要的非对称加密系统。它们在 CTF 竞赛中时有出现，其中背包密码系统和 Paillier 加密是最常见的两种。

## 常见种类

### 背包密码（Knapsack / Merkle-Hellman）

Merkle-Hellman 背包密码是基于子集和问题（NP-完全）的公钥加密系统。通过将超递增序列转换为一般背包向量作为公钥。

**算法原理**：
- 私钥：超递增序列 $(a_1, a_2, ..., a_n)$，乘数 $w$ 和模数 $m$
- 公钥：$b_i = w \times a_i \bmod m$
- 加密：将消息分为 $n$ 位二进制串，$c = \sum m_i \times b_i$
- 解密：$c' = w^{-1} \times c \bmod m$，再求解超递增背包

**攻击手法**：
- **Shamir 攻击**：利用格基约简（LLL）破解 Merkle-Hellman 背包
- **低密度攻击**：当背包密度 $d < 0.9408$ 时可用 LLL 破解
- **格攻击**：构造特定格，在格中寻找短向量恢复明文

### Paillier 加密

Paillier 加密是一种同态加密算法，基于复合剩余类问题。

**算法原理**：
- $n = pq$，$\lambda = \text{lcm}(p-1, q-1)$
- 公钥：$n$
- 私钥：$\lambda$
- 加密：$c = g^m \times r^n \bmod n^2$（$r$ 随机）
- 解密：$m = L(c^\lambda \bmod n^2) \times \mu \bmod n$

**同态性质**：
- 加法同态：$E(m_1) \times E(m_2) \equiv E(m_1 + m_2) \pmod{n^2}$
- 标量乘法：$E(m)^k \equiv E(m \times k) \pmod{n^2}$

**攻击手法**：
- 若 $n$ 可分解，整个系统被攻破
- 选择密文攻击：利用同态性质构造相关密文
- 参数选择不当：$g$ 的选择影响安全性

## 相关工具

- **`sage`**：格基约简（LLL）、数论函数
- **`fpylll`**：Python 格运算库
- **`phe`**：Python Paillier 同态加密库

## 防御建议

- 背包密码已不安全，不应使用
- Paillier 需要足够大的 $n$（≥2048 位）
- 标准实现要防范选择密文攻击

## 示例思路

```python
# 背包密码格攻击
from sage.all import *

c = 0x...  # 背包密文
b = [...]  # 公钥向量
n = len(b)
# 构造格
M = Matrix(ZZ, n+1, n+1)
for i in range(n):
    M[i,i] = 1
    M[i,n] = b[i]
M[n,0:n] = [1]*n
M[n,n] = -c
# LLL 约简
L = M.LLL()
# 检查短向量恢复明文
```
