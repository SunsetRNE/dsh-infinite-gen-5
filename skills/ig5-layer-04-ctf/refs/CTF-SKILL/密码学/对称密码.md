# 对称加密（Symmetric Encryption）

## 概述

对称加密指加密和解密使用相同密钥的加密算法。对称加密分为流密码和块密码两大类，是现代密码学的基础。CTF 中常见的对称加密题目涉及 AES、DES 等标准算法，以及 ECB/CBC 等操作模式相关的漏洞利用。

## 常见种类

### AES 密码（Advanced Encryption Standard）
AES 是美国 NIST 在 2001 年选定的对称加密标准，前身为 Rijndael 算法。

**参数**：块大小 128 位，密钥长度 128/192/256 位，轮数 10/12/14。
**内部结构**：SubBytes → ShiftRows → MixColumns → AddRoundKey（每轮）。

AES 的攻击和漏洞主要在操作模式层面（见 AES 专题）。

### DES 密码（Data Encryption Standard）
DES 曾是 NIST 标准（1977-2001），现已被 AES 替代。56 位密钥，64 位块大小，16 轮 Feistel 网络。

**弱点**：56 位密钥可被暴力破解，出现差分/线性分析攻击。

**3DES（Triple DES）**：用两个或三个 DES 密钥执行三次 DES 操作：$C = E_{k3}(D_{k2}(E_{k1}(P)))$。有效密钥长度 112 或 168 位，但速度较慢。

## 常见攻击手法

### 暴力破解
针对 DES 等短密钥算法（56 位），现代硬件可在短时间内遍历全部密钥空间。

### 侧信道攻击
分析加密过程的物理泄漏（时间、功耗、电磁辐射）恢复密钥。

### 已知明文攻击
已知部分明文-密文对，利用块密码的数学性质推导密钥。

### 错误注入攻击
向加密设备注入错误，通过比较正确和错误输出分析密钥。

### 模式攻击
针对不当使用块密码操作模式（ECB、CBC、OFB、CFB、CTR、GCM 等）的攻击。

## 相关工具

- **`pycryptodome`**：`Crypto.Cipher.AES`、`DES`、`DES3`
- **`openssl enc`**：命令行加密解密
- **`hashcat`**：GPU 加速破解

## 防御建议

- 使用 AES-256 作为首选算法
- 使用认证加密模式（GCM、CCM、ChaCha20-Poly1305）
- 使用适当的密钥长度（≥128 位）
- 密钥管理安全，不硬编码密钥
- 定期更新加密方案

## 示例思路

```python
from Crypto.Cipher import AES
from Crypto.Util.Padding import pad, unpad

key = b'Sixteen byte key'
cipher = AES.new(key, AES.MODE_CBC, iv=b'Sixteen byte iv.')
ct = cipher.encrypt(pad(b'Hello World', 16))
# 解密
cipher2 = AES.new(key, AES.MODE_CBC, iv=b'Sixteen byte iv.')
pt = unpad(cipher2.decrypt(ct), 16)
print(pt)  # b'Hello World'
```

对称加密安全的关键在于密钥保密和操作模式正确使用，而不是算法选择。
