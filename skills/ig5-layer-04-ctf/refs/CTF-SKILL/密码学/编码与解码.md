# 编码（Encoding）

## 概述

编码是将信息从一种形式转换为另一种形式的过程，是密码学中最基础的技能点。CTF 竞赛中经常出现各种编码的混合使用，选手需要掌握常见编码的特征和转换方法。编码不同于加密，编码不涉及密钥，只是数据表示形式的变换。

## 常见编码类型

### 电话拨号编码
电话键盘上的字母对应数字（2-9），如 `2=ABC, 3=DEF, 4=GHI, 5=JKL, 6=MNO, 7=PQRS, 8=TUV, 9=WXYZ`。常见形式为数字序列需要映射回字母。

### Morse 编码
由点（`.`）和划（`-`）组成，字符间用空格分隔，单词间用 `/` 分隔。特征：只有 `.`、`-` 和空格。在线工具或 Python 的 `morse` 库可解码。

### 敲击码（Tap Code）
5×5 棋盘密码，用两个数字表示一个字母（行和列），常用于囚犯通讯。例如 `2,3` 表示第2行第3列的字母。

### 曼彻斯特编码（Manchester Code）
用跳变表示 0 和 1 的编码方式。在无线通信和网络协议中常见。低到高跳变为 0，高到低跳变为 1（或相反，取决于规范）。

### 格雷编码（Gray Code）
相邻两个数只有一个二进制位不同的编码方式，常用于传感器和通信中。

### 字母表编码
`A=1, B=2, ..., Z=26` 或 `A=0, B=1, ..., Z=25` 的数字字母映射。

### ASCII 编码
将字符转换为 ASCII 码值（0-127）。常见形式为十进制、十六进制或二进制表示的 ASCII 数值序列。

### Base 编码
- **Base16**：即十六进制
- **Base32**：使用 A-Z 和 2-7，每 5 位编码
- **Base64**：使用 A-Z、a-z、0-9、+、/，每 6 位编码，末尾 `=` 填充
- **Base58**：类似 Base64 但去掉了易混淆字符
- **Base85/Ascii85**：每 4 字节编码为 5 个 ASCII 字符

### 霍夫曼编码（Huffman Coding）
基于字符频率构建最优前缀码的压缩编码。需要频率表才能解码。

### XXencoding
类似 Base64 的早期编码方式，使用 `+-` 到 `z` 的字符集。

### URL 编码
`%` 后跟两位十六进制表示特殊字符，如空格编码为 `%20`。

### Unicode 编码
- `\uXXXX` 形式（Python/Java 转义）
- UTF-8、UTF-16、UTF-32 编码
- 零宽字符编码

### HTML 实体编码
`&xxx;` 或 `&#DDD;` 或 `&#xHH;` 形式表示 HTML 实体。

### 进制转换
常见于二进制、八进制、十进制、十六进制之间的相互转换。`010` 开头的数字可能是八进制，`0x` 开头是十六进制。

### Brainfuck 编码
Brainfuck 是一种极简的编程语言，仅由 `><+-.,[]` 八个字符组成。在 CTF 中常作为编码后的输出形式，需要用 BF 解释器执行。

## 常见攻击手法

1. **识别特征**：观察字符集判断编码类型（如全为 A-Z2-7 则为 Base32，包含 `+/=` 则为 Base64）
2. **多层嵌套解码**：题目可能嵌套多种编码，需要一层层解码
3. **频率分析辅助**：对于未知编码，统计字符频率辅助判断
4. **摩斯码变种**：注意空格和分隔符的变化

## 相关工具

- **CyberChef**：最强大的编码解码工具
- **Python `base64`/`binascii`**：标准库编解码
- **`morse` / `morse3`**：摩斯码库
- **`pwntools`**：`unhex()`、`b64d()` 等便捷函数
- **在线工具**：rapidtables.com、md5decrypt.net

## 防御建议

编码不是安全机制，不应使用编码替代加密。敏感数据必须使用强加密算法（如 AES）而非简单的 Base64 等方式保护。

## 示例思路

一段密文 `5A41434F4445524841434B`，特征为 0-9 和 A-F，长度为偶数 → Base16（Hex）解码得 `ZACODERHACK`。若密文包含大量 `%` 符号如 `%48%65%6C%6C%6F`，则先 URL 解码再 Hex 解码。
