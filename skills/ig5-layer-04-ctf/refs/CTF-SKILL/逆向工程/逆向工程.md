# REVERSE 技能树 - CTF 逆向工程

## 概述

逆向工程（Reverse Engineering）是 CTF 中最具挑战性的类别之一，要求选手从二进制程序、加密数据或混淆代码中恢复出原本的逻辑结构、算法或隐藏信息。逆向工程不仅是安全研究的基础能力，也是理解现代软件保护机制、发现漏洞的必经之路。

本知识库将 REVERSE 技能划分为 14 大子类别，覆盖从基础分析到高级对抗、从 PC 平台到移动平台、从常见语言到特定算法的各类方向。

---

## 子类别总览

### 1. [逆向分析基础](逆向分析基础.md)
涵盖逆向工程的入门技能，包括常用工具使用（IDA Pro、Ghidra、GDB 等）、静态分析技巧、动态调试方法、程序补丁制作以及各类逆向分析的基础知识。

### 2. [低级语言分析](低级语言分析.md)
涉及各类低级语言的逆向分析，包括 Intel x86/x64 汇编、ARM/Thumb 汇编、MIPS 汇编、SMALI（Android Bytecode）、MSIL（.NET IL）、Python 字节码以及其他低级中间表示的分析技术。

### 3. [高级语言逆向](高级语言逆向.md)
涵盖常见高级语言编译产物的逆向分析技术，包括 C/C++、C#、Python（编译后）、Java、Golang、Rust、Lua、AutoIt 等语言生成的可执行文件或中间代码的识别与还原。

### 4. [可执行文件逆向](可执行文件逆向.md)
针对不同可执行文件格式的逆向技术，包括 DOS (COM/EXE)、PE (Windows)、ELF (Linux)、APK (Android)、Mach-O (macOS) 以及其他可执行文件格式的分析方法论。

### 5. [静态分析对抗](静态分析对抗.md)
针对静态分析的对抗技术与绕过方法，包括可执行式/不可执行式花指令、代码混淆、OLLVM 混淆、虚拟化保护 (VM)、API 动态调用、代码自解密、加壳与脱壳以及其他静态分析对抗技术。

### 6. [动态调试对抗](动态调试对抗.md)
针对动态调试的各种检测与绕过技术，包括基于内存标志、API 调用、进程跟踪、TLS 回调、时间差、调试器特征、异常处理、断点检测、沙箱环境等各类反调试手法的分析与绕过。

### 7. [代码注入](代码注入.md)
各类代码注入技术，包括远程线程注入、DLL 注入、IAT Hook、Inline Hook、Process Hollowing（进程镂空）、Message Hook、APC 注入、DLL 反射加载、SSDT Hook 以及其他 Windows/Linux 平台代码注入技术。

### 8. [异常处理](异常处理.md)
Windows 平台的各种异常处理机制分析，包括 VEH（向量化异常处理）、SEH（结构化异常处理）、UEF（未处理异常过滤器）、VCH（向量化异常处理继续处理）以及其他基于异常的代码执行与反调试技术。

### 9. [GUI 程序逆向](GUI程序逆向.md)
针对图形用户界面程序的逆向分析，涵盖 MFC（Microsoft Foundation Classes）框架逆向、Qt 框架逆向以及其他 GUI 框架（WinForms、WPF、GTK+ 等）的分析技术。

### 10. [Python 程序逆向](Python程序逆向.md)
专门针对 Python 程序的逆向分析技术，包括 PyInstaller 打包程序的解包、PYC 字节码反编译、PYD 二进制模块逆向、Nuitka 编译程序逆向以及其他 Python 打包/混淆工具的还原方法。

### 11. [Android 逆向](Android程序逆向.md)
Android 平台的逆向分析技术，包括 DEX 字节码逆向、Native（JNI/NDK）层逆向、资源文件分析、AndroidManifest 分析、Root 检测绕过、APK 重打包等 Android 应用逆向方法论。

### 12. [Golang 逆向](Golang程序逆向.md)
针对 Go 语言编译程序的逆向技术，重点是 Go 程序的符号恢复（函数签名、类型信息、interface 识别）、运行时结构识别（goroutine、channel、map）、Go 特有的调用约定分析等。

### 13. [Rust 逆向](Rust程序逆向.md)
针对 Rust 语言编译程序的逆向技术，包括 Rust 程序的符号恢复、所有权系统相关的结构识别（Box/Rc/Arc/Option/Result）、trait/vtable 分析、恐慌（panic）机制、Rust 调用约定等。

### 14. [逆向中的密码学](加密与解密.md)
逆向分析中常见的加密与编码算法识别、还原和破解技术，包括 XOR/ROT/栅栏/仿射等古典密码、BASE 系列编码、TEA/XTEA/XXTEA 系列、BlowFish/ChaCha20/Salsa20 流密码、LCG/PRESENT/CRC32、RSA/RC4/HASH、DES/3DES/AES/SM4 等现代密码算法，以及方程组求解、矩阵运算等数学计算在逆向中的应用。

## 常用工具

- **IDA Pro + Hex-Rays** - 静态反汇编 + 反编译
- **Ghidra** - 开源反编译框架
- **x64dbg / OllyDbg / GDB** - 动态调试
- **PE-Bear / CFF Explorer / 010 Editor** - 可执行文件结构分析
- **dnSpy** - .NET 反编译
- **uncompyle6 / pycdc / pyinstxtractor** - Python 反编译
- **jadx / JEB** - Android 逆向
- **CyberChef** - 编码/解码/加密/解密在线工具
- **CAPSTONE / KEYSTONE / UNICORN** - 多架构汇编/反汇编/模拟框架
- **DiE (Detect it Easy) / ExeInfo** - 查壳工具
