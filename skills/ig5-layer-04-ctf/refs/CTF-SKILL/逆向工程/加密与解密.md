# 逆向中的密码学 (Crypto in Reverse)

## 概述

在 CTF 逆向题目中，加密和解密算法无处不在。开发者为了保护关键数据（flag、许可密钥、用户密码）通常会使用各种加密算法对数据进行保护。逆向工程师需要识别出程序中使用的加密/编码算法，理解其参数，并编写对应的解密/解码程序以恢复原始数据。

逆向中的密码学分析涉及从简单的 XOR 操作到复杂的 RSA/AES 算法识别。分析的难点在于算法可能被魔改、参数被隐藏、或通过代码混淆进行保护。

---

## 常见分析手法

### 1. 算法魔改 (Modified Algorithm)
许多 CTF 题目会对标准加密算法进行修改，使其与标准实现略有不同:

- **常量修改**: AES 的 S-box 被替换、TEA 的 DELTA 值被改变、标准 IV 被修改。
- **轮数修改**: AES 的轮数（标准 10/12/14 轮）被改变。
- **操作顺序修改**: 加密步骤的顺序被调换（如 CBC 模式中 IV 与密文异或的顺序反转）。
- **自定义 Feistel 网络**: 使用标准算法的结构但替换了内部的 F 函数。
- **识别方法**: 与已知算法的常量/结构进行比对，找出差异点并调整解密代码。

### 2. XOR 运算
XOR（异或）是最基本也最常见的加密操作，在 CTF 中几乎无处不在。

**单字节 XOR**:
- 密钥为 1 字节。
- 爆破 0-255，寻找可读的明文（或通过频率分析）。

**多字节 XOR (重复密钥)**:
- 密钥长度 N 字节。
- **破解方法**:
  1. 猜测密钥长度（Hamming Distance / Kasiski 方法）。
  2. 按密钥长度将密文分组。
  3. 对每组进行单字节 XOR 频率分析（或已知明文攻击）。
- 参考工具: `xortool`、`xorBruteForcer`。

**流式 XOR (One-time Pad 变种)**:
- 密钥由伪随机数生成器（PRNG）产生。
- 需要逆向出 PRNG 算法并恢复种子/状态。

**XOR 变形**:
- `XOR + ADD` 混合: `(data[i] + key[i]) ^ key[i]` 等。
- `ROT(XOR(...))`: 循环移位与 XOR 的组合操作。
- 多轮 XOR: `data = data ^ key1; data = data ^ key2;`。

### 3. ROT 系列 (Caesar Cipher)
ROT（Rotation）是经典的代换密码。

- **ROT13**: 英文字母循环移位 13 位，常用于隐藏文本（对大小写敏感）。
- **ROT47**: ASCII 码 33-126 范围内的循环移位。
- **自定义 ROT**: 任意偏移量的字母/ASCII 移位。
- **识别**: 统计字母频率分布，确认是简单的移位而非代换。
- **工具**: `tr` 命令、`rot13`、Python `str.maketrans`。

### 4. 栅栏密码 (Rail Fence Cipher)
栅栏密码是一种简单的转置密码。

- 将明文按锯齿形（Zigzag）排列在"栅栏"行上，然后按行读取。
- 解密需要知道栅栏的"深度"（行数）。
- 常见变种: W 型栅栏、螺旋矩阵转置等。

### 5. 仿射密码 (Affine Cipher)
仿射密码是单表替换密码的泛化:
```
E(x) = (a * x + b) mod m
D(x) = a^(-1) * (x - b) mod m
```
- `a` 必须与 `m` 互质（gcd(a, m) = 1）。
- 密钥空间小（对于英文字母只有 312 种可能性），可暴力破解。
- 逆向中常见于古典密码类的 CTF 题目。

### 6. BASE 编码 (Base64/Base32/Base16)
BASE 编码不是加密算法（无密钥），但常被用于隐藏数据。

**Base64 特征**:
- 字母表: `A-Za-z0-9+/`。
- 结尾可能包含 `=`（填充）。
- 每 3 字节输入 -> 4 字符输出。
- 常见变种: URL-safe Base64（`-` 代替 `+`，`_` 代替 `/`）、自定义字母表。

**Base32**:
- 字母表: `A-Z2-7`。
- 每 5 字节输入 -> 8 字符输出。

**Base16** = Hex。

**分析**:
- 逆向中 BASE 编码通常与其他加密操作组合（先加密 -> 再 BASE 编码）。
- 自定义字母表时，需要动态提取字母表字符串。

### 7. TEA / XTEA / XXTEA 系列
Tiny Encryption Algorithm 系列是简洁高效的对称分组密码。

**TEA**:
- 分组: 64 位，密钥: 128 位。
- 循环: 32 轮（或自定义轮数）。
- 特征常量: `DELTA = 0x9E3779B9`（黄金分割分数）。
- 解密时需要注意轮数是否与标准一致。

**XTEA**:
- TEA 的改进版，修复了 TEA 的密钥等效性问题。
- 特征常量: 同 TEA（`DELTA = 0x9E3779B9`）。
- 密钥调度更复杂，但识别标准是 DELTA 常量和 64 位分组操作模式。

**XXTEA**:
- 支持可变长度分组的 TEA 变种（不是固定 64 位）。
- 内部包含多个 TEA 轮次。
- 识别较困难，但 DELTA 常量也是关键线索。

**逆向要点**:
- 搜索 0x9E3779B9（或低 32 位）在代码中出现的引用。
- 常见的识别特征: 多个异或 + 移位操作（左移 4/右移 5 加 key 索引）。
- 确认轮数和密钥长度后，可实现标准的加解密。

### 8. BlowFish
Blowfish 是一种对称分组密码（64 位分组，可变密钥长度 32-448 位）。

**特征**:
- 使用 S-box 和 P-array（P1-P18）。
- **P-array 初始化常量**: `0x243F6A88`、`0x85A308D3` 等（π 的小数部分）。
- 这组常量是识别 Blowfish 的最强线索。

**逆向要点**:
- 在 IDA 中搜索 `0x243F6A88` 等常量可快速定位。
- 关注密钥扩展（Key Expansion）阶段的代码。
- 标准 16 轮 Feistel 网络结构。

### 9. ChaCha20 / Salsa20
ChaCha20 和 Salsa20 是流密码，广泛用于现代协议（TLS、SSH、WireGuard）。

**Salsa20 初始矩阵**:
```
"expand 32-byte k" (ASCII: 0x61707865, 0x3320646e, 0x79622d32, 0x6b206574)
```
- + 密钥 (32 字节) + 随机数 (8 字节) + 计数器 (8 字节) = 64 字节状态。

**ChaCha20 变种**:
- 使用不同的初始常量（"expand 32-byte k" 相同但布局不同）。
- 轮函数中使用的移位量不同（Salsa20 是 7/9/13/18，ChaCha20 是 16/12/8/7）。

**逆向要点**:
- 搜索字符串 `"expand 32-byte k"` 或其二进制表示 `0x61707865`。
- 关注 64 字节状态的 4 个常量、4 个轮换加法/异或操作。
- ChaCha20 的计数器为 64 位（大端）。

### 10. LCG 算法 (Linear Congruential Generator)
LCG 是伪随机数生成器:
```
X_{n+1} = (a * X_n + c) mod m
```
- 常用于生成伪随机密钥流、洗牌、IV 生成。
- **逆向要点**: 从连续的输出值中恢复参数 a、c、m。
- 已知三个连续值可以求解参数（m 通常为 2^32、2^48、2^64）。

### 11. PRESENT
PRESENT 是轻量级分组密码（适用于物联网）。

- 分组: 64 位，密钥: 80/128 位。
- 31 轮 SPN 结构。
- 特征: 16 个 4 位 S-box + 位置换层（Permutation Layer）。
- **逆向时特征**: 查找 16 个 4 位输入输出的 S-box 表。

### 12. CRC32
CRC32（循环冗余校验）不是加密算法，但常被用于数据完整性校验或哈希。

**特征常量**: 多项式 `0xEDB88320`（逆向反射表示）或 `0x04C11DB7`（正向表示）。
**应用**: 在逆向中 CRC32 常被用于:
- 生成"哈希"后的 ID/索引值。
- 校验关键数据段是否被篡改。
- 混淆函数名（函数名 -> CRC32 -> 索引）。

### 13. RSA
RSA 是公钥密码系统，广泛用于密钥交换和数字签名。

**参数**:
- `n = p * q`（公钥）。
- `e`（公钥指数，常为 65537 或 3 等）。
- `d`（私钥指数）。
- 加密: `c = m^e mod n`，解密: `m = c^d mod n`。

**逆向要点**:
- 搜索大数（Big Integer）常量（n、e、d、p、q）。
- 寻找模幂运算（Modular Exponentiation）的代码。
- CTF 中常见场景:
  - 从二进制中提取 n 和 e，破解较弱的密钥（如 p 和 q 接近的 Fermat 分解）。
  - 在内存中找到私钥 d。
  - 填充方案（PKCS#1 v1.5 / OAEP）的识别和还原。
- 工具: `openssl`、`rsatool`、`RsaCtfTool`。

### 14. RC4
RC4 是流密码（已弃用，因安全缺陷），但仍在大量旧程序和 CTF 中出现。

**特征**:
- 密钥调度算法 (KSA): 初始化 256 字节 S-box。
- 伪随机生成算法 (PRGA): 生成密钥流。
- **识别**: 查找 256 字节的初始 S-box（通常为 0,1,2,...,255）和两轮内循环交换。
- 密钥长度可变。

**安全性缺陷**:
- 密钥流偏向性（前若干字节可预测，建议丢弃前 3072 字节）。
- 相同密钥产生相同密钥流（重用时 XOR 可破解放送的两条消息）。

### 15. HASH 算法 (MD5 / SHA1 / SHA256 / SHA512)
哈希函数在逆向中广泛用于密码存储、完整性校验和指纹生成。

**标准常量识别**:
- **MD5**: 初始常量: `0x67452301`、`0xEFCDAB89`、`0x98BADCFE`、`0x10325476`。
- **SHA1**: 初始常量: `0x67452301`、`0xEFCDAB89`、`0x98BADCFE`、`0x10325476`、`0xC3D2E1F0`。
- **SHA256**: 8 个初始常量 + 64 个轮常量。
- **SHA512**: 8 个 64 位初始常量 + 80 个 64 位轮常量。

**逆向要点**:
- 搜索初始常量的二进制值快速定位 HASH 函数。
- 区分加密与哈希: 哈希算法不可逆（单向），只有比较输出值的方式。
- CTF 中破解简单密码/弱密码哈希时，使用 `hashcat` / `john`。

### 16. DES / 3DES
数据加密标准（DES）是 64 位分组密码，3DES 是三重 DES 应用。

**特征**:
- S-box 表（8 个 6->4 位 S-box）。
- IP（初始置换）和 FP（最终置换）表。
- 子密钥生成的移位（PC1/PC2）。

**3DES**:
- `EDE` 模式: `C = E_{k1}(D_{k2}(E_{k3}(P)))`
- 若 k1=k2=k3 = 标准 DES。
- 若 k1=k3 != k2 = 双密钥 3DES。

**逆向识别**: S-box 表是识别 DES 的最强特征，共 8 个表，每个 4 行 16 列 4 位值。

### 17. AES (Rijndael)
AES 是当今最广泛使用的对称分组密码。

**特征**:
- **S-box**: 16x16 字节替换表（`0x63, 0x7C, 0x77, 0x7B, ...`）。
- **分组**: 固定 128 位，密钥: 128/192/256 位。
- **轮数**: 10/12/14 轮。
- 四个操作: SubBytes、ShiftRows、MixColumns、AddRoundKey。

**逆向要点**:
- 在 IDA 中搜索 S-box 数组（256 字节）是最直接的定位方法。
- 使用查找表实现（T-table）时，有 4 个 256 字的查找表（T0-T3）。
- AES 的 S-box(Inverse) 也可用于识别: `0x00, 0x03, 0x05, 0x0F, ...`
- 密钥扩展（Key Expansion）的特定轮常数（RCON）: `0x01, 0x02, 0x04, 0x08, 0x10, ...`

**工具**: `aeskeyfind`（在内存/二进制中搜索 AES 密钥）。

### 18. SM4 (国密)
SM4 是中国国家密码标准的分组密码算法。

**特征**:
- 分组 128 位，密钥 128 位，32 轮。
- S-box: 16x16 位替换表（特定值）。
- 轮常数和系统参数（FK/CK 数组）的特定值。
- 固定参数 FK = `0xA3B1BAC6, 0x56AA3350, 0x677D9197, 0xB27022DC`。

**逆向要点**:
- FK 数组是识别 SM4 的最强特征。
- S-box 与 AES 不同，可区分两者。
- 常用于国内 CTF 题目。

### 19. 方程组求解
逆向中经常出现使用多变量线性方程组进行"加密"的逻辑。

**识别特征**:
- 一系列线性操作: `result[i] = Σ(a[i][j] * input[j]) + b[i]`。
- 使用矩阵乘法、多元一次方程求值。
- **破解**: 已知明文对 -> 高斯消元求解系数 -> 预测输出。
- 工具: `numpy`、`z3`、`sage`。

### 20. 矩阵运算
矩阵在密码学中用于线性变换（如 Hill 密码）和某些自定义算法。

**逆向要点**:
- 识别矩阵乘法循环: `for i: for j: for k: C[i][j] += A[i][k] * B[k][j]`。
- 提取矩阵维度和数值。
- **Hill 密码破解**: 已知明文对 -> 求矩阵逆 -> 恢复密钥矩阵。

## 攻击/还原思路

### 通用还原流程
```
1. 识别算法:
   - 搜索常量表（AES S-box、DES S-box、MD5/SHA 初始值、TEA DELTA 等）
   - 识别循环结构和操作模式（Feistel、SPN、流密码）

2. 提取密钥和参数:
   - 硬编码的密钥（字符串、常量数组）
   - 密钥生成逻辑（从输入派生密钥）
   - IV、nonce、计数器初始值

3. 编写解密脚本:
   - 使用标准库（pycryptodome、openssl）或手动实现
   - 注意算法参数的差异（轮数、模式、填充方式）

4. 处理魔改:
   - 对比标准实现，找出修改点
   - 调整解密代码以匹配魔改版本

5. 验证结果:
   - 解密后的数据是否符合预期（flag 格式、可读文本）
   - 如不正确，回溯检查参数或解密逻辑
```

### 示例: 识别并还原 AES 加密
```
# 1. 在二进制中发现 256 字节的替换表
# 2. 与 AES S-box 对比确认（0x63, 0x7C, 0x77, ...）
# 3. 找到 AddRoundKey 和 MixColumns 操作确认加密模式
# 4. 提取密钥（16 字节）和 IV（16 字节）——假设 CBC 模式
# 5. Python 还原:

from Crypto.Cipher import AES
key = bytes([...])  # 提取的密钥
iv = bytes([...])    # 提取的 IV
cipher = AES.new(key, AES.MODE_CBC, iv)
plain = cipher.decrypt(ciphertext)
print(plain.strip())
```
