# AI 安全知识库

## 概述
AI安全涉及机器学习模型生命周期中的各类安全威胁与防护措施，包括数据层面攻击、模型层面攻击、部署环境安全等。

| 技能 | 描述 |
|------|------|
| [信息搜集](AI信息搜集.md) | 模型信息搜集、数据集信息搜集 |
| [模型攻击](模型攻击.md) | 对抗样本攻击、模型反向工程、模型数据窃取、模型窃取攻击、模型越狱攻击、模型后门攻击 |
| [数据攻击](数据攻击.md) | 数据投毒攻击、数据伪造攻击 |
| [模型评估](模型评估.md) | 模型性能评估、模型公平性评估、模型可解释性 |
| [模型防御](模型防御.md) | 增强训练、模型加密、输入规范化、输出结果校验、防御性蒸馏、隐私保护技术、模型监控 |
| [数据处理](数据处理.md) | 数据预处理 |
| [安全防御](安全防御.md) | 安全模型训练 |
| [系统安全](系统安全.md) | 沙箱攻击、模型智能体攻击 |
