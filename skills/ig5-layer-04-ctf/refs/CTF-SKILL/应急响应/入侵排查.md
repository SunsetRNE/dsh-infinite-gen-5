# 入侵排查

## 概述
入侵排查是安全事件发生后进行的系统化调查和分析过程，通过日志、文件、进程、网络等多维度信息确定入侵范围、攻击路径和影响。

## 排查内容

### Web失陷事件入侵排查
- **Web日志分析**：分析访问日志中的异常请求、扫描行为、注入尝试
- **WebShell排查**：
  - **文件时间异常**：查找近期创建或修改的脚本文件
  - **隐藏文件检查**：查找点开头的隐藏Web文件
  - **一句话木马**：检测eval、system、exec等危险函数调用
  - **图片马检查**：检测图片文件中隐藏的WebShell代码
- **文件完整性检查**：对比Web文件的hash值发现篡改
- **中间件日志**：分析PHP、Tomcat、Nginx等中间件的错误日志
- **可疑进程检查**：检查Web服务器上的异常进程
- **数据库审计**：检查数据库的异常查询和操作记录
- **敏感文件检查**：查找泄露的配置文件、备份文件
- **挖矿程序排查**：检测挖矿木马的进程和文件
- **后门账户检查**：检查系统是否添加了后门用户

### 勒索病毒事件入侵排查
- **感染范围评估**：确定受影响的系统和服务范围
- **加密文件识别**：识别勒索软件加密的文件类型和范围
- **勒索信分析**：分析勒索信的赎金要求和联系信息
- **勒索软件家族识别**：通过文件后缀、加密算法识别勒索软件类型
- **传播路径追踪**：分析勒索软件在内部的传播途径
- **初始入口确定**：确定勒索软件的最初感染入口
- **横向移动分析**：分析勒索软件的横向移动方式
- **数据备份检查**：检查备份系统是否也被加密
- **解密可能性评估**：评估是否存在免费的解密工具
- **IOC提取**：提取勒索软件的文件hash、域名、IP等IOC
- **时间线重建**：从初始入侵到加密爆发的时间线

### 挖矿木马事件入侵排查
- **进程排查**：
  - **CPU占用检查**：查找CPU占用异常高的进程
  - **隐藏进程检查**：检测Rootkit隐藏的挖矿进程
  - **进程名伪装**：识别伪装为系统进程的挖矿程序
- **网络连接排查**：
  - **矿池连接检查**：识别连接矿池的TCP连接
  - **异常端口检测**：检测非标准的网络服务端口
  - **流量特征分析**：分析挖矿程序的通信流量模式
- **文件排查**：
  - **挖矿程序文件**：查找挖矿程序本体(如xmrig、cgminer)
  - **守护脚本检查**：查找挖矿程序的启动和守护脚本
  - **定时任务检查**：检查cron中挖矿程序的持久化设置
  - **启动项检查**：检查系统服务的自启动项
- **持久化机制排查**：
  - **计划任务**：crontab、Windows Task Scheduler
  - **系统服务**：伪装为系统服务的挖矿程序
  - **内核模块**：检查恶意内核模块
  - **LD_PRELOAD**：检查LD_PRELOAD注入
- **横向移动检查**：查找挖矿木马是否传播到其他主机

### 系统后门事件入侵排查
- **用户账户排查**：
  - **隐藏账户**：查找Windows的隐藏用户
  - **克隆账户**：检测RID劫持的克隆管理员
  - **Shadow账户**：检测影子账户
  - **SSH公钥检查**：检查.ssh/authorized_keys中的未授权公钥
- **服务后门排查**：
  - **系统服务**：检查异常的服务安装
  - **驱动后门**：检测恶意内核驱动程序
  - **Windows服务**：使用sc query检查服务
- **启动后门排查**：
  - **注册表启动项**：RUN/RunOnce等启动键值
  - **启动文件夹**：Startup目录中的启动脚本
  - **Bootkit检查**：检查MBR/EFI分区的恶意代码
  - **计划任务**：隐藏的计划任务后门
- **网络后门排查**：
  - **反向连接**：检查反连Shell的进程和连接
  - **端口监听**：检测后门监听的端口
  - **协议隧道**：检测ICMP/DNS/HTTP隧道后门
- **Rootkit排查**：
  - **内核Rootkit**：检查内核模块和系统调用劫持
  - **用户态Rootkit**：检查LD_PRELOAD注入和库劫持
  - **文件隐藏**：使用工具检测隐藏的文件和进程

### 容器失陷事件入侵排查
- **容器逃逸检查**：
  - **特权容器**：检查是否使用了privileged模式
  - **挂载检查**：检查容器是否挂载了宿主机敏感目录
  - **Capabilities**：检查容器是否有SYS_ADMIN等危险capabilities
  - **系统调用异常**：检测容器中异常的宿主机系统调用
- **容器镜像分析**：
  - **基础镜像安全**：检查是否使用了受感染的镜像
  - **镜像层分析**：分析镜像各层的文件修改
  - **运行进程检查**：检查容器内的异常进程
- **Kubernetes环境排查**：
  - **RBAC审计**：检查K8s RBAC配置的异常修改
  - **Pod异常检查**：识别异常的Pod创建行为
  - **ConfigMap/Secret检查**：检查敏感配置的泄露
  - **网络策略检查**：检查NetworkPolicy的配置异常
- **日志取证**：
  - **容器日志**：获取和保存失陷容器的日志
  - **K8s事件**：分析K8s集群中的异常事件
  - **审计日志**：K8s API Server审计日志分析

### 综合攻击类型事件入侵排查
- **APT攻击排查**：
  - **攻击链重建**：还原从初始访问到数据窃取的完整攻击链
  - **横向移动分析**：追踪攻击者在内部的横向移动路径
  - **持久化发现**：查找攻击者建立的持久化机制
  - **数据窃取评估**：评估被窃取的数据范围和类型
  - **C2通信分析**：追踪与C2服务器的通信记录
- **DDoS攻击排查**：
  - **攻击源分析**：分析攻击流量的来源IP
  - **攻击类型识别**：识别DDoS攻击的类型(CC、SYN Flood等)
  - **受害者影响**：评估服务影响范围和持续时间
- **数据泄露排查**：
  - **数据外传流量**：分析异常的数据出站流量
  - **泄露文件追踪**：追踪被窃取文件的访问记录
  - **用户行为分析**：分析涉及数据访问的用户行为模式

## 排查建议
- 建立标准化的入侵排查流程
- 先隔离受影响系统防止进一步扩散
- 确保收集的电子证据的完整性和链式保管
- 在排查过程中避免破坏关键证据
- 使用自动化工具提高排查效率
- 建立详细的排查文档和报告
- 排查后进行复盘和改进安全措施
