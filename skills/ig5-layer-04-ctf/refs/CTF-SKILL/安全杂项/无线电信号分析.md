# 无线电信号分析（Radio Signal Analysis）

## 概述

无线电信号分析是 CTF 中较为高阶的题目类型，涉及对无线通信信号的捕获和解码。题目通常提供无线电信号样本（如 IQ 数据、音频记录等），选手需要分析信号特征、解调和解码隐藏信息。这类题目需要了解信号处理、调制方式和通信协议的基本知识。

## 常见信号类型

### 遥控器信号分析
遥控器（如遥控车、遥控门）使用特定频率（通常为 27MHz、315MHz、433MHz、868MHz、2.4GHz）的无线信号。

**常见调制方式**：
- **ASK（振幅键控）**：有无载波表示 0/1
- **FSK（频移键控）**：不同频率表示 0/1
- **OOK（开关键控）**：ASK 的特例

**攻击方法**：
1. 捕获遥控器信号（使用 SDR 或逻辑分析仪）
2. 分析信号时序和编码规则
3. 重放攻击

### 蓝牙信号分析
蓝牙（Bluetooth）和低功耗蓝牙（BLE）信号分析。

**协议分析**：
- 广播信道（37/38/39）：设备发现和广播数据
- 数据信道：连接后的数据传输
- ATT/GATT 协议：服务和特征读取
- HCI 日志：主机控制接口日志

**工具**：`Wireshark`（支持 BLE）、`Ubertooth`、`nRF Sniffer`。

### Zigbee 信号分析
Zigbee 是低功耗物联网无线协议（基于 IEEE 802.15.4）。

**攻击分析**：
1. 信道扫描：发现活跃的 Zigbee 网络
2. 包捕获：嗅探 Zigbee 通信
3. 密钥提取：分析网络密钥
4. 重放攻击：重放 Zigbee 命令

**工具**：`KillerBee`、`Zigdiggity`、`Api-Mote`。

## 常用工具和硬件

### 软件定义无线电（SDR）
- **RTL-SDR**：低成本的 USB 电视棒，可接收 24MHz-1.7GHz
- **HackRF One**：可收发 1MHz-6GHz
- **BladeRF**：可收发 47MHz-6GHz
- **LimeSDR**：全双工 SDR

### 软件工具
- **GNU Radio**：开源 SDR 信号处理框架
- **GQRX**：SDR 频谱分析仪
- **Universal Radio Hacker (URH)**：无线协议分析
- **Audacity**：音频信号分析
- **inspectrum**：无线信号离线分析
- **rtl_433**：433MHz 设备解码
- **KillerBee**：Zigbee 安全工具

### 分析流程

1. **信号捕获**：使用 SDR 设备捕获信号，保存为 IQ 数据
2. **频谱分析**：查看信号频率、带宽和强度
3. **解调**：选择合适的解调方式（AM/ FM/ SSB/ CW）
4. **协议分析**：识别和解析通信协议
5. **数据提取**：提取隐藏在信号中的数据

## 常见攻击手法

### 信号调制识别
通过分析信号的频谱、时域波形和 IQ 图识别调制方式：
- **AM**：载波幅度随基带信号变化
- **FM**：载波频率随基带信号变化
- **PM**：载波相位随基带信号变化
- **ASK/OOK**：振幅键控，通常用于遥控器
- **FSK**：频率键控，有 2-FSK、4-FSK、GFSK
- **PSK**：相位键控，有 BPSK、QPSK、8PSK
- **QAM**：正交振幅调制，同时调制幅度和相位

### 重放攻击（Replay Attack）
1. 捕获合法的无线信号
2. 分析信号格式
3. 在需要时重放该信号
4. 可能需要对信号进行时域上的调整

### 滚动码攻击
现代遥控器使用滚动码（Rolling Code）防止重放攻击：
- KeeLoq 攻击：对微控制器加密算法的攻击
- Jamming 攻击：干扰合法信号，捕获后用于后续使用

### 信号逆向工程
1. 采集足够的信号样本
2. 分析脉冲宽度（Pulse Width）
3. 解析数据帧格式
4. 识别同步头和校验和
5. 提取完整协议

## 防御建议

从防御角度看无线电安全：
- 使用滚动码防止重放攻击
- 实施双向认证
- 加密无线通信
- 使用跳频扩频（FHSS）
- 最小化无线信号发射功率
