# 文档隐写（Document Steganography）

## 概述

文档隐写是利用办公文档（Word、Excel、PowerPoint、PDF 等）的文件结构特性，在文档中隐藏秘密信息。由于文档格式复杂，通常包含大量不影响视觉呈现的元数据、修订信息、隐藏文本、注释等，为隐写提供了多种途径。在 CTF 中，文档隐写题目需要选手熟悉文档格式的内部结构。

## 常见技术

### 隐藏文字（Hidden Text）
大多数办公软件支持隐藏文字功能。在 Word 中，设置字体为"隐藏"可使文字在正常视图中不可见。

**检测方法**：
- Word：文件→选项→显示→选中"隐藏文字"
- 转为纯文本：将文档另存为纯文本（.txt）格式
- 查看文档的 XML 源码（Office Open XML 格式）

### 文本隐水印（Text Watermark）
通过微调文本的字符间距、字体大小、颜色、行间距等物理特性来编码信息。人眼难以察觉这些微小变化。

**常见方法**：
- **行移位编码**：上下微调行位置
- **字移位编码**：左右微调字符位置
- **特征编码**：修改字体、大小、颜色等属性
- **零宽字符**：在文本中插入零宽空格等不可见字符

### 零宽字符隐写
利用 Unicode 零宽字符（零宽空格 U+200B、零宽非连接符 U+200C 等）在文本中嵌入信息。这些字符不可见但存在于文本中。

**检测**：
- 使用十六进制编辑器查看
- Python 检查字符串中是否包含非标准 Unicode 字符

### 文档结构隐写

#### Office Open XML 格式
现代 Office 文档（.docx、.xlsx、.pptx）是 ZIP 压缩包，内部包含 XML 文件。

**隐藏位置**：
- **注释（Comments）**：`word/comments.xml`
- **页眉页脚**：`word/header*.xml`、`word/footer*.xml`
- **自定义 XML 数据**：`customXml/`
- **文档属性**：`docProps/`
- **VBA 宏代码**：`word/vbaProject.bin`
- **关系文件**：`_rels/.rels`
- **媒体文件**：`word/media/` 可包含附加图片
- **字体表**：`word/fontTable.xml`

#### PDF 格式
- **元数据（Metadata）**：XMP 元数据字段
- **注释（Annotations）**：PDF 注释和标记
- **隐藏对象**：未引用的间接对象
- **图层（OCG）**：可选内容组（图层）
- **嵌入文件（Embedded Files）**：PDF 可以嵌入附件
- **字体**：自定义字体中隐藏信息

#### ODF 格式
Open Document Format 也是 ZIP 压缩的 XML 结构，与 OOXML 类似的隐藏位置。

## 相关工具

- **`7-Zip`**：解压 Office 文件查看内部 XML
- **`python-docx`**：读取 Word 文档内容
- **`openpyxl`**：读取 Excel 文件
- **`PyMuPDF (fitz)`**：PDF 分析和修改
- **`peepdf`**：PDF 隐写分析
- **`origami-pdf`**：PDF 分析和操作
- **`exiftool`**：查看文档元数据

## 防御建议

文档隐写检测应关注：
- 文件大小异常（与内容不匹配）
- 文档中的不可见字符
- 异常多的注释或修订
- 嵌入的大型对象

## 示例思路

```python
# 提取 Office 文档中的隐藏信息
import zipfile
from lxml import etree

docx_path = 'document.docx'
with zipfile.ZipFile(docx_path, 'r') as z:
    # 查看文档中的注释
    if 'word/comments.xml' in z.namelist():
        xml_content = z.read('word/comments.xml')
        root = etree.fromstring(xml_content)
        for comment in root.iter('{http://schemas.openxmlformats.org/wordprocessingml/2006/main}comment'):
            text = comment.find('.//{http://schemas.openxmlformats.org/wordprocessingml/2006/main}t')
            if text is not None:
                print(f"Comment: {text.text}")
    
    # 查看自定义 XML
    for name in z.namelist():
        if name.startswith('customXml'):
            print(f"File: {name}")
                print(z.read(name).decode('utf-8', errors='ignore'))
```
