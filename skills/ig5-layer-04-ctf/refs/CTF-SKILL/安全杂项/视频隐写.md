# 视频隐写（Video Steganography）

## 概述

视频隐写利用视频文件的结构和编码特性，将秘密信息隐藏在视频流中。视频文件本质上是一系列图片帧（帧内编码）加上运动矢量（帧间编码），因此所有图片隐写技术都可应用于视频。此外，视频特有的结构（如时间戳、帧率、元数据等）也提供了隐藏信息的额外空间。

## 常见技术

### 帧提取（Frame Extraction）
视频由连续的帧组成，信息可能隐藏在特定帧中。

**帧分析类型**：
- **单帧隐写**：某一帧（或几帧）包含隐写信息
- **帧序列隐写**：信息分布在多帧中（如 LSB 连续帧提取）
- **关键帧/非关键帧**：I 帧（关键帧）通常不依赖其他帧，容易提取分析

**提取方法**：
- 使用 `ffmpeg` 将视频拆分为单帧图片
- 对每一帧使用图片隐写工具分析
- 注意帧间距、帧顺序可能是编码的一部分

### 视频结构隐写

#### 元数据隐藏
视频文件的容器格式（MP4、AVI、MKV 等）包含大量元数据字段：
- 标题、作者、备注等文本字段
- 创建时间、修改时间
- 软件信息（编码器名称、版本）
- 自定义标签（如 MP4 的 udta→meta→ilst）

#### 时间戳隐藏
- 帧时间戳（PTS/DTS）的微调
- 视频长度/持续时间的微妙偏差

#### IDR 帧间隔
信息可以被编码为 IDR（Instantaneous Decoder Refresh）帧之间的间隔差异。

#### GOP 结构隐藏
GOP（Group of Pictures）的结构模式可以被用来编码信息。

#### 运动矢量隐写
在 P 帧和 B 帧的运动矢量中嵌入信息，修改运动矢量的精度。

## 常见攻击手法

### ffmpeg 帧提取
```bash
# 将视频提取为图片序列
ffmpeg -i video.mp4 frames/frame_%04d.png

# 提取特定时间范围
ffmpeg -i video.mp4 -ss 10 -t 5 frames/frame_%04d.png
```

### 逐帧比较
比较相邻帧的差异或特定帧和预期内容的差异。

### 字幕轨道
视频文件可能在字幕轨道中隐藏信息。检查 SRT、ASS 等字幕字幕。

### 音频轨道
视频的音频轨道可能包含音频隐写信息。提取音频并分析。

```bash
ffmpeg -i video.mp4 -vn -acodec copy audio.aac
```

## 相关工具

- **`ffmpeg`**：视频处理、帧提取、音视频分离
- **`ffprobe`**：视频元数据查看
- **`MediaInfo`**：媒体文件信息查看
- **`MP4Box`**：MP4 容器分析
- **`VLC`**：逐帧播放
- **Python `opencv-python` / `moviepy`**：视频处理

## 防御建议

视频隐写防御关注视频文件的异常大小、元数据异常、帧间统计异常。安全的视频分发应使用数字签名和哈希验证。

## 示例思路

```python
import cv2
import numpy as np

# 提取视频帧并分析 LSB
cap = cv2.VideoCapture('video.mp4')
bits = ""
frame_count = 0
while True:
    ret, frame = cap.read()
    if not ret:
        break
    # 从每一帧的左上角像素提取 LSB
    pixel = frame[0, 0]
    for channel in range(3):
        bits += str(pixel[channel] & 1)
    frame_count += 1
    if frame_count > 100:  # 只分析前100帧
        break
cap.release()

# 转换提取的比特
result = ""
for i in range(0, len(bits), 8):
    if i + 8 <= len(bits):
        char = chr(int(bits[i:i+8], 2))
        result += char
print(result)
```
