# 日志分析（Log Analysis）

## 概述

日志分析是 CTF 取证类题目中的重要组成部分。通过对系统日志、应用日志、Web 服务器日志等的分析，还原攻击事件、追踪攻击者行为、提取隐藏数据。日志记录了系统中发生的事件，成为取证调查的重要来源。

## 常见类型

### 系统日志分析

#### Windows 事件日志
Windows Event Log 文件格式为 `.evt`（旧）或 `.evtx`（新），记录系统、安全和应用事件。

**重要事件 ID**：
| 事件 ID | 描述 |
|---------|------|
| 4624 | 登录成功 |
| 4625 | 登录失败 |
| 4634 | 注销 |
| 4688 | 新进程创建 |
| 4698 | 计划任务创建 |
| 1102 | 日志被清除 |
| 4720 | 用户账号创建 |

**工具**：`wevtutil`、`Event Viewer`、`python-evtx`、`logparser`。

```bash
# 使用 wevtutil 查询安全日志
wevtutil qe Security /q:"*[System[(EventID=4624)]]" /c:10 /f:text
```

#### Linux 系统日志
- `/var/log/syslog` / `/var/log/messages`：通用系统日志
- `/var/log/auth.log` / `/var/log/secure`：认证日志
- `/var/log/kern.log`：内核日志
- `/var/log/apt/`：包管理日志
- `/var/log/cron`：计划任务日志

**命令**：`grep`、`journalctl`、`logwatch`。

### HTTP 日志分析

#### Apache/Nginx 访问日志
标准日志格式示例：
```
192.168.1.1 - - [10/Oct/2023:13:55:36 +0000] "GET /admin.php HTTP/1.1" 200 2326
```

**分析要点**：
- 异常请求（SQL 注入、XSS、路径遍历）
- 扫描行为（大量 404/403）
- 文件包含尝试
- POST 请求中的 payload
- User-Agent 异常

#### 漏洞扫描日志
根据 HTTP 日志中的请求模式识别攻击类型：
- SQL 注入：`union`, `select`, `'`, `--` 等关键词
- LFI：`../`, `file://`, `/etc/passwd`
- SSRF：`http://`, `file://`, `gopher://`
- RCE：`system()`, `exec()`, `passthru()` 等

### SQL 盲注日志分析
SQL 盲注的日志中具有特殊特征：
1. **时间盲注**：`SLEEP()` 函数导致的请求时间差异
2. **布尔盲注**：条件判断导致的响应内容差异

**分析**：通过日志中的 `SLEEP(n)` 函数调用或大量重复的条件查询识别盲注。

## 常见攻击手法

### 时间线重建
1. 提取所有日志中的时间戳
2. 建立事件时间线
3. 识别攻击的各个阶段（侦察→武器化→利用→安装→命令控制→行动）

### 异常检测
- 统计 IP 请求频率和模式
- 分析请求 URL 的参数长度和内容
- 检测非标准的 User-Agent
- 寻找时间异常的请求

### 日志关联
- 将不同来源的日志关联分析
- 跨系统追踪攻击者
- 关联 IP、用户、进程等实体

## 相关工具

- **Windows Event Viewer**：图形化事件日志查看
- **`wevtutil`**：Windows 事件日志命令行工具
- **`python-evtx`**：Python EVTX 解析
- **`LogParser`**：Microsoft 日志查询工具
- **`journalctl`**：systemd 日志查询
- **`GoAccess`**：HTTP 日志分析
- **`Splunk` / `ELK Stack`**：日志分析平台
- **`grep` / `awk` / `sed`**：文本处理三剑客

## 防御建议

良好的日志管理是安全的基础：
- 集中式日志收集（SIEM）
- 日志完整性保护（防篡改）
- 日志保留策略符合合规要求
- 定期进行日志审计

## 示例思路

```bash
# Apache 日志分析常见攻击
grep -E "(union|select|load_file|into outfile)" access.log

# 统计异常请求 IP
awk '{print $1}' access.log | sort | uniq -c | sort -rn | head -20

# 查找扫描行为（大量 404）
grep '404' access.log | awk '{print $1}' | sort | uniq -c | sort -rn | head -10

# 分析系统日志中的 SSH 暴力破解
grep "Failed password" /var/log/auth.log | awk '{print $11}' | sort | uniq -c | sort -rn

# 查看 EVTX 日志
python -c "
import Evtx.Evtx as evtx
with evtx.Evtx('Security.evtx') as log:
    for record in log.records():
        print(record.xml())
                if record.System.EventID == 4624:
            break
```
