# 压缩包分析（Archive Analysis）

## 概述

压缩包分析是 CTF MISC 类题目中非常常见的考点。题目通常将隐藏信息放入 ZIP、RAR、7Z 等压缩包中，并通过设置密码、修改结构、伪加密等方式增加提取难度。选手需要掌握压缩包文件结构、密码破解方法、已知攻击手法等。

## 常见格式

- **ZIP**：最通用的格式，支持多种加密方式（ZIP 2.0 传统加密、AES 加密）
- **RAR**：压缩率高，支持固实压缩和恢复记录
- **7Z / 7Zip**：使用 LZMA 算法，压缩率高，支持 AES-256 加密
- **GZip / Tar**：Unix 常用
- **BZip2**：压缩率高但速度慢

## 常见攻击手法

### 伪加密（Fake Encryption）
ZIP 文件有一个标志位指示是否加密。将伪加密标志（位 6 置位）置 1 但实际并未加密，解压软件会提示输入密码。

**修复方法**：
1. 使用十六进制编辑器修改 ZIP 文件的通用位标志（general purpose bit flag）
2. 将位 6（0x40）清零

**ZIP 伪加密位位置**：
- 文件头中偏移 6（0x06）：通用位标志
- 将 0x09 改为 0x00（位 0 和位 3 清零）

**其他格式**：
- RAR：修改文件头中的加密标志
- 7z：修改 7z 头的加密标志位

### 暴力破解（Brute Force）
枚举所有可能的密码组合，适用于短密码场景。

**工具**：
- `fcrackzip`：ZIP 暴力破解
- `rarcrack`：RAR 密码破解
- `John the Ripper`：支持多种格式

### 字典攻击（Dictionary Attack）
使用常见密码字典进行破解。

**常用字典**：`rockyou.txt`、自定义字典（基于题目信息）。

```bash
# fcrackzip 字典攻击
fcrackzip -D -p /usr/share/wordlists/rockyou.txt encrypted.zip

# John the Ripper ZIP 破解
zip2john encrypted.zip > hash.txt
john --wordlist=/usr/share/wordlists/rockyou.txt hash.txt
```

### 掩码攻击（Mask Attack）
当知道密码的部分特征时（如密码格式、长度、字符集），使用掩码加速破解。

**hashcat 掩码示例**：
```
# 密码格式：8位数字
hashcat -a 3 -m 17200 hash.txt ?d?d?d?d?d?d?d?d
# 密码格式：flag{xxx}
hashcat -a 3 -m 17200 hash.txt flag{?a?a?a?a?}
```

### 明文攻击（Known Plaintext Attack）
若知道 ZIP 中某个文件的明文内容，可以利用该信息快速破解加密 ZIP。

**条件**：
- ZIP 使用 ZipCrypto Store（不压缩）或 Deflate 压缩方式
- 知道至少 12 字节的明文（以及对应的密文位置）

```bash
# pkcrack 明文攻击
pkcrack -c encrypted_file.txt -p known_plaintext.txt -P known_plaintext.zip -C encrypted.zip
```

### CRC32 碰撞（CRC32 Collision）
ZIP 中每个文件的 CRC32 校验和是公开的。若文件的长度很短（如 1-4 字节），可以通过暴力枚举所有可能的明文，使其 CRC32 与已知值匹配。

**场景**：短文本已知但隐藏（如在 ZIP 注释中或通过 CRC 验证）。

```python
import binascii
import itertools

target_crc = 0x6144B6C3
for length in range(1, 5):
    for combo in itertools.product(range(256), repeat=length):
        data = bytes(combo)
        if binascii.crc32(data) & 0xFFFFFFFF == target_crc:
            print(f"Found: {data}")
            exit()
```

### 注释查看（Comment Inspection）
ZIP 文件可以有文件注释和中央目录注释，密码或提示可能直接写在注释中。

### 压缩包结构分析（Archive Structure Analysis）
查看压缩包内部的文件结构：
- 文件列表和文件名
- 文件顺序
- 隐藏文件（文件名以点开头或特殊字符）
- 文件大小和压缩比异常
- 嵌套压缩包

## 相关工具

- **`7-Zip`**：通用压缩/解压
- **`fcrackzip`**：ZIP 密码破解
- **`John the Ripper`**：密码破解
- **`hashcat`**：GPU 加速破解
- **`pkcrack`**：ZIP 明文攻击
- **`rarcrack`**：RAR 破解
- **`zipinfo` / `unzip -l`**：查看 ZIP 内容
- **`bkcrack`**：ZIP 已知明文/内部文件攻击

## 防御建议

压缩包加密不能替代真正的数据保护：
- 使用强密码（>12 位，混合字符）
- 使用 AES-256 加密而非 ZipCrypto
- 不要在压缩包中包含明文样本（防止明文攻击）

## 示例思路

```python
# CRC32 碰撞破解短文本
import binascii
import string

crc_value = 0x12345678  # 从 ZIP 文件头获取 CRC32

# 枚举所有可能的 4 字符组合
for a in string.printable:
    for b in string.printable:
        for c in string.printable:
            for d in string.printable:
                data = (a + b + c + d).encode()
                if binascii.crc32(data) & 0xFFFFFFFF == crc_value:
                    print(f"Content: {data}")
                    exit()
```
