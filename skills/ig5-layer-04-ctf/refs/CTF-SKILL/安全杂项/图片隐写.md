# 图片隐写（Image Steganography）

## 概述

图片隐写是 CTF 中最常见的隐写方式，利用图片文件的格式特性和人眼的感知局限性，将秘密信息隐藏在图片中。图片隐写技术涵盖空间域（如 LSB）、变换域（如 DCT）、文件结构等多个层面。

## 常见技术

### 附加内容（Appended Data）
在图片文件尾部直接附加数据。图片查看器通常忽略尾部多余数据，而附加的文件仍可被提取。

**检测方法**：
- 使用 `strings` 查看图片的末尾字符串
- 对比文件实际大小和图片数据应有的大小
- 使用 `binwalk` 检测嵌入式文件

### 图种（Image + Archive）
将 ZIP/RAR 等压缩包附加到图片文件尾部。是最常见的信息隐藏方式之一。

**提取方法**：
```bash
# 直接解压（WinRAR/7zip 可自动识别）
# 或使用 binwalk 提取
binwalk -e image.jpg

# 或手动分离
copy image.jpg /b + archive.zip /b output.jpg
```

### EXIF（Exchangeable Image File Format）
数字图片的元数据区域，可存储拍摄参数、相机型号、GPS 坐标、作者信息等。CTF 中常见的隐藏位置。

**查看方法**：
- `exiftool image.jpg`
- Python `PIL.Image._getexif()`
- Windows 右键属性→详细信息

### 图片宽高隐写（Dimension Stego）
修改 PNG/JPG 图片的高度或宽度值，使图片显示不完整，隐藏部分像素信息。

**PNG 宽高修复**：
- PNG 的 IHDR 块包含宽高信息（偏移 0x10-0x17）
- 暴力尝试不同的高度值，直到 CRC 校验通过或图片显示正常
- 使用 Python 的 `zlib.crc32` 校验

### LSB 隐写（Least Significant Bit）
修改像素颜色分量（RGB）的最低位来隐藏信息。对视觉影响极小，人眼无法察觉。

**检测与提取**：
- 使用 `zsteg`（PNG/BMP 自动检测）
- 使用 `stegsolve` 查看各个位平面
- Python 手动提取 LSB

### 数字水印隐写（Digital Watermark）
在图片中嵌入鲁棒的不可见水印，通常用于版权保护。提取需要特定的算法和密钥。

### DCT 域 JPG 隐写
JPG 图片的 DCT（离散余弦变换）系数中嵌入信息。JPEG 图片使用 8×8 块的 DCT 系数，修改高频系数隐藏信息。

**检测**：使用 `stegdetect` 或手动分析 DCT 系数分布。

### Arnold 置乱（Arnold Cat Map）
对图片像素位置进行置乱变换，使图像混乱。经过指定次数的逆变换可恢复原始图像。具有周期性特征。

### 图片容差隐写（PNG IDAT）
利用 PNG 的 IDAT 数据块存储额外信息，文件大小异常大。

### APNG 相关
动画 PNG 包含多个帧（fcTL 帧控制块），信息可能隐藏在不同帧中。

### GIF 相关
GIF 文件支持多帧动画，信息可以隐藏在帧延迟时间、帧顺序或调色板中。

### BMP 相关
BMP 文件结构简单，LSB 隐写和文件尾附加是最常见的方式。

### 图片结构隐写（Chunk-based）
PNG 文件的辅助块（如 tEXt、zTXt、iTXt）可以存储文本信息。修改块长度或添加自定义块。

### FFT 隐写（频域隐写）
对图片进行傅里叶变换，在频域中嵌入信息后再逆变换。

## 相关工具

- **`stegsolve`**：Java 图片隐写分析工具
- **`zsteg`**：PNG/BMP LSB 隐写检测
- **`stegdetect`**：JPG 隐写检测
- **`jsteg`**：JPG 隐写提取
- **`outguess`**：JPG 隐写
- **`exiftool`**：EXIF 信息查看
- **`binwalk`**：嵌入式文件检测
- **`pngcheck`**：PNG 文件结构分析

## 防御建议

隐写术是信息隐藏技术，在国家安全和隐私保护中有合法用途。在网络安全防御中，应关注异常文件的传输，使用流量分析检测隐写数据通道。

## 示例思路

```python
# LSB 隐写提取
from PIL import Image

img = Image.open('stego.png')
pixels = img.load()
bits = ''
for y in range(img.size[1]):
    for x in range(img.size[0]):
        r, g, b = pixels[x, y]
        bits += str(r & 1)
        bits += str(g & 1)
        bits += str(b & 1)

# 每 8 位作为一个字节转换
chars = []
for i in range(0, len(bits), 8):
    byte = int(bits[i:i+8], 2)
    if 32 <= byte <= 126:
        chars.append(chr(byte))
    else:
        break
print(''.join(chars))
```
