# 数字取证（Digital Forensics）

## 概述

数字取证是 CTF 竞赛中涵盖范围最广的类别之一，涉及从各种数字设备和存储介质中提取、恢复和分析数据。取证题目考察选手对磁盘镜像、内存快照、文件系统和操作系统内部结构等知识的掌握。取证分析通常遵循"获取-分析-报告"的标准流程。

## 常见类型

### 磁盘镜像分析（Disk Image Analysis）

磁盘镜像是对硬盘、U盘等存储设备的逐位复制，常见格式包括 `.dd`、`.E01`（EnCase）、`.AFF` 等。

**常见文件系统和分析内容**：
- **NTFS**：Windows 主文件表（MFT）、USN Journal、$LogFile、$Recycle.Bin
- **FAT32**：FAT 表、目录项
- **ext2/3/4**：Linux 索引节点（inode）、超级块、日记
- **APFS / HFS+**：macOS 文件系统

**分析工具**：
- `Sleuth Kit / Autopsy`：开源取证框架
- `FTK Imager`：磁盘查看和提取
- `X-Ways Forensics`：专业取证工具
- `OSForensics`：取证分析

### BitLocker 加密磁盘取证
Windows BitLocker 全盘加密。

**取证方法**：
- 恢复密钥（Recovery Key）在 AD 中存储
- 休眠状态恢复密钥（主密钥在内存中）
- 冷启动攻击（Cold Boot Attack）
- DMA 攻击（FireWire/Thunderbolt）

### AD1 磁盘取证（AccessData FTK Imager）
AD1 是 AccessData 的逻辑镜像格式，可以使用 FTK Imager 查看。

### VMDK 磁盘取证（VMware Virtual Disk）
VMware 虚拟磁盘格式，可使用 `7-zip` 解压或直接挂载分析。

```bash
# 挂载 VMDK（Linux）
modprobe nbd max_part=16
qemu-nbd -c /dev/nbd0 image.vmdk
mount /dev/nbd0p1 /mnt
```

### 加密磁盘取证
对整个磁盘或容器加密（如 VeraCrypt、LUKS、FileVault）的取证分析。

**方法**：
- 获取密码或密钥文件
- 内存中提取解密密钥
- 使用取证工具执行在线解密

### 内存镜像分析（Memory Forensics）

内存镜像捕获物理内存（RAM）的内容，可恢复正在运行的进程、网络连接、加密密钥、解密的数据等。

**常见格式**：
- Windows：`.raw`、`.dmp`、`.vmem`
- Linux：`.lime`、`.raw`
- macOS：`.mem`

**分析框架**：
- **Volatility 2/3**：最流行的内存取证框架
- **Rekall**：Google 的内存取证工具

#### Windows 内存取证
使用 Volatility 分析 Windows 内存镜像：

```bash
# 识别镜像信息
volatility -f memory.dmp imageinfo
# 列出进程
volatility -f memory.dmp pslist
# 提取进程内存
volatility -f memory.dmp memdump -p 1234 -D output/
# 提取 cmd 历史
volatility -f memory.dmp cmdscan
volatility -f memory.dmp consoles
# 查看网络连接
volatility -f memory.dmp netscan
# 提取注册表
volatility -f memory.dmp hivelist
volatility -f memory.dmp dumpregistry -o 0x... -D output/
# 密码哈希提取
volatility -f memory.dmp hashdump
# 剪贴板内容
volatility -f memory.dmp clipboard
```

#### Linux 内存取证
使用 Volatility 3 的 Linux 插件：
- `linux.pslist`：进程列表
- `linux.bash`：Bash 历史
- `linux.netstat`：网络连接
- `linux.proc`：进程内存提取
- `linux.dmesg`：内核日志

#### macOS 内存取证
macOS 内存取证使用 Volatility 3 的 Mac 插件：
- `mac.pslist`：进程列表
- `mac.netstat`：网络状态
- `mac.check_sysctl`：内核配置

### Android 取证
Android 设备取证包括：
- ADB 备份提取
- 逻辑提取（SQLite 数据库、Shared Preferences）
- 物理提取（JTAG、Chip-off）
- 应用数据分析（微信、WhatsApp 等）

### U 盘取证
- 主引导记录（MBR）分析
- 隐藏分区
- 文件系统残留数据
- 删除文件恢复

### 数据库取证
分析 SQLite、MySQL、SQL Server 等数据库文件：
- 查询记录和表结构
- 恢复已删除的记录
- 查看 WAL（Write-Ahead Log）和 Journal

### Web 浏览器取证
分析浏览器历史记录、缓存、Cookie、书签、下载记录等。

**位置**（以 Chrome 为例）：
- `History`：SQLite 数据库，`urls` 和 `visits` 表
- `Cookies`：SQLite 数据库
- `Bookmarks`：JSON 格式文件
- `Login Data`：保存的密码（加密）

### 安全事件分析
综合多种线索还原安全事件：
- 恶意软件感染路径
- 横向移动痕迹
- 数据泄露时间线
- 攻击者 TTPs（Tactics, Techniques, Procedures）

## 相关工具

- **Sleuth Kit / Autopsy**：磁盘取证
- **Volatility 2/3**：内存取证
- **FTK Imager**：磁盘查看
- **`foremost` / `scalpel`**：文件恢复
- **`bulk_extractor`**：批量信息提取
- **`photorec` / `testdisk`**：文件恢复
- **`plaso (log2timeline)`**：时间线分析
- **Wireshark**：网络取证
- **SQLite Browser**：SQLite 数据库查看
- **`recoverjpeg`**：JPEG 恢复

## 防御建议

数字取证的防御含义是减少数字痕迹：
- 使用全盘加密
- 及时清理敏感数据
- 使用安全删除工具
- 最小化日志保留

## 示例思路

```bash
# 使用 Volatility 分析 Windows 内存
volatility -f mem.dmp --profile=Win10x64_19041 pslist
volatility -f mem.dmp --profile=Win10x64_19041 cmdline
volatility -f mem.dmp --profile=Win10x64_19041 netscan
volatility -f mem.dmp --profile=Win10x64_19041 notepad

# 使用 foremost 恢复文件
foremost -i disk.dd -o recovered/

# 使用 bulk_extractor 提取信息
bulk_extractor -o output/ disk.dd
```
