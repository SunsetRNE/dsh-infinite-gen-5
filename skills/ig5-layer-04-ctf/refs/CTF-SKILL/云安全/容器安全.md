# 云容器安全

## 概述
云容器安全涵盖容器化部署环境中从镜像构建到运行时的全生命周期安全，包括容器逃逸、镜像漏洞和编排安全等。

## 常见攻击手法

### 容器逃逸
- **特权容器逃逸**：利用privileged标志获取宿主机权限
- **capabilities滥用**：利用SYS_ADMIN等Linux capabilities实现逃逸
- **挂载逃逸**：利用宿主机的文件系统挂载实现逃逸
- **cgroup漏洞利用**：利用cgroup的notify_on_release机制逃逸
- **内核漏洞利用**：利用操作系统内核漏洞从容器逃逸
- **Docker Socket挂载**：利用/var/run/docker.sock控制宿主机Docker

### 镜像漏洞利用
- **基础镜像漏洞**：使用包含已知漏洞的基础镜像
- **恶意镜像**：从不受信任的源拉取包含恶意软件的镜像
- **漏洞依赖库**：利用镜像中引入的漏洞第三方库
- **最近更新漏洞**：利用镜像构建时已存在的漏洞

### 不安全的容器编排
- **Kubernetes RBAC误配置**：利用过于宽松的RBAC权限
- **Pod安全策略绕过**：利用Pod Security Policies配置缺陷
- **API Server暴露**：利用公开暴露的Kubernetes API Server
- **etcd未授权访问**：利用未认证的etcd存储获取集群信息
- **Dashboard漏洞**：利用Kubernetes Dashboard配置缺陷

### 容器网络隔离不足
- **容器间通信滥用**：利用容器间默认互通的特性
- **网络策略缺失**：利用未配置NetworkPolicy的命名空间
- **服务发现滥用**：利用DNS服务发现机制枚举集群服务
- **流量转发绕过**：利用容器间流量转发绕过网络隔离

### 容器注册表安全
- **注册表未认证访问**：利用未配置认证的私有注册表
- **镜像标签篡改**：利用latest标签的不确定性
- **注册表凭证泄露**：从CI/CD配置中提取注册表凭证

## 相关工具
- **Trivy**：容器镜像漏洞扫描工具
- **kube-bench**：Kubernetes CIS基准测试
- **kube-hunter**：Kubernetes渗透测试工具
- **Falco**：容器运行时安全监控
- **Docker Bench Security**：Docker安全基准检测
- **Aqua Security**：容器安全平台

## 防御建议
- 不使用特权容器
- 使用受信任的基础镜像并定期更新
- 配置Pod安全标准和网络策略
- 开启Kubernetes RBAC审计日志
- 使用镜像签名和策略控制
- 实施运行时安全监控
