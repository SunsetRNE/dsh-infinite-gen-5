# 云DevOps安全

## 概述
DevOps安全关注CI/CD管道、代码仓库、自动化工具和配置管理在云环境中的安全风险。

## 常见攻击手法

### CI/CD管道安全
- **CI/CD配置泄露**：从CI/CD配置文件中提取凭证和密钥
- **管道注入攻击**：利用CI/CD环境变量注入恶意命令
- **构建过程篡改**：篡改构建过程中的依赖下载和编译步骤
- **制品篡改**：在构建产物中植入后门
- **部署权限滥用**：利用过度授权的部署角色提升权限

### 代码仓库泄露
- **公开仓库密钥扫描**：在公开代码仓库中搜索密钥和凭证
- **仓库历史泄露**：从git历史记录中提取已删除的敏感信息
- **分支保护绕过**：绕过分支保护规则直接推送代码
- **Webhook滥用**：利用代码仓库Webhook触发恶意CI/CD流水线

### 自动化工具漏洞
- **Terraform状态文件泄露**：获取包含基础设施状态的Terraform文件
- **Ansible Playbook泄露**：从Playbook中提取SSH密钥和密码
- **Packer镜像篡改**：篡改自动化镜像构建过程
- **Helm Chart安全漏洞**：利用Helm配置错误部署后门应用
- **配置管理后端攻击**：攻击Vault、Consul等配置管理工具

### 凭证管理不足
- **硬编码凭证**：在代码中硬编码云服务凭证
- **凭证共享**：共享服务账号或管理员凭证
- **凭证轮转缺失**：长期未更换泄露的凭证
- **Secret管理不当**：使用不安全的Secret存储方案

### 配置管理错误
- **基础设施即代码(IaC)安全漏洞**：Terraform/CloudFormation模板中的安全配置错误
- **配置漂移**：实际环境与配置管理记录不一致
- **环境差异**：开发/测试环境与生产环境配置不一致
- **变更管理缺失**：未经审核的配置变更导致安全事件

## 相关工具
- **GitLeaks**：git仓库密钥扫描
- **tfsec**：Terraform安全扫描
- **Checkov**：IaC安全扫描工具
- **Snyk**：依赖漏洞和配置扫描
- **Bridgecrew**：云基础设施安全
- **HashiCorp Vault**：密钥管理平台

## 防御建议
- 实施CI/CD管道安全扫描
- 使用预提交钩子防止密钥提交
- 应用最小权限的CI/CD角色
- 实施基础设施即代码(IaC)安全扫描
- 使用Secret管理工具管理凭证
- 实施变更审批流程
- 定期轮转凭证和密钥
