# 云原生安全

## 概述
云原生安全涉及基于容器、服务网格、微服务、声明式API等云原生技术架构的安全风险和防护。

## 常见攻击手法

### 云原生应用漏洞
- **微服务通信漏洞**：利用服务间通信机制的认证缺失
- **API网关滥用**：利用API网关配置错误绕过认证
- **服务网格TLS配置错误**：利用mTLS配置缺陷拦截通信
- **应用配置注入**：通过ConfigMap和Secret配置注入恶意配置
- **Sidecar代理攻击**：利用Envoy等Sidecar代理的配置漏洞

### 云原生API滥用
- **Kubernetes API滥用**：利用Kubernetes API Server配置漏洞
- **自定义资源定义(CRD)漏洞**：利用CRD中的安全隐患
- **Admission Webhook绕过**：绕过准入控制器检查
- **Operator漏洞利用**：利用Operator组件的高权限
- **CRD权限提升**：利用自定义资源的RBAC误配置提升权限

### 服务网格安全
- **Istio授权策略绕过**：绕过Istio AuthorizationPolicy
- **mTLS配置绕过**：利用PERMISSIVE模式跳过双向TLS
- **Envoy配置劫持**：修改Envoy代理的xDS配置
- **遥测数据篡改**：篡改服务网格的分布式追踪数据
- **服务入口滥用**：利用Ingress Gateway配置漏洞

### 云原生架构误配置
- **命名空间隔离不足**：利用命名空间之间的弱隔离
- **Pod安全标准绕过**：绕过Pod Security Standards限制
- **网络策略配置缺陷**：利用不完善的NetworkPolicy配置
- **存储类配置错误**：利用动态存储配置的安全漏洞
- **节点池隔离误配置**：利用节点配置差异进行攻击

### 云原生安全策略
- **OPA/Gatekeeper策略绕过**：绕过开放策略代理的约束规则
- **Kyverno策略滥用**：利用策略对特定资源的豁免
- **安全上下文约束缺失**：利用PodSecurityPolicy配置漏洞
- **合规策略验证缺失**：利用缺少的合规检查

## 相关工具
- **Kube-bench**：CIS Kubernetes基准测试
- **Kube-hunter**：K8s渗透测试工具
- **Istioctl analyze**：Istio配置分析
- **OPA Gatekeeper**：策略引擎工具
- **Kyverno**：Kubernetes策略引擎
- **Falco**：运行时安全监控

## 防御建议
- 启用服务网格的STRICT mTLS模式
- 配置细粒度的网络策略
- 使用OPA/Gatekeeper实施策略合规
- 实施Pod安全准入控制
- 定期进行安全审计和渗透测试
- 监控服务网格的遥测数据
- 限制Operator的权限范围
