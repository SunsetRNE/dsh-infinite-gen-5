# 云Serverless安全

## 概述
Serverless安全关注无服务器架构中函数权限、代码安全、事件源和架构层面的安全风险。

## 常见攻击手法

### 函数权限错误
- **IAM角色过度授权**：函数IAM角色权限过于宽泛
- **函数URL公开访问**：未认证的公开函数端点
- **资源访问控制缺失**：函数可访问超出需要的云资源
- **VPC权限误配置**：函数VPC配置可能导致网络隔离失效

### 函数代码注入
- **环境变量注入**：通过函数环境变量注入恶意代码
- **依赖包污染**：利用恶意依赖包注入后门
- **运行时命令注入**：在函数代码中执行用户控制的命令
- **文件操作类漏洞**：利用文件读写操作实现任意代码执行
- **反序列化攻击**：利用不安全的反序列化函数执行代码

### 事件源滥用
- **S3事件触发滥用**：通过向S3上传文件触发恶意操作链
- **DynamoDB流滥用**：利用DynamoDB Streams触发函数
- **SQS消息欺骗**：伪造SQS消息触发函数执行
- **API Gateway事件滥用**：利用API Gateway的请求参数注入
- **定时事件劫持**：利用CloudWatch Events触发的定时任务

### 无服务器架构滥用
- **资源耗尽攻击**：通过大量并发调用来消耗函数资源
- **冷启动利用**：利用函数冷启动阶段的安全漏洞
- **依赖链滥用**：利用函数之间的调用链进行横向移动
- **临时存储滥用**：利用/tmp目录进行恶意文件存储

### 无服务器函数滥用
- **函数递归调用**：利用函数无限递归调用造成成本消耗
- **函数超时利用**：利用长超时设置耗尽计算资源
- **并发限制绕过**：突破函数的并发执行限制

## 相关工具
- **Lambdaguard**：AWS Lambda安全审计
- **PureSec**：Serverless安全平台
- **Snyk**：开源依赖漏洞扫描
- **AWS Lambda Power Tuning**：函数性能分析
- **Serverless Framework**：无服务器框架安全配置

## 防御建议
- 为函数IAM角色配置最小权限
- 验证和清理所有函数输入参数
- 使用依赖扫描工具检查第三方库漏洞
- 设置函数并发限制和超时控制
- 启用函数日志和监控
- 加密函数环境变量中的敏感信息
- 使用危险函数替代方案
