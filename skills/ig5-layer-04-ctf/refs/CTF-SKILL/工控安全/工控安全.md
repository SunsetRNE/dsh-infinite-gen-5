# 工控安全知识库

## 概述
工业控制系统安全涉及SCADA、DCS、PLC等工控设备的安全性评估，涵盖网络、设备、物理等多维度的安全风险。

## 技能清单

| 技能 | 描述 |
|------|------|
| [信息搜集](工控信息搜集.md) | 设备信息搜集、网络拓扑信息搜集、协议信息搜集、系统信息搜集 |
| [网络](网络通信.md) | 未加密通信、协议漏洞、中间人攻击、流量分析、通信劫持 |
| [设备漏洞](工控设备漏洞.md) | 固件漏洞、默认密码、固件反编译、固件篡改、设备后门、设备越权访问 |
| [逻辑漏洞](工控逻辑漏洞.md) | 控制逻辑篡改、逻辑漏洞利用、PLC程序仿真、组态工程利用、逻辑缺陷、命令注入、权限提升、安全配置错误 |
| [物理安全](物理安全.md) | 物理访问控制、设备篡改、硬件调试接口、旁路攻击、物理破坏 |
| [补丁管理](补丁管理.md) | 补丁缺失、补丁管理不当、漏洞未修复、补丁回退 |
| [监控](安全监控.md) | 日志分析、入侵检测、异常行为检测、实时监控、事件响应 |
| [安全策略](安全策略.md) | 访问控制策略、身份认证策略、网络分段、安全审计、应急响应计划、安全培训 |
| [供应链](供应链安全.md) | 第三方组件漏洞、供应链攻击、供应商管理、组件篡改、供应链评估 |
| [恶意软件](恶意代码分析.md) | 反连木马、恶意程序操作 |
