# PWN 技能树 - CTF 二进制漏洞利用

## 概述

PWN 是 CTF 中最核心的类别之一，主要考察选手对二进制程序漏洞的挖掘与利用能力。PWN 涉及从底层内存操作到高级漏洞利用链构造的全过程，要求选手具备扎实的汇编基础、操作系统原理知识、调试能力和创造性思维。

本知识库将 PWN 技能划分为 8 大子类别，覆盖从入门到高阶的各类技术方向。

---

## 子类别总览

### 1. [内存破坏漏洞](内存破坏漏洞.md)
涵盖各类内存相关的漏洞类型，包括内存未初始化、内存溢出（堆/栈）、Off-by-One/Null、越界读写、内存泄露、Use-After-Free、Double Free、整数溢出等。这些是 PWN 中最基础也最频繁出现的漏洞类型。

### 2. [逻辑漏洞](二进制逻辑漏洞.md)
涉及程序逻辑层面的缺陷，包括条件竞争（Race Condition）、类型混淆（Type Confusion）、鉴权绕过、命令注入、信息泄露等。此类漏洞通常不依赖于传统的内存破坏，而是利用程序设计的缺陷。

### 3. [其他 PWN 技术](其他类型PWN.md)
涵盖无法归入传统分类的 PWN 技术，包括 IO_FILE 结构体利用、侧信道攻击、Shellcode 编写、Blind-PWN（盲打）、提权利用、解释器 PWN（Python/Lua/JS 引擎等）、Sandbox Escape、VM Escape、Browser PWN 等。

### 4. [栈溢出利用](栈漏洞利用.md)
栈相关的漏洞利用技术，包括 Ret2text、Ret2shellcode、Ret2syscall、Ret2libc、Ret2csu、Ret2VDSO、SROP（Sigreturn-Oriented Programming）、`dl_runtime_resolve` 利用、Stack Pivoting（栈迁移）、Canary 绕过等。

### 5. [堆漏洞利用](堆漏洞利用.md)
堆相关的漏洞利用技术，涵盖 Unlink 攻击、Fastbin Attack（Fastbin 伪造/双 Free）、Unsorted Bin Attack、Large Bin Attack、Tcache Attack（Tcache poisoning/dup）、Tcache Stashing Unlink Attack、House of 系列（House of Force/Spirit/Einherjar/Orange/Storm 等）、Musl-PWN、其他堆管理器（jemalloc 等）利用。

### 6. [格式化字符串漏洞](格式化字符串漏洞利用.md)
格式化字符串漏洞的利用技术，包括 32 位格式化字符串利用、64 位格式化字符串利用、栈上利用、非栈上利用、通过格式化字符串实现内存信息泄露等。

### 7. [内核漏洞利用](Linux内核漏洞利用.md)
Linux 内核级别的漏洞利用技术，包括内核堆风水（Heap Fengshui）、内核 Heap Spray、内核 UAF、内核 ROP、Bypass 内核保护机制（SMAP/SMEP/KASLR/Stack Canary）、Double Fetch 漏洞利用等。

### 8. [架构 PWN](异构PWN.md)
针对不同 CPU 架构的 PWN 技术，包括 ARM-PWN、AArch64-PWN、MIPS32-PWN、MIPS64-PWN、PowerPC-PWN、RISC-V-PWN 及其他少见架构的 PWN 技巧。

## 学习路径建议

| 阶段 | 内容 |
|------|------|
| 入门 | 栈溢出（Ret2text/Ret2shellcode）、基础格式化字符串、简单整数溢出 |
| 进阶 | Ret2libc/Ret2syscall、Canary 绕过、Tcache Attack、Unlink |
| 高阶 | House of 系列、内核利用、Browser PWN、VM Escape、多架构 PWN |

建议掌握 C/汇编基础后，先熟悉 Linux 下的 ELF 文件结构、GDB 调试、pwntools 使用，再逐步深入各类漏洞的利用细节。

## 常用工具

- **pwntools** - Python 编写的 CTF PWN 框架
- **GDB + pwndbg/GEF/PEDA** - 动态调试
- **one_gadget** - 查找 libc one_gadget
- **ROPgadget** - ROP 链搜索
- **seccomp-tools** - 沙箱规则检查
- **qemu-user** - 多架构模拟执行
- **angr / z3** - 符号执行与约束求解
