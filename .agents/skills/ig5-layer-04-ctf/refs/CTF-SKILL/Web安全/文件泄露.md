# 文件泄露

## 概述

文件泄露（File Leak）指由于配置不当、备份残留或调试信息未清除等原因导致的非授权文件访问。在 CTF 中，文件泄露通常是获取源代码、配置文件或敏感数据的突破口。常见的泄露类型包括版本控制系统泄露、备份文件泄露和 IDE 配置文件泄露等。

## 常见攻击手法

### 1. 源码文件泄露

- **Git 泄露**：`.git` 目录未配置访问限制，可通过 `GitHack`、`git_dumper` 等工具下载所有历史版本。使用 `git log` 查看提交历史并在老版本中查找被删除的敏感信息（如 flag、密码）。
  - 检测：访问 `/.git/HEAD` 返回 `ref: refs/heads/master`
  - 利用：`GitHack.py -u http://target.com/.git/`
- **SVN 泄露**：`.svn` 目录暴露，使用 `svn-extractor` 下载源码。
  - 检测：访问 `/.svn/entries`
- **DS_Store 泄露**：macOS 的 `.DS_Store` 文件暴露目录结构信息，使用 `ds_store_exp` 解析。
  - 检测：访问 `/.DS_Store`
- **Mercurial (hg) 泄露**：`.hg` 目录暴露，访问 `/.hg/`。

### 2. 备份文件泄露

- **编辑器备份**：常见的编辑器备份文件后缀如 `.swp`（Vim）、`.swo`、`.bak`、`~` 后缀文件。
  - 示例：访问 `index.php~`、`index.php.bak`、`index.php.swp`
- **压缩包备份**：网站源码备份文件如 `www.zip`、`www.tar.gz`、`backup.zip`、`web.zip`、`site.rar`。
  - 常见命名：`backup.zip`、`wwwroot.zip`、`code.zip`、`web.rar`
  - 下载后可能包含完整源码或数据库文件。
- **时间戳备份**：`.php.1`、`.php.old`、`.php.save` 等后缀。
- **配置文件泄露**：`.env`（环境变量文件）、`config.php`、`config.inc.php`、`database.php` 等包含数据库连接信息的文件。

### 3. 网站信息泄露

- **目录遍历**：Web 服务器未禁用目录列表时，可直接通过 URL 列出目录下所有文件。
  - Apache：`Options +Indexes`
  - Nginx：`autoindex on;`
- **调试接口**：
  - PHP 探针：`phpinfo.php`、`info.php`、`p.php`
  - 调试模式：`/debug`、`/console`（Laravel Debug）、Django Debug 页面
- **日志文件**：`access.log`、`error.log`、`install.log` 可能包含路径信息或测试数据。
- **phpMyAdmin**：`/phpmyadmin/`、`/admin/`、`/pma/` 等常见的数据库管理后台路径。

### 4. 其他泄露

- **API 文档泄露**：`/swagger.json`、`/api/docs`、`/api/swagger` 等可能暴露未预期的 API 接口。
- **源代码注释**：HTML/JS 中的注释泄露后端接口路径、数据库表结构、测试账号等。
- **GitHub 泄露**：搜索目标在 GitHub 上的仓库，查找密钥、配置文件或内部工具。

## 相关工具

| 工具 | 用途 |
|------|------|
| GitHack / git_dumper | 恢复 .git 泄露的源码 |
| dvcs-ripper | SVN/Git 等版本控制泄露利用 |
| ds_store_exp | 解析 .DS_Store 文件 |
| dirsearch / gobuster | 目录扫描 |
| ffuf | 快速模糊测试 |

## 防御建议

- 禁止版本控制目录（.git、.svn）的 Web 访问
- 不要在 Web 目录存放备份压缩包
- 禁用目录列表功能
- 生产环境关闭调试模式
- 定期清理临时文件、编辑缓存和日志文件

## CTF 中的常见考点

- 通过 `.git` 泄露获取完整源码和历史提交中的 flag
- 下载 `www.zip` 获得网站源码，审计发现漏洞
- `index.php.bak` 获取备份源码
- `.DS_Store` 泄露目录结构，找到隐藏页面
