# AI 信息搜集

## 概述
AI信息搜集是AI安全评估的第一步，旨在获取目标AI系统的模型架构、训练数据、API接口、部署环境等信息，为后续攻击和评估奠定基础。

## 常见手法

### 模型信息搜集
- **模型架构推断**：通过分析模型输出维度、推理时间等侧信道信息推断模型架构
- **API行为探测**：通过构造不同输入观察输出规律，推断模型类型和参数规模
- **模型文档搜集**：从公开文档、论文、GitHub仓库等渠道获取模型技术细节
- **模型文件分析**：分析公开的模型权重文件（如PyTorch的.pth、TensorFlow的.pb）获取架构信息

### 数据集信息搜集
- **公开数据集识别**：查找目标模型可能使用的公开训练数据集
- **数据分布推断**：通过查询分析模型对不同输入的响应，推测训练数据分布
- **数据来源追溯**：分析模型输出特征，追溯训练数据中可能包含的特定样本
- **数据泄露检测**：检测模型是否意外泄露了训练数据中的敏感信息

### 元数据搜集
- 分析模型文件的元数据（创建时间、框架版本、硬件要求等）
- 从模型卡（Model Card）和文档中提取安全相关信息
- 搜集模型发布者的其他项目和历史版本信息

## 相关工具
- **Ghidra/IDA Pro**：逆向分析模型文件格式
- **Netron**：可视化神经网络模型结构
- **Frida**：动态分析模型推理过程
- **Custom Scripts**：基于Python的模型API探测脚本
- **Wireshark**：捕获分析模型API通信流量

## 防御建议
- 限制模型API的访问频率和查询深度
- 对模型文件进行加密和混淆处理
- 最小化公开文档中的技术细节披露
- 实施严格的访问控制和认证机制
- 监控异常查询模式，检测信息搜集行为
