# 以太坊信息搜集

## 概述
以太坊信息搜集是区块链安全分析的基础，通过收集智能合约和账户信息来识别潜在的安全风险。

## 常见手法

### 智能合约信息搜集
- **合约代码获取**：从Etherscan等区块链浏览器获取已验证的合约源码
- **字节码分析**：反编译未验证合约的字节码(EVM bytecode)
- **ABI接口提取**：从合约交易数据中推断ABI接口定义
- **合约事件分析**：分析合约的Event日志了解合约行为
- **合约存储布局**：分析合约的存储布局获取状态变量信息
- **合约依赖分析**：识别合约调用的外部合约和库
- **编译器版本识别**：从字节码元数据中识别编译器版本
- **优化设置分析**：识别合约编译时的优化设置

### 账户信息搜集
- **地址余额查询**：查询以太坊地址的ETH余额
- **代币余额查询**：查询地址持有的ERC20/ERC721等代币
- **交易数量统计**：统计地址的发起的交易总数
- **账户类型识别**：区别外部账户(EOA)和合约账户
- **nonce值获取**：获取地址的交易计数(nonce)
- **代码哈希**：获取合约账户的代码哈希
- **代币授权查询**：查询地址对DApp的Token授权情况
- **关联账户发现**：通过交易图发现关联账户

### 链上数据搜集
- **交易历史**：获取地址的完整交易记录
- **内部交易**：分析合约调用产生的内部转账
- **事件日志**：搜索和过滤特定合约的Event日志
- **区块信息**：获取区块的时间戳、Gas使用等
- **存储证明**：获取合约特定存储槽的值
- **交易追踪**：追踪交易完整的执行路径

### 链下信息搜集
- **项目文档**：目标项目的白皮书、技术文档
- **GitHub代码**：目标项目的开源代码库
- **社交媒体**：Discord、Twitter等社区信息
- **审计报告**：第三方安全审计报告
- **漏洞赏金**：历史漏洞和修复记录

## 相关工具
- **Etherscan**：以太坊区块链浏览器
- **Etherscan API**：区块链数据API
- **Dedaub**：合约反编译工具
- **the_ethereum_explorer**：链上分析工具
- **Ethereum-etl**：以太坊数据导出工具
- **Dune Analytics**：链上数据分析平台
- **Tenderly**：交易模拟和调试

## 防御建议
- 在Etherscan上验证并开源合约源码
- 删除编译元数据中的敏感信息
- 谨慎管理合约的管理员权限
- 定期监控合约的异常活动
- 避免在合约中硬编码敏感信息
