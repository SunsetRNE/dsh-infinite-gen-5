# IoT 信息搜集

## 概述
IoT信息搜集是物联网安全评估的基础，包括对IoT设备、固件、通信协议和无线信号的全面信息收集。

## 常见手法

### 设备信息搜集
- **设备型号识别**：通过外观、标签、包装识别设备型号
- **硬件接口探测**：识别设备的UART、JTAG、SPI、I2C等调试接口
- **芯片信息获取**：识别主控芯片、Wi-Fi芯片、存储芯片型号
- **操作系统识别**：通过网络指纹或固件分析识别设备操作系统
- **应用层协议识别**：识别设备的应用层通信协议
- **Web管理接口**：发现设备的Web管理界面和版本
- **移动APP分析**：分析设备配套的移动应用获取API接口

### 固件信息搜集
- **固件下载**：从厂商官网获取设备固件
- **固件更新机制**：分析设备的OTA固件更新机制
- **固件格式识别**：识别固件的文件格式(cramfs、squashfs、JFFS2等)
- **Bootloader信息**：分析设备的bootloader类型(U-Boot、RedBoot等)
- **固件版本历史**：收集固件的版本发布历史和安全更新
- **固件签名分析**：分析固件签名验证机制

### 协议分析
- **网络协议识别**：识别设备使用的MQTT、CoAP、HTTP、WebSocket等协议
- **专有协议分析**：逆向分析厂商自定义的通信协议
- **协议版本探测**：确定协议版本和实现细节
- **协议加密分析**：分析通信是否加密及加密方式
- **数据包结构分析**：分析协议数据包的结构和字段

### 无线信号分析
- **频率扫描**：扫描设备使用的无线通信频率
- **调制方式识别**：识别信号的调制方式(FSK、QPSK、OFDM等)
- **信号强度测量**：测量设备无线信号的强度和范围
- **协议栈识别**：识别无线通信的协议栈
- **时序分析**：分析无线通信的时序规律

## 相关工具
- **Wireshark**：网络协议分析
- **Aircrack-ng**：无线网络分析
- **GNU Radio**：软件无线电分析
- **HackRF**：SDR硬件平台
- **RTL-SDR**：软件定义无线电
- **Nmap**：网络和设备扫描
- **Firmwalker**：固件信息提取
- **Binwalk**：固件分析工具

## 防御建议
- 禁用调试接口(UART/JTAG)
- 加密固件和通信数据
- 实施安全的固件更新机制
- 最小化信息泄露(标签、Web界面)
- 使用安全的协议版本
- 对无线通信实施加密
