# 物联网安全知识库

## 概述
物联网安全涵盖IoT设备固件分析、无线通信安全、硬件接口攻防等多个领域，是CTF中硬件与嵌入式安全的核心方向。

## 技能清单

| 技能 | 描述 |
|------|------|
| [信息搜集](物联网信息搜集.md) | 设备信息搜集、固件信息搜集、协议分析、无线信号分析 |
| [固件分析](固件分析.md) | 固件提取、固件解包、固件逆向、固件补丁分析、固件签名验证、固件解密 |
| [网络](物联网网络安全.md) | 端口扫描、服务枚举、漏洞扫描、协议漏洞利用、中间人攻击、DoS攻击 |
| [无线](无线安全.md) | Wi-Fi安全、Bluetooth安全、Zigbee安全、NFC安全、RF信号分析 |
| [设备漏洞](物联网设备漏洞.md) | 默认密码利用、硬编码密码、命令注入、缓冲区溢出、权限提升、未授权访问、固件更新劫持、硬件调试接口、物理访问攻击、侧信道攻击、数据泄露、配置错误、传感器欺骗、设备克隆、设备劫持 |
