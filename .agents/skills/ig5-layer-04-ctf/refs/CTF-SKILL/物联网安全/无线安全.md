# IoT 无线安全

## 概述
IoT无线安全涉及物联网设备使用的各种无线通信技术的安全性，包括Wi-Fi、Bluetooth、Zigbee、NFC和RF信号分析。

## 常见攻击手法

### Wi-Fi安全
- **WPA2/WPA3破解**：使用字典攻击或PMKID攻击破解Wi-Fi密码
- **WPS漏洞利用**：利用WPS的PIN码暴力破解漏洞
- **Evil Twin攻击**：创建伪造的Wi-Fi热点窃取凭据
- **Deauth攻击**：发送取消认证帧断开设备连接
- **802.11协议漏洞**：利用Wi-Fi协议实现的安全漏洞
- **企业Wi-Fi攻击**：攻击WPA2-Enterprise的认证机制
- **Wi-Fi Direct攻击**：利用Wi-Fi Direct的安全配置缺陷
- **Wi-Fi定位跟踪**：通过Wi-Fi信号定位和跟踪设备

### Bluetooth安全
- **蓝牙经典(BR/EDR)攻击**：
  - **BlueBorne漏洞**：利用蓝牙协议栈的远程代码执行漏洞
  - **蓝牙嗅探**：捕获蓝牙通信数据进行分析
  - **蓝牙Pin码破解**：暴力破解蓝牙配对PIN码
  - **蓝牙重放攻击**：重放捕获的蓝牙数据包
- **蓝牙低功耗(BLE)攻击**：
  - **BLE嗅探**：使用Ubertooth等工具捕获BLE通信
  - **BLE MITM攻击**：拦截并修改BLE通信
  - **BLE信道嗅探**：跳频序列跟踪和信道嗅探
  - **BLE泛洪攻击**：发送大量BLE请求耗尽设备资源
  - **MAC地址追踪**：跟踪BLE设备的MAC地址

### Zigbee安全
- **Zigbee嗅探**：捕获Zigbee无线通信数据包
- **Zigbee密钥提取**：从设备中提取网络密钥和链路密钥
- **Zigbee重放攻击**：重放Zigbee控制命令
- **Zigbee设备加入攻击**：在设备加入网络时进行攻击
- **Zigbee信道干扰**：干扰Zigbee的通信信道
- **Zigbee协议漏洞**：利用Zigbee协议实现的安全漏洞
- **Touchlink攻击**：利用Zigbee Touchlink的物理接近特性

### NFC安全
- **NFC数据窃取**：通过接近读取NFC标签中的数据
- **NFC重放**：捕获并重放NFC通信数据
- **NFC克隆**：克隆NFC标签或卡片
- **NFC中间人攻击**：在NFC通信中拦截和修改数据
- **NFC支付攻击**：攻击NFC支付终端的安全机制
- **NFC中继攻击**：远程中继NFC通信突破位置限制

### RF信号分析
- **频率扫描**：使用SDR扫描设备使用的RF频率
- **调制分析**：分析RF信号的调制方式
- **解码解调**：解调RF信号还原控制数据
- **RF重放攻击**：捕获并重放RF遥控信号
- **Rolling Code攻击**：破解遥控器的滚动码机制
- **RF信号干扰**：使用RF信号干扰设备通信
- **Sub-1GHz分析**：分析433MHz/868MHz/915MHz频段信号
- **胎压监测(TPMS)攻击**：拦截和伪造胎压监测数据

## 防御建议
- 使用最新的加密协议(WPA3、BLE 5.x)
- 实施设备配对时的安全认证
- 加密无线通信数据
- 使用滚动码技术防止重放攻击
- 定期更新无线协议栈固件
- 禁用不必要的无线功能
- 实施信号强度和距离检测
- 使用安全的密钥分发机制
