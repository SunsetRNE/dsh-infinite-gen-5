# IoT 固件分析

## 概述
固件分析是IoT安全的核心技术，通过对设备固件的提取、解包、逆向和漏洞分析，发现固件中的安全缺陷。

## 常见手法

### 固件提取
- **物理提取**：通过SPI Flash编程器直接读取Flash芯片内容
- **JTAG/SWD提取**：通过调试接口读取固件
- **串口引导提取**：通过U-Boot命令行从串口导出固件
- **OTA抓包提取**：捕获OTA更新数据包还原固件
- **厂商网站下载**：从厂商支持页面下载固件
- **APP资源提取**：从移动APP中提取固件资源
- **逻辑分析提取**：通过分析通信总线时序提取固件

### 固件解包
- **文件系统提取**：使用Binwalk提取文件系统(cramfs、squashfs等)
- **压缩固件解压**：识别并解压压缩的固件(gzip、lzma等)
- **固件头部分析**：分析固件头部结构获取加载地址、校验信息
- **加密固件解密**：分析加密算法并解密固件
- **固件拼接**：将分区固件拼接为完整固件
- **文件提取后分析**：分析解包后的配置文件、Web资源、二进制文件

### 固件逆向
- **二进制程序分析**：使用IDA Pro、Ghidra逆向设备二进制程序
- **配置文件分析**：分析配置文件中的密码、密钥、API端点
- **Web接口分析**：分析固件中的Web服务端代码
- **硬编码信息提取**：提取硬编码的密码、密钥、Token
- **漏洞挖掘**：在逆向过程中发现缓冲区溢出、命令注入等漏洞
- **后门分析**：分析是否存在隐藏的后门功能

### 固件补丁分析
- **补丁对比分析**：比较不同版本的固件识别安全修复
- **补丁逻辑理解**：分析补丁修复的安全漏洞细节
- **未公开漏洞发现**：通过补丁分析发现尚未公开的安全漏洞
- **补丁缺失验证**：验证最新固件是否完整修复了已知漏洞

### 固件签名验证
- **签名算法识别**：识别固件签名使用的算法(RSA、ECDSA、HMAC等)
- **签名绕过技术**：寻找签名验证的逻辑缺陷
- **公钥提取**：从固件中提取签名验证的公钥
- **签名伪造**：在私钥已知的情况下伪造签名
- **降级攻击**：强制设备使用未签名的旧版本固件

### 固件解密
- **加密算法逆向**：逆向分析固件的加解密算法
- **密钥获取**：从设备硬件或APP中提取解密密钥
- **侧信道攻击**：通过功耗分析等方式获取解密密钥
- **静态分析破译**：通过静态分析获取加密/解密方法
- **动态调试解密**：通过JTAG等接口动态调试获取解密后数据

## 相关工具
- **Binwalk**：固件分析和提取
- **Ghidra**：固件逆向分析
- **IDA Pro**：反汇编和逆向
- **Firmwalker**：固件内容搜索
- **Firmadyne**：固件仿真
- **QEMU**：CPU模拟执行
- **Flashrom**：Flash芯片读写
- **OpenOCD**：JTAG调试
- **Firmware Analysis Toolkit**：固件分析工具包
- **FMK(Firmware Mod Kit)**：固件修改工具包

## 防御建议
- 使用强加密保护固件内容
- 实施可信启动链验证
- 安全的固件签名机制
- 禁用设备的调试接口
- 实施反逆向工程保护(代码混淆)
- 不硬编码敏感信息
- 定期进行固件安全审计
