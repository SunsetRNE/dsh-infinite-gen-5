# 社会工程学

## 概述
社会工程学是利用人类心理弱点获取信息或系统访问权限的攻击技术，是渗透测试中的重要组成部分。

## 常见攻击手法

### 钓鱼攻击
- **鱼叉式钓鱼(Spear Phishing)**：针对特定个人或组织的定制化钓鱼攻击
- **CEO诈骗(Whaling)**：针对高层管理人员的钓鱼攻击
- **克隆钓鱼(Clone Phishing)**：克隆合法邮件并进行篡改后发送
- **商业邮件诈骗(BEC)**：冒充CEO/CFO要求紧急转账
- **短信钓鱼(Smishing)**：通过短信发送钓鱼链接
- **语音钓鱼(Vishing)**：通过电话进行语音钓鱼
- **QR码钓鱼(Quishing)**：通过QR码指向钓鱼网站
- **水坑攻击(Watering Hole)**：感染目标经常访问的网站
- **诱饵攻击(Baiting)**：使用诱饵(如U盘)诱导目标
- **鱼叉式短信(Spear Smishing)**：针对特定目标的短信钓鱼

### 钓鱼攻击流程
- **信息收集**：收集目标个人信息、工作信息、联系人等
- **钓鱼场景设计**：设计可信的钓鱼场景和话术
- **钓鱼平台搭建**：搭建钓鱼网站或伪造登录页面
- **邮件/消息制作**：制作逼真的钓鱼邮件或消息
- **攻击执行**：向目标发送钓鱼邮件或消息
- **数据收集**：收集目标的凭证或敏感信息
- **后续利用**：使用获取的信息进行进一步攻击

### 冒充攻击
- **技术支持冒充**：冒充IT技术支持要求提供密码
- **执法机构冒充**：冒充警察或调查人员要求配合
- **合作伙伴冒充**：冒充业务合作伙伴发送恶意文件
- **供应商冒充**：冒充供应商要求更新支付信息
- **同事冒充**：冒充同事请求紧急操作
- **权威机构冒充**：冒充银行、税务等机构的官方通知
- **招聘冒充**：冒充招聘人员发送恶意附件
- **身份伪造**：伪造身份证明获取信任

### 垃圾邮件
- **恶意附件邮件**：发送包含恶意宏的Office文档
- **恶意链接邮件**：发送指向恶意网站的链接
- **社交工程邮件**：利用紧急、好奇等心理诱导点击
- **定向广告邮件**：发送高度定制的广告邮件
- **假通知邮件**：发送虚假的账户异常、订单确认等通知
- **恶意订阅**：让目标订阅大量垃圾邮件掩盖重要通知
- **邮件洪水攻击**：用大量邮件淹没目标邮箱

### 物理入侵
- **尾随攻击(Tailgating)**：跟随授权人员进入受限区域
- **冒充维修人员**：冒充维修、清洁等工作人员
- **冒充访客**：冒充合作伙伴或客户访问
- **肩窥攻击(Shoulder Surfing)**：偷窥屏幕或键盘输入
- **垃圾搜索(Dumpster Diving)**：在垃圾桶中搜索敏感文件
- **BadUSB攻击**：放置包含恶意固件的USB设备
- **内部威胁利用**：利用内部人员的信任关系

### 社交媒体攻击
- **虚假账号建立**：创建虚假的社交媒体账号建立信任
- **信息收集**：通过社交平台收集目标个人信息
- **社交关系分析**：分析目标的社交关系网络
- **个人问题利用**：利用目标在社交平台流露的个人问题
- **虚假招聘**：通过虚假招聘信息获取个人信息
- **假社交圈**：建立虚假的社交圈接近目标
- **社交平台漏洞**：利用平台的隐私设置漏洞

### 诱骗攻击
- **U盘诱饵攻击**：在停车场等场所放置含恶意程序的U盘
- **充电站欺骗**：在公共充电站植入恶意设备
- **Wi-Fi热点欺骗**：建立虚假Wi-Fi热点诱骗连接
- **文件共享陷阱**：在P2P网络中放置诱惑文件名
- **虚假奖品**：用虚假的中奖信息诱导点击
- **紧急情况利用**：利用灾难、疫情等紧急情况进行诈骗
- **技术支持诈骗**：谎称检测到病毒诱导安装恶意软件

### 恶意软件传播
- **鱼叉式邮件附件**：发送包含恶意宏的文档
- **驱动下载(Drive-by Download)**：在恶意网站自动下载恶意软件
- **恶意广告(Malvertising)**：通过在线广告传播恶意软件
- **软件捆绑**：将恶意软件捆绑在合法软件中
- **社会工程学下载**：诱导用户下载并运行恶意程序
- **伪造软件更新**：提示用户安装伪造的软件更新
- **恶意Chrome扩展**：诱导用户安装恶意浏览器扩展

### 恶意链接
- **URL混淆**：使用同形异义字、短链接等技术隐藏真实URL
- **URL重定向**：使用合法的重定向服务指向恶意网站
- **链接伪装**：在文字链接中隐藏不同的实际URL
- **iframe注入**：在合法页面中嵌入恶意iframe
- **剪贴板劫持**：诱导用户粘贴恶意链接

### 恶意附件
- **恶意宏文档**：包含恶意宏的Office文档
- **恶意PDF**：包含恶意JavaScript或漏洞利用的PDF
- **恶意压缩包**：包含恶意文件的压缩包
- **双扩展名文件**：利用双扩展名隐藏真实文件类型
- **自解压文件**：执行后自动释放恶意文件的SFX包
- **恶意脚本附件**：.vbs、.js、.bat等恶意脚本
- **恶意快捷方式**：包含恶意命令的LNK文件

## 防御建议
- 实施员工安全意识培训计划
- 定期进行钓鱼模拟测试
- 建立邮件安全网关过滤恶意邮件
- 实施多因素认证(MFA)
- 建立社交工程事件报告机制
- 限制公开暴露的员工信息
- 实施物理访问控制措施
- 不信任未知来源的USB设备
- 对重要操作实施双人审批
- 建立快速响应和处理机制
- 使用DMARC/DKIM/SPF防止邮件伪造
