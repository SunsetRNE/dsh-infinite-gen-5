# 数据安全知识库

## 概述
数据安全关注数据在全生命周期中的保密性、完整性和可用性，涵盖数据识别、传输、存储、使用、销毁等环节。

## 技能清单

| 技能 | 描述 |
|------|------|
| [信息搜集](数据信息搜集.md) | 数据识别、数据分类与分级、数据资产盘点 |
| [数据传输](数据传输.md) | 数据加密、传输协议安全 |
| [数据存储](数据存储.md) | 数据库安全分析、文件系统安全、数据备份与恢复、数据完整性校验 |
| [数据使用](数据使用.md) | 访问控制、数据脱敏、数据生命周期管理 |
| [DLP](数据泄露防护.md) | 数据泄露检测、数据泄露响应、数据泄露追踪 |
| [隐私](隐私保护.md) | 个人信息保护、隐私合规检查、隐私风险评估 |
| [数据销毁](数据销毁.md) | 数据清洗、数据擦除、数据销毁验证 |
