# 工控监控安全

## 概述
工控监控安全涉及工业控制系统的日志分析、入侵检测、异常行为监控和事件响应等安全监控技术。

## 常见分析内容

### 日志分析
- **PLC日志分析**：分析PLC的诊断缓冲区和系统日志
- **HMI日志审计**：分析HMI的操作记录和报警日志
- **SCADA日志分析**：分析SCADA服务器的事件日志和审计记录
- **历史数据库日志**：分析实时历史数据库的变更记录
- **网络设备日志**：分析交换机、防火墙等网络设备的日志
- **工控防火墙日志**：分析工控防火墙的规则匹配记录
- **OPC服务器日志**：分析OPC服务器的访问日志

### 入侵检测
- **基于签名的检测**：使用已知攻击特征检测入侵行为
- **基于异常的检测**：通过建立基线检测偏离正常的行为
- **工控协议深度检测**：分析工控协议的数据内容
- **功能码异常检测**：检测异常的Modbus功能码使用
- **寄存器访问模式**：检测异常的寄存器访问模式
- **命令序列分析**：分析控制命令的执行序列
- **ICS-Snort规则**：使用专门的工控Snort规则

### 异常行为检测
- **网络流量基线**：建立工控网络的流量基线模型
- **通信频率异常**：检测异常的通信频率和间隔
- **数据值异常**：检测传感器数据的突变成异常值
- **设备行为异常**：检测设备的异常行为模式
- **时序异常检测**：检测控制指令的时序异常
- **协议合规检测**：检测协议实现是否合规

### 实时监控
- **网络流量监控**：实时监控工控网络的通信流量
- **设备状态监控**：实时监控PLC、RTU等设备的运行状态
- **工业协议监控**：实时监控工控协议的通信内容
- **资产变动监控**：监控网络中的资产新增和变更
- **性能指标监控**：监控网络延迟、吞吐量等性能指标
- **告警实时推送**：将安全告警实时推送到安全运营中心

### 事件响应
- **事件确认**：确认安全事件的真伪和严重程度
- **影响评估**：评估安全事件对生产的影响范围
- **应急隔离**：隔离受影响的工控系统
- **证据收集**：收集事件相关的日志和流量数据
- **事件分析**：分析事件的攻击路径和手段
- **恢复计划**：制定系统恢复的操作步骤
- **事后复盘**：总结事件原因和改进建议

## 相关工具
- **Wireshark**：网络协议分析
- **Snort/Suricata**：入侵检测系统
- **Splunk/ELK**：日志管理和分析
- **GRASSMARLIN**：工控网络可视化和分析
- **Nozomi Networks**：工控安全监控
- **Claroty**：工控网络安全
- **Dragos Platform**：工控威胁检测
- **QRadar**：安全信息和事件管理(SIEM)

## 防御建议
- 部署工控专用的入侵检测系统
- 建立工控网络的流量基线
- 实施7x24小时的安全监控
- 建立工控安全事件响应团队
- 定期进行安全监控演练
- 集成多源安全数据进行分析
