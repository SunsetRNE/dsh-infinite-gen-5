# 工控物理安全

## 概述
工控物理安全关注工业控制系统现场设备的物理安全防护，包括访问控制、设备篡改、硬件接口攻击等。

## 常见攻击手法

### 物理访问控制
- **机柜门锁破解**：打开未上锁或使用万能钥匙可打开的机柜
- **机房入侵**：通过社会工程学或安防漏洞进入控制室
- **设备面板操作**：直接操作设备面板获取信息或修改参数
- **标签信息利用**：从设备标签获取型号、序列号、IP地址等信息
- **维护记录分析**：获取设备维护记录了解系统弱点

### 设备篡改
- **传感器替换**：用恶意传感器替换现场传感器
- **执行器干扰**：干扰或破坏执行器的正常工作
- **信号线搭接**：在信号线上搭接窃听设备
- **电源干扰**：对PLC、RTU等设备进行电源干扰
- **接地线篡改**：修改设备接地引发电气干扰

### 硬件调试接口
- **JTAG接口利用**：通过JTAG/SWD接口读取或写入固件
- **UART串口访问**：通过UART串口获取设备Shell
- **SPI/I2C总线探测**：通过调试总线读取存储器数据
- **测试点利用**：利用PCB上的测试点分析信号
- **边界扫描(Boundary Scan)**：通过JTAG边界扫描分析PCB

### 旁路攻击
- **功耗分析(SPA/DPA)**：通过分析设备功耗曲线提取密钥
- **电磁辐射分析**：通过电磁辐射分析获取设备内部信号
- **时序分析**：通过分析运算时间推断密钥信息
- **故障注入攻击**：通过电源毛刺、时钟毛刺等诱导设备出错
- **声波侧信道**：通过设备运行的声音推断内部状态

### 物理破坏
- **设备物理破坏**：锤击、水浸、火烧等方式破坏设备
- **通信线路切断**：切断PLC和SCADA之间的通信线路
- **电源中断**：切断或中断工控设备的电源供应
- **环境攻击**：改变温度、湿度等环境条件导致设备异常
- **电磁干扰(EMI)**：使用强电磁场干扰设备正常运行

- **Saleae Logic Analyzer**：逻辑分析仪
- **USBee**：USB协议分析
- **ChipWhisperer**：侧信道分析平台
- **OpenOCD**：JTAG调试软件
- **Oscilloscope**：示波器信号分析
- **Logic Analyzer**：逻辑分析仪

## 防御建议
- 实施严格的物理访问控制
- 加固机柜和设备的物理安全
- 禁用生产环境的调试接口
- 使用防篡改封条和传感器
- 部署视频监控和入侵检测
- 实施设备防篡改检测机制
- 培训员工物理安全意识和应急响应
