# 工控恶意软件

## 概述
工控恶意软件是专门针对工业控制系统设计的恶意程序，包括反连木马、破坏性恶意软件和信息窃取程序。

## 常见类型

### 反连木马
- **工控协议隧道木马**：使用Modbus、S7等工控协议建立隐蔽通信隧道
- **SCADA反向连接**：从工控网络内部主动向外部C2服务器建立连接
- **PLC后门通信**：利用PLC的通信模块建立反连通道
- **HMI木马**：在HMI中植入使用工控协议通信的木马
- **防火墙隧道绕过**：使用OOB(out-of-band)通信绕过工控防火墙

### 恶意程序操作
- **工控数据窃取**：窃取PLC程序、组态工程、工艺参数等敏感数据
- **控制逻辑破坏**：修改或删除PLC中的控制逻辑程序
- **传感器数据伪造**：向SCADA发送伪造的传感器读数
- **报警系统禁用**：禁用或修改报警系统配置
- **历史数据篡改**：修改历史数据库中的数据
- **HMI画面篡改**：修改HMI操作界面欺骗操作员

### 已知工控恶意软件分析
- **Stuxnet(震网)**：首个针对工控系统的恶意软件，破坏伊朗核离心机
- **BlackEnergy(黑暗力量)**：针对乌克兰电力系统的恶意软件
- **Industroyer(CrashOverride)**：针对电力变电站的恶意软件
- **TRITON(Trisis)**：针对SIS安全仪表系统的恶意软件
- **Pipedream(Incontroller)**：多工控协议的恶意软件框架
- **Havex**：通过工控软件供应链传播的恶意软件

### 恶意软件传播方式
- **USB介质传播**：通过U盘等可移动存储设备传播
- **供应链传播**：通过软件或固件更新传播
- **邮件钓鱼传播**：通过网络钓鱼邮件传播
- **远程连接传播**：通过远程维护通道传播
- **横向移动**：在工控网络内部横向移动
- **云连接传播**：通过工控系统的云连接传播

### 恶意软件检测分析
- **静态分析**：分析恶意软件的文件结构、代码特征
- **动态分析**：在受控环境中运行分析恶意软件行为
- **网络行为分析**：分析恶意软件的通信流量特征
- **工控协议特征**：分析恶意软件使用的工控协议命令
- **内存取证**：从系统内存中提取恶意软件样本
- **IOC提取**：提取妥协指标(IOC)用于检测

## 防御建议
- 实施工控网络与应用层白名单
- 禁用USB和可移动存储设备
- 实施严格的网络分段和隔离
- 部署工控网络入侵检测系统
- 建立恶意软件检测和响应机制
- 限制工控系统的互联网连接
- 定期进行恶意软件扫描和清理
- 建立工控系统备份和恢复机制
