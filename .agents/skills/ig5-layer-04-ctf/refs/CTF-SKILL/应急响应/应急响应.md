# 应急响应知识库

## 概述
应急响应涵盖安全事件发生后的日志分析、流量分析、入侵排查等技术环节，是CTF中取证与溯源方向的核心内容。

## 技能清单

| 技能 | 描述 |
|------|------|
| [日志分析](应急日志分析.md) | Windows日志分析、Linux日志分析、数据库日志分析、容器日志分析、其它应用日志分析 |
| [流量分析](流量分析.md) | 数据通信协议流量分析、Web攻击流量分析、远控通信流量分析、数据泄漏流量分析、数据加密流量分析、综合攻击类型事件流量分析 |
| [入侵排查](入侵排查.md) | Web失陷事件入侵排查、勒索病毒事件入侵排查、挖矿木马事件入侵排查、系统后门事件入侵排查、容器失陷事件入侵排查、综合攻击类型事件入侵排查 |
