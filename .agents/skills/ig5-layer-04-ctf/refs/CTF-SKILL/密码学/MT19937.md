# MT19937 梅森旋转算法

## 概述

MT19937（Mersenne Twister 19937）是由松本眞和西村拓士在 1997 年设计的伪随机数生成器。其名称来源于周期为 $2^{19937} - 1$（梅森素数）。MT19937 是 Python 和许多其他语言的默认 PRNG（`random` 模块）。虽然具有良好的统计特性，但 MT19937 不是密码学安全的随机数生成器。CTF 中常出现利用其可预测性的题目。

**内部状态**：
- 624 个 32 位整数（总状态 19968 位）
- 索引指针 $i$（当前使用的位置）

**生成过程**：
1. **初始化**：由种子生成 624 个状态字
2. **扭转（Twist）**：每生成 624 个随机数后，状态被"扭转"更新
3. **提取（Temper）**：从当前状态字通过线性变换生成输出值

## 常见攻击手法

### 随机数恢复（State Recovery from Outputs）

给定连续的 MT19937 输出，可以恢复完整的内部状态。

**原理**：
MT19937 的 tempering 阶段是可逆的。给定一个输出值 $o$，可以通过逆向 tempering 变换恢复对应的状态字 $s$。

**攻击步骤**：
1. 收集 624 个连续的 32 位输出
2. 对每个输出逆向 tempering 操作
3. 得到完整的 624 个状态字
4. 可以精确预测之后的所有输出

**Python `random` 模块攻击**：
```python
import random

# 恢复状态
def untemper(y):
    # 逆向 Megumi Tempering
    y ^= y >> 18
    y ^= (y << 15) & 0xEFC60000
    # 逆向 y ^= (y << 7) & 0x9D2C5680
    y ^= (y << 7) & 0x9D2C5680
    y ^= (y << 14) & 0x42D83F80  # 补偿
    # 逆向 y ^= y >> 11
    y ^= y >> 11
    y ^= y >> 22  # 补偿
    return y

# 读取 624 个随机数
# 假设通过某种方式获得了 624 个连续输出
rand_vals = []
state = [0] * 624
for i in range(624):
    state[i] = untemper(rand_vals[i])
```

### 随机数预测（Prediction）

一旦恢复内部状态，就可以继续生成后续的所有随机数并准确预测。

**应用场景**：
- 预测后续抽奖/验证码
- 预测密钥生成
- 预测加密中的 nonce 或盐值

### 部分状态恢复（Partial State Recovery）

当无法获得全部 624 个连续输出时，可以使用观察到的部分输出结合其他信息恢复状态。

- **非连续输出**：需要额外的暴力搜索
- **部分位输出**：如只输出低 16 位，需要更多样本

### 种子恢复（Seed Recovery）

当种子空间很小时（如 `time.time()` 作为种子），可暴力搜索种子。

## 防御建议

MT19937 不适合密码学用途：
- 密码学随机数使用 `os.urandom()`、`secrets` 模块
- 使用系统 CSPRNG（如 Windows 的 CryptGenRandom）
- 使用 ChaCha20 等密码学安全的 PRNG
