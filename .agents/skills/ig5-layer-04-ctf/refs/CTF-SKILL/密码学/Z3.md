# Z3 求解器

## 概述

Z3 是微软研究院开发的强大约束求解器（SMT Solver），支持整数、位向量、布尔值、数组、字符串等多种类型的约束求解。在 CTF 密码学题目中，Z3 广泛应用于密码分析、方程求解、约束满足等场景。与暴力破解不同，Z3 通过逻辑推理和数学方法高效地搜索解空间。

## 主要功能

### 位向量求解（BitVec）
对固定位宽的整数进行运算和约束求解，适用于密码算法中的位操作。

```python
from z3 import *
x = BitVec('x', 32)
s = Solver()
s.add(x ^ 0xDEADBEEF == 0x12345678)
print(s.check())
print(s.model())
```

### 整数求解（Int）
对整数域进行约束求解。

```python
x, y, y = Ints('x y z')
s = Solver()
s.add(x + y + z == 100, x > y, y > z, z > 0)
```

### 布尔求解（Bool）
命题逻辑公式求解。

### 数组求解（Array）
支持数组索引和更新的约束求解。

### 字符串求解（String）
Z3 的 Seq 和 String 排序支持字符串约束，可用于逆向和密码分析。

## 常见应用场景

### 解密方程组
当加密过程可表示为约束方程组时，使用 Z3 直接求解满足条件的变量（如密钥、明文）。

**适用场景**：
- 线性/非线性方程混合的加密系统
- 有限域上的多项式方程
- 位运算密集的加密算法（AES、MD5 等的逆向分析）

### 密码分析
用于分析加密算法的特性，如寻找碰撞、分析差分传播等。

### 逆向工程
配合符号执行工具（如 angr），Z3 可用作约束求解后端。

### 预测随机数
对 LCG、MT19937 等 PRNG，将输出作为约束，求解内部状态。

## 使用技巧

1. **类型选择**：位操作使用 BitVec，数学运算使用 Int/Real
2. **变量声明**：根据问题域选择合适的类型和位宽
3. **约束添加**：逐步添加约束并检查可解性
4. **性能优化**：
   - 使用 `set_param()` 调整求解策略
   - 拆解复杂约束为简单约束
   - 使用 `solver.seeding()` 结果进行符号简化
5. **多解获取**：找到一个解后，添加排除约束继续求解

## 相关工具

- **`z3-solver` (pip)**：Python API
- **`angr`**：符号执行框架，Z3 作为后端

## 防御建议

Z3 是分析工具，不能直接防止。密码系统应基于经过验证的困难问题，不依赖运算本身的难以分析性。

## 示例思路

```python
from z3 import *

# 逆向一个简单的 XOR + ADD 加密
flag_len = 10
flag = [BitVec(f'f_{i}', 8) for i in range(flag_len)]

# 加密过程约束
cipher = [0x4A, 0x5B, 0x6C, 0x7D, 0x8E, ...]  # 已知密文
key = 0x55

s = Solver()
for i in range(flag_len):
    s.add((flag[i] ^ key) + i == cipher[i])

# 添加可打印字符约束
for i in range(flag_len):
    s.add(Or(And(flag[i] >= 0x20, flag[i] <= 0x7E), flag[i] == 0))

if s.check() == sat:
    model = s.model()
    result = ''.join(chr(model[flag[i]].as_long()) for i in range(flag_len))
    print(f"Decrypted: {result}")
```
