# 加法密码（Additive Cipher）

## 概述

加法密码是最简单的替换密码，通过将字母在字母表中的位置加上一个固定偏移量（密钥 k）来加密。数学上表示为 $E(x) = (x + k) \mod 26$。凯撒密码（Caesar Cipher）是 ROT3 的特例，ROT13 是偏移 13 的特殊版本。

## 常见种类

### 凯撒密码（Caesar Cipher）
偏移量为 3 的加法密码。Julius Caesar 曾用来传递军事信息。密文特征：字母被平移，但保留字母本身的结构。

### ROT13
偏移量为 13 的加法密码。由于 13 × 2 = 26，ROT13 加密一次和解密一次是相同的操作（对合）。常用于论坛隐藏剧透内容。

### ASCII 移位
对 ASCII 码值进行加减操作，不限于字母范围。例如 `ord(c) + n` 或 `ord(c) - n`。范围可以是 0-127 或 0-255。

## 常见攻击手法

### 暴力破解（Brute Force）
加法密码只有 25 种可能的偏移（对于字母表），可以尝试所有偏移并检查哪个产生有意义的明文。手工可尝试偏移 1-25，自动化可用 Python 脚本。

### 词频分析
对于较长文本，即使不知道偏移量，也可以通过英文字母频率（E、T、A、O 等最高频）推断出偏移。

### ASCII 移位分析
如果密文包含非字母字符（如标点、数字），需要考虑 ASCII 范围内的移位。需要根据上下文判断移位的范围和方向。

## 相关工具

## 防御建议

加法密码在现代安全中毫无用处，只有 25 个有效密钥，可瞬间暴力破解。不应在任何安全场景中使用。

## 示例思路

```
密文: WKH HDJOH LV LQ WKH QHAW URRP
尝试偏移 3 解密 (每个字母减 3):
W→T, K→H, H→E, 空格, H→E, D→A, J→G, O→L, H→E, ...
得到: THE EAGLE IS IN THE NEXT ROOM
```

Python 实现：
```python
cipher = "WKH HDJOH LV LQ WKH QHAW URRP"
for shift in range(26):
    plain = ''.join(chr((ord(c)-65-shift)%26+65) if c.isalpha() else c for c in cipher)
    if 'THE' in plain:
        print(f"shift={shift}: {plain}")
```
