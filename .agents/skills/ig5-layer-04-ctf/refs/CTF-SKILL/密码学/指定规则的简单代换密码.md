# 简单替换密码（Simple Substitution Cipher）

## 概述

简单替换密码是古典密码中最通用的一类，每个明文字母被替换为另一个字母，映射关系是任意的双射（置换）。相比加法密码和仿射密码，其密钥空间更大（26! ≈ 4×10²⁶），但依然可以通过词频分析等方法破解。

## 常见种类

### 埃特巴什码（Atbash Cipher）
将字母表反转映射：A→Z, B→Y, C→X, ... , Z→A。实际上是仿射密码在 $a=-1, b=25$ 时的特例（或 $a=25, b=25$）。对对合密码，加密和解密相同。常出现在圣经密码、古典文献和 CTF 签到题中。

### Keyword Cipher
用关键字生成替换表：先写出关键字（去重），然后按字母顺序补全剩余字母。例如关键字 CIPHER，则映射表为 `C I P H E R A B D F G J K L M N O Q S T U V W X Y Z`。

### 随机替换密码
完全随机的字母映射，密钥空间最大，但也是词频分析的标准目标。

## 常见攻击手法

### 词频分析（Frequency Analysis）
英文文本的字母频率特征在替换后仍然保留。常见策略：
1. 单字母频率：E > T > A > O > I > N > S > H > R ...
2. 双字母频率（Digram）：TH, HE, IN, ER, AN, RE, ED, ON, ES, ST, EN, AT, TO, NT, HA, ND, OU, EA, NG, AL
3. 三字母频率（Trigram）：THE, AND, THA, ENT, ION, TIO, FOR, NDE, HAS, NCE

### 模式匹配
- 重复字母模式：如 `TT`、`LL`、`SS` 等常见双写
- 单词模式：如 `XYYX` 模式的词可能是 THAT、BEEN 等
- 短词识别：单字母词只能是 A 或 I，三字母词 THE 可能性极高

### 字典辅助
用字典文件（如 `/usr/share/dict/words`）匹配部分解密结果，提高准确率。

### 爬山法（Hill Climbing）
用随机替换表开始，通过交换映射表中的字母对来逐步提高与英文频率分布的匹配度。

## 相关工具

- **quipqiup.com**：自动破解任意替换密码的最佳在线工具
- **CyberChef**：Atbash、Substitution 模块
- **Python**：字典映射、频率统计
- **`pycipher`** 库：支持多种古典密码

## 防御建议

简单替换密码在现代完全不安全。词频分析和模式匹配可在几秒内破解任意长度的密文。必须使用多表密码（如维吉尼亚）或现代加密标准。

## 示例思路

```
埃特巴什码: 密文 "ZGYZHSR"
A↔Z, B↔Y, C↔X, ...
Z→A, G→T, Y→B, Z→A, H→S, S→H, R→I
得到: ATBASHI (即 ATBASH)
```

Keyword Cipher 破解思路：
```python
# 构建 keyword 替换表
keyword = "CIPHER"
key = ''.join(dict.fromkeys(keyword.upper() + 'ABCDEFGHIJKLMNOPQRSTUVWXYZ'))
# key = CIPHERABDFGJKLMNOQSTUVWXYZ
# 然后建立映射解密即可
```
