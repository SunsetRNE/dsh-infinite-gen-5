# 密钥交换（Key Exchange）

## 概述

密钥交换是公钥密码学的重要应用之一，允许两方在不安全的通信信道上协商出一个共享密钥。最著名的密钥交换协议是 Diffie-Hellman 密钥交换（DHKE），其安全性基于离散对数问题的难解性。在 CTF 中，密钥交换题目主要围绕参数选择不当和实现缺陷展开。

## 常见种类

### Diffie-Hellman 密钥交换（DHKE）

由 Whitfield Diffie 和 Martin Hellman 在 1976 年提出，是第一个公钥密码协议。

**协议流程**：
1. 选择公开参数大素数 $p$ 和生成元 $g$
2. Alice 选择私钥 $a$，计算公钥 $A = g^a \bmod p$ 发送给 Bob
3. Bob 选择私钥 $b$，计算公钥 $B = g^b \bmod p$ 发送给 Alice
4. Alice 计算 $s = B^a \bmod p = g^{ab} \bmod p$
5. Bob 计算 $s = A^b \bmod p = g^{ab} \bmod p$
6. 双方共享密钥 $s$

### 椭圆曲线 Diffie-Hellman（ECDH）
将 DH 协议迁移到椭圆曲线上，使用 ECC 点乘代替模幂运算。

**协议**：$s = a \times Q_b = b \times Q_a$，其中 $Q_a = a \times G$，$Q_b = b \times G$（$G$ 为基点）。

### 三方 Diffie-Hellman
将 DH 扩展到三方，通过一轮通信协商共享密钥。

### 静态-临时 DH（Static-Ephemeral DH）
一方使用固定的静态密钥，另一方使用临时密钥。

## 常见攻击手法

### 小参数攻击
当 $p$ 很小时（< 512 位），攻击者可求解离散对数恢复私钥，从而算出共享密钥。

### 中间人攻击（MITM）
若 DH 交换未经认证，攻击者可拦截并替换公钥，与双方分别建立密钥。

### 小群攻击（Small Subgroup Attack）
当 $p-1$ 有多个小素因子时，攻击者将公钥限制在小阶子群中，通过 CRT 恢复私钥。

### 静态私钥重用
若一方使用固定的私钥 $a$ 与多个对方通信，攻击者可通过 $A = g^a$ 计算 $g^{ab}$。

### 生成元选择攻击
若 $g$ 的阶很小（如 $g = 1$ 或 $g = p-1$），共享密钥被完全控制。

### 无效曲线攻击（针对 ECDH）
攻击者提供不在约定曲线上的点，使 ECDH 在小阶曲线上执行，泄露私钥信息。

## 相关工具

- **`pycryptodome`**：`Crypto.Protocol.DH`
- **`sage`**：离散对数、ECC 运算
- **`OpenSSL`**：DH 参数生成
- **`gmpy2`**：模幂运算

## 防御建议

- 使用足够大的参数（$p \geq 2048$ 位）
- 使用安全素数（$p = 2q + 1$）防止小群攻击
- 验证收到的公钥在正确的群中
- 使用认证密钥交换（如 SIGMA、STS 协议）防止 MITM
- 优先使用 ECDH 和 Curve25519

## 示例思路

```python
# 小 p 的 DH 破解
p = 0x...  # p 较小
g = 2
A = 0x...  # Alice 公钥
B = 0x...  # Bob 公钥

# 解离散对数恢复私钥
from sage.all import *
a = discrete_log(Mod(A, p), Mod(g, p))
# b = discrete_log(Mod(B, p), Mod(g, p))
s = pow(B, a, p)  # 共享密钥
```
