# 离散对数问题（Discrete Logarithm）

## 概述

离散对数问题（DLP）是现代密码学的基础安全假设之一。给定一个有限循环群 $G$、生成元 $g$ 和元素 $y = g^x$，求整数 $x$。DLP 的困难性是 ElGamal、Diffie-Hellman、DSA 等算法安全性的基础。在 CTF 中，当参数选择不当时，DLP 可以在可接受的时间内求解。

## 常见攻击手法

### 暴力破解（Brute Force）
最直接的方法，尝试所有可能的 $x$ 直到找到 $g^x \equiv y \pmod{p}$。仅当 $x$ 的范围很小时可行。时间复杂度 $O(n)$，空间复杂度 $O(1)$。

### Baby-step Giant-step（BSGS）
Shanks 算法，是时间-空间权衡的经典。将 $x$ 表示为 $x = i \times m + j$ 其中 $m = \lceil \sqrt{n} \rceil$。先计算所有 $g^j$ 存入哈希表，再搜索 $y \times (g^{-m})^i$。时间复杂度 $O(\sqrt{n})$，空间复杂度 $O(\sqrt{n})$。适用于阶在 $2^{20}$ 到 $2^{40}$ 之间的群。

### Pollard's rho 算法
使用 Floyd 判圈算法检测伪随机序列中的碰撞。不需要大存储空间，时间复杂度 $O(\sqrt{n})$，空间复杂度 $O(1)$。是 BSGS 的存储友好替代方案。

### Pollard's kangaroo 算法
也称为 Pollard's lambda 算法，当 $x$ 在某个区间 $[a, b]$ 内时特别有效。设置"驯服袋鼠"和"野生袋鼠"两个伪随机游走序列，寻找碰撞。时间复杂度 $O(\sqrt{b-a})$。

### Pohlig-Hellman 算法
当群阶 $N$ 可分解为小素数的乘积 $N = \prod p_i^{e_i}$ 时，利用中国剩余定理将 DLP 分解为小群上的 DLP。先在子群中求解再组合。是 $p-1$ 有小素因子时的首选攻击方法。

## 防御建议

- 使用安全素数：$p = 2q + 1$，其中 $q$ 为大素数
- 群的阶应有大素因子（≥256 位）
- 使用椭圆曲线群替代乘法群
- 不使用小参数群的 DLP 方案

## 示例思路

```python
# Baby-step Giant-step
def bsgs(g, y, p):
    n = p - 1  # 群的阶
    m = int(n**0.5) + 1
    table = {}
    cur = 1
    for j in range(m):
        table[cur] = j
        cur = cur * g % p
    factor = pow(g, -m, p)
    cur = y
    for i in range(m):
        if cur in table:
            return i * m + table[cur]
        cur = cur * factor % p
    return None
```
