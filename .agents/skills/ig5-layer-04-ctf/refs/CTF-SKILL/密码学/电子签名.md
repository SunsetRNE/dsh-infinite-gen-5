# 数字签名（Digital Signature）

## 概述

数字签名是公钥密码学的核心应用之一，用于验证消息的完整性、真实性和不可否认性。签名者使用私钥签名，验证者使用公钥验证。在 CTF 中，数字签名相关的题目常考察签名的代数性质、重用随机数、哈希使用不当等问题。

## 常见种类

### RSA 数字签名
使用 RSA 算法进行签名和验证。

**签名**：$\sigma = H(m)^d \bmod n$
**验证**：$H(m) \equiv \sigma^e \pmod{n}$

**常见攻击**：
- **签名同态伪造**：$\sigma_1 \times \sigma_2 \equiv \text{sign}(m_1 \times m_2) \pmod{n}$
- **Blinding 攻击**：若签名预言机对任意消息签名（不检查格式），可恢复 $m$ 的签名
- **PKCS1 填充攻击**：对未正确填充的签名进行数学操作

### ElGamal 数字签名
ElGamal 签名方案基于离散对数问题。

**签名**：选择随机 $k$，$r = g^k \bmod p$，$s = (H(m) - x \times r) \times k^{-1} \bmod (p-1)$
**验证**：$g^{H(m)} \equiv y^r \times r^s \pmod{p}$

**常见攻击**：
- **$k$ 重用**：恢复私钥
- **$k$ 已知**：恢复私钥
- **通用伪造**：选择 $e, v$ 构造合法的 $(r, s)$

### DSA 数字签名
DSA 是美国 NIST 标准的签名算法。

**签名**：$r = (g^k \bmod p) \bmod q$，$s = k^{-1}(H(m) + x \times r) \bmod q$
**验证**：$u_1 = H(m) \times s^{-1} \bmod q$，$u_2 = r \times s^{-1} \bmod q$，验证 $r \equiv (g^{u_1} \times y^{u_2} \bmod p) \bmod q$

**常见攻击**：已知 $k$ 攻击、$k$ 重用攻击、$k$ 偏置攻击（详见 DSA 专题）

### 盲签名（Blind Signature）
签名者在不了解消息内容的情况下签名。攻击者可利用盲签名恢复敏感信息或构造欺诈签名。

### 环签名（Ring Signature）
签名者可以代表一个群体签名而不泄露具体身份。匿名性分析是 CTF 考点。

## 常见攻击手法

### 同态性质滥用
利用 RSA 签名的乘法同态性，通过合法签名的乘积构造新签名。

### 已知签名攻击（Known Signature Attack）
攻击者知道多个消息的签名，利用代数关系构造新签名。

### 存在伪造（Existential Forgery）
使用选择的 $r$ 和 $s$ 反向计算消息，使验证通过（对于某些签名方案）。

## 相关工具

- **`pycryptodome`**：`Crypto.Signature` 模块
- **`openssl dgst`**：命令行签名验证
- **`gmpy2`**：大数运算

## 防御建议

- 使用 PSS 填充（RSA-PSS）防止乘法同态攻击
- 签名时使用独立的随机数生成器
- 使用 EdDSA 等现代签名方案
- 哈希和签名之间使用安全填充

## 示例思路

```python
# RSA 签名同态攻击
# 已知公钥 (n, e) 和两个消息的签名
# sign(m1) = pow(m1, d, n), sign(m2) = pow(m2, d, n)
# 则 sign(m1 * m2 mod n) = sign(m1) * sign(m2) mod n

s1 = pow(m1, d, n)  # 已知
s2 = pow(m2, d, n)  # 已知
s_new = (s1 * s2) % n  # 这就是 m1*m2 mod n 的签名
```
