# 多表替换密码（Polyalphabetic Cipher）

## 概述

多表替换密码使用多个替换表来加密明文，每个位置的字母使用不同的替换规则，从而有效抵抗词频分析。多表密码的安全性远高于单表替换，在 16 世纪到 19 世纪被认为是不可破解的。CTF 中常见的多表密码包括维吉尼亚密码、Playfair 密码、希尔密码等。

## 常见种类

### 维吉尼亚密码（Vigenère Cipher）
最经典的多表密码。使用关键字控制每个位置的偏移量。加密：$C_i = (P_i + K_{i \bmod len(K)}) \bmod 26$。解密：$P_i = (C_i - K_{i \bmod len(K)}) \bmod 26$。

### Playfair 密码
使用 5×5 密钥矩阵（I 和 J 合并），以双字母为单位加密。将明文分组为两字母一组，加密规则取决于两字母在矩阵中的位置（同行、同列或矩形）。

### 棋盘密码（Polybius Square / Checkerboard）
5×5 网格，每个字母用行号和列号表示。可用关键字扰乱网格顺序增强安全性。

### 关键字密码（Keyword Cipher）
同上述简单替换中的 Keyword Cipher，但可与多表结合。

### 希尔密码（Hill Cipher）
基于线性代数的加密方法，使用 $n \times n$ 密钥矩阵将 $n$ 个明文字母加密为 $n$ 个密文字母。加密：$C = P \times K \bmod 26$。要求密钥矩阵在 $\bmod 26$ 下可逆。

### 自动密钥密码（Autokey Cipher）
密钥由关键字和明文本身组合而成，避免了维吉尼亚密码的周期性特征。加密：$C_i = (P_i + K_i) \bmod 26$，其中 $K_i$ 为关键字后接明文。

### 二方密码（Two-Square Cipher）
使用两个 5×5 矩阵进行加密，类似 Playfair 的变体，但使用两个不同的矩阵。

### 四方密码（Four-Square Cipher）
使用四个 5×5 矩阵，加密时同时使用两个密钥矩阵和两个固定位置矩阵。

## 常见攻击手法

### 维吉尼亚密码破解
1. **Kasiski 测试**：查找密文中重复的片段，计算重复片段之间的距离，取最大公约数猜测密钥长度
2. **重合指数法（Index of Coincidence）**：计算不同偏移下的重合指数，确定密钥长度
3. ** Friedman 测试**：用公式 $k \approx \frac{0.0265n}{0.065 - I_c + 0.0365n}$ 估算密钥长度
4. **确定密钥长度后**：对每列进行词频分析破解

### 希尔密码破解
- **已知明文攻击**：若知道 $n$ 组明密文对，可建立线性方程组求解密钥矩阵
- **唯密文攻击**：困难，需要结合词频分析和矩阵特性

### Playfair 破解
- 已知明文攻击：用明密文对恢复密钥矩阵
- 配合词频和双字母频率分析

## 防御建议

多表密码在现代已不满足安全要求，维吉尼亚密码可通过 Kasiski 测试破解，希尔密码密钥空间有限。现代应用应使用 AES 等经过验证的对称加密算法。

## 示例思路

```
维吉尼亚密码密文: "WFQJXHXQHWW"
已知密钥为 "CTF"：
C=2, T=19, F=5
W-2=U, F-19=R, Q-5=L, J-2=H, X-19=E, H-5=C, ...
得到: URLHEC...
```

Kasiski 测试 Python 实现：
```python
def find_repeats(cipher, min_len=3):
    repeats = {}
    for i in range(len(cipher) - min_len):
        seq = cipher[i:i+min_len]
        pos = cipher.find(seq, i+min_len)
        if pos != -1:
            gap = pos - i
            repeats.setdefault(gap, []).append(seq)
    return repeats
```
