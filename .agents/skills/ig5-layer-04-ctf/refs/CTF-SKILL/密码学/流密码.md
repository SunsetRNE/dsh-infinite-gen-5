# 流密码 XOR

## 概述

流密码（Stream Cipher）对明文逐位（或逐字节）与密钥流进行加密，最常见的操作是 XOR（异或）。XOR 加密的数学原理非常简单：$c = m \oplus k$。由于 XOR 的可逆性，解密与加密相同：$m = c \oplus k$。流密码的安全完全依赖于密钥流的不可预测性和一次性使用。

## 常见攻击手法

### 密钥流重用攻击
流密码最致命的错误：使用相同的密钥 $k$ 加密两条不同的消息 $m_1$ 和 $m_2$：
$$c_1 \oplus c_2 = (m_1 \oplus k) \oplus (m_2 \oplus k) = m_1 \oplus m_2$$
若知道一条消息中的部分内容，可恢复对应位置的另一条消息。

### 已知明文攻击
若知道明文 $m$ 和密文 $c$，可以直接恢复密钥流：$k = m \oplus c$。

### 部分已知明文攻击
若知道明文的某些固定模式（如 HTTP 请求头的 `GET`、文件头的 `%PDF`），可推测对应位置的密钥流。

### 多消息 XOR 攻击
多条消息共享同一密钥流时：使用差分分析和统计方法恢复所有明文。

### 选择明文攻击
若攻击者可以控制加密的输入，直接得到特定位置的密钥流。

### 频率分析
若密钥流是伪随机的但存在统计偏置（如 RC4 的偏置），可利用统计方法恢复明文。

### 猜测-确认攻击
通过猜测单词恢复密钥流，再用恢复的密钥流解密其他部分，验证猜测的正确性。

## 防御建议

- 密钥流**永不重用**（One-time pad 精神）
- 使用安全的密钥流生成器（AES-CTR、ChaCha20）
- 使用认证加密防止篡改
- 结合 nonce/IV 确保每次加密使用不同的密钥流

## 示例思路

```python
def xor(a, b):
    return bytes(x ^ y for x, y in zip(a, b))

# 密钥流重用攻击
c1 = bytes.fromhex("...")
c2 = bytes.fromhex("...")
xor_pt = xor(c1, c2)  # m1 ^ m2

# 若已知某个消息的片段
known_part = b"FLAG{"
key_stream = xor(c1, known_part)  # 恢复对应位置的密钥流
# 解密 c2 的对应位置
m2_part = xor(c2, key_stream)

# 使用常见词恢复更多
# 假设恢复位置通常是英文单词，尝试不同的词语组合
```

```python
# 多消息 XOR（m个消息）恢复
# 统计每列中空格出现次数，可恢复所有消息
import string

# 假设每行（消息）长度相同
def recover_xor(ciphertexts):
    msg_length = max(len(c) for c in ciphertexts)
    key = bytearray(msg_length)
    # 对每个位置，统计常见字符
    for pos in range(msg_length):
        candidates = []
        for c in ciphertexts:
            if pos < len(c):
                k = c[pos] ^ ord(' ')
                if chr(k) in string.printable:
                    candidates.append(k)
        # 选择最常见的候选
        key[pos] = max(set(candidates), key=candidates.count)
    return bytes(key)
```
