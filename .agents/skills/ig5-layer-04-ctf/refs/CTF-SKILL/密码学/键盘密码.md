# 键盘密码（Keyboard Cipher）

## 概述

键盘密码利用计算机或手机键盘的布局来编码信息。这类密码利用了人机交互界面的特征，具有不易被自动化工具识别的特点。CTF 中常见的键盘密码根据使用设备和坐标系的不同有多种变体。

## 常见种类

### 手机键盘密码（Mobile Keyboard Cipher / T9 Cipher）
利用手机九宫格键盘（旧式手机 T9 输入法），每个数字对应多个字母：2=ABC, 3=DEF, 4=GHI, 5=JKL, 6=MNO, 7=PQRS, 8=TUV, 9=WXYZ。两种编码方式：
- **单数字编码**：数字代表按键次数，如 `22` 表示 B（按键 2 两次）
- **按键序列**：数字序列如 `43556` → "HELLO"

### 电脑键盘棋盘密码（Keyboard Grid Cipher）
将键盘按键按行列坐标编码。例如 QWERTY 键盘第一行 QWERTYUIOP，第二行 ASDFGHJKL，第三行 ZXCVBNM。每个字母用 (行,列) 坐标表示。

### 电脑键盘坐标加密（Keyboard Coordinate Cipher）
直接用键盘上的位置坐标（如 X,Y 坐标）来表示按键。通常以 Q 为原点 (0,0) 建立坐标系。

### 电脑键盘 QWE 加密（QWE Cipher）
将键盘 QWERTY 布局映射到 ABCDEF... 顺序。如键盘上 Q 的位置对应 A，W 对应 B，E 对应 C，依此类推。解密时将密文字母在 QWERTY 键盘上的位置映射为标准字母表顺序。

### 键盘布局加密（Dvorak Cipher）
利用 QWERTY 和 Dvorak 两种键盘布局的差异进行编码。例如 QWERTY 的字母在 Dvorak 布局下对应不同的字母。

### Dvorak 键盘加密
将 Dvorak 键盘布局作为映射表进行替换加密。在 QWERTY 键盘上按 Dvorak 布局击键时会得到不同的字母输出。

## 常见攻击手法

### 手机键盘解码
将数字序列按 T9 输入法规则映射回字母。注意多义性：同一数字序列可能对应多个单词。

### QWE 映射还原
建立 QWERTY 键盘位置到 ABC 顺序的映射表：
```
Q→A, W→B, E→C, R→D, T→E, Y→F, U→G, I→H, O→I, P→J,
A→K, S→L, D→M, F→N, G→O, H→P, J→Q, K→R, L→S,
Z→T, X→U, C→V, V→W, B→X, N→Y, M→Z
```

### 坐标解码
根据给定的键盘布局和坐标系统，定位每个坐标对应的字符。

## 防御建议

键盘密码不是安全的加密方法，只是基于布局的编码变换。不应在真实安全场景中使用。

## 示例思路

```
QWE 密文: ITSSG → 键盘映射: I→H, T→E, S→L, S→L, G→O → "HELLO"

手机键盘密文: 43556 → 4=GHI, 3=DEF, 5=JKL, 5=JKL, 6=MNO
根据上下文确定: 4按两次→H, 3按两次→E, 5按三次→L, 5按三次→L, 6按三次→O → "HELLO"
```

```python
# QWE decoder
qwe_map = {'Q':'A','W':'B','E':'C','R':'D','T':'E','Y':'F','U':'G',
           'I':'H','O':'I','P':'J','A':'K','S':'L','D':'M','F':'N',
           'G':'O','H':'P','J':'Q','K':'R','L':'S','Z':'T','X':'U',
           'C':'V','V':'W','B':'X','N':'Y','M':'Z'}
ciph = "ITSSG"
print(''.join(qwe_map.get(c, c) for c in ciph))  # HELLO
```
