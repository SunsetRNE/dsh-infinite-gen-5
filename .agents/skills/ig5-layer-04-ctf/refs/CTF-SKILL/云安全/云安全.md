# 云安全知识库

## 概述
云安全涵盖云基础设施、平台和服务的安全评估与攻击技术，包括IaaS、PaaS、SaaS各层的安全风险。

## 技能清单

| 技能 | 描述 |
|------|------|
| [信息搜集](云信息搜集.md) | 云服务信息枚举、云服务配置文件收集、云服务元数据收集 |
| [IAM](身份与访问管理.md) | 弱口令攻击、权限提升、多因素认证绕过、API密钥泄露、临时凭证滥用、角色切换攻击 |
| [网络](云网络安全.md) | VPC配置错误、安全组配置错误、云防火墙绕过、云网络流量分析 |
| [数据保护](数据保护.md) | 数据存储加密不足、数据传输加密不足、数据泄露监测、云存储权限错误、快照和备份泄露 |
| [容器](容器安全.md) | 容器逃逸、镜像漏洞利用、不安全的容器编排、容器网络隔离不足、容器注册表安全 |
| [Serverless](无服务器计算.md) | 函数权限错误、函数代码注入、事件源滥用、无服务器架构滥用、无服务器函数滥用 |
| [监控](监控与日志.md) | 日志配置错误、日志泄露、监控绕过、日志篡改 |
| [DevOps](DevOps安全.md) | CI/CD管道安全、代码仓库泄露、自动化工具漏洞、凭证管理不足、配置管理错误 |
| [云原生](云原生安全.md) | 云原生应用漏洞、云原生API滥用、服务网格安全、云原生架构误配置、云原生安全策略 |
| [合规](合规与审计.md) | 合规性检查、安全审计、事件响应、风险评估、合规报告生成 |
| [第三方](第三方服务.md) | 第三方API安全、第三方服务配置错误、外部依赖管理、第三方服务漏洞、第三方服务监控 |
| [灾难恢复](灾难恢复.md) | 备份策略、恢复计划测试、灾难恢复演练、业务连续性计划、灾难恢复自动化 |
