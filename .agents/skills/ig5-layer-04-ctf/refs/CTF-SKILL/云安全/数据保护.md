# 云数据保护

## 概述
云数据保护关注云环境中数据的存储安全、传输安全和访问控制，确保数据在存储和传输过程中保持机密性、完整性和可用性。

## 常见攻击手法

### 数据存储加密不足
- **未加密存储桶**：利用未启用默认加密的S3存储桶
- **弱加密算法**：使用AES-256之外的不安全加密算法
- **密钥管理漏洞**：利用KMS密钥策略配置错误解密数据
- **客户端加密绕过**：绕过客户端加密直接访问底层存储
- **快照未加密**：利用未加密的数据快照获取敏感信息

### 数据传输加密不足
- **HTTP而非HTTPS**：利用使用HTTP的非加密传输通道
- **TLS版本过低**：利用TLS 1.0/1.1等过时协议
- **证书验证缺失**：利用未正确验证证书的客户端
- **内部网络未加密**：利用VPC内部未加密的流量

### 数据泄露监测
- **存储桶公开访问检测**：发现公开可读的云存储桶
- **数据外传监控**：监控异常的数据下载和传输行为
- **API数据泄露识别**：分析API响应中的敏感数据
- **第三方数据共享检测**：识别与未授权第三方的数据共享

### 云存储权限错误
- **公开读写存储桶**：利用配置为公开读写的S3存储桶
- **ACL配置错误**：利用存储桶ACL中的错误权限
- **对象级权限绕过**：利用继承的桶策略绕过对象级权限
- **跨账户访问滥用**：利用配置不当的跨账户访问策略
- **临时URL泄露**：利用泄露的预签名URL获取文件访问权限

### 快照和备份泄露
- **公开快照**：发现并利用公开的EBS/RDS快照
- **备份泄露**：从备份文件中提取敏感信息
- **版本控制漏洞**：利用S3版本控制访问被覆盖或删除的数据
- **跨区域备份泄露**：利用备份复制的配置错误

## 相关工具
- **S3Scanner**：S3存储桶扫描工具
- **Bucket Stream**：存储桶发现工具
- **CloudSploit**：云存储安全检查
- **ScoutSuite**：多云安全配置审计
- **AWS Macie**：数据敏感信息识别

## 防御建议
- 默认启用存储桶加密
- 实施最低权限访问策略
- 使用AWS Macie等工具自动发现敏感数据
- 启用S3 Block Public Access
- 定期审计存储桶权限和访问日志
- 使用数据分类和标记策略
- 实施数据生命周期管理
