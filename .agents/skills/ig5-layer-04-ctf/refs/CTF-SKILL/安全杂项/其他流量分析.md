# 其他流量分析（Other Traffic Analysis）

## 概述

除 Web 流量和 USB 流量外，CTF 中还涉及各种网络协议和通讯协议的流量分析。这些题目涵盖从应用层协议到硬件通讯协议的广泛范围。分析这些流量需要了解协议规范、数据包结构和通信流程。

## 常见类型

### 网络协议

#### FTP 流量分析
FTP（File Transfer Protocol）传输文件时使用明文通信，命令和数据分离。

**分析要点**：
- 用户名和密码（USER/PASS 命令）
- 传输的文件内容（通过数据连接）
- PORT/PASV 模式

**Wireshark 过滤**：
```
ftp
ftp.request.command == "USER" or ftp.request.command == "PASS"
```

#### ICMP 流量分析
ICMP 用于网络诊断（ping/tracert），可被用于隐写。

**分析方法**：
- Ping 包的数据部分可能包含隐藏信息
- ICMP 时间戳字段
- ICMP 包大小和间隔的隐写

**Wireshark 过滤**：`icmp`

#### SMTP 流量分析
SMTP 用于电子邮件传输。

**分析要点**：
- 发件人/收件人（MAIL FROM/RCPT TO）
- 邮件标题（Subject）
- 邮件正文和附件
- Base64 编码的附件

**Wireshark 过滤**：`smtp`

#### Telnet 流量分析
Telnet 是明文的远程登录协议。

**分析要点**：
- 登录凭据（用户名、密码）
- 执行的命令和输出

**Wireshark 过滤**：`telnet`

#### SMB 流量分析
SMB（Server Message Block）用于 Windows 文件共享。

**分析要点**：
- 文件传输内容
- SMB 管道通信
- SMB 版本（SMB1/2/3）

**Wireshark 过滤**：`smb` 或 `smb2`

#### ADB 流量分析
ADB（Android Debug Bridge）用于 Android 调试。

**分析要点**：
- ADB 命令和数据
- Shell 命令和输出
- 文件传输

**Wireshark 过滤**：`adb`

#### MQTT 流量分析
MQTT 是物联网的轻量级消息协议。

**分析要点**：
- Topic 名称
- Payload 数据
- 发布/订阅模式

**Wireshark 过滤**：`mqtt`

### 无线密码破解
对 WiFi 捕获包进行 WEP/WPA/WPA2 破解。

**工具**：
- `aircrack-ng`：WEP/WPA 破解
- `hashcat`：GPU 加速 PMKID/Handshake 破解
- `crunch`：生成密码字典

### 蓝牙流量分析
分析蓝牙（Bluetooth/BLE）通信流量，提取广播数据、ATT 协议数据等。

**工具**：
- `Ubertooth`：蓝牙嗅探
- `Wireshark`：蓝牙协议分析
- `blue_hydra`：蓝牙设备发现

### 加密流量分析
对加密协议（TLS、SSH、IPsec 等）的流量分析。

**方法**：
- **指纹识别**：根据 TLS 握手特征识别客户端/服务器
- **大小分析**：加密后的包大小仍可能泄露信息
- **时序分析**：通信时间模式
- **Tor 流量识别**：根据流量特征识别 Tor 通信

### 损坏流量恢复
从损坏或不完整的 PCAP 文件中恢复通信内容。

**工具**：
- `pcapfix`：修复损坏的 PCAP/PCAPNG 文件
- `Wireshark` 的"修复记录文件"功能

### 硬件通讯协议
- **UART/串口通信**：异步串行通信
- **I2C**：集成电路间总线
- **SPI**：串行外设接口
- **CAN 总线**：控制器局域网（汽车电子）
- **Modbus**：工业控制协议

## 相关工具

- **Wireshark / tshark**：通用流量分析
- **NetworkMiner**：网络取证
- **`aircrack-ng`**：无线破解
- **`pcapfix`**：PCAP 文件修复
- **`Scapy`**：Python 流量处理库
- **`Bro/Zeek`**：网络分析框架

## 防御建议

流量分析用于网络监控和入侵检测：
- 使用加密通信（TLS、SSH、HTTPS）
- 网络分段和访问控制
- 异常流量检测
- 日志记录和审计

## 示例思路

```bash
# FTP 提取文件
tshark -r capture.pcap -Y "ftp-data" -T fields -e data.data | xxd -r -p > extracted_file

# 解密 WiFi 流量
aircrack-ng -w wordlist.txt -b BSSID handshake.cap

# ICMP 隐写提取
tshark -r capture.pcap -Y "icmp" -T fields -e data.data

# 修复 PCAP
pcapfix corrupted.pcap
```
