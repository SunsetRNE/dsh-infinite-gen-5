# 文件结构分析（File Structure）

## 概述

文件结构分析是 CTF MISC 中最基础的技能。每个文件类型都有特定的二进制格式（Magic Number / File Signature），通过分析文件头、文件尾和内部结构，可以识别文件类型、检测文件损坏、修复文件头错误等操作。许多 CTF 题目通过修改文件头或破坏文件结构来隐藏信息。

## 常见文件签名

| 文件类型 | 十六进制签名 | ASCII 标识 |
|---------|-------------|-----------|
| JPEG | `FF D8 FF E0` | `ÿØÿà` |
| PNG | `89 50 4E 47 0D 0A 1A 0A` | `.PNG....` |
| GIF | `47 49 46 38 39 61` / `47 49 46 38 37 61` | `GIF89a`/`GIF87a` |
| ZIP | `50 4B 03 04` | `PK..` |
| RAR | `52 61 72 21 1A 07 00` | `Rar!...` |
| PDF | `25 50 44 46` | `%PDF` |
| ELF | `7F 45 4C 46` | `.ELF` |
| BMP | `42 4D` | `BM` |
| TIFF | `49 49 2A 00` / `4D 4D 00 2A` | `II*.` / `MM.*` |
| AVI | `52 49 46 46 ... 41 56 49` | `RIFF..AVI` |
| MP3 (ID3) | `49 44 33` | `ID3` |
| FLAC | `66 4C 61 43` | `fLaC` |
| WAV | `52 49 46 46 ... 57 41 56 45` | `RIFF..WAVE` |

## 常见攻击手法

### 文件头修复
当文件头被篡改或删除时，根据文件内容恢复正确的文件头：
- JPEG 图片缺少头部 → 补充 `FF D8 FF E0 00 10 4A 46 49 46 00 01`
- PNG 缺少签名 → 补充 `89 50 4E 47 0D 0A 1A 0A`
- ZIP 文件头被修改 → 恢复 `50 4B 03 04`

### 文件拼接
多个文件被拼接或附加到一起：
- 使用 `binwalk` 自动检测和提取嵌入式文件
- 使用 `foremost` 根据文件签名提取所有文件
- 手动在十六进制编辑器中观察文件尾和下一个文件头

### 文件格式混淆
- PNG 和 ZIP 文件的"图种"：图片文件尾部附加 ZIP 数据
- PDF 中嵌入其他文件
- 文档中包含隐藏对象

### Magic Number 修改
修改文件头部的 magic bytes，使系统无法识别文件类型：
- 将 PNG 的 `PNG` 改为 `png` 或其他
- 将 ZIP 的 `PK` 改为其他字节

## 相关工具

- **`file`**：自动文件类型检测
- **`binwalk`**：嵌入式文件检测和提取
- **`foremost`**：文件恢复和分类提取
- **`010 Editor`**：二进制模板编辑
- **`WinHex`**：十六进制编辑和分析
- **`CyberChef`**：解析和查看文件格式

## 防御建议

文件结构分析是用于渗透测试和 CTF 的技术。在日常安全中，应使用文件完整性验证（如 SHA-256 校验）防止文件被篡改。

## 示例思路

```bash
# 使用文件签名提取所有嵌入式文件
binwalk -e suspicious_file.png

# 使用 foremost 自动提取
foremost -i suspicious_file.png -o output/

# 检测文件类型
file unknown_file
```
