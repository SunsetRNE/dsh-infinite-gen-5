# 条码与二维码（Barcode & QR Code）

## 概述

条码（Barcode）和二维码（QR Code）是将信息编码为黑白相间的图形图案的技术。在 CTF 中，条码相关题目涉及标准条码的解码、条码结构的分析、自定义条码的解读等。选手需要了解常见条码的标准格式、纠错原理和数据结构。

## 常见种类

### 一维条形码（1D Barcode）
- **Code 39**：可编码数字、大写字母和少量符号
- **Code 128**：可编码全部 ASCII 字符
- **EAN-13 / UPC-A**：商品条码，13/12 位数字
- **Codabar**：常用于图书馆和血库
- **Interleaved 2 of 5**：仅数字，成对编码

### 二维码（QR Code）
QR Code（Quick Response Code）是最常见的二维码标准。

**版本**：1-40 版本，从 21×21 到 177×177 模块
**纠错级别**：L(7%)、M(15%)、Q(25%)、H(30%)
**编码模式**：数字、字母数字、字节、汉字

### 海明码（Hamming Code）
错误检测和纠正码，在编码理论中重要。并非标准条码，但可能以条码形式出现。

**原理**：在数据位中插入校验位，可以检测和纠正一定数量的错误。

### 汉信码（Chinese Han Xin Code）
中国自主知识产权的二维码标准，由中国物品编码中心开发。与 QR Code 结构不同。

### DataMatrix
另一种常见的二维码，由黑白模块组成的矩阵，常用于小型物品标识。

### PDF417
堆叠式二维码（层叠条码），用于旅行文件和身份识别。

## 常见攻击手法

### 条形码解码
- 使用 `zbar` 或 `zxing` 库自动解码
- 使用在线扫描工具
- 对于损坏条码，手动分析条码宽度模式

### 二维码结构分析
QR 码包含：
1. **位置探测图形**：三个角的大方块
2. **定时图案**：交替的黑白模块
3. **格式信息**：纠错级别和掩码信息
4. **数据区域**：编码的数据
5. **纠错码字**：Reed-Solomon 纠错码

### 二维码损坏恢复
QR Code 内置纠错编码，部分损坏仍可解码：
- 根据版本和纠错级别，可承受一定比例的损坏
- 使用图像处理修复污损区域
- 调整对比度、反转颜色

### 自定义条码解码
对于非标准条码：
- 分析黑白条的比例和排列规律
- 查找可能的编码规则
- 转换为二进制后再解码

## 相关工具

- **`zbar`**：命令行条码解码
- **`zxing`**：Java/Python 条码库
- **`pyzbar`**：Python zbar 绑定
- **`qrazybox`**：QR Code 结构分析在线工具
- **`boofcv`**：QR/DataMatrix 检测
- **在线工具**：zxing.org、online-barcode-reader.inliteresearch.com

## 防御建议

条码本身是数据编码方式，不提供安全性。在安全敏感场景中：
- 对条码内容进行验证码/签名验证
- 条码扫描器防范注入攻击
- 不依赖条码的物理安全性

## 示例思路

```python
from pyzbar.pyzbar import decode
from PIL import Image

# 解码条码/二维码
img = Image.open('barcode.png')
results = decode(img)
for result in results:
    print(f"Type: {result.type}")
    print(f"Data: {result.data.decode('utf-8')}")
```
