# 音频隐写（Audio Steganography）

## 概述

音频隐写利用人耳听觉系统的局限性，在音频信号中隐藏秘密信息。CTF 中常见的音频隐写包括波形分析、频谱分析、LSB 隐写、回声隐写等。WAV（无损）和 MP3（有损压缩）是最常见的音频格式。

## 常见技术

### 波形图分析（Waveform Analysis）
直接观察音频的波形图可以发现隐藏的信息。当秘密信息被编码为特定波形模式时（如振幅高低变化表示二进制），可以直观看到。

**工具**：Audacity 查看波形图，注意振幅的规律性变化。

### 频谱图分析（Spectrogram Analysis）
在频域中查看音频信号。信息可能被嵌入在特定频率段，或通过频率调制隐藏。

**提取方法**：
- Audacity 中切换到频谱图视图
- 调整频谱参数（FFT 大小、窗口类型等）优化显示
- 使用 `sox` 命令行工具

### MP3Stego
专门针对 MP3 文件的隐写工具。在 MP3 编码过程中将信息嵌入到比特流中。

**用法**：
```bash
# 提取隐藏信息
MP3Stego -extract -P password stego.mp3
```

### DTMF（Dual-Tone Multi-Frequency）
双音多频信号，即电话拨号音。每个按键由两个频率的正弦波叠加组成。

**识别**：在音频中识别 DTMF 音调，用工具或手动解码。

**工具**：`dtmf-decoder`、Audacity 频谱分析。

### Deepsound
专门的音频隐写软件，使用 AES-256 加密后再隐藏到音频文件中。

**提取**：需要密码，使用 Deepsound 软件提取隐蔽文件。

**检测**：音频文件大小异常大，或通过统计检测。

### SSTV（Slow Scan Television）
慢扫描电视，将图像通过音频信号传输。常见于无线电爱好者活动和 CTF 题目。

**解码**：
- `RX-SSTV`（Windows）
- `qsstv`（Linux）
- 使用 Audacity 播放，SSTV 解码器实时解码

### 调幅调频混音（AM/FM Modulation）
将二进制数据通过振幅调制（ASK）或频率调制（FSK）编码到音频中。

**解码**：分析信号跳变，提取原始数据。

### 曼彻斯特解码（Manchester Decoding）
将比特流编码为跳变信号。每个比特周期内有一个或两个跳变表示 0 或 1。

### MP3 位隐写（MP3 Bit Stego）
利用 MP3 编码中的帧头保留位或填充位隐藏信息。

### WAV 高低频提取
在 WAV 文件中，信息可能隐藏在超声波（>20kHz）或次声波（<20Hz）频段，人耳听不到但存在于数字信号中。

### 音频倒放（Audio Reversal）
将音频反向播放可能揭示隐藏的信息（如反向语音）。

**Audacity**：效果→反向。

### 其他音频隐写技术
- **回声隐写**：在音频中加入特定延迟的回声编码信息
- **相位编码**：在相位分量中嵌入数据
- **扩频隐写**：将信号扩展到宽频段以降低检测可能性

## 相关工具

- **Audacity**：音频分析和编辑（波形、频谱）
- **Sonic Visualiser**：专业音频分析
- **`sox`**：命令行音频处理
- **`MP3Stego`**：MP3 隐写
- **`Deepsound`**：DeepSound 隐写工具
- **`qsstv` / RX-SSTV**：SSTV 解码器
- **`dtmf-decoder`**：DTMF 解码

## 防御建议

音频隐写可用于隐蔽通信。防御者应关注音频文件的大小异常和统计特征异常，使用音频隐写检测工具。

## 示例思路

```bash
# 使用 Audacity 分析频谱图
# 1. 打开音频文件
# 2. 切换到频谱图显示
# 3. 调整频率范围到可显示范围
  
# 使用 sox 查看音频统计信息
sox audio.wav -n stat

# 提取音频中的 DTMF 音调
dtmf-decoder audio.wav

# SSTV 解码（使用 qsstv 或将音频导入后播放）
# 播放音频的同时打开 SSTV 解码器进行实时解码
```
