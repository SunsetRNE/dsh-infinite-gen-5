# MISC 杂项

## 概述

MISC（杂项）是 CTF 竞赛中涵盖范围最广的类别，涉及文件分析、隐写术、流量分析、取证分析、编码解码、压缩包分析等多个领域。MISC 题目考察选手的全面能力和动手实践能力，通常需要多种工具的组合使用和对文件格式的深入理解。

## 常用工具概览

- **`010 Editor / WinHex`**：十六进制编辑器
- **`binwalk`**：固件分析和文件提取
- **`foremost`**：文件恢复和提取
- **`strings`**：提取文件中的可打印字符串
- **`stegsolve`**：图片隐写分析工具
- **`zsteg`**：PNG/BMP LSB 隐写检测
- **`Wireshark`**：网络流量分析
- **`Audacity`**：音频分析
- **`Volatility`**：内存取证
- **`Autopsy / Sleuth Kit`**：磁盘取证
- **`fcrackzip`**：压缩包密码破解
- **`CyberChef`**：综合编码解码工具

## 通用方法论

1. **文件头识别**：检查文件头（magic bytes）确认文件类型
2. **`file` 命令**：使用 `file` 命令自动检测文件类型
3. **`strings` 分析**：提取字符串，搜索 Flag 格式或关键信息
4. **`binwalk` 扫描**：检测文件中的嵌入式文件
5. **`foremost` 提取**：从镜像中提取文件
6. **信息关联**：将发现的不同信息关联起来思考
7. **隐写分析**：对图片、音频等文件进行隐写检查
