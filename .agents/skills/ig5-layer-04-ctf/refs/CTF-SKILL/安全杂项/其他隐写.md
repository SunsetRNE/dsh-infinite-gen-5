# 其他隐写技术（Other Steganography）

## 概述

除图片、音频、视频、文档等常见载体外，CTF 中还出现了大量其他类型的隐写技术。这些隐写方法利用特定的数据格式、传输协议或系统特性来隐藏信息。掌握这些技术可以帮助选手应对各种非常规的隐写题目。

## 常见技术

### 零宽隐写（Zero-Width Character Stego）
利用 Unicode 中的零宽字符（Zero-Width Space）在文本中嵌入信息。

**常用零宽字符**：
| 字符 | Unicode | 用途 |
|------|---------|------|
| 零宽空格（ZWSP） | U+200B | 表示 1 |
| 零宽非连接符（ZWNJ） | U+200C | 表示 0 |
| 零宽连接符（ZWJ） | U+200D | 分隔符 |
| 左至右标记（LRM） | U+200E | 额外编码 |
| 右至左标记（RLM） | U+200F | 额外编码 |

**检测**：使用十六进制编辑器查看或 Python 检测 `unicodedata`。

### NTFS 流隐写（NTFS ADS）
NTFS 文件系统支持备用数据流（Alternate Data Stream, ADS），可在文件之外附加数据。

**创建**：`echo hidden > file.txt:hidden.txt`
**查看**：`dir /R`、`streams.exe`（Sysinternals）

### PYC 隐写
Python 编译文件的 `.pyc` 文件中可以隐藏信息。通过修改字节码的 co_code 部分或利用 marshaled 对象的填充位。

**工具**：`pyc隐写分析`、`uncompyle6` 反编译。

### Emoji 隐写
利用 Emoji 表情符号编码信息。每个 Emoji 对应不同的 Unicode 码位，可映射为二进制数据。

**方式**：
- 每个 Emoji 代表一个特定值
- Emoji 序列代表比特流
- Emoji 的变体选择器（Variation Selector）隐藏数据

### SNOW 隐写
SNOW（Steganographic Nature Of Whitespace）在纯文本文件的空格和制表符中隐藏信息。

**工具**：`stegsnow` 命令行工具。

```bash
stegsnow -C -p password stego.txt
```

### TTL 隐写
在网络数据包的 IP 头 TTL（Time To Live）字段中嵌入信息。修改每个包 TTL 值的低比特位来传输数据。

### 流隐写（Network Flow Stego）
利用网络通信流的时序特征（包间隔时间、包大小、包顺序）来编码信息。

### 可执行文件隐写（PE/ELF Stego）
在 PE（Windows）或 ELF（Linux）可执行文件中隐藏数据。

**隐藏位置**：
- 文件尾附加数据
- 节之间的空白（Section Gap）
- 资源段（.rsrc）
- 校验和未使用的字段
- 导入表/导出表中的保留字段

### 马赛克还原（Mosaic Restoration）
将打乱或马赛克化的图片重新恢复。可能涉及拼图、图片碎片重组、马赛克模糊去除等。

**工具**：`montage`、`ImageMagick`、AI 辅助还原。

### 拼图（Jigsaw Puzzle）
将图片切割成碎片并打乱顺序，需要恢复原始顺序。有时碎片是图片数据块而非完整图片文件。

### 键盘隐写（Keyboard Stego）
通过键盘按键的位置、手指的运动模式或按键时间间隔编码信息。

### 游戏相关（Game Stego）
在游戏存档、游戏截图、游戏资源文件中隐藏信息。例如 Minecraft 地图、游戏纹理（Texture）等。

## 相关工具

- **`stegsnow`**：空格隐写
- **`steghide`**：多种载体隐写
- **`streams.exe`**：NTFS ADS 检测
- **`uncompyle6`**：PYC 反编译
- **`GIMP`**：图片操作
- **`ImageMagick`**：图片处理
- **Python `unicodedata`**：Unicode 字符分析

## 防御建议

隐写检测是一个复杂的领域：
- 文件大小异常监控
- 网络流量的时序分析
- 文本中包含的不可见字符检测
- 系统日志中的 ADS 创建记录

## 示例思路

```python
# 零宽字符提取
import unicodedata

text = "正常文本\u200B\u200C\u200B\u200C"
binary = ""
for char in text:
    if char == '\u200B':  # ZWSP → 1
        binary += '1'
    elif char == '\u200C':  # ZWNJ → 0（或其他约定）
        binary += '0'

# 解析二进制
result = ""
for i in range(0, len(binary), 8):
    if i + 8 <= len(binary):
        char_code = int(binary[i:i+8], 2)
        result += chr(char_code)
print(result)
```
